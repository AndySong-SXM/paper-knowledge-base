## 🎯 研究动机与创新点

1. **通用压控忆阻器 + HNN 的新动力学机制**：提出通用电压控制忆阻器模型 i = W(φ)v = (a + cos(πF(φ)))v，其中 F(·) 为奇/偶分段符号和函数（F_odd / F_even），可将忆阻 Hopfield 神经网络（MTN-HNN）的平衡点组织成曲线（H1/H2），a = 0 时系统共有 29 个平衡点。论文强调存在 USFP 与 USFP-1，但不存在 Shil'nikov 型 USFP-2，即经典同宿轨判据不适用，从而论证多涡卷自激吸引子可以在不依赖 Shil'nikov 定理的情况下产生——这是对经典多涡卷构造方法论的补充。
2. **突发放电（bursting firing）行为的系统刻画**：在忆阻 HNN 中观察到周期、混沌、随机、暂态四类 bursting，并给出对称周期 bursting 的特征值分析（e±1 与原点平衡点特征值）。
3. **多双涡卷（multidouble-scroll）数量规律**：F_odd 给出 2M+1 个涡卷（演示 1/3/5），F_even 给出 2N+2 个涡卷（演示 2/4/6），并用"密-疏-密"分岔带解释涡卷数量切换。

## 🔧 核心方法

**忆阻器模型（通用压控型）**：

- 忆导：W(φ) = a + cos(πF(φ))
- 端口方程：i = W(φ)v = (a + cos(πF(φ)))v
- 内部状态：dφ/dt = wv − pF(φ)
- F 为奇/偶分段符号和函数，决定平衡点曲线形状与涡卷拓扑；单个参数 a 即可调控全局动力学拓扑。

**MTN-HNN 模型 5 / 模型 6**：

- 模型 5：4 维，无电磁辐射项；
- 模型 6：5 维，引入电磁辐射耦合项 I = K·W₂(φ₂)x₂，W₂ = −0.015 + cos(πF)，W = 0.01 + cos(πF)；
- 典型参数：p₁ = p₂ = 0.1，w₁ = 1.4，w₂ = 0.566，k₁ = 0.5，K = 2.2。

**平衡点结构**：H1/H2 两条平衡点曲线；a = 0 时共 29 个平衡点（i = 1…29）；存在 USFP 与 USFP-1，但不存在 USFP-2（Shil'nikov 型同宿条件不成立），论文以此论证自激吸引子不依赖 Shil'nikov 定理——这是与经典多涡卷构造的关键区别。

## 📊 动态分析

- **a 参数分岔**（区间 [−0.4, 0.4]）：倍周期道路在 a ≈ −0.35 / −0.30 / −0.24 / −0.23 处逐级出现；单侧混沌涡卷（a = −0.22 时 φ > 0；a = −0.12 时 φ < 0）；a = 0 双涡卷；a = 0.15 呈 bursting 混沌；a = 0.25 为周期；周期窗口位于 a ≈ −0.17 / −0.015 / 0.06。

## 🎲 PRNG 与 NIST / 加密性能

**密钥流生成（式 16）**：RK-4 步长 0.1 迭代模型 6，丢弃前 300 个暂态值，记录三个神经元输出 (x₁(i), x₂(i), x₃(i)) 存入矩阵 Y(1:3,:)：

- C(3k+i) = Y(i, k+2) − (1/3)Σⱼ Y(j, k+1)
- S(n) = mod(⌊C(n) × 10¹¹⌋, 256)

**加密算法**（密钥 = (a, a₂, K, x₁(0), x₂(0), x₃(0), φ(0), φ₂(0))）：

1. 置乱：图像拉平为向量 A，由 S 的前 MN 个元素生成无重复序列 X，按 A(X(i)) ↔ A(X(MN−i+1))，i = 1…⌊MN/2⌋ 逐对交换；
2. 模加扩散（式 17）：前向 Bᵢ = mod(Pᵢ + S₁(i) + Aᵢ₋₁, 256)，后向 Cᵢ = mod(Pᵢ + S₂(i) + Bᵢ₊₁, 256)；
3. "有限域"乘法扩散（式 18）：Cᵢ = mod(P1ᵢ × S₁(i) × Cᵢ₋₁, 256)，Cᵢ = mod(P1ᵢ × S₃(i) × Cᵢ₊₁, 256)。

## ⚠️ 不足与可借鉴之处

1. **"有限域乘法"名不副实**：mod 256 环不是有限域（256 非素数，偶元素无逆元）。当 S₁/S₃ 取偶数值时式 (18) 的乘法步骤不可逆，解密正确性存疑。借鉴其"模乘扩散"思想时应改用 GF(2⁸) 真有限域（AES 的不可约多项式）或模素数 257。
2. **三路密钥流同源于一条混沌轨道**：S₁/S₂/S₃ 均由式 (16) 从同一轨道切片生成，彼此存在相关性；论文未给出三路序列的互相关系数或独立 NIST 检验。
3. **置乱结构偏弱**：⌊MN/2⌋ 次首尾对称交换只是全部位置换的一个小子集，等效密钥空间远小于 MN!，抗暴力搜索能力不足；且置乱与扩散分离的经典结构对选择明文攻击的防护依赖扩散强度。
4. **量化精度敏感**：mod(⌊C×10¹¹⌋, 256) 严重依赖浮点精度，PC 双精度与 FPGA 单精度产生不同密钥流，论文未做跨平台一致性测试（对硬件加密方案这是关键工程问题）。
5. **密钥敏感性/密钥空间量化缺失**：未见密钥空间位数、密钥敏感性 NPCR 等常规数据，安全性论证不完整。
6. **bursting 术语宽泛**：周期、混沌、随机、暂态均称 bursting，缺乏统一的快慢时间尺度分离判据（如 Rinzel 分岔分析）。
7. **FPGA 浮点路线资源开销大**：IEEE-754 单精度 IP 占用资源多，未与定点化/查表方案对比；RK-4 步长 0.1 的单精度长期累积误差未量化。
8. **作者自承局限**：未做初值偏移调控（initial offset-boosting）、未针对高分辨率图像做分块加密优化。

**可借鉴点**：

- 通用压控忆阻器 (a + cos(πF(φ))) "单参数 a 控全局拓扑"的设计思想；
- 平衡点曲线 H1/H2 + 29 平衡点的自激多涡卷构造（绕开 Shil'nikov 定理）；
- "密-疏-密"分岔带解释涡卷数量切换；
- 动力学-加密-硬件一体化叙事框架，适合写入综述与基金本子。
