## 一、建模动机与系统方程（Sec. 2）

**核心立意**：已有 HNN 混沌研究全部使用单一激活函数（"single activation function across all neurons"），而生物神经系统本质上是异质的（heterogeneous）——本文让三个神经元分别使用三种不同的有界激活函数，构造"最简三神经元异质 HNN"。

**离散模型**：由三神经元 HNN 经 Euler 差分离散化（式 1，一般全连接形式），置自连接权重 $g_{11}=g_{22}=g_{33}=0$，得仅含 6 个耦合权重的 3D-DHNN：

$$\begin{cases} x_{n+1} = \mu x_n + g_{12} f_2(y_n) + g_{13} f_3(z_n) \\ y_{n+1} = \mu y_n + g_{21} f_1(x_n) + g_{23} f_3(z_n) \\ z_{n+1} = \mu z_n + g_{31} f_1(x_n) + g_{32} f_2(y_n) \end{cases}$$

- $f_1(x)=\sin x$（神经元 1，刻画周期性极化），$f_2(y)=\tanh y$（神经元 2），$f_3(z)=\dfrac{2}{1+e^{-z}}-1$（神经元 3，sigmoid 型）。
- 注意 $f_3(z)=\tanh(z/2)$，与 $f_2$ 同属 sigmoid 族——异质性实际体现在 sin vs sigmoid 族两类，第三神经元严格说是 $f_2$ 的缩尺度版（这一观察对"异质"叙事强度有影响，见"不足"第 8 条）。
- $\mu\in(-1,1)$ 为神经元衰减系数，是全文主要分岔参数；所有激活函数过原点（$f_i(0)=0$）。

**固定点与稳定性**：固定点满足 $(1-\mu)X^*=g_{12}\tanh Y^*+g_{13}\sigma(Z^*)$ 等三式（式 3 整理形式），由 Jacobian 特征值分类为稳定点 SP、不稳定点 UP、Neimark-Sacker 点 NSP、fold 分岔点 FBP，绘制在 $\mu-X$ 平面上（Fig. 2）。

## 二、共存分岔行为（Sec. 2.2，全文理论亮点）

取 $\mu\in[0.15,0.6]$ 示意，三组初值 $(1,1,1)$、$(1.6,-3.2,5.3)$、$(-1.6,3.2,-5.3)$（注意后两组关于原点中心对称）：

- $\mu\in[0.2,0.395]$：无共存，全体混沌迭代；
- $\mu\in[0.3975,0.4901]$：**共存分岔窗口**——上下轨迹外缘成对出现的 FBP 引入垂直对称的 fold 分岔，产生两条共存稳定轨道；原点附近吸引区内原先不稳定的混沌轨道持续存在，直至 $\mu=0.4896$ 突然稳定化；
- $\mu=0.4928$：两条稳定轨道经垂直对称 Neimark-Sacker 分岔变为不稳定准周期轨道（一个零 LE）；
- $\mu=0.5831$：准周期轨道演化为单正 LE 的混沌轨道，共存消失，分岔图形成完整混沌带。

**机理解释**（本文最有价值的理论陈述）：分岔图中共存行为发生的参数值与固定点的 FBP/NSP 位置**精确对应**——是固定点的空间排布及其稳定性转变"托起了"3D-DHNN 的共存分岔行为。$\mu=0.45$ 处呈现"一个多折混沌吸引子 + 两个稳定固定点"三吸引子共存，吸引盆取 $z_0=5.3/1.0/-5.3$ 三个切片绘制，盆结构关于原点对称（Fig. 4）。LE 谱（Jacobian 法，QR 正交化）在共存窗口内出现两个正 LE（超混沌）与 LE1=0（准周期）的交替。

## 三、多折叠超混沌吸引子（Sec. 3）

**彩色混合分岔切片**：固定 $g_{21}=2.0, g_{23}=2.0, g_{31}=2.0, g_{32}=-1.5$，对 $\mu\in\{0,0.1,\dots,0.6\}$ 在 $(g_{12},g_{13})\in[-8,8]^2$ 平面绘制按"两个最大 LE 符号 + 轨道周期性"着色的切片：HC=两正 LE（橙）、CH=一正一负（红）、QP=一零一负（黄）、SP/P1（灰/绿）、P2–P8（其他色）。$\mu$ 增大混沌与超混沌区从细条纹扩张为条带交织的主体。

**代表点**：$g_{12}=4.0, g_{13}=-6.0$（其余同上），以 $\mu$ 为分岔参数——分岔图与 LE 谱一一对应。取 8 个 $\mu$ 值得 x-y 相图（Fig. 7）：吸引子呈多折叠（multifolded）流形，上下边缘伸出数目不等的"舌片（tongues）"。**规律**：固定点的空间分布限定吸引子动力学范围，固定点**数目**决定舌片数目；$\mu$ 增大→固定点增多且沿水平轴散布→吸引子跨度水平扩展、舌片增殖；左右两翼的不稳定固定点无法组织连贯舌片，不参与成舌。

**Kaplan–Yorke 维数**（Sec. 3.2，Table 1）：8 个 $\mu$ 值（0.20–0.55）全部 $\lambda_1>0,\lambda_2>0,\lambda_3<0$，且 $\lambda_1+\lambda_2+\lambda_3$ 轻微为正（0.0759–0.2430）→ $j=3$，**$D_{KY}=3$ 饱和**（等于映射嵌入维）。作者解读：吸引子"厚实"地占满三维相空间区域——弱体积膨胀 + 满维吸引子，是加密密钥流"高熵"主张的几何基础。注意这与常见耗散混沌映射（$D_{KY}<3$）形成对比，是有别于知识库多数离散忆阻映射的一个特征。

## 五、FPGA 实现（Sec. 3.4）

- 平台：Zynq-7020（XC7Z020CLG400-2），PS（ARM Cortex-A9）+ PL 异构，AXI 互联。
- PL 侧 Verilog：sin 用 **Xilinx CORDIC IP**，tanh 用**查找表 LUT**，sigmoid 用指数函数数值近似电路；内部 **32 bit 有符号定点（24 bit 小数）**，对外量化到 **10 bit** 输出；PS 侧配置权重/初值，AXI-STREAM 数据交换。
- 验证：示波器 XY 模式采集（SDS804X，1 V/div，100 μs/div，1 GSa/s）与数值吸引子强一致（Fig. 8）；进一步把 FPGA 内部 32 bit 定点状态经 UART 逐样本回传主机，与双精度数值相图叠绘对比（Fig. 9，定点红 vs 浮点蓝），定量评估有限字长影响——**定点/浮点相图叠加对照是比一般"示波器看一眼"更扎实的手法，值得借鉴**。

## 六、口令驱动的图像加密系统（Sec. 4，CIES）

**密钥派生（KDF 驱动，全文工程亮点）**：

```
key  = KDF(password, salt, 2000 轮)          // PBKDF 式
h_img = ImageHash(明文) = [h1,h2,h3]          // 位置加权和，模大素数 p1=1e9+7, p2=1e9+9, p3=1e9+21
h_key = KeyHash(key)                          // 迭代模累加 + XOR
seed  = MultiRoundHash([key, h_img, h_key], 5 轮)  // → 32 bit 整数
Parameters = RNG(seed)
```

口令 8–128 字符；混沌参数取值范围：$\mu\in[0.2,0.8], g_{12}\in[2,6], g_{13}\in[-8,-4], g_{21},g_{23},g_{31}\in[1,4], g_{32}\in[-2.5,-1.5]$；CML 参数 $\varepsilon\in[0.2,0.4]$、logistic $\mu_{cml}\approx3.99$–$4.00$、**格子长度 = 像素数 N**。

**置乱（两阶段）**：①CML 迭代末态序列 $\{s_i\}_{i=1}^N$ 升序排序得置换索引 $\pi_{cml}$（式 10）；②将序列零填充到 $M=2^O$（$O=\lceil\log_2\lceil\sqrt N\rceil\rceil$）的方阵，按 **Hilbert 空间填充曲线**遍历得 $\pi_H$（式 11），取前 N 个元素还原 H×W。

**扩散（双向明文反馈，严格可逆）**——前向：

$$\text{Key}_{fwd}(i)=\lfloor(x_i+y_i+z_i)\times10^6\rfloor\bmod 256,\quad C_{fwd}(i)=(P(i)+\text{Key}_{fwd}(i)+C_{fwd}(i-1))\bmod 256$$

且每像素后将密文+明文反馈进混沌状态 $x_i\leftarrow(x_i+(C_{fwd}(i)+P(i))/512)\bmod 1$（式 12），$C_{fwd}(0)=IV_{fwd}=\lfloor x_0\times10^6\rfloor\bmod256$。反向：扰动初值 $(x_0+0.001,\dots)$ 的第二轨道从 $i=N$ 到 1：

$$C(i)=(C_{fwd}(i)+\text{Key}_{bwd}(i)+C(i+1))\bmod 256,\quad \tilde y_i\leftarrow(\tilde y_i+C(i)/256)\bmod 1$$

$C(N+1)=IV_{bwd}=\lfloor y_0\times10^6\rfloor\bmod256$（式 13）。解密按反向递推精确逆序还原，**逐位无损**。混沌状态反馈（前向注 x、反向注 ỹ）使密钥流与明文/密文纠缠，是"明文反馈扩散"的具体化。

**硬件实现**：三层分工——PC（MATLAB 界面与分析）、PS（口令校验 + 2000 轮 KDF + AXI4-Lite + UART 115200）、PL（3D-DHNN 定点 + CML + 扩散 + FIFO 流水，AXI-Stream）。资源占用（Table 4）：LUT 15,234（28.6%）、FF 10,156（9.5%）、DSP48E1 48（21.8%）、BRAM36 36 块（25.7%）。

## 八、不足

1. **Table 1/Table 2 LE 数值差 10 倍未解释**（0.47981 vs 4.7880，同参数同初值）——要么是归一化不同，要么是笔误；全文未提，影响 LE 可复现性。
2. **有效密钥空间被 32 bit seed 锁死（最严重问题）**：口令 8–128 字符 + 2000 轮 KDF + 明文哈希的派生链看着扎实，但最终收敛到 `seed = MultiRoundHash(...) → 32 bit 整数`，所有混沌参数、CML 参数、初值偏移全部由该 seed 经 RNG 产生——**有效密钥熵 ≤ 32 bit，暴力穷举 2³² 次即可复现全部密钥流**，"口令驱动"只是入口体验而非安全增益。这正是 paper_112 综述批评的"注水式密钥空间"与本库 paper_100（LTS-S 盒）同类问题，且比那篇更隐蔽（派生链包装很厚）。
3. **无 NIST SP 800-22 全套**：混沌序列与密文随机性仅跑 runs/frequency/serial 三项，连 SP 800-22 的 15 项门槛都未做，而知识库 014/016/070 等 2022–2024 年工作早已以 NIST 15 项全过为标配。
4. **无鲁棒性测试**：无噪声/裁剪/丢包下的解密实验（paper_023/028 等标配 50% 裁剪可恢复）。
5. **仅 2 张 512 级灰度标准图**，无彩色、无全黑/全白/全灰极端明文（paper_112 综述列的九项指标里"特殊明文"直接缺席）。
6. **固定点字长口径不一致**：3.4 节系统实现明确"32 bit 有符号定点（24 bit 小数）"，4.2 节加密系统描述却写"fixed-point arithmetic (16-b…)"（正文截断处），到底是 16 位还是 32 位影响混沌退化与加密一致性论证。
7. **吞吐口径未交代**：76.8 Mbps 与 0.0068 s 反推对应约 256×256 灰度图（65,536 px × 8 bit / 0.0068 s ≈ 77 Mbps），但未写明图像尺寸与测试条件；Table 7 的 Matlab 对比对象平台/图尺寸也不明，公平性弱于 paper_111 的 CPU 降频对齐做法。
8. **"异质"叙事打了折扣**：$f_3=\tanh(z/2)$ 与 $f_2=\tanh$ 同族，真正的异质性只在 sin vs sigmoid 族之间；且未与"同激活函数但参数不同"的基线系统做对照实验来证明异质性本身是复杂度来源（只与外部经典映射对比）。
9. 共存分岔窗口 $\mu\in[0.3975,0.4901]$ 的解析边界由数值扫描给出，fold/NS 分岔的正规形计算未做（只到特征值分类层面）；吸引盆只画三个 z 切片，未做盆熵等全局量化（对照 paper_112 综述提到的 basin entropy 工具）。
10. CML 格子长度 = 像素数 N：512² 图像即 26 万格子的硬件 CML，资源开销与长程耦合退化（有限精度下 logistic μ≈4 的动态退化，paper_112 挑战 4）均未讨论。

## 九、可借鉴之处

1. **KDF + 明文哈希 + 多轮混合哈希的密钥派生框架**结构完整（口令/salt/明文三源合一），结构本身可移植——只需把 32 bit seed 换成 256 bit 并接标准 KDF（如 PBKDF2-HMAC-SHA256 + HKDF），"口令驱动混沌加密"即可兼得体验与安全，可直接改造成自己方案的密钥管理章节（与 paper_111 的 ECDHE 协商形成"口令场景 vs 协商场景"双方案）。
2. **双向明文反馈扩散 + 混沌状态回注**（前向注 x、反向注 ỹ，明文密文双重反馈）写法干净、严格可逆、O(N) 原地可行，适合嵌入式课"扩散结构设计"教学案例。
3. **CML 排序置乱 + Hilbert 空间填充曲线二级置乱**：Hilbert 曲线保持空间局部性的遍历是免费的空间混沌补充，非 2 幂尺寸图像的补零嵌入策略可直接复用。
4. **定点/浮点相图叠加对照实验**（FPGA 状态经 UART 回传 vs 双精度模拟）比示波器截图验证高一个档次，写硬件实现章节的现成模板。
5. **"固定点空间排布 → 共存分岔 → 多折叠吸引子 → 舌片数目"的机理叙事链**：把分岔行为归因到固定点几何，是"动力学分析"章节组织方式的好示范；$D_{KY}=3$ 饱和（弱体积膨胀满维吸引子）的提法也可作为"高熵密钥流"几何论据的新颖素材。
6. **作者自承"一阶差分指标 ≠ 抗选择明文攻击"**：写论文 limitation 时的诚实范式，评审面前加分。
