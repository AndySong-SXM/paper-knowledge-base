## 二、研究背景与问题

### 2.1 研究背景

混沌系统的研究起源于1963年Lorenz对大气湍流现象的分析。混沌系统可分为两大类：**连续混沌系统**和**离散混沌系统**。传统混沌系统依赖非线性函数（三角函数、绝对值函数、指数函数等）产生混沌振荡。

**忆阻器（Memristor）** 作为Chua教授1971年提出的第四种基本无源非线性电路元件，描述了电荷与磁通之间的关系。2008年HP实验室首次用TiO₂和铂实现了纳米级忆阻器，引发了研究热潮。2009年，Chua进一步提出了**忆感器（Meminductor）**和**忆容器（Memcapacitor）**两种记忆元件。

### 2.2 研究现状

近年来，离散忆阻器方向取得了重要进展：
- **Bao (2020)**：设计了基于忆阻器、电容和采样开关串联的离散混沌系统
- **Bao (2021)**：通过前向Euler差分算法获得离散忆阻器，与逻辑映射耦合得到2-D忆阻逻辑映射
- **Deng (2021)**：提出n维广义离散忆阻器模型
- **Peng (2021)**：用后向差分算法获得离散忆阻器模型，与Henon映射耦合
- **Ma (2022)**：设计局部有源离散忆阻器模型，构建超混沌映射（但吸引子类型单一）
- **Zhong (2022)**：推导通用电压控制离散忆阻器模型
- **Yuan (2023)**：提出离散忆阻器的级联、并联和复合方法

### 2.3 核心问题

1. **离散忆感器（Discrete Meminductor）的研究尚属空白**——此前无人研究离散忆容器和离散忆感器
2. **现有离散忆阻器混沌映射的吸引子类型单一**——需要探索更多样化的动力学行为
3. **缺乏同时融合离散忆阻器和离散忆感器的高维混沌系统**
4. **需要从数值仿真走向硬件实现验证**

## 三、核心方法与创新点

### 3.1 理论创新一：离散忆感器模型的首次提出

**连续忆感器模型**：
$$i(t) = L_M^{-1}(\rho)\varphi(t), \quad L_M^{-1}(\rho) = e + g\cos(\rho)$$

其中 $\rho(t) = \int_{-\infty}^{t} \varphi(t)dt$ 为磁通的时间积分。

**离散忆感器模型**（本文首次提出）：
$$\Delta\varphi(t_n) = k_1 v(t_n), \quad \Delta\rho(t_n) = k\varphi(t_n)$$

展开形式：
$$i(t_n) = L_M^{-1}(\rho(t_n))\varphi(t_n)$$
$$\varphi(t_{n+1}) = \varphi(t_n) + k v(t_n)$$
$$\rho(t_{n+1}) = \rho(t_n) + k\varphi(t_n)$$

通过正弦交流信号 $v_n = H\sin(\omega n)$ 验证，特征曲线的旁瓣面积随 $\omega$ 增大而减小，符合忆感器基本特性。

### 3.2 理论创新二：5-D超混沌映射的构建

基于经典Henon映射，同时引入离散忆阻器和离散忆感器，构建5维超混沌映射：

$$x_{n+1} = 1 - ax_n^2 + (e + gc\cos(w_n))y_n$$
$$y_{n+1} = b x_n$$
$$z_{n+1} = z_n + k x_n$$
$$w_{n+1} = w_n + k z_n$$
$$u_{n+1} = u_n + k y_n$$

**关键特征**：
- $z_n$ 为离散忆阻器的内部状态变量（电荷积累）
- $w_n$ 为离散忆感器的磁通变量
- $u_n$ 为离散忆感器的磁通积分变量
- 参数 $k \neq 0$ 保证系统不存在固定点 → **隐藏吸引子**

### 3.3 实验贡献：DSP硬件实现

- 使用 **TMS320F28335** 芯片实现5-D超混沌映射
- 通过D/A转换器（8552）将数字序列转为模拟信号
- 示波器（EDS102C）捕获相图
- 采用栈技术存储迭代数据，避免数据丢失

### 3.4 创新点总结

| 创新点 | 具体内容 | 意义 |
|--------|---------|------|
| 首次提出离散忆感器模型 | 基于差分方法从连续忆感器离散化 | 填补了离散记忆元件研究的空白 |
| 5-D双记忆元件超混沌映射 | 同时融合离散忆阻器和离散忆感器 | 首个同时包含两种离散记忆元件的混沌系统 |
| 多类型吸引子共存 | 参数变化产生6种不同形态的混沌吸引子 | 突破了现有离散忆阻器映射吸引子单一的局限 |
| 吸引子共存现象 | 同一参数下不同初始条件产生不同吸引子 | 多稳态特性增强工程应用潜力 |
| 图像加密应用 | 基于DNA编码的完整加密方案 | 验证了系统的密码学应用价值 |
| DSP硬件验证 | TMS320F28335平台实现 | 从数值仿真到物理实现的闭环验证 |

## 四、实验设计与结果

### 4.1 混沌吸引子分析

固定参数 $g = 0.01$，初始值 $(x_0, y_0, z_0, w_0, u_0) = (-10, 5, 10, 1, -5)$，通过改变参数 $c, d, a, e, b, k$ 获得**6种不同类型的混沌吸引子**：

| 编号 | 关键参数 | 吸引子特征 |
|------|---------|-----------|
| (a) | c=0.1, b=2, a=0.0001, d=0.5, e=0.001, k=0.3 | 多翼型超混沌吸引子 |
| (b) | d=0.5, b=2.5, k=0.2, a=0.0002, e=0.01, c=0.1 | 扩展型超混沌吸引子 |
| (c) | c=0.2, e=0.01, a=-0.0001, d=0.1, b=0.1, k=0.2 | 环形混沌吸引子 |
| (d) | k=0.4, d=0.5, c=0.1, b=2, e=0.01, a=0.0002 | 密集型超混沌吸引子 |
| (e) | b=2, e=0.01, c=0.1, d=0.1, a=0.0002, k=0.2 | 分散型混沌吸引子 |
| (f) | c=0.2, e=0.01, d=0.1, a=0.0001, b=0.1, k=0.6 | 复杂分形吸引子 |

### 4.2 固定点分析

由于 $k \neq 0$，系统**不存在固定点**，因此产生的混沌吸引子属于**隐藏吸引子（Hidden Attractor）**。隐藏吸引子的 basin 不包含任何不稳定固定点的邻域，这使得系统的动力学行为更加复杂和不可预测。

### 4.3 Lyapunov指数与分岔分析

**Lyapunov指数计算方法**：通过Jacobian矩阵的连续乘积 $J = J_{N-1} \cdot J_{N-2} \cdots J_0$ 的特征值获得。

$$LE_i = \sigma_i = \lim_{n \to \infty} \frac{1}{n} \ln|\lambda_i|$$

**参数 $b$ 变化**（$b \in [-2, 2]$）：
- 系统呈现超混沌状态
- Lyapunov指数谱与分岔图高度吻合
- 吸引子形态随 $b$ 变化呈现丰富多样性

**参数 $c$ 变化**（$c \in [-0.1, 0]$）：
- 系统在周期态、混沌态和超混沌态之间频繁切换
- 体现了系统复杂的动力学特性

**参数 $k$ 变化**（$k \in [0.01, 2]$）：
- 系统在混沌态、超混沌态和周期态之间转换
- Lyapunov指数与分岔图相互验证

### 4.4 多稳态分析

通过改变不同维度的初始条件，验证了系统的**吸引子共存现象**：

| 变化的初始条件 | 固定参数 | 共存现象 |
|---------------|---------|---------|
| $z_0$ | a=0.0001, b=2, c=0.1, d=0.1, e=0.01, g=0.01, k=0.3 | 不同 $z_0$ 产生不同吸引子 |
| $z_0$（d=0.5） | 同上但 d=0.5 | 参数微调改变共存模式 |
| $y_0$ | a=-0.0001, b=0.1, c=0.2, d=0.1, e=0.01, g=0.1, k=0.2 | $y_0$ 变化产生不同动力学行为 |
| $z_0$ | a=-0.0002, b=0.1, c=0.2, d=0.1, e=0.01, g=0.01, k=0.2 | 验证多稳态的普遍性 |
| $w_0$ | a=0.05, b=3, c=0.1, d=0.5, e=0.01, g=0.01, k=0.0001 | $w_0$ 变化产生共存吸引子 |
| $u_0$ | 同上 | $u_0$ 变化产生共存吸引子 |

### 4.5 图像加密实验

**加密流程**（11步）：
1. 输入明文图像 $I$（$M \times N$）
2. 计算明文相关参数 $qq$
3. 生成5维混沌序列并量化为伪随机序列
4. 零频中心移位 + 分块（4块）
5. 生成位置索引序列
6. Arnold置乱 + 块内零频中心移位
7. 合并块
8. DNA编码
9. DNA加法运算
10. DNA解码 + 列交换 + 重编码
11. 最终DNA解码得到密文

**安全性分析结果**：

| 安全指标 | 结果 | 评价 |
|---------|------|------|
| NIST测试（混沌序列） | 全部通过 | 伪随机性优良 |
| NIST测试（加密图像） | 全部通过 | 加密安全性高 |
| 直方图均匀性 | 密文直方图高度均匀 | 抗统计攻击 |
| 相关系数（明文） | 趋近1 | — |
| 相关系数（密文） | 趋近0 | 相邻像素相关性被有效破坏 |
| 信息熵（明文） | 7.0097, 6.6782, 7.3406 | — |
| 信息熵（密文） | 7.9972, 7.9967, 7.9973 | 极接近理论最大值8 |
| 时间复杂度 | $O(M \times N \times 8)$ | — |
| 空间复杂度 | $O(M \times N \times 8)$ | — |

### 4.6 DSP实现结果

- 参数设置：$d=0.1, e=0.01$，初始值 $(10, 5, 10, -5)$
- 使用栈技术存储迭代数据
- 示波器捕获的相图与数值仿真结果一致
- 验证了5-D超混沌映射的物理可实现性

## 五、主要结论

1. **首次提出离散忆感器模型**：通过差分方法从连续忆感器推导而来，特征曲线验证了其正确性
2. **构建了5-D超混沌映射**：同时融合离散忆阻器和离散忆感器，具有隐藏吸引子特性
3. **丰富的动力学行为**：系统可产生6种不同类型的混沌吸引子，且存在吸引子共存现象（多稳态）
4. **有效的图像加密方案**：基于DNA编码的加密算法通过了NIST测试、直方图分析、相关分析和信息熵分析
5. **DSP硬件验证**：在TMS320F28335平台上的实现结果与数值仿真一致，证明了方案的可行性
6. **应用前景广阔**：该5-D超混沌映射在混沌工程应用中具有巨大价值

## 六、批判性评价

### 6.1 优势

1. **原创性强**：首次提出离散忆感器模型，填补了该领域的研究空白
2. **系统完整**：从理论建模 → 动力学分析 → 应用设计 → 硬件实现，形成了完整的研究闭环
3. **动力学分析全面**：涵盖相图、LE谱、分岔图、谱熵复杂度、多稳态等多个维度
4. **发表期刊顶级**：IEEE TIE 是工业电子领域顶级期刊（中科院一区），论文质量经过严格同行评审
5. **硬件验证有力**：DSP实现为理论结果提供了物理层面的佐证

### 6.2 不足与局限

1. **离散忆感器模型验证不够充分**：仅通过正弦输入的特征曲线验证，缺乏更深入的理论分析（如稳定性证明、与连续模型的收敛性分析）
2. **加密方案安全性分析不够深入**：
   - 缺少差分攻击分析
   - 未进行已知/选择明文攻击测试
   - 未与最新的图像加密方案进行充分对比
   - 缺少密钥空间分析和密钥敏感性分析
3. **DSP实现精度问题**：论文提到"由于DSP硬件实现的精度有限"，但未详细讨论量化误差对动力学特性的影响
4. **多稳态分析偏定性**：仅通过相图展示共存现象，缺少定量的分岔边界分析和共存吸引子的basin结构
5. **参数空间探索有限**：仅对 $b, c, k$ 三个参数进行了分岔分析，未系统探索完整的6维参数空间

### 6.3 可改进方向

1. 补充离散忆感器的严格数学理论（稳定性、收敛性证明）
2. 增加加密方案的全面安全性评估（差分攻击、密钥空间、鲁棒性测试）
3. 探索FPGA实现以获得更高精度和速度
4. 研究离散忆容器（Discrete Memcapacitor）模型，完善离散记忆元件家族
5. 进行更系统的参数空间分析，绘制完整的混沌参数区域图

## 八、关键公式速查

### 8.1 离散忆阻器模型

$$v(t_n) = M(q(t_n)) \cdot i(t_n), \quad M(q(t_n)) = c + d\sin(q(t_n))$$
$$q(t_{n+1}) = q(t_n) + k \cdot i(t_n)$$

### 8.2 离散忆感器模型（本文首次提出）

$$i(t_n) = L_M^{-1}(\rho(t_n)) \cdot \varphi(t_n), \quad L_M^{-1}(\rho) = e + g\cos(\rho)$$
$$\varphi(t_{n+1}) = \varphi(t_n) + k \cdot v(t_n)$$
$$\rho(t_{n+1}) = \rho(t_n) + k \cdot \varphi(t_n)$$

### 8.3 5-D超混沌映射

$$x_{n+1} = 1 - ax_n^2 + (e + gc\cos(w_n))y_n$$
$$y_{n+1} = bx_n$$
$$z_{n+1} = z_n + kx_n$$
$$w_{n+1} = w_n + kz_n$$
$$u_{n+1} = u_n + ky_n$$

### 8.4 Lyapunov指数计算

$$LE_i = \lim_{n \to \infty} \frac{1}{n} \ln|\lambda_i|, \quad J = J_{N-1} \cdot J_{N-2} \cdots J_0$$

### 8.5 信息熵

$$H(m) = -\sum_{i=1}^{L} P(m_i)\log_2 P(m_i)$$

### 8.6 相关系数

$$\rho_{xy} = \frac{\sum_{i=1}^{N}(x_i - E(x))(y_i - E(y))}{\sqrt{\sum_{i=1}^{N}(x_i - E(x))^2 \cdot \sum_{i=1}^{N}(y_i - E(y))^2}}$$

### 8.7 位置索引序列

$$x_2 = \text{mod}(x_{11} + y_{11} + z_{11}, m) + 1$$
$$y_2 = \text{mod}(z_{11} + w_{11} + u_{11}, m) + 1$$
