## 二、研究背景与问题

### 2.1 研究背景

**忆阻器（Memristor）** 自2008年惠普实验室成功制备以来，因其独特的记忆结构和非线性特性，在非线性电路、神经网络、神经形态计算等领域受到广泛关注。忆阻器常被用作构建忆阻混沌系统或电路的非线性项，以产生丰富的动力学行为。

**离散忆阻器（Discrete Memristor, DM）** 于2020年被提出，具有离散状态、可编程性、低功耗和抗干扰等固有优势，在超混沌映射设计、嵌入式系统开发和神经网络等领域展现出潜在应用价值。

### 2.2 现有研究的局限性

1. **连续忆阻系统复杂度高**：连续忆阻系统模型复杂、硬件电路庞大、计算效率低，不适合工程应用
2. **离散忆阻映射动力学行为有限**：现有DM映射虽能产生超混沌和共存行为，但缺乏灵活的初始增强（initial-boosted）极端多稳态
3. **极端多稳态控制不灵活**：现有方法难以通过切换忆阻器初始条件灵活控制多稳态或极端多稳态

### 2.3 研究问题

**核心问题**：如何构建一种新型且最简单的离散忆阻映射，能够产生显著的初始增强极端多稳态（initial-boosted extreme multistability）？

**具体子问题**：
- 如何通过并行两个离散忆阻器产生复杂的超混沌行为？
- 如何实现忆阻器初始条件控制的线性和平面极端多稳态？
- 如何通过微控制器数字电路平台验证动力学行为？

## 三、核心方法与创新点

### 3.1 核心方法

#### 3.1.1 离散忆阻器模型

**正弦型离散忆阻器（SDM）**：
$$
\begin{cases}
v_n = \sin(\pi q_n) \cdot i_n \\
q_{n+1} = q_n + i_n
\end{cases}
$$

**余弦型离散忆阻器（CDM）**：
$$
\begin{cases}
v_n = \cos(\pi q_n) \cdot i_n \\
q_{n+1} = q_n + i_n
\end{cases}
$$

#### 3.1.2 双忆阻器超混沌映射构建

**同质SSDM映射**（两个正弦DM并联）：
$$
\begin{cases}
x_{n+1} = k_1 \sin(\pi y_n) x_n + k_2 \sin(\pi z_n) x_n \\
y_{n+1} = y_n + x_n \\
z_{n+1} = z_n + x_n
\end{cases}
$$

**异质SCDM映射**（正弦+余弦DM并联）：
$$
\begin{cases}
x_{n+1} = k_1 \sin(\pi y_n) x_n + k_2 \cos(\pi z_n) x_n \\
y_{n+1} = y_n + x_n \\
z_{n+1} = z_n + x_n
\end{cases}
$$

其中：
- $k_1, k_2$：耦合强度参数
- $x_n$：非忆阻器状态变量
- $y_n, z_n$：两个DM的内部状态变量

#### 3.1.3 稳定性分析

**平面固定点**：$S = (0, \mu, \eta)$，其中$\mu$和$\eta$对应DM的初始条件$y_0$和$z_0$

**特征值**：
$$\lambda_1 = 1, \quad \lambda_2 = 1, \quad \lambda_3 = k_1 M_1(\mu) + k_2 M_2(\eta)$$

**临界稳定边界条件**：
$$k_1 M_1(\mu) + k_2 M_2(\eta) \pm 1 = 0$$

### 3.2 主要创新点

| 创新点 | 描述 |
|--------|------|
| **首次实现离散映射中的初始增强极端多稳态** | 首次在离散映射中发现忆阻器初始条件控制的线性和平面极端多稳态 |
| **最简单的代数结构** | 仅用2个非线性项实现超混沌和极端多稳态，模型复杂度最低 |
| **同质与异质双映射对比** | 提出SSDM（同质）和SCDM（异质）两种映射，对比分析其动力学差异 |
| **周期循环增强机制** | 揭示忆阻器初始条件的周期循环特性（周期为2），实现固定偏移的非破坏性增强 |
| **微控制器硬件验证** | 开发STM32F407数字电路平台，验证数值仿真结果 |

## 四、实验设计与结果

### 4.1 耦合强度相关动力学

**实验设置**：
- 参数范围：$k_1 \in [-2, 2], k_2 \in [-2, 2]$
- 初始条件：$(x_0, y_0, z_0) = (0.1, 0.1, 0.1)$

**主要发现**：

| 映射类型 | 超混沌参数 | 最大LE |
|----------|------------|--------|
| SSDM | $(k_1, k_2) = (0.84, 1)$ | $(0.2553, 0.0962, 0)$ |
| SCDM | $(k_1, k_2) = (1.08, -1.5)$ | $(0.2680, 0.0864, 0)$ |

**动力学行为演化**：稳定点 → 周期-2 → 周期-4 → 周期-8 → 混沌 → 超混沌

### 4.2 初始条件相关极端多稳态

**单区域极端多稳态**：
- 在$(\mu, \eta)$平面上，系统呈现无穷多个异质吸引子共存
- 吸引子类型：稳定点、周期-2、周期-4、周期-6、周期-8、混沌、超混沌

**初始增强机制**：
- 由于三角函数忆阻值的周期为2，初始条件具有周期循环特性
- 当$\mu = \mu_0 + 2m$和$\eta = \eta_0 + 2n$（$m, n$为任意整数）时，吸引子沿y和z坐标方向以固定宽度2偏移

## 五、主要结论

### 5.1 理论贡献

1. **首次在离散映射中实现初始增强极端多稳态**：通过并行两个具有周期三角函数忆阻值的DM，构建了能产生线性和平面极端多稳态的最简单离散映射

2. **揭示周期循环增强机制**：由于正弦/余弦函数的周期性，忆阻器初始条件具有周期为2的循环特性，使得共存吸引子可以沿y和z坐标方向以固定宽度非破坏性增强

3. **建立稳定性分析框架**：通过Jacobian矩阵和特征值分析，确定了平面固定点的临界稳定边界条件

1. **密码学应用**：高随机性的超混沌序列可用于图像加密和安全通信，无限扩展的密钥流空间提高了安全性

2. **硬件实现优势**：微控制器数字电路平台具有高精度、小体积、低功耗优势，便于工程应用

3. **潜在扩展应用**：可扩展至储备池计算、辅助分类器生成对抗网络、群智能算法等领域

## 八、关键公式速查

### 8.1 离散忆阻器模型

**正弦型（SDM）**：
```
v_n = sin(π·q_n) · i_n
q_{n+1} = q_n + i_n
```

**余弦型（CDM）**：
```
v_n = cos(π·q_n) · i_n
q_{n+1} = q_n + i_n
```

### 8.2 双忆阻器超混沌映射

**SSDM映射**（同质）：
```
x_{n+1} = k_1·sin(π·y_n)·x_n + k_2·sin(π·z_n)·x_n
y_{n+1} = y_n + x_n
z_{n+1} = z_n + x_n
```

**SCDM映射**（异质）：
```
x_{n+1} = k_1·sin(π·y_n)·x_n + k_2·cos(π·z_n)·x_n
y_{n+1} = y_n + x_n
z_{n+1} = z_n + x_n
```

### 8.3 稳定性条件

**临界稳定边界**：
```
k_1·M_1(μ) + k_2·M_2(η) ± 1 = 0
```

**不稳定条件**：
```
|k_1·M_1(μ) + k_2·M_2(η)| > 1
```

### 8.4 初始增强条件

**周期循环特性**：
```
μ = μ_0 + 2m  (m = 0, ±1, ±2, ...)
η = η_0 + 2n  (n = 0, ±1, ±2, ...)
```

**偏移宽度**：2（沿y和z坐标方向）
