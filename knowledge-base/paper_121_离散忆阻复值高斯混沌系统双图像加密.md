## 一、核心思想

把**离散忆阻器**首次嵌入**复值（complex-valued）混沌映射**：提出忆阻复值高斯模型（memristive complex-valued Gaussian model, MCVGM），将复混沌的代数复杂性（复变量、复参数）与忆阻器的物理记忆性（内部状态变量）结合。主要贡献链条：

1. **模型**：正弦离散忆阻器 + 复值高斯型映射，构成三维实值系统等价的复值系统；
2. **理论**：证明系统具有对偶对称性 (a, z) → (−a, iz)，解释了最大 Lyapunov 指数关于参数 a 奇对称的实验现象；给出三种对称性破缺变换（变量旋转、参数复化、复共轭）；
3. **硬件**：CORDIC 双模式（旋转+双曲）在 FPGA 上复用一套硬件同时计算 sin/cos 与 exp，并用 **K-S 检验**严格判定硬件与数值分布一致性（本组笔记中首次）；
4. **应用**：把"双图像 = 复值矩阵实部/虚部"的思想落成完整双图像联合加密方案（K1 置乱—K2 复扩散—K3 量化异或）。

## 二、系统模型

### 2.1 离散忆阻器

采用正弦型离散忆阻器（与 paper_027 Lai 实域忆阻高斯映射同款）：

- i_n = sin(π·w_n)·v_n
- w_{n+1} = v_n

即忆阻内部状态 w 记录上一时刻的端电压 v，忆阻电导按 sin(πw) 调制——具有"记忆 + 非线性调制"双重属性。

### 2.2 MCVGM 复值形式

- z[n+1] = b·exp(−a·z²[n]) + k·sin(π·y[n])·|z[n]|
- y[n+1] = |z[n]|
- k = (1 − b_r) + i·(1 − b_i)，即忆阻增益 k 被绑定在复参数 b = b_r + i·b_i 上（a, b 均为复参数，文中动力学分析围绕 a 的实部角色与 b 的实/虚部展开）。

结构解读：b·exp(−a·z²) 是复值高斯型非线性项（复混沌发动机），k·sin(πy)·|z| 是忆阻器注入项——用忆阻内部变量 y 调制复状态 z 的幅度 |z|。

### 2.3 实值等价形式（式 4）

令 z = z_r + i·z_i，记：

- E = exp(−a·(z_r² − z_i²))
- φ = 2a·z_r·z_i
- v = |z| = sqrt(z_r² + z_i²)

则：

- z_r[n+1] = b_r·E·cos φ − b_i·E·sin φ + (1 − b_r)·sin(πy)·v
- z_i[n+1] = b_r·E·sin φ + b_i·E·cos φ + (1 − b_i)·sin(πy)·v
- y[n+1] = v

即一个三维实值离散系统（两个状态变量 z_r, z_i + 忆阻内部变量 y），但本质上由复代数结构驱动——这是复值混沌"低维实实现、高维复行为"的典型案例。

## 三、动力学分析

### 3.1 参数扫描（QR 法 LE，5×10⁴ 次迭代）

- **参数 a**：a ∈ [−1.95, 1.95] 区间内系统处于混沌；LLE 曲线关于 a = 0 **奇对称**——这不是巧合，由对偶对称性定理保证（见 3.2）。
- **参数 b_r**：固定 a = 0.2, b_i = 0.1，b_r ∈ [0, 0.62] 时混沌；
- **参数 b_i**：b_i ∈ [−0.512, 0.4] 时混沌（注意负虚部参数同样可用，复参数符号自由带来额外密钥维度）。

### 3.2 对偶对称性（定理 + 证明）

**变换 T：(a, z) → (−a, i·z)** 把 MCVGM 映回自身：把 a 取反、状态乘虚数单位 i，迭代方程形式不变。证明思路：z² → (iz)² = −z²，exp(−a z²) → exp(−(−a)·(−z²)) = exp(−a z²) 复原；|iz| = |z| 使忆阻项不变。该对称性解释了 LLE 关于 a = 0 的奇对称结构——**对称性定理直接约束谱结构**，是本文理论上最漂亮的一点。

### 3.3 对称性破缺变换

为产生非对称、多样的吸引子结构（多密钥/多吸引子应用的原料），文中给出三种显式破缺手段：

1. **状态变量旋转**：对 z 施加固定角度旋转；
2. **参数复化**：a → i·a（把实参数角色换成纯虚参数）；
3. **复共轭**：z → z̄（交换虚部符号）。

### 3.4 动力学分析空白

文中**未做**：不动点/平衡集求解与稳定性分析（复值高斯项使不动点方程无闭式解，作者选择绕过）、有界性证明、共存吸引子（多稳态）搜索、复杂度-熵谱（如 SE/CPE）、NIST 随机性检验。混沌判定完全依赖 Lyapunov 指数。

## 四、FPGA 实现

- **平台**：Verilog，Xilinx Zynq-7000 xc7z020clg400-1；DAC 为 AD9767 输出相图；
- **定点格式**：32 位定长小数，1 符号 + 6 整数 + 25 小数——与 paper_115、paper_117 完全同模板（本组硬件实现高度标准化）；
- **CORDIC 双模式复用**：
  - 旋转模式（rotation mode）计算 sin/cos；
  - 双曲模式（hyperbolic mode）计算 exp；
  - 通过 K1/K2 缩放因子补偿 CORDIC 增益；
  - 一套迭代硬件同时支撑三角函数与指数函数，省去两套查找表；
- **一致性验证（亮点）**：不止对比相图，还做 **Kolmogorov–Smirnov 检验**——三个变量的 p 值分别为 0.145、0.356、0.131，均远大于 0.05，认为硬件轨迹与数值轨迹同分布；
- **误差**：90% 以上采样点误差 < 8×10⁻⁴，最大误差 ≤ 1.24×10⁻³。
- **缺失**：无 LUT/FF/DSP/BRAM 资源占用表、无时序收敛报告、无功耗数据——硬件成本无法评估。

## 五、双图像复值加密系统

### 5.1 编码思想

把两幅 M×N 灰度图像 P1、P2 编码为一个复矩阵：

- I = P1 + i·P2（实部 = 图 1，虚部 = 图 2）

一次复值混沌迭代同时搅动两幅图像，天然实现**跨图像交叉混淆**——这是"复值加密"相对"两次单图加密"的本质优势。

### 5.2 密钥与流程

- **密钥**：(a, b_r, b_i, z_r0, z_i0, y0)，共 6 个分量；迭代前丢弃 N0 = 1000 次暂态；
- **K1（置乱）**：从忆阻变量 y 序列取 M+N 个采样，排序得到行置换与列置换，对复矩阵 I 做行列重排；
- **K2（复扩散）**：以复乘形式扩散——(d_r + i·d_i) + 0.5·z 乘到每个复像素上，d = 5 + 0.5i 为扩散常数；实、虚两通道在一步复乘中互相耦合扩散；
- **K3（量化异或）**：密钥流 z_s = mod(floor((z + 1)×10¹²), 256)，按字节与密文复矩阵分量做 CXOR，输出两幅实图像形式的密文。

### 5.3 实验设置

4 组标准测试图像对：Cameraman/House、Pepper/Starfish、Butterfly/Aircraft、Parrot/Lena；256×256；MATLAB R2024a。

## 七、不足

1. **忆阻增益绑定缺乏动机**：k = (1−b_r) + i(1−b_i) 是硬凑的代数设定，忆阻器"独立记忆"的角色被削弱——系统仍可退化为普通复值映射，忆阻引入的增量动力学贡献未被单独论证。
2. **无不动点/平衡集/有界性分析**：混沌判定只靠 LE；复值高斯项的无界风险（z² 在虚轴方向发散）未被讨论。
3. **加密指标不完整**：无 NPCR/UACI、NIST、χ²，安全性结论不充分（见第六节）。
4. **密钥空间凑整**：(10¹⁶)⁶ 按灵敏度人为取整；实际有效精度受 double 精度与 32 位定点实现的限制，达不到宣称的 2³¹⁸。
5. **K3 量化可逆性存疑**：mod(floor((z+1)×10¹²), 256) 依赖 10¹² 级量化，定点硬件下该步是否严格可逆、误差是否累积，文中未交代。
6. **K1 置换结构暴露面大**：排序置乱仅取 M+N 个 y 样本，对已知明文结构攻击的抵抗力未讨论。
7. **无效率数据**：无加密时间、无吞吐率、无与轻量级方案（如 paper_120 的 2285.67 KB/s 并行方案）的公平对比。
8. **FPGA 无资源/时序/功耗表**：硬件成本不可评估，工程闭环不完整。
9. **动力学展示有限**：无共存吸引子、无初值敏感性分岔图，吸引子多样性主要靠对称性破缺变换的文字描述。
10. **对比面窄**：仅 3 篇对比，且未与本组复值 HNN 网络工作（paper_095 方向）做"映射 vs 网络"对照。

## 八、可借鉴之处

1. **双图像 = 复值矩阵实/虚部**：把 N 幅图编码为复（或超复）动力系统状态的思路，天然实现跨图交叉混淆；>2 幅图可推广到四元数/矩阵值系统，也适用于视频帧组加密。
2. **对偶对称性证明套路**："定理 + 变量替换"证明 (a,z)→(−a,iz) 对称性的方法可直接迁移到其他含 exp(−a z²) 结构的复值映射，用于解释和预测谱对称性。
3. **K-S 检验做硬件-数值一致性判定**：比相图肉眼对比严格，值得在 paper_113/115/117/119 同款 FPGA 工作中推广为标准流程。
4. **CORDIC 双模式工程配方**：旋转模式算 sin/cos + 双曲模式算 exp + K1/K2 缩放补偿，一套硬件复用，是复值混沌 FPGA 化的实用模板。
5. **对称性破缺三种操作**（旋转/参数复化/共轭）：为"多吸引子—多密钥"提供廉价的显式构造手段。
6. **复乘一步双通道扩散**：(d+0.5z) 复乘使实、虚通道互相耦合，比分别扩散再交叉耦合更紧凑，扩散深度/轮数可进一步压缩。

- **paper_027**（Lai 等，实域忆阻高斯映射）：本文的直接前身——把实域"高斯映射 + 正弦离散忆阻器"结构整体复值化，sin(πw) 忆阻器原样保留，可对照复值化前后谱结构变化。
