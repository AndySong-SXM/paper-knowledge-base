## 一、核心思想（Sec. 1）

- **选题轴：器件极性修正 + 联邦学习新应用**。既有**光子量子忆阻器（PQM）**基于 Mach–Zehnder 干涉仪（MZI）单端口光子计数读出，光子数非负 ⇒ 输出**单极性（unipolar）**，不适合需要双极信号的动力学/密码应用。本文提出**差分光子量子忆阻器（D-PQM）**：同时测量 MZI 两个互补输出端口并做平衡差分检测，**无需任何后处理校正即获得以零点为中心的双极性对称捏滞回线（pinched hysteresis）**，且抑制激光强度漂移等共模扰动。
- **器件 → 突触的最小耦合**：把 D-PQM 作为**单条自适应突触支路**嵌入标准三神经元连续 HNN（其余通路保持常数权重），得到紧凑 **4D D-PQM–HNN**。刻意"最小干预"设计以隔离忆阻光子元件的独立贡献。
- **应用闭环 = IoMT 联邦学习双向保密通信**：用混沌信号为联邦学习（FL）的全局模型下发（downlink）与客户端更新上传（uplink）生成会话相关密钥流，在 Wisconsin 乳腺癌数据集（699 样本 × 9 特征）上验证：加密前后精度同为 94.29%，int32 定点映射使通信量比 double 传输**减少约 50%**；STM32F303ZE 微控制器实时硬件验证。
- **卖点清单**：①D-PQM 本征双极对称捏滞（一、三象限）；②紧凑 4D 模型 + 系统动力学分析（平衡流形/耗散/LE/KY）；③复混沌区间 + 边界超混沌倾向；④IoMT FL 双向轻量保密外壳；⑤STM32 硬件验证。
- **自我定位诚实**：明确说自己是"轻量保密外壳（lightweight confidentiality wrapper）"，与 secure aggregation、差分隐私、同态加密等**互补而非替代**；不声称完整认证加密框架。

## 二、D-PQM 器件模型（式 1–12）

### 2.1 忆阻系统一般形式

$$y(t)=f(x,s,t)\,x(t),\qquad \dot s(t)=r(x,s,t)$$

电压控制情形下 x/y 为电压/电流，f(·) 为忆导，s 为内态。

### 2.2 标准 PQM 的单极性局限（式 2–4）

可调 MZI 单端口测量：⟨n_out⟩ = [1 − R(θ)]⟨n_in⟩，R(θ) 受内相态 θ(t) 控制；光子数期望非负 ⇒ 信号单极性。理想 MZI 两端口：

$$P_1(t)=\langle n_{in}(t)\rangle R(\theta(t)),\qquad P_2(t)=\langle n_{in}(t)\rangle[1-R(\theta(t))],\quad R(\theta)=\tfrac{1+\cos\theta}{2}$$

### 2.3 差分读出与两种差分形式（式 5）

原始差分 y_Δ = P₁ − P₂ = ⟨n_in⟩cosθ（保留幅度信息、含 DC 偏移）；归一化差分 y_N = (P₁−P₂)/(P₁+P₂) = cosθ（双极有界 [−1,1]、抑制共模强度漂移，但与输入幅度无关）。

### 2.4 居中对齐的双极 D-PQM（式 6–9）★核心器件方程

居中输入（把光子数期望线性映射到 [−1,1]）：x_pqm = 2(⟨n_in⟩ − 1/2)；居中对齐输出：

$$y_{pqm}(t) = 2y_\Delta - y_N = x_{pqm}(t)\cos\theta(t) \;\Rightarrow\; y_{pqm}=W(\theta)\,x_{pqm},\quad W(\theta)=\cos\theta$$

内态（相位）演化律：$\dot\theta(t)=\frac{\alpha}{2}x_{pqm}(t)$，α>0 为增益；因子 1/2 补偿居中定义的缩放，保证有效反馈强度与标准 PQM 一致。得**一、三象限对称双极捏滞回线**。

### 2.5 有界变体（式 10，软正则化）

$$\theta_s(t)=\theta_{max}\tanh\!\big(\tfrac{\theta(t)}{\theta_{max}}\big),\qquad y^{bnd}_{pqm}=x_{pqm}\cos\theta_s$$

θ_max 控制饱和水平，防长时仿真/强反馈下相位无限漂移；主文动力学分析用基线式 (8)，式 (10) 仅作数值安全替代。

### 2.6 捏滞数值验证（式 11–12，Sec. 3）

激励 ⟨n_in⟩ = sin²(ωt)，ω ∈ {0.3,0.5,0.7,0.9,1.5,3.0}，每周期 6000 采样，梯形积分；θ̇ = ⟨n_in⟩ − 1/2 居中驱动。标准 PQM 回线锁于第一象限；D-PQM 回线跨一、三象限对称；频率升高回线面积收缩（记忆效应减弱）。有界变体仅低压频段轻微内缩。

**建模口径声明（值得记录）**：全部讨论在**期望值层面**进行，不计及弱测量反作用与量子噪声/散粒噪声——是"物理启发的降阶模型"，非完整量子态演化模型。

## 三、D-PQM–HNN 状态方程（式 13–20）

### 3.1 基线三神经元 HNN（式 13–15）

ϕ(·)=tanh(·)；$\dot x=-x+\sum_j w_{1j}\phi(\cdot)$ 等；为突出 D-PQM 支路，刻意令 w₁₂ 待定、w₃₂=0。

### 3.2 D-PQM 突触替换（式 16–19）

D-PQM 输入取突触前神经元激活 x_in=ϕ(y)=tanh(y)，输出 y_pqm=ϕ(y)cosθ；以忆阻耦合替换常数权重：

$$w_{12}\phi(y)\;\Rightarrow\;-k\cos(\theta)\,\phi(y)$$

k 为耦合增益；负号使 θ≈0 时为抑制性耦合（w_eff≈−k）；符号约定不具限制性（可吸收入 θ 的 π 相移）。

### 3.3 4D D-PQM–HNN（式 20）★系统方程

$$\begin{cases} \dot x = -x + w_{11}\phi(x) - k\cos(\theta)\phi(y) + w_{13}\phi(z) \\ \dot y = -y + w_{21}\phi(x) + w_{22}\phi(y) + w_{23}\phi(z) \\ \dot z = -z + w_{31}\phi(x) + w_{33}\phi(z) \\ \dot\theta = \frac{\alpha}{2}\phi(y) \end{cases}$$

结构解读：三神经元 x/y/z 全部 tanh 激活；常数权重 w_ij 中仅 **y→x 一条支路被 D-PQM 调制**（有效耦合 −kcosθ），内态 θ 由 ϕ(y) 驱动、cosθ 反馈调制 y→x 突触。基准权重 **w₁₁=2.5, w₁₃=0.6, w₂₁=2, w₂₂=1.6, w₂₃=1.15, w₃₁=−5, w₃₃=−1.2**；控制参数 k（耦合强度）、α（相位更新率）。RK4、h=0.01、初值 [0.1,0.1,0.1,0.1]、暂态 500 s（5×10⁴ 步）。Fig. 4 相图：神经元平面密集奇怪吸引子；x–θ 平面呈**非规则几何的滞回带**（而非简单极限环），说明 θ 既跟随又反向塑造网络动力学。

## 四、非线性动力学（Sec. 5）

### 4.1 平衡流形与稳定性（式 21–31）★

由 θ̇ = α/2·ϕ(y) = 0 ⇒ **ϕ(y*)=0 ⇒ y*=0**；D-PQM 耦合项含 ϕ(y) 在平衡处消失 ⇒ **θ* 自由**——平衡构成**一参数流形**：

$$E=\{(x^*,0,z^*,\theta_0):(x^*,z^*)\text{ 满足式 (23)},\ \theta_0\in\mathbb R\}$$

即**线平衡（line of equilibria）**——忆阻系统典型特征。平凡平衡线 {(0,0,0,θ₀)} 恒存在（tanh 奇对称），非零平衡由 Newton–Raphson 数值求解。Jacobi 在平衡处呈块下三角：

$$J(X^*)=\begin{bmatrix}A(\theta^*)&0\\ b^T&0\end{bmatrix},\ b^T=[0,\ \tfrac{\alpha}{2},\ 0]$$

必含一个零特征值（θ 中性方向），横向 3×3 矩阵 A(θ*)（式 28）决定 (x,y,z) 稳定性。平凡流形 E₀ 的特征多项式：

$$p(\lambda)=\lambda^3+0.1\lambda^2+(2k\cos\theta_0-0.72)\lambda+(0.18-1.35k\cos\theta_0)=0$$

θ₀=0 时 λ₁≈0.6642，λ₂,₃≈−0.3821±j1.8004——横向鞍-焦型不稳定 + θ 方向中性稳定。

### 4.2 耗散性与有界性（式 32–33）

散度 ∇·F = (−1+w₁₁ϕ'(x)) + (−1+w₂₂ϕ'(y)) + (−1+w₃₃ϕ'(z))（θ̇ 不显含 θ ⇒ ∂θ̇/∂θ=0）。由 ϕ'∈(0,1] 得保守上界 ∇·F ≤ −3+(w₁₁+w₂₂+w₃₃) = **−0.1 < 0** ⇒ 平均体积收缩；与实测 ΣLᵢ≈−0.1411 一致。tanh 饱和限幅 + |θ̇|≤α/2=0.025 ⇒ 轨迹有界。

### 4.3 Lyapunov 谱与 Kaplan–Yorke 维（Benettin–QR）

基准点（k=1.5 名义运行点）：**L = (0.1148, 0.0047, −0.0010, −0.2596)，D_KY = 3.4562**。T_LE=5000、dt_LE=0.005。L₁ 明确为正；**L₂ 微正但极接近零、数值敏感**——作者保守表述为"复杂混沌 + 边界超混沌倾向（borderline hyperchaotic tendency）"，全文不下"稳健超混沌"结论。

### 4.4 谱鲁棒性 Table 1（11 组数值实验，★本文学风最大亮点）

## 五、应用：IoMT 联邦学习双向权重加密（Sec. 6）

### 5.1 架构与威胁模型

四层 IoMT-FL：L4 医疗数据源（可穿戴/监护）→ L3 K 个边缘客户端（医院，私数据集 D_i）→ **L2 本文安全层** → L1 云 FL 服务器（FedAvg）。**双向保护**：下行 Enc(W_g^(r)) 全局模型、上行 Enc(ΔW_i^(r)) 本地更新。**威胁模型仅被动窃听**（可观信道不可触端点，不能注入/篡改/重放）；不含完整性/认证、恶意客户端、投毒、secure aggregation——作者明确列为未来工作。

### 5.2 FedAvg 与 delta 模式（式 35–36）

W^(r) = (1/K)Σ W_i^(r)；模型向量化 p^(r)=Flatten(W^(r))；上行用增量 Δp_i^(r) = p_i^(r) − p̂^(r−1)_i（delta 模式，参考一致性条件：服务器须用与客户端相同的 p^(r−1)）；或全权重模式。

### 5.3 Nonce 调度与域分离（式 37）

$$n = n_0 + a\,r + b\,i + c\,d,\quad d\in\{1(\text{下行}),2(\text{上行})\}$$

a=1,000,003、b=10,007、c=97（round r / 客户端 i / 方向 d 域分离常量）⇒ 显式分离下界 **43 bit**（不含主初态熵；作者强调这只是"上下文相关流分离下界"，**不是密码学密钥长度**）。

### 5.4 密钥流生成与轻量加密核（式 38–47）★协议核心

1. **预热**：RK4 积分后定时常数丢弃 N₀=⌊T_discard/h⌋ 步（稳定开销、可复现）；
2. **采样**：L 个连续状态 {X_k}（每个荷载元素一个）；
3. **置乱**：对状态分量 y_k 排序 π = argsort({y_k})（荷载长度置换）；
4. **掩码序列**：s_k = |γ·x_k·θ_k| mod 1（γ=1000），K_k = ⌊2³²·s_k⌋（32 bit 密钥流）；
5. **定点化**：q_k = sat_int32(round(Q_s·p_k))；
6. **加密三件套**：置换 u_k←uint32(q_{π(k)}) → XOR u_k←u_k⊕K_k → **扩散链** c_k = (u_k + ROTL(c_{k−1},ρ)) mod 2³²，c₀=0；
7. 解密逆序：去扩散 → 去 XOR → π⁻¹ → 反量化。

## 九、不足

1. **超混沌证据弱且作者自知**：L₂≈0.0047 仅为 L₁ 的 4%，Table 1 显示其符号随步长/时长/初值翻转（Case 11 换初值后 L₁ 掉到 0.0253、D_KY 2.4559）——全文最高卖点"borderline hyperchaotic"其实是"数值上站不住的微正 L₂"，安全应用用单正 LE 的混沌已够，超混沌宣称无必要。
2. **轻量密码核安全性无形式化**：置换+XOR+ROT 链结构（式 43–45）与经典 SPN 同源，但**无已知明文/选择明文/差分分析**，无密钥空间严格计算（43 bit 仅为 nonce 分离下界；主初态有效精度在 double 与 STM32 定点间未对齐）；ρ、γ、Q_s 等常数无敏感性讨论。
3. **威胁模型过窄**：被动窃听 only；无完整性/认证/重放防护（chaining 扩散 c_{k−1} 在丢包下无法自同步），作者自列未来工作但意味着现方案**不能独立上线**。
4. **实验规模太小**：MLP 111 参数、699 样本玩具数据集；85× 开销比与 50% 通信节省都不具外推性；真实 IoMT 模型（≥10⁶ 参数）上 RK4 混沌积分逐元素采样 L 个状态会成为瓶颈（每荷载元素一个 RK4 步）。
5. **D-PQM 是"数学模型"不是器件演示**：期望值级降阶模型、无量子噪声/散粒噪声，STM32 跑的只是 ODE 仿真——"光子量子忆阻"标题与硬件内容（STM32）之间存在落差，全文无光学实验。
6. **θ 缠绕 [−π,π] 是数值补丁**：长期积分靠缠绕防漂移，缠绕点附近的动力学不连续性与对 LE 的影响未讨论（4.4 的 L₂ 敏感或与此相关）。
7. **加密指标谱系不全**：无 NPCR/UACI（图像加密指标不适用可原谅），但密文层面只做了字节直方图/相邻相关，**NIST 测密钥流不测密文**；荷载级"代表例"Fig. 13 与总体指标的口径区分虽诚实，但样本量仍小。
8. **复用混沌系统做密钥流的的老问题**：RK4 步长 h、量化 γ=1000、|x_k θ_k| mod 1 的 mod 1 操作对低精度平台不可微/不可逆，定点实现下 K_k 的可复现性（服务器-客户端两端一致）依赖两端完全相同的浮点路径，跨平台一致性未验证。
9. **nonce 常数 a/b/c 固定公开**，域分离全靠 nonce 调度；若主初态泄露，多轮流可联动攻破——无前后向安全讨论。
10. 与 secure aggregation/DP 的"互补"仅停留在引言-讨论层面，**无组合实验**（如叠加 DP 后精度-隐私-开销三维权衡）。

## 十、可借鉴之处

1. **"器件极性"作为构造动机**：从"单端口光子计数 ⇒ 单极性输出"这一器件物理事实出发，用平衡差分检测天然得到双极对称捏滞——把器件层面的非理想性转化为系统级构造原则的写法，可迁移到忆阻/忆容/忆感建模选题（对照库内 101 忆容器、036 离散忆阻器级联）。
2. **Table 1 式"自我证伪"实验模板**：宣称超混沌/复杂动力学时，主动给 11 组 Δt/时长/初值对照证明次正 LE 的脆弱性——这是回应"超混沌灌水"批评的最佳实证姿势，值得引入本组论文的 LE 报告规范。
3. **混沌 + 联邦学习的新应用轴**：跳出"混沌→图像加密"红海，转向 FL 参数交换保密（双向、会话相关、与训练过程解耦）——为省青基/课程提供"混沌在隐私计算中的轻量定位"叙事样本；且作者对"与 secure aggregation/DP/HE 互补不替代"的谦逊定位恰好是可引用的立场模板。
4. **nonce 域分离调度式 n₀+a·r+b·i+c·d**：多轮/多客户端/双向的流隔离设计，结构简单可移植到多用户混沌保密通信。
5. **密钥流生成管线**：预热丢弃 N₀ → 逐元素采样 → argsort 置乱 + |γxθ| mod 1 掩码 + ROT 扩散链，与量化-反量化往返误差 <5×10⁻⁷ 的"无损定点传输"论证——给"混沌加密保 FL 效用"提供了工程上站得住的端到端闭环模板。
6. **诚实标注实验口径**：NIST 测密钥流不测密文、Random Excursions 仅适用子集、43 bit 不是密钥长度、85× 开销是小模型假象——每处易夸大处都做了口径限定，值得作为写作规范学习。
