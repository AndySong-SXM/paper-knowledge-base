## 🎯 研究动机与创新点

现有混沌加密的根基是混沌发生器，其安全性上限由发生器的动力学复杂度决定。两条公认演进路线：从人工构造混沌映射 → 利用生物/神经系统内在非线性（忆阻 HNN 系列）；以及从实值域 → 复值域（复值系统天然携带幅值+相位双通道信息，可描述量子态矢量、电磁波传播等物理现象）。但**已有离散 HNN 混沌模型几乎全部局限在实值域**，复值混沌研究集中在人工设计的复值映射上，没有人做过"神经网络本体的复值化"。本文把两条路线交汇，四大贡献：

1. **首个复值离散时间 Hopfield 神经网络（CVDHNN）**：两神经元复值 DHNN + 分裂复值正弦激活 f(z)=sin(x)+i·sin(y)，把复值混沌研究对象从"人工构造的复值映射"移到"神经网络动力学框架"。
2. **严格动力学分析**：不动点存在性（零等值线+向量场数值求解）、稳定性（Jacobian 特征值判据）、QR 法 LE 谱、单参数/双参数分岔分析，确认大范围超混沌。
3. **FPGA 物理实现**：Zynq-7000（XC7Z020）50 MHz、Q5.27 定点、CORDIC 正弦、AD9767 双通道 14 bit DAC；系统做 12–64 bit 七种位宽的**周期检测**（Brent 算法、1000 随机初值、最长测到 2 TB / 1.34 亿步迭代），证明 32 bit 定点工程上不退化；NIST SP 800-22 15 项全过 + **TestU01 五大电池（Rabbit/Alphabit/BlockAlphabit/SmallCrush/Crush）全过**——随机性论证强度高于知识库多数论文。
4. **专用复值加密方案**：多阶段混淆-扩散管线全部围绕复值运算设计（像素配对置乱 → 复值 XOR 扩散 → 笛卡尔→极坐标变换 + 数位分解置乱 → 复值迷宫扩散），明文绑定的动态密钥重初始化混沌系统，给出形式化的 PCA/CCA 抵抗论证。

## 🔧 核心方法

### CVDHNN 模型（式1–4）

两神经元复值离散 HNN（由连续 HNN 经欧拉差分离散化后复值化）：

```
z1(n+1) = µ·z1(n) + w11·f(z1(n)) + w12·f(z2(n))
z2(n+1) = µ·z2(n) + w21·f(z1(n)) + w22·f(z2(n))        (式1)
```

- 激活函数取**分裂复值正弦** f(z) = sin(x) + i·sin(y)（式2，x、y 为 z 的实/虚部）——复域提供了幅值+相位的设计空间，作者明确弃用 tanh/sigmoid（那是实值域选择）。
- µ∈(0,1) 实值衰减因子；权重矩阵固定为 W = [[a, b], [−1, 0]]（式3），其中 a=a_r+i·a_i、b=b_r+i·b_i 为**复值控制参数**（第二神经元权重固定，第一神经元权重作可调变量——降维便于分析）。代入得核心系统：

```
z1(n+1) = µ·z1(n) + a·f(z1(n)) + b·f(z2(n))
z2(n+1) = µ·z2(n) − f(z1(n))                            (式4)
```

按 z=x+iy 分解即得等价 4 维实值系统。默认参数 µ=0.1，a=−2+i，b=−2+1.5i，初值 z0=[0.1+0.1i, 0.1+0.1i]。

### 不动点与稳定性（式5–9）

不动点方程（式5）中 Z2 可显式表出 Z2 = f(Z1)/(µ−1)（式6），代回得单方程（式7）；解析求解困难（实虚部非线性耦合），故分解为二维实值方程组 F1(x,y)=0、F2(x,y)=0（式8），用**零等值线交点 + 向量场**数值求解（Fig.1）。Jacobian（式9）在该不动点的特征值 λ₁,₂=0.898±0.195i、λ₃,₄=−2.698±1.195i——模长均大于 1 ⇒ **不动点不稳定**（离散系统稳定判据：全部特征值位于复平面单位圆内），系统具备产生复杂动力学的条件。

### 动力学分析（第 3 节）

- LE 用 **QR 分解法**（Algorithm 1：每步取 Jacobian 乘累积 Q，QR 后对 R 对角取对数累加，S_i/T），兼顾速度与精度。
- 参数 a 扫描（b=−2+1.5i 固定）：a_r∈[−20,20]（a_i=1）时 [−0.5,0.6] 附近 LLE<0（非混沌），区间外**两个正 LE**（超混沌），且 |a_r| 越大 LE 越大；a_i 扫描类似（非混沌区 [−1.2,0.6]，左半平面有周期窗 [−9.9,−9.6]）。
- 参数 b 扫描（a=−2+1i 固定）：b_r 在 [−4,3.5] 内 LE 波动（超混沌↔周期交替），右半平面有较宽周期窗；b_i 的周期窗位于 [−2,−0.95]、[0.15,0.5]。
- 结论：|参数|增大普遍增强超混沌性；规则动力学集中在原点附近的对称小区间；周期窗位置随参数而异——**为加密密钥范围选取提供了依据**（后文密钥区刻意避开这些窗口）。

### FPGA 实现（第 4 节）

- 平台：Xilinx Zynq-7000（XC7Z020CLG400-1），50 MHz；AD9767 双通道 14 bit DAC 输出示波器显示相图。
- 定点格式 **Q5.27**（符号位+4 整数位+27 小数位）在动态范围/精度/资源间取平衡；正弦用 **CORDIC 旋转模式**（式10：纯移位-加迭代 x_{i+1}=x_i−d_i·(y_i≫i)，y_{i+1}=y_i+d_i·(x_i≫i)，z_{i+1}=z_i−d_i·α_i，α_i=arctan(2^{−i})），避开浮点单元。
- 架构（Fig.5）：4 个状态寄存器 + 4 个并行正弦模块 + 4 个次态计算单元 + MUX + 控制逻辑，**单时钟周期完成一次完整迭代**（全并行数据通路）。
- **精度-资源权衡**（Table I–II, Fig.7）：32 bit 配置所有状态变量 RMSE<0.62，较 24 bit 提升 65%；64 bit 更准但资源浪费，12–24 bit 精度不足——32 bit 是最优平衡点。
- **周期检测**（Table III，本文最有工程严谨性的部分）：Brent 算法 + 1000 个随机初值 + 数据量 1 GB–2 TB（约 1.34 亿次迭代）；**12–24 bit 位宽全部出现短周期**，32/64 bit 在最大测试体量下**零周期**。结论：32 bit 定点生成 2 TB 伪随机数不发生周期退化，满足密码应用要求。
- 随机性：NIST SP 800-22（10⁶ bit，α=0.01）**15 项全过**（Table IV）；**TestU01 五电池全过**（Rabbit/Alphabit/BlockAlphabit/SmallCrush/Crush，P>0.001，Table V）。

### 加密方案（第 5 节）

**密钥调度**：用户 256 bit 私钥 Kp → SHA-256 得 H → 均分 8 段 32 bit，每段再拆 4 个 32 bit 子段 XOR 压缩为 K_j（式11，j=1…8）→ 线性缩放 P_j=L_j+K_j·(U_j−L_j)（式12）映射为 8 个系统参数/初值。取值范围按分岔分析**刻意避开周期窗**：a_r,b_r∈[−20,−10]，a_i,b_i∈[5,20]，z0∈[−20,20]；百万随机密钥统计 100% 落入混沌区。有效密钥空间：浮点 2²⁵⁶；**Q5.27 定点量化后 2²¹⁶**（每参数 2²⁷ 级离散），仍超 2¹⁰⁰ 暴力破解阈值；参数敏感度 S=1−|ρ|>0.98，参数间相关性低。

**加密管线（4 级混淆-扩散，全程复值运算）**：

1. **像素配对置乱（confusion）**：Sc 实部 argsort 索引 → 像素非顺序两两配对重排，打破空间相关性。
2. **复值 XOR 扩散**：第二通道混沌序列 Sc[:,2] 量化到 [0,255] 得 M，对配对图像按位复值异或（式14：(v_r^k⊕m_r^k)+j(v_i^k⊕m_i^k)），实虚部（即两个配对像素）同时被改。
3. **极坐标域数位分解置乱（Algorithm 2）**：复值图像转极坐标 (R,Θ)；R、Θ 各自量化为 16 bit 整数，拆成 4 个十进制数位；R 的 4 位全排列，**Θ 只排低 3 位、保留最高位**（防止相位整周回绕导致置乱失效）——这个细节处理得专业；重组回复值数组。
4. **复值迷宫扩散（Algorithm 3，核心创新）**：先对中间密文 Z 做 SHA-256 得 H_Z，S_d=SHA-256(H_Z∥Kp) 派生种子 **重初始化 CVDHNN** 得动态密钥序列 K_d——明文绑定、同 Kp 加密多图也互不相关（stateless）；混沌路径 P=argsort(Im(K_d[:,2]))（式15）定义像素激活顺序；激活像素 Z_i 对其 **8 邻域**逐一施加复值旋转 Z_j^new=Z_j^old·e^{jφ_j}（式16），旋转角 φ_j=∠Z_i+∠K_i+α·sin(β·t)+γ_j（式17，依赖中心像素相位、动态密钥相位、步数和邻居基准角）——变化沿混沌路径链式级联，单像素改动扩散全图。

解密为严格逆序：共轭旋转（−φ_j）逆迷宫扩散 → 逆数位分解置乱 → 极坐标→笛卡尔逆变换 → 逆 XOR → 逆配对置乱。确定性系统保证正确密钥精确重建（Fig.10 四组实验）。

### 形式化安全论证（5.B 节）

把加密分解为 E_Kp(I)=C2(K_d(Z), C1(Kp,I))（式18，C1=前三阶段、C2=迷宫扩散）：
- **CPA**：动态密钥 K_d 由明文 Z 经 SHA-256 单向派生，ΔZ 比特差经雪崩放大后 ΔC 可忽略，优势界 P[A(ΔI,ΔC)=1] ≤ 1/2^{ΔZ}+ε(λ)（式20）。
- **CCA**：解密依赖加密时同一 K_d，而 K_d 不可从 C 无 K_p 推出，敌手构造密文解密后落入合法明文集概率 ≤ 1/2¹²⁸（式22）。
注意：ε(λ) 只由"SHA-256 雪崩效应"启发式给定，**并非严格归约**，实质是论证性安全而非可证明安全。

## ⚠️ 不足与可借鉴之处

**不足**：

1. **零误码容忍（作者自己承认的第一条）**：明文绑定的动态密钥 + 链式迷宫扩散 + argsort 路径依赖，意味着密文任意单比特错误都会使解密全图崩坏；论文**没有任何抗噪/抗裁剪/抗丢包实验**（093 有裁剪+噪声、094 有 50% 椒盐，本文全无）， noisy channel 适用性只靠 future work 里的喷泉码口头承诺。对"video technology"期刊的定位而言，传输鲁棒性缺位是明显短板。
2. **SHA-256 开销与轻量性叙事冲突**：两轮 SHA-256（密钥调度 + 明文绑定）对资源受限场景不友好，4K 加密 4.52 s 也不算快；作者承认但仅给"硬件加速/轻量哈希"的未来方向。
3. **无侧信道防护**：定点迭代的时间/功耗泄漏（Hamming weight、迭代次数固定模式）未做常数时间或随机化掩蔽，FPGA 实现章节只验证了混沌源，加密链路未上板——与 094 一样"FPGA 只做发生器"，硬件闭环不完整。
4. **形式化安全是论证性的**：式(20)(22) 的 ε(λ) 靠"SHA-256 雪崩"启发式给定，无随机谕言机归约；"P ≤ 1/2¹²⁸" 的 CCA 界推导过程较草。真正的可证明安全还得看 088（D-NTRU）那类基于格假设的构造。
5. **NIST 只测单条 10⁶ bit 序列**，未做多样本比例检验——但被 TestU01 五电池补强，随机性证据链总体仍强于知识库平均水平。
6. **彩色图三通道独立加密**：通道间无耦合（对比 094 的 3D→1D 全局置乱一次打乱 RGB），跨通道相关性攻击面未讨论。
7. **迷宫扩散的旋转只改相位**：Z_j·e^{jφ_j} 为模 1 复数乘法，每个复值（像素对）的模（能量）守恒、仅角度重排——能量分布信息经极坐标置乱后被掩盖，但"模守恒"结构本身是潜在的代数攻击线索，论文未分析。
8. 复值激活 f(z)=sin(x)+i·sin(y) 是"分裂型（split-type）"而非全复值解析函数（如 sin(z)），动力学的"复值性"主要体现在双通道参数与相位运算上，标题的 complex-valued 成色略打折扣（但该选择换到了硬件可实现性，属合理工程取舍）。

**可借鉴**：

1. **Brent 周期检测 + 多位宽扫描的混沌工程化范式**：12–64 bit 七档位宽 × 1000 随机初值 × 2 TB 体量定量回答"定点实现何时退化"，这是把混沌系统搬上资源受限硬件前应有的标准动作，远胜"画个相图就说硬件可行"的常见写法。毕设/本子涉及 FPGA-DSP 实现时可直接套用该实验设计。
2. **分岔分析反向指导密钥空间设计**：先扫参数平面找出超混沌主区与周期窗，再把密钥映射范围**显式避开周期窗**并做百万密钥统计验证——"密钥区合法性"这个常被审稿人攻击的点被系统性封堵。
3. **TestU01 五电池作为 NIST 的补强**：Crush 电池对长程相关与位级缺陷敏感，过全套比只报 NIST 15 项更有说服力；写加密论文时值得照搬。
4. **动态密钥重初始化的"stateless 多图加密"**：S_d=SHA-256(H_Z∥Kp) 每次加密重新播种，同密钥加密多张图像零同步泄漏——解决了一类确定式混沌加密"同密钥流复用"的结构性弱点，且比 094 的 LSB 嵌入方案干净（无单点故障）。
5. **复值迷宫扩散的邻域传播机制**：8 连通复旋转 + 混沌激活路径的组合是一种新颖的扩散拓扑（传统行列/螺旋扫描的替代），"激活顺序由密钥明文共同决定"的思想可迁移到其他扩散结构设计。
6. **极坐标数位分解置乱的相位保护细节**：Θ 只排低 3 位数位防整周回绕——把"置乱必须保持在值域双射"这条隐性约束显式处理，加密算法设计中这类 off-by-one 式陷阱的专业处理值得学习。
7. **消融实验的写法**：同框架换发生器 + 多样本统计检验，直接回答"复值化到底有没有用"——比单纯罗列指标对比更有因果说服力。
