## 二、研究背景与问题

### 2.1 混沌理论与分数阶微积分

混沌是确定性系统中的不规则复杂运动行为，广泛存在于自然界中。Lorenz基于大气环流模型发现了著名的Lorenz系统[1]，May基于生态种群方程发现了Logistic映射[2]。混沌已被广泛应用于控制、加密、电力系统、神经网络等领域[5-9]。

分数阶微积分是经典微积分的推广，能够将记忆效应和滤波效应引入常微分和偏微分方程。分数阶非线性系统相比整数阶系统能揭示更丰富的动力学特征。在分数阶定义中，Caputo定义因具有更清晰的物理解释而最受认可，有利于实际系统的求解和工程应用。

### 2.2 船舶电力系统

船舶电力系统具有强非线性、强耦合和复杂动力学行为的特点。**角度不稳定性（Angular Instability）**是船舶电力系统运行中的不稳定状态，会导致混沌振荡，威胁电力系统的稳定运行。随着运行时间增加，混沌振荡变得更加不可控，最终导致电力系统崩溃。

### 2.3 极端多稳态

极端多稳态（Extreme Multistability）指系统具有无穷多个共存吸引子。大多数具有极端多稳态的混沌系统是通过添加忆阻器、周期函数或扰动获得的。然而，本文提出的分数阶船舶电力系统**无需添加忆阻器、控制器或常数**，即可展现极端多稳态、多涡卷吸引子和吸引子偏移等有趣现象。

### 2.4 研究动机

- 现有研究多基于整数阶电力系统，分数阶模型能更准确地描述物理现象
- 船舶电力系统尚未使用ADM算法求解
- 尚无分数阶船舶电力系统的数字电路（DSP）实现研究

## 三、核心方法与创新点

### 3.1 Adomian分解法（ADM）求解分数阶系统

#### Caputo分数阶导数定义

$$D_t^q f(t) = \frac{1}{\Gamma(m-q)} \frac{d^m}{dt^m} \int_0^t (t-\tau)^{m-q} f^{(m)}(\tau) d\tau, \quad m-1 < q < m$$

#### ADM分解框架

对于分数阶微分方程 $D_t^q x(t) = f(x(t))$，可表示为：

$$D_t^q x(t) = Lx(t) + Nx(t) + g(t)$$

其中 $L$ 为线性项，$N$ 为非线性项，$g(t)$ 为常数项。状态变量分解为 $x = \sum_{i=0}^{\infty} x_i$，非线性项分解为 $Nx = \sum_{i=0}^{\infty} A_i$。

**核心创新：三角函数乘积项的优化分解。** 针对系统中的复合三角函数项 $b \sin x \cos z$，利用积化和差公式转换为：

$$b \sin x \cos z = \frac{b}{2}[\sin(x+z) + \sin(x-z)]$$

然后对每一项进行Adomian多项式展开，避免了直接对乘积项分解的复杂性。这是本文在方法论上的关键贡献——**首次提出分数阶混沌系统中三角函数复合项的ADM求解方法**。

### 3.2 分数阶船舶电力系统模型

#### 原始整数阶模型（双发电机并联）

$$\dot{\delta} = \omega$$
$$H \dot{\omega} = P_m - P_e \sin\delta - D\omega$$

其中 $\delta$ 为功角，$\omega$ 为转子角速度，$H$ 为转动惯量，$P_m$ 为机械功率输入，$P_e$ 为电磁功率，$D$ 为阻尼系数。

#### 引入电磁干扰后的无量纲模型

$$\dot{x} = y$$
$$\dot{y} = -\sin x - ay + b\sin x \cos(\mu t) + c$$

其中 $a = D/H$，$b = \Delta P/H$，$c = P_m/H$，$\mu = \beta/H$。

#### 分数阶模型

$$D_t^q x = y$$
$$D_t^q y = -\sin x - ay + b\sin x \cos z + c$$
$$D_t^q z = \mu$$

### 3.3 时变平衡点分析

系统平衡点满足 $y=0$ 且 $-\sin x_e + b\sin x_e \cos(\mu t) + c = 0$。由于时间 $t$ 的存在，$x_e$ 的值是**时变的且多值的**，因此系统的平衡点随时间演化。这是系统产生复杂动力学的数学根源。

平衡点稳定性由特征方程 $\lambda^2 + a\lambda - \cos x_e + b\cos x_e \cos(\mu t) = 0$ 决定，特征值为：

$$\lambda_{1,2} = \frac{-a \pm \sqrt{a^2 - 4(\cos x_e - b\cos x_e \cos(\mu t))}}{2}$$

### 3.4 DSP硬件实现

基于TMS320F28335 DSP平台实现，采用模块化设计方法。关键优化：预计算Gamma函数系数 $g_1, g_2, g_3, g_4$ 和 $G_1, G_2, G_3, G_4$，避免每次迭代重复计算，大幅减少DSP计算量。

## 四、实验设计与结果

### 4.1 参数敏感性分析

固定参数 $q=0.95, a=0.4, c=0.23, \mu=1$，初始值 $(0.1, 0.01, 1)$：

| 分析对象 | 参数范围 | 步长 | 主要发现 |
|---------|---------|------|---------|
| 阶次 $q$ | 0.6 ~ 1 | 0.001 | 通过倍周期分岔进入混沌，$q \in [0.855, 1]$ 存在周期窗口 |
| 参数 $a$ | 0.3 ~ 0.55 | 0.0005 | $a \in [0.3, 0.3345]$ 出现角度不稳定性，之后通过逆倍周期分岔退化为周期 |
| 参数 $b$ | 1.6 ~ 1.95 | 0.0005 | 系统对参数 $b$ 敏感，微小变化可导致角度不稳定性 |
| 参数 $c$ | 0.1 ~ 0.35 | 0.0005 | 类似参数 $a$，存在角度不稳定区间 |

### 4.2 角度不稳定性

当参数 $a=0.33$（角度不稳定性参数），仿真时间分别为1000s、3000s、5000s时：
- **混沌吸引子涡卷数量随仿真时间增加而增加**
- 这意味着一旦角度不稳定性发生，不可逆转，且越来越严重，最终导致电力系统崩溃

### 4.3 极端多稳态验证

**稳定状态**（$a=0.4$）：初始条件对系统影响很小，仅有两种分岔路径。

**角度不稳定性状态**（$a=0.33$）：初始条件对系统影响极大：
- $x(0)$ 从 -5 到 5 变化时，产生**无穷多个多涡卷混沌吸引子**
- 存在至少三种不同类型的混沌吸引子（图13展示了三种）
- 混沌吸引子随初始条件变化发生**偏移（offset）**
- 证明了系统的**极端多稳态**特性

### 4.4 谱熵（SE）复杂度分析

在 $x(0)-y(0)$ 平面绘制复杂度图：
- **稳定状态**（$a=0.4$）：复杂度不高，混沌态与周期态之间有清晰边界
- **角度不稳定性**（$a=0.33$）：复杂度显著增加，各种状态交织，系统变得更加不可预测

### 4.5 DSP硬件验证

基于TMS320F28335实现，通过DAC8552数模转换和示波器观测。实验结果与MATLAB数值仿真基本一致，验证了分数阶船舶电力系统在DSP平台上的可行性。

## 五、主要结论

1. **首次将Caputo分数阶导数引入双发电机并联船舶电力系统**，构建了分数阶船舶电力系统模型
2. **优化了ADM算法中三角函数乘积项的分解方法**，利用积化和差公式简化了复合非线性项的处理
3. 系统展现了丰富的动力学特性：可变相空间轨迹、共存吸引子、典型分岔
4. 发现了**角度不稳定性现象**：混沌涡卷数随仿真时间增加而增加，不可逆转
5. **无需添加忆阻器、控制器或常数**，系统自然产生极端多稳态、多涡卷混沌吸引子和吸引子偏移
6. 通过谱熵复杂度分析揭示了角度不稳定性下系统不可预测性显著增强
7. 在TMS320F28335 DSP平台上成功实现，验证了理论分析的正确性

## 六、批判性评价

### 6.1 优势

1. **跨学科创新**：将分数阶微积分、混沌理论与船舶电力系统工程问题有机结合，开辟了分数阶电力系统动力学分析的新方向
2. **方法论贡献**：三角函数乘积项的ADM分解优化具有通用性，可推广至其他含三角函数复合项的分数阶系统
3. **物理意义明确**：角度不稳定性的发现具有实际工程指导意义——揭示了船舶电力系统崩溃的动力学机制
4. **完整的实验验证链条**：数值仿真 + DSP硬件实现，形成理论到实验的闭环

### 6.2 不足

1. **系统维度较低**（3维），动力学复杂度有限，未达到超混沌（需要至少2个正LE）
2. **极端多稳态的严格数学证明不够充分**——主要通过数值仿真展示无穷共存吸引子，缺乏解析证明
3. **DSP实现精度有限**——论文承认示波器采集图像存在轻微误差，且仅展示了相图对比，缺乏定量误差分析
4. **未讨论控制策略**——虽然发现了角度不稳定性的危害，但未提出相应的控制或抑制方法
5. **谱熵分析较简略**——仅展示了二维复杂度图，未与其他复杂度度量（如近似熵、样本熵）进行对比
6. **参数 $b$ 的物理含义**——$b = \Delta P/H$ 代表电磁干扰功率与转动惯量之比，但未讨论实际船舶中 $\Delta P$ 的典型取值范围

### 6.3 与知识库论文的关联

- 与 **002号论文**（Liu T et al., 2024 分数阶多翼混沌系统）形成互补：002关注分数阶多翼系统的多稳定性与电路实现，本文关注分数阶船舶电力系统的极端多稳态与DSP实现
- 与 **009号论文**（Kong et al., 2024 分数阶忆阻HNN）共享分数阶微积分建模方法，但本文未引入忆阻器
- 与 **018号论文**（Bukhari et al., 2022 分数阶Rössler系统）同属分数阶混沌系统研究，但本文的工程应用背景（船舶电力系统）更为具体
- 与 **022号论文**（Shen et al., 2014 任意正LE超混沌系统设计）形成方法论对比：022通过闭环级联构造高维超混沌，本文通过物理系统建模发现自然极端多稳态
- 与 **012号论文**（de Souza, 2004 冲击系统LE计算）和 **021号论文**（Strukov, 2008 忆阻器物理实现）共同构成动力系统从理论分析到物理实现的研究图谱

## 八、关键公式速查

### 8.1 Caputo分数阶导数

$$D_t^q f(t) = \frac{1}{\Gamma(m-q)} \frac{d^m}{dt^m} \int_0^t (t-\tau)^{m-q} f^{(m)}(\tau) d\tau$$

### 8.2 分数阶船舶电力系统

$$D_t^q x = y$$
$$D_t^q y = -\sin x - ay + b\sin x \cos z + c$$
$$D_t^q z = \mu$$

参数：$a = D/H$（阻尼比），$b = \Delta P/H$（电磁干扰比），$c = P_m/H$（机械功率比），$\mu = \beta/H$（干扰频率比）

### 8.3 ADM近似解

$$\tilde{x}_j(t) = c_j^0 + \frac{c_j^1}{\Gamma(q+1)}(t-t_0)^q + \frac{c_j^2}{\Gamma(2q+1)}(t-t_0)^{2q} + \frac{c_j^3}{\Gamma(3q+1)}(t-t_0)^{3q} + \frac{c_j^4}{\Gamma(4q+1)}(t-t_0)^{4q}$$

### 8.4 三角函数积化和差分解

$$b\sin x \cos z = \frac{b}{2}[\sin(x+z) + \sin(x-z)]$$

### 8.5 平衡点特征值

$$\lambda_{1,2} = \frac{-a \pm \sqrt{a^2 - 4(\cos x_e - b\cos x_e \cos(\mu t))}}{2}$$

其中判别式 $\Delta_1 = a^2 - 4(\cos x_e - b\cos x_e \cos(\mu t))$

### 8.6 DSP预计算系数

$$g_i = \frac{h^{iq}}{\Gamma(iq+1)}, \quad G_i = \frac{1}{\Gamma(iq+1)} \quad (i=1,2,3,4)$$
