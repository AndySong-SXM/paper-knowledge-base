## 🎯 研究动机与创新点

分数阶微分（FOD）具有记忆历史信息的能力，比整数阶系统复杂度更高、更贴近真实物理过程。现有忆阻 Hopfield 神经网络（MHNN）研究大多停留在整数阶，分数阶忆阻 HNN（FOMHNN）中同时出现多种复杂动力学尚无报道。本文核心创新：

1. **两种分数阶忆阻器**：提出两类新型分数阶忆阻器模型，其中一种被**严格证明同时具有极端多稳态、局部有源性和非易失性**——三性合一的忆阻器此前未见。
2. **忆阻器双重物理角色**：用忆阻器模拟神经元的**自突触（autapse）**，同时描述**电磁辐射引起的电磁感应现象**，物理图像清晰。
3. **新型 5D FOMHNN**：在电磁辐照环境下建立 5 维分数阶忆阻 HNN，数值仿真发现**超混沌、多涡卷、极端多稳态、降阶"超频"（overclocking）行为、初值偏移增强共存吸引子**等丰富动力学。作者称这是首次在 FOMHNN 中同时观察到如此多种动力学行为。
4. **低开销加密 + 全硬件闭环**：基于 FOMHNN 设计"高效、低内存开销"的图像加密方案（摘要称**舍弃了传统扩散与置乱环节仍保持极佳明文敏感性**），并在 FPGA 上同时实现混沌系统与加密算法，面向万物互联时代的硬件加密应用。

## 🔧 核心方法

### 系统模型

- **基础结构**：3 神经元 Hopfield 神经网络（tanh 激活），神经元连接权重中嵌入两类分数阶忆阻器，扩展为 **5 维 Caputo 分数阶系统**（状态变量含神经元状态 + 忆阻器内部状态 ϕ、磁通 u）。
- **忆阻器 1（自突触）**：非理想磁控型，忆导函数含多段/非线性项，其内部状态方程含泄露项（非理想性来源）；数学上证明其功率关断稳态数可变（非易失）且具备局部有源性，是极端多稳态的根源。
- **忆阻器 2（电磁辐射感应）**：理想磁控型，模拟电磁辐射对神经元膜的影响，引入电磁感应非线性耦合项。
- **数值求解**：采用 **Adomian 分解法（ADM）** 推导系统等效差分形式。作者选择 ADM 的理由：收敛快、截断误差小，且迭代式为纯代数运算（加/乘 + 记忆数组），天然适配 FPGA 并行架构——这一"连续分数阶系统→离散代数迭代→数字硬件"的映射路线是全文工程价值的骨架。

### 加密方案

- 基于 FOMHNN 混沌序列设计图像加密，目标是**低内存开销、低硬件实现难度**。
- 摘要的显著表述：尽管**舍弃了独立的扩散与置乱模块**，密文仍表现出优秀的明文敏感性（NPCR/UACI 接近理想值），暗示其敏感性主要来自混沌系统本身对初值/参数的极端敏感性（极端多稳态 + 超混沌），而非经典置乱-扩散结构。具体密钥生成与序列使用机制需全文核实。

### FPGA 实现

- 因模拟电路抗干扰性差，采用更稳健的数字电路路线：FPGA 实现所提 FOMHNN，并扩展实现图像加密应用，形成"混沌源—加密算法"全硬件闭环（板卡型号、资源占用、功耗等指标摘要未给出，待全文补全）。

## 📊 实验与性能分析

### 动力学行为

- **超混沌**：5D 系统中出现罕见的超混沌行为（多于一个正 Lyapunov 指数）。
- **多涡卷**：忆阻器非线性函数控制涡卷数量与形态。
- **极端多稳态**：无穷多共存吸引子，由忆阻器初值（尤其磁通初值）偏移增强（initial offset boosting）诱导。
- **降阶"超频"行为**：随分数阶阶数 q 降低出现的特殊动力学（作者称为 overclocking），是分数阶系统区别于整数阶的新调控维度。
- 分析手段：动态仿真 + 分岔图 + Lyapunov 指数谱 + 吸引盆等标准工具组合。

### 加密安全性（Lena 图）

| 信息熵 | 7.9995 | 8 |
| NPCR | 99.6095% | 99.6094% |
| UACI | 33.4671% | 33.4635% |

- 密文随机性高、统计特性接近理想。
- FPGA 硬件实验验证了 FOMHNN 与加密方案的物理可实现性。

## ⚠️ 不足与可借鉴之处

**不足**：
1. 本次精读未取得 PDF 全文，**密钥空间、NIST SP800-22 测试、抗选择明文/已知明文攻击分析、密钥敏感性**等关键安全性数据未能核实——这是本文是否经得起密码分析检验的决定性部分，待补读全文。
2. "舍弃扩散与置乱仍达理想 NPCR/UACI"的机制若依赖明文相关密钥或混沌序列直接异或，必须防范选择明文攻击；摘要未说明防御设计。
3. 极端多稳态在数字有限精度下会退化（吸引子合并），FPGA 定点/浮点实现是否保留极端多稳态特性需要实验证据。
4. 加密测试仅报告 Lena 标准图，缺多图库与鲁棒性（噪声/裁剪/丢失）数据。
5. 分数阶 ADM 迭代计算成本高于整数阶映射，吞吐率与资源开销数据待全文确认。

**可借鉴**：
1. **忆阻器双重角色建模**："自突触 + 电磁辐射感应"一个元件两种物理解释，写论文时物理动机饱满。
2. **三性合一证明范式**：极端多稳态 + 局部有源 + 非易失的严格证明路线，值得移植到自己的忆阻器建模工作中。
3. **阶数 q 作为新调控/密钥维度**：降阶"超频"行为提示分数阶阶数可像参数一样参与密钥设计，且 q 的变化不改变系统结构。
4. **ADM→FPGA 工程路线**：分数阶连续系统经 ADM 化为纯代数迭代后直接映射 FPGA，对自己做 STM32/FPGA 硬件加密（cipherflow 产品化）有直接参考价值。
5. **低内存开销加密设计目标**：面向物联网终端的"算法复杂度让位于硬件可实现性"的设计哲学。
