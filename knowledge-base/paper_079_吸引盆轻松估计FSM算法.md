## 二、研究背景与问题

### 2.1 研究动机

在多稳态动力系统中，**吸引盆（basin of attraction）** 是核心概念之一——它记录了哪些初始条件会收敛到哪一个吸引子。由于绝大多数非线性系统的吸引盆无法解析求解，数值模拟成为唯一可行的方法。

吸引盆的估计不仅有理论意义，更有广泛的应用价值：
- **揭示混沌暂态动力学**：有些初始条件在进入非混沌吸引子前会经历长时间混沌行为 [Aguirre, 2009]。
- **分形盆边界分析**：通过不确定性维度（final state sensitivity）[Grebogi, 1983] 或盆熵（basin entropy）[Daza, 2016] 量化系统的最终状态不确定性。
- **临界点分析（tipping point analysis）**：盆稳定性（basin stability）量化吸引子对参数扰动的鲁棒性 [Menck, 2013]；临界概率揭示参数漂移对全局动力学的影响 [Kaszás, 2019]。

### 2.2 现有方法的不足

| 方法 | 局限性 |
|------|--------|
| 暴力法（长时间积分后比较最后N点） | 仅对不动点有效；积分步长变化和采样问题导致对极限环/混沌吸引子失败 |
| Lyapunov谱比较 [Freire, 2008] | 计算复杂；对称吸引子可能具有相同Lyapunov谱，无法区分 |
| 四叉树递归细分 [Saupe, 1987] | 内存需求大；高维状态空间或大范围分形边界时效率极低 |

### 2.3 核心问题

**如何在不预知吸引子数量、位置和性质的条件下，自动且高效地识别所有吸引子并估计其吸引盆？**

## 三、核心方法与创新点

### 3.1 方法概述

本文提出了一种**完全自动化的方法**，基于Poincaré回复定理（Poincaré recurrence theorem），通过在状态空间网格上构建**有限状态机（Finite State Machine, FSM）**来识别吸引子及其吸引盆。该方法的核心思路是利用吸引子的唯一确定属性：**其在状态空间中的位置**。

### 3.2 算法两个核心组件

#### （1）状态空间网格化与吸引子识别（Sec. II.A）

- 将状态空间划分为规则网格，每个网格单元对应一个初始条件。
- 维护一个与网格同等大小的标签数组，记录每个单元的"身份"（未知/吸引子点/盆点）。
- **基于回复的吸引子识别**：
  - 从初始条件出发，沿动力学流演化，标记途经的单元为 `v`（visited，已访问）。
  - 当轨迹连续 `mx_chk_fnd_att` 次进入已被标记为 `v` 的单元时，判定发现新吸引子（触发自Poincaré回复定理——吸引子上的轨迹必然反复经过相同的状态空间区域）。
  - 之后连续标记新访问单元为吸引子点，直到累计 `mx_chk_loc_att` 个连续单元。
  - 最后，将初始条件标记为该吸引子吸引盆的一部分，并清除暂态轨迹的 `v` 标记。

> 关键参数默认值（可调整）：`mx_chk_fnd_att = 100`（发现吸引子阈值）、`mx_chk_loc_att = 100`（定位吸引子阈值）。

#### （2）有限状态机（FSM）框架（Sec. II.B）

FSM是整个算法的主控制器，有5种状态：

| 状态 | 含义 | 触发条件 |
|------|------|----------|
| `att_search` | 搜索新吸引子 | 初始状态 |
| `att_found` | 已发现新吸引子 | 内部计数达到 `mx_chk_fnd_att` |
| `att_hit` | 当前点落入已知吸引子区域 | 输入标签为偶数（吸引子标签） |
| `bas_hit` | 当前点落入已知吸引盆 | 输入标签为奇数 `< v`（已知盆标签） |
| `lost` | 轨迹偏离定义网格 | 输入标签为 -1（超出网格） |

**FSM操作逻辑**：
1. 状态/输入变化时 → 复位计数器 `c = 0`
2. 状态不变时 → 计数器递增 `c += 1`
3. 计数器超过阈值 → 将初始网格单元写入最终标签

**编码规则**：吸引子用偶数 `2k` 标记，对应吸引盆用奇数 `2k+1` 标记（`k > 0`）。`-1` = 网格外，`1` = 未处理，`v` = 访问过（使用下一个未用的奇数）。

### 3.3 核心创新点

1. **零先验知识需求**：无需预知吸引子数量、位置或类型（不动点/极限环/混沌），算法全自动识别。
2. **普适性极强**：适用于离散与连续系统、Poincaré映射、频闪映射、高维系统到低维空间的投影。
3. **FSM架构的系统性**：将吸引子搜索、盆匹配、异常处理（轨迹偏离网格）统一为有限状态机，避免复杂的控制逻辑，代码简洁且可扩展。
4. **两种运行模式**：
   - **模式一（全自动）**：无先验知识，自动发现所有吸引子并估计盆。
   - **模式二（精细分析）**：用户提供已知吸引子坐标，在指定区域精细化盆估计（通过最小距离匹配）。
5. **`bas_hit` 加速机制**：当轨迹进入已知吸引盆后，无需等待到达吸引子即可判定归属，显著加速填充过程（网格越满越快）。

### 3.4 限制与对策（Sec. II.D）

- **网格分辨率依赖**：网格必须足够大以包含所有吸引子，且足够细以分离不同吸引子。分辨率由 `ρ^D`（ρ为每维网格点数）决定。
- **积分步长 `Δt`**：必须使轨迹每步访问不同网格单元。代码自动推荐 `Δt` 约为平均单元穿越时间的10倍。`Δt` 偏大仅降低效率但不损失精度。
- **高维系统的内存瓶颈**：吸引盆数组大小随维度指数增长（∼ρ^D）；10维系统已可能超出典型计算机内存。建议用随机采样替代全网格。

## 四、实验设计与结果

### 4.1 测试场景（9种动力学系统，Sec. III）

| 编号 | 系统 | 类型 | 维度 | 关键特征 |
|:---:|------|------|:---:|----------|
| (a) | Hénon映射 | 2D离散 | 2 | 混沌吸引子+逃逸到无穷 |
| (b) | Duffing振子 | 2D频闪映射 | 2 | 两个共存吸引子 |
| (c) | 磁摆 | 4D连续→2D投影 | 4→2 | 分形盆边界 |
| (d) | 磁摆（放大） | 同上 | 4→2 | 分形结构的精细化 |
| (e) | Thomas循环系统 | 3D连续→Poincaré截面 | 3 | 交错吸引周期轨道 |
| (f) | Lorenz84 | 3D连续 | 3 | 混沌+周期+不动点三共存；两个吸引子在状态空间极近 |
| (g) | 耦合Logistic映射 | 4D离散 | 4 | 极端多稳态（∼26个共存吸引子） |
| (h) | Lorenz96EBM | 6D连续 | 6 | 双稳态（混沌+周期）；盆边界光滑 |

### 4.2 关键实验结果

- **Lorenz84（最难场景）**：三个吸引子中两个在状态空间极近（仅100³网格分辨率可分离），算法自动成功分离。
- **耦合Logistic映射（4D）**：发现约26个共存吸引子，但作者坦言不确定是否找到全部。
- **Lorenz96EBM（6D）**：使用粗网格 `10×10×10×10×10×101`（仅最后一维加密），耗时约1.5小时，盆比例≈(0.61, 0.39)。
- **性能基准**（磁摆，512,000初始条件，80×80×80网格）：仅需3分钟（AMD Ryzen 5 3600，单核）。
- 即使排除"先发现吸引子"的耗时，FSM方法仍优于暴力法（Fig. 5），主要优势来自 `bas_hit` 加速和网格信息复用。

## 五、主要结论

1. **FSM+Poincaré回复的方法论是成功的**：通过对9种不同性质动力系统的测试（离散/连续、低维/高维、固定点/周期/混沌吸引子、分形盆边界），算法在所有场景中均成功识别吸引子并估计吸引盆。

2. **性能超越暴力法**：即使在不公平对比场景（吸引子为固定点、盆边界强分形）下，FSM算法仍优于暴力法。

3. **与Julia生态的深度集成**：实现于DynamicalSystems.jl库，可无缝衔接Lyapunov谱计算、盆熵、盆稳定性、临界概率等下游分析。

4. **约10行代码即可使用**：极简的API设计，降低了研究门槛。

5. **未来方向**：计划集成Stender & Hoffmann (2021)的bSTAB方法——通过特征空间分类估计盆比例而无需计算完整盆阵列，特别适合高维系统。

## 六、批判性评价

### 6.1 优点

- **方法论独特且优雅**：利用Poincaré回复定理这一动力系统最基本的定理构建算法，思路简洁深刻。FSM形式化让算法逻辑透明、可扩展。
- **真正的"零先验"**：相比需要预知吸引子特征或数量的方法，该算法在不假设动力系统任何性质的前提下工作。
- **普适性覆盖全面**：作者刻意选择了极具多样性的9种系统（从2D到6D、从离散到连续、从简单到极端多稳态），证明了方法的通用性。
- **开源与可复现**：完整代码开源，提供可运行的Julia脚本生成所有图表。CC BY许可开放使用。
- **用户友好**：约10行代码即可运行，默认参数覆盖大多数场景。

### 6.2 不足与改进空间

- **高维扩展性局限**：6D系统已需1.5小时计算（仅粗网格），10D系统内存已无法承受。虽然提出随机采样方案，但未在论文中实现或验证。
- **不可并行化**：FSM的单轨迹串行特性使其天然不适合并行计算，在大规模计算场景下受限。
- **对"丢失吸引子"缺乏保证**：网格分辨率不足时可能漏掉极端接近的吸引子，算法自身无法检测这种失败（不会报错，只会输出较少吸引子）。
- **网格定义需要用户判断**：初始网格范围、分辨率、积分步长等参数仍依赖用户对动力系统的粗略了解。
- **耦合Logistic映射的26个吸引子不确定完整**：作者自己承认"不确定是否找到所有吸引子"，暴露了方法在极端多稳态场景下的局限性。

## 八、关键公式速查

### 8.1 Lorenz84 系统（主要测试案例）

$$
\begin{cases}
\dot{x} = -y^2 - z^2 - a x + a F \\
\dot{y} = x y - y - b x z + G \\
\dot{z} = b x y + x z - z
\end{cases}
$$

参数：`F = 6.886, G = 1.347, a = 0.255, b = 4.0`

### 8.2 Hénon 映射

$$
\begin{cases}
x_{n+1} = 1 - a x_n^2 + y_n \\
y_{n+1} = b x_n
\end{cases}
$$

参数：`a = 1.4, b = 0.3`

### 8.3 磁摆（Magnetic Pendulum）

$$
\ddot{x} = -\omega^2 x - \alpha \dot{x} - \sum_{i=1}^{N} \frac{x - x_i}{D_i^3}
$$

其中 $D_i = \sqrt{(x - x_i)^2 + (y - y_i)^2 + d^2}$，磁体位置 $x_i$ 均匀分布于单位圆上。参数：`α = 0.2, ω = 1, d = 0.3, N = 3`

### 8.4 Thomas 循环系统

$$
\begin{cases}
\dot{x} = \sin(y) - b x \\
\dot{y} = \sin(z) - b y \\
\dot{z} = \sin(x) - b z
\end{cases}
$$

参数：`b = 0.1665`

### 8.5 耦合 Logistic 映射（4D）

$$
u_i' = \lambda - u_i^2 + \frac{k}{D} \sum_{j \neq i}(u_j^2 - u_i^2)
$$

参数：`D = 4, λ = 1.2, k = 0.08`

### 8.6 算法核心参数表

| 参数 | 功能 | 默认值 | 推荐调优场景 |
|------|------|:------:|--------------|
| `mx_chk_att` | 确认吸引子存在 | 2 | 吸引子间距极小 |
| `mx_chk_fnd_att` | 发现吸引子阈值 | 100 | 存在混沌吸引子 |
| `mx_chk_loc_att` | 定位吸引子阈值 | 100 | 存在混沌吸引子 |
| `mx_chk_lost` | 轨迹丢失容忍 | 20 | 网格不够大时 |

> **笔记摘要**: Datseris & Wagemakers (2022) 提出了一个基于有限状态机（FSM）和Poincaré回复定理的全自动吸引盆估计方法。该方法无需任何先验知识（吸引子数量、位置、类型），在离散化状态空间网格上通过检测轨迹回复来识别吸引子，再通过FSM的5种状态（att_search/found/hit, bas_hit, lost）管理整个匹配过程。方法适用于离散/连续系统、Poincaré映射、频闪映射及高维投影，已在9种截然不同的动力学系统上验证成功（含6D Lorenz96EBM和~26吸引子的4D耦合Logistic映射）。实现于DynamicalSystems.jl库，约10行代码即可使用，性能优于传统暴力法。主要局限在于高维系统的内存瓶颈（~ρ^D）和不可并行化。

```julia
using DynamicalSystems, OrdinaryDiffEq

function lorenz84(u, p, t)
    F, G, a, b = p
    x, y, z = u
    dx = -y^2 - z^2 - a*x + a*F
    dy = x*y - y - b*x*z + G
    dz = b*x*y + x*z - z
    return SVector(dx, dy, dz)
end

F, G, a, b = 6.886, 1.347, 0.255, 4.0
p = [F, G, a, b]
u0 = rand(3)
lo = ContinuousDynamicalSystem(lorenz84, u0, p)

xg = range(-1, 3; length = 100)
yg = range(-2, 3; length = 100)
zg = range(-2, 2.5; length = 100)
grid = (xg, yg, zg)
diffeq = (alg = Vern9(), reltol = 1e-9, abstol = 1e-9)

basins, attractors = basins_of_attraction(grid, lo; diffeq)
fracs = basin_fractions(basins)

for (key, att) in attractors
    u0_att = att[1]
    ls = lyapunovspectrum(lo, 10000; u0 = u0_att)
    println("Attractor $key: spectrum=$ls, fraction=$(fracs[key])")
end
```
