## 一句话定位

把**环面参数方程**直接嵌入离散映射框架造出二维环面超混沌映射 2D-THM——有解析不变集可证全局有界、动态幅值由环面参数 (R, r) 直接控制、产生花瓣状超混沌吸引子；加密侧的核心创新是**极坐标域变换提取吸引子几何特征（方向索引 Θ / 移动距离 P / 象限归属 Q），融合编码成单个 8-bit 特征字节**驱动置乱+双向扩散，存储开销比双精度浮点 keystream 降 8 倍，最后在 Zynq7100（XC7Z100）上做到 1 MB 图像加密 47.28 ms、功耗 0.725 W。是 paper_105（同团队 Nonlinear Dynamics 2025，环面激活 HNN 纯软件加密）预告已久的硬件对偶篇，也把 104/105 的"网格/环面超混沌"三部曲补完。

## 系统模型（第 II 节）

### 2D-THM 构造（式 1-3）——环面投影嵌入

- 环面参数方程（式 1）：x=(R+r·cosθ)cosφ，y=(R+r·cosθ)sinφ，z=r·sinθ。R>0 为中心到生成圆距离，r>0 为生成圆半径。
- 两个变换方程（式 2）：T1(θ,φ)=(R+r·cosθ)·cos(b·φ)，T2(θ,φ)=(R+r·cosθ)·sin(b·φ)，b 为正调节参数（调制三角函数频率，**不影响变量上界**）。
- 映射模型（式 3）：

  x_{n+1} = T1(y_n, x_n) − T1(x_n, y_n) + ζ
  y_{n+1} = T2(y_n, x_n) − T2(x_n, y_n)

  其中 ζ=10⁻² 是为防止初值 x0=y0 时系统不振荡引入的微小常数。
- 设计动机：传统离散映射输出不保证有界；环面投影"环形、连续、周期"，天然给出有界构造。

### 有界性与全局有界性（式 4-7，不变集方法）

- 不变集定义（Definition 1）：紧集 S 在映射 g 下不变 ⇔ 任意 x0∈S，∀n∈Z，gⁿ(x0)∈S。
- 构造矩形不变集（式 4）：Ω={(x,y): |x|≤2(R+r)+|ζ|, |y|≤2(R+r)}。
- 有界性：利用 |cos(·)|≤1、|sin(·)|≤1，记 Hx=R+r·cos x、Hy=R+r·cos y（|Hx|,|Hy|≤R+r），直接放缩得 (x1,y1)∈Ω，数学归纳得全轨道留在 Ω。
- **全局有界性**：对 Ω 外任意初值，第一次迭代后即满足 |x1|≤2(R+r)+|ζ|、|y1|≤2(R+r)——即**任意初值至多 1 次迭代进入 Ω**。这是"全局"的干净证法（单步吸收域=全平面）。
- Remark 1-3：R、r 直接扩张 Ω 边界；ζ 只影响 x 方向偏移；b 只调制频率、上界不变。

### 花瓣状超混沌吸引子（图 2-4）

- 固定 R=10、b=0.4 变 r：r=1 近圆形吸引子 → r=2 多花瓣初现 → r=3/4 花瓣结构展开并沿圆周扩张，中心区因折叠出现**雄蕊状（stamen-like）结构**；r 增大第一个 LE 单调增。
- 固定 R=10、r=4 变 b（注：图 2 caption 写 fixed r=5，正文写 r=4，**原文此处不一致**）：b=0.15 不规则刺状 → 0.2 对称规则刺状 → 0.3 中心对称消失、更平滑 → 0.4 恢复对称花瓣；两个 LE 均随 b 单调增。b 控制对称性与平滑度。
- 3-D 分岔图（(x0,y0)=(1,0)，R-r-b 空间）：SP（稳定点）/周期/混沌/超混沌多行为共存。
- **UP 分析（形成机制，图 4，R=100）**：把不稳定点（红点）与超混沌吸引子（灰轨迹）同图画出——r=20 时 UP 在吸引子大部区域均匀密集分布，内区密集 → 折叠动力学强 → 雄蕊状结构，外区稀疏 → 花瓣状结构；r=50 时大花辦对应 UP 稀疏区、多重折叠轨迹对应 UP 密集区。UP 分布与吸引子结构强关联 → 作者称这是 2D-THM **抗退化的鲁棒超混沌**的来源。

## 性能评估（第 III 节）

### 熵指标对比（表 I，迭代长度 10⁴，各映射最优参数）

- 9 种熵/复杂度指标全上：SampEn、PermEn、SpecEn、DispEn、DivEn、IncrEn、RangEn、SyDyEn + LE（开源工具 [37]）。
- 对比 9 个代表性 2-D 映射：2D-TDM、2D-MTM、2D-DMCC、2D-STB、2D-MGM、2D-SCMCI、2D-SFHM、2D-MCM。
- 结果：**SampEn 2.1963 全场最高**；PermEn 6.5448（与 2D-TDM、2D-SFHM 同档，显著高于 2D-STB/2D-MTM）；SpecEn/DispEn/DivEn/IncrEn/RangEn/SyDyEn **六项全部最高**；LE=(3.7717, 3.1358) 仅低于 2D-SFHM。

### 密钥空间有效性（图 5）

- 全参数域 SpecEn 稳定落在 [0.9590, 0.9600]——"大参数偏移也能回到混沌轨道"，初值与参数均适合做密钥。

## 加密算法（第 IV 节）——吸引子特征提取与编码

### 坐标域变换（式 9）

- 对相邻迭代点 (x_n,y_n)→(x_{n+1},y_{n+1}) 作极坐标化：

  ϱ_n = √((x_{n+1}−x_n)² + (y_{n+1}−y_n)²)   （径向距离 → 拉伸特性）
  ϑ_n = arctan2(|y_{n+1}−y_n|, |x_{n+1}−x_n|) ∈ [0, π/2]  （折叠角 → 旋转特性）

- 取绝对差把角度折叠进 [0,π/2]，实现"角度大小"与"象限方向"解耦，为后面独立提取 Q 铺垫。图 6：花瓣吸引子 → 极坐标域呈峰状分布，横轴 ϑ 全覆盖（遍历性）、纵轴 ϱ 大范围（强拉伸）。

### 密钥生成——动态密钥注入（式 10-11）

- 每轮迭代从密钥集循环取一个 32-bit 无符号整数并按位注入：

  ζ_n = (KSET[n mod N] ⊻ (n ≪ 3)) / 2³² ∈ [0,1)

- N 可调（本文 N=8），注入式(11) 的 x 方程扰动项。卖点：密钥不止初始化注入，而是贯穿整个 keystream 生成过程；借 2D-THM 的鲁棒性保证注入后仍稳定。（注：原动力学证明基于常数 ζ，动态 ζ_n∈[0,1) 下有界性仍成立，但 UP 结构是否保持未重新分析。）

### 置乱（式 12-14，方向索引 + 移动距离）

- 迭代 L=H×W 次，提取 ϱ、ϑ 序列。
- 方向索引：ϑ 的 [0,π/2] 均分 8 段（每段 π/16），映射方向索引 Θ_i∈{1..8}；方向矩阵 D（式 12，8×2）把 Θ 映射为水平/垂直分量 (Dh,Dv)，8 方向中心 ±45°/±90°/±135°/±180°。
- 移动距离：P_i = (⌊ϱ_i⌋ mod 8) + 1 ∈ [1,8]。
- 像素跳步置换（式 14）：x'=(x+Dh·⌊P·(1+ξ)·H⌋) mod H，y'=(y+Dv·⌊P·(1+ξ)·W⌋) mod W，ξ=0.05 扰动因子，P(x,y)↔P(x',y') **成对交换**，行优先遍历全图。

### 特征融合与 8-bit 编码（式 15，核心创新）

- 三特征融合字节：S_i = ((Θ_i−1)·2⁵) ∨ ((P_i−1)·2²) ∨ (Q_i−1)。
  即 **Θ 占 3 bit（高）+ P 占 2 bit + Q 占 2 bit = 8 bit**，S_i∈[0,255]。
- 存储开销对比：传统双精度浮点 keystream 每值 64 bit → 本文 8 bit，**省 8 倍内存**；硬件上只需存一份与图像同尺寸的 8-bit 特征序列，无需浮点数据或大索引数组——这是"资源受限硬件适配"叙事的支点。

### 扩散（式 16，双向）

- 前向扩散：CF_1=P'_1⊕S_1；CF_i=P'_i ⊙(S_i⊕CF_{i−1})（i≥2）。
- 后向扩散：CB_L=CF_L⊕S_L；CB_i=CF_i ⊙(S_i⊕CB_{i+1})（i≤L−1）。
- ⊕ 为 XOR，⊙ 为模 256 加法；S 同时融合方向/距离/象限三特征进扩散。

## 安全分析（IV-C，十项）

- **Probability of bits**：100×8×2²⁰ bit keystream 分 100 样本，|Z|<1.96 全过。
- **密钥敏感性（NBCR）**：翻转 K1–K4 各自 LSB，NBCR_Enc/NBCR_Dec 均 ≈50%（表 III）。
- **密钥空间**：8×32-bit 密钥集 2²⁵⁶ + (x0,y0) 各 32-bit 2⁶⁴ = **2³²⁰** > 2¹⁰⁰ 阈值。
- **统计**：直方图方差 + 卡方（χ²₀.₀₅(255)≤293.24783）全过。
- **差分**：NPCR 99.61% / UACI 33.46%（理论 99.60%/33.46%）；1-bit 明文翻转致全部密文位改变（图 10）。
- **相关性**：10,000 对相邻像素，水平/垂直/对角三方向密文相关 ≈0。
- **信息熵**：密文 IE ≈ 7.99。
- **选择明文**：P1⊕P2 ≠ C1⊕C2 几乎全位置成立（NPSI，表 V + 图 11）。
- **鲁棒性**：椒盐噪声 0.01/0.05/0.1/0.15、剪切 6.25%/12.5%/25%/50% 均可恢复主体。
- **对比**：表 VI 与已有方案比，2³²⁰ 密钥空间为对比中最大，NPCR/UACI 达理论值。

## FPGA 硬件实现（IV-D）

- 平台：**ZYNQ7100（XC7Z100FFG900-2）**，双核 ARM Cortex-A9 + 可编程逻辑，片上 BRAM 共 3.31 MB。
- 架构：上位机经**以太网**收发图像；**AXI4-STREAM** 传图像数据、**AXI4-LITE** 管 DMA 配置与密钥；PS 预处理 → PL 加密 → 回传。密钥更新或图像尺寸变化时重生成特征序列。
- 定点：**Q8.16** 定点表示所有算术运算；扩散过程用**小 FIFO** 缓存前项明文/密文像素，省 BRAM。
- 存储：1024×1024 灰度 ≈1 MB 明文 = 30.21% BRAM；特征序列只存一份 8-bit。
- 资源（表 VII）：**BRAM 68.61%**（存整图+特征序列所致），**LUTRAM 仅 0.60%，DSP 仅 3.22%**，LUT/FF 占用低。
- 功耗（Vivado 评估）：PL 侧加密逻辑**总功耗 0.725 W**。
- 速度：1024×1024 灰度加密 **47.28 ms**、解密 **62.08 ms**（图 14）。
- 跨平台对比（表 VIII）：x86 CPU 最快但功耗高几个量级，FPGA 在速度/能效间取得平衡（所有 CPU/ARM 平台用同一 C 实现保证公平）。
- 与已发表 FPGA 加密对比（表 IX/X，256×256 灰度口径）：加密时间 100 次热启动平均，吞吐与延迟有竞争力；提出 **BPP（bits per pixel）= RAM_total×2²⁰/L** 指标量化片上内存效率。
- **安全考量（罕见的自我批评）**：当前密钥经 PS 侧 AXI4-LITE 管理，暴露软件攻击面；更安全的方案是密钥完全在 PL 内生成存储，但这又引入硬件木马风险；未来工作拟引入**轻量级运行时自认证**（challenge-response 协议校验 FSM 状态转移与 datapath 操作，检测 Trojan）[57]。

## 不足与可借鉴之处

- **置乱结构偏弱的疑点**：式(14) 是成对交换（swap）+行优先单遍遍历，每个像素只参与一次交换，置乱更接近"带方向跳步的对合置换"，可能残留位置结构信息；作者未给置换的循环结构/不动点分析，置乱本身的密码学强度论证全靠 NPCR/UACI 间接支撑。
- **特征序列信息论熵未分析**：Θ 3 bit、P 2 bit 的理论容量有限，S_i 的 8 bit 中有效熵高度依赖 (ϱ,ϑ) 的经验分布是否均匀；作者只做了密文层统计检验，未回头验证特征序列本身的分布均匀性——而这正是"特征编码"方案成立的前提。
- **NPCR/UACI 只报单点**：未给多轮差分演化（SEI/MSFEI 类指标）与不同测试图像下的均值方差；表 VI 表述"99.61%/33.46%"接近理论值但样本规模不明。
- **动态注入下的理论断裂**：有界性/UP 分析都在常数 ζ 下完成，ζ_n 动态注入后 UP 分布与"抗退化"机制是否保持未讨论（虽有界性显然保留）。
- **BRAM 天花板**：68.61% BRAM 占用意味着图像尺寸上到 2048×2048 就必须外接 DDR，本文未讨论 offload 方案与特征序列的流式生成；"省内存"卖点在大图上打折。
- **密钥管理安全是明示短板**：作者自己承认密钥走 AXI4-LITE 有软件攻击面，全 PL 密钥管理+自认证只是 future work。
- 无密文流 NIST 测试（只测了混沌序列）；无已知明文攻击测试；选择明文仅做 XOR 不等式检验。
- 可借鉴：
  1. **"吸引子特征提取→8-bit 编码→接线加密"三段论**是 paper_105"特征接线"思想的极致化：极坐标变换把距离/角度/象限解耦为三条独立特征通道、再融合为单字节，对 STM32 等 MCU 毕设极有价值——8-bit 特征存储意味着裸机也能跑完整算法；
  2. **不变集 + 单步全局吸收的有界性证明模板**干净可教（Definition 1 + 放缩 + 归纳），适合写进课程讲义作"混沌映射数学化"范例；
  3. 动态密钥注入式 ζ_n=(K[n mod N]⊻(n≪3))/2³² 是几乎零成本的防退化+扩钥手段，可直接复用；
  4. FPGA 工程细节务实：Q8.16 定点、扩散 FIFO 缓存前项、特征序列只占一份 8-bit——LUTRAM 0.60%/DSP 3.22% 的"轻逻辑重存储"画像对毕设硬件选型有参考；
  5. **BPP 内存效率指标**与跨平台能效对比（Table VIII）是写硬件实验章节的现成范式；
  6. 罕见的"实现侧安全自我批评"（密钥管理攻击面 + 自认证方向）提示了混沌加密硬件论文的审稿关注点。
