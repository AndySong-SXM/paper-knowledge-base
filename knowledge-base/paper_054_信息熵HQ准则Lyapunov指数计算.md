## 二、研究背景与问题

### 2.1 研究背景

最大Lyapunov指数(Largest Lyapunov Exponent, LE)是判断时间序列是否处于混沌状态的核心判据之一。当动力学系统的最大Lyapunov指数大于零时，系统处于混沌状态。在实际工程应用中（如故障信号实时诊断），从实测时间序列准确计算Lyapunov指数具有重要意义。

### 2.2 现有方法的局限性

| 方法 | 代表工作 | 局限性 |
|------|---------|--------|
| **轨道跟踪法** | Wolf et al. (1985) | 受参数影响大，计算精确度较差 |
| **小数据量法** | Rosenstein et al. (1993) | 参数选取存在不足，相空间重构参数独立求解 |
| **改进互信息法** | 蒋爱华等 (2015) | 仅优化时间延迟，未考虑嵌入维数与时间延迟的耦合关系 |
| **空间栅格法** | 杨爱波等 (2012) | 计算速度快，但对噪声鲁棒性不佳 |
| **kd树算法** | 刘树勇等 (2012) | 提高邻近点搜索效率，但未解决参数选取问题 |
| **加权平均法** | 杨永锋等 (2012) | 使用最大无波动区间作为拟合区域，便捷但精度有限 |
| **多延迟点均值法** | 李彬彬 (2011) | 过程简单，但误差较大 |

### 2.3 核心问题

小数据量法在实际应用中存在两个关键环节的不足：

1. **相空间重构参数确定缺乏整体性**：传统方法将嵌入维数 $m$ 和时间延迟 $\tau$ 分别独立求解，无法保持原动力系统的整体特性，导致重构的相空间并非最优。

2. **邻近点个数选取主观性强**：邻近点数量太少导致计算精度差，太多则使计算繁琐。通常采用固定邻近点个数法或固定邻域半径法，缺乏足够的说服力。

## 三、核心方法与创新点

### 3.1 整体思路

本文提出一种**改进的小数据量法**，通过两个关键改进解决上述问题：
- 利用**信息熵模型**联合优化相空间重构参数 $(m, \tau)$
- 利用**HQ准则**自动确定最优邻近点个数 $K$

### 3.2 信息熵优化相空间重构参数

#### 3.2.1 理论基础

根据Takens嵌入定理，对于混沌时间序列 $x(1), x(2), \ldots, x(n)$，存在合适的嵌入维数 $m$ 和时间延迟 $\tau$ 使得重构相空间：

$$X(n) = (x(n), x(n+\tau), \ldots, x(n+(m-1)\tau)) \in \mathbb{R}^m$$

与原混沌系统具有等价关系。即存在映射 $F: \mathbb{R}^m \to \mathbb{R}^m$ 使得：

$$X(n+\tau) = F(X(n)), \quad n = 1, 2, \ldots$$

其分量形式为：

$$x(n+j\tau) = f(x(n), x(n+\tau), \ldots, x(n+(j-1)\tau)), \quad j = 1, 2, \ldots, m$$

化简后：

$$x(n+m\tau) = f(x(n), x(n+\tau), \ldots, x(n+(m-1)\tau))$$

#### 3.2.2 信息熵模型建立

**基本定义**：
- **信息熵**（描述变量不确定性）：
  $$H(X) = -\sum_{i=1}^{n} p(x_i) \lg p(x_i)$$

- **联合熵**：
  $$H(X, Y) = -\sum_{i=1}^{n}\sum_{j=1}^{k} p(x_i, y_j) \lg p(x_i, y_j)$$

- **条件熵**（Y已知时X遗留的不确定性）：
  $$H(X|Y) = -\sum_{i=1}^{n}\sum_{j=1}^{k} p(x_i, y_j) \lg p(x_i|y_j)$$

**关键关系式**：
$$H(X|Y) = H(X, Y) - H(Y)$$

当 $H(X|Y) = 0$ 时，表示Y已知后X的不确定性可以完全消除，即X可以由Y完全确定。

#### 3.2.3 优化模型

记 $X_1 = x(n), X_2 = x(n+\tau), \ldots, X_m = x(n+(m-1)\tau), X_{m+1} = x(n+m\tau)$

**目标函数**：
$$\min H(m, \tau) = H(X_{m+1} | X_1, X_2, \ldots, X_m)$$

**约束条件**：$m$ 和 $\tau$ 为非负整数

利用条件熵与联合熵的关系，转化为：
$$\min H(m, \tau) = H(X_1, X_2, \ldots, X_m, X_{m+1}) - H(X_1, X_2, \ldots, X_m)$$

#### 3.2.4 遗传算法求解

由于熵函数复杂，采用遗传算法(GA)进行优化：

| 步骤 | 内容 |
|------|------|
| **编码** | 参数 $m$ 和 $\tau$ 采用二进制编码 |
| **初始群体** | 群体规模 $Q \in [30, 80]$ |
| **适应值函数** | $fit(x) = H(X_1, \ldots, X_{m+1}) - H(X_1, \ldots, X_m)$ |
| **选择算子** | 比例选择算子 |
| **交叉算子** | 两点交叉，交叉概率 $p_c \in (0.7, 0.95)$ |
| **变异算子** | 基本位变异，变异概率 $p_m \in (0.01, 0.2)$ |
| **终止条件** | 最大迭代次数 $T < 100$ |

### 3.3 HQ准则确定邻近点个数

#### 3.3.1 从AIC准则到HQ准则

**AIC准则**（赤池信息准则）用于平衡模型拟合精度与复杂度：
$$\text{AIC}(p, q) = \ln\sigma^2 + \frac{2(p+q+1)}{N}$$

**HQ准则**（Hannan-Quinn定阶准则）对AIC进行了完善：
$$\Phi(p, q) = \ln\sigma^2 + \frac{D \cdot \ln(\ln N)}{N}(p + q + 1)$$

其中 $D > 2$ 为权重常数。

#### 3.3.2 应用于邻近点个数选择

将HQ准则应用于邻近点个数 $K$ 的选择：

$$\Phi(K) = \ln\sigma^2(K) + K \cdot \frac{D \cdot \ln(\ln N)}{N}$$

其中归一化均方误差：
$$\sigma^2 = \frac{1}{l \cdot n_a} \sum_{i=1}^{l} \sum_{j=1}^{n_a} \left( \frac{x[v(i)+j-1] - \bar{x}[v(i)+j-1]}{(1/N)\sum_{i=1}^{N}[x(i)-\bar{x}]^2} \right)^2$$

**参数设置**：$l = 200, n_a = 3, D = 8$

**最优邻近点个数**：使 $\Phi(K)$ 取得最小值的 $K$

### 3.4 创新点总结

| 创新点 | 说明 |
|--------|------|
| **联合优化重构参数** | 首次将信息熵模型同时用于嵌入维数 $m$ 和时间延迟 $\tau$ 的联合优化，克服了独立求解的局限性 |
| **保持动力学关系** | 信息熵优化保证了重构后仍保持原系统的动力学关系 |
| **自动确定邻近点** | 利用HQ准则自动确定最优邻近点个数，避免了主观经验选取 |
| **提高抗噪性** | 通过优化参数选取，显著提高了算法对噪声的鲁棒性 |

## 四、实验设计与结果

### 4.1 实验一：Lorenz系统

**系统方程**：
$$\begin{cases} x' = -\sigma(x - y) \\ y' = -xz + rx - y \\ z' = xy - bz \end{cases}$$

**参数**：$\sigma = 10, r = 28, b = 8/3$
**初始条件**：$x(0) = 1, y(0) = 0, z(0) = 1$
**求解方法**：四阶Runge-Kutta法，步长0.02
**数据集**：7500个点，去除前5000个暂态点，取后2500个点归一化到 $[0, 1]$，原始数据选前2000个点

**最优参数**：
- 嵌入维数 $m = 9$
- 时间延迟 $\tau = 4$
- 邻近点个数 $K = 11$（HQ准则最小值）

**计算结果对比**：

| 方法 | LE值 | 误差(%) |
|------|------|---------|
| 小数据量法 | 2.8977 | 6.8 |
| 文献[5]方法 | 2.9032 | 6.6 |
| **本文方法** | **3.0373** | **2.3** |
| 标准值[13] | 3.1096 | - |

### 4.2 实验二：含噪声Henon系统

**系统方程**：
$$y_{i+1} = 1 - ay_i^2 + by_{i-1}$$

**参数**：$a = 1.4, b = 0.3$
**初始条件**：$y_1 = y_2 = 0.5$
**数据集**：去除前2000个点，取后2000点

**最优参数**：
- 嵌入维数 $m = 2$
- 时间延迟 $\tau = 1$
- 邻近点个数 $K = 5$（HQ准则最小值）

**不同噪声水平下的计算结果**：

| 噪声水平 | 方法 | LE值 | 误差(%) |
|----------|------|------|---------|
| **10%** | 小数据量法 | 0.4268 | 2.1 |
| | 文献[5]方法 | 0.4242 | 1.5 |
| | **本文方法** | **0.4199** | **0.5** |
| **30%** | 小数据量法 | 0.4276 | 2.4 |
| | 文献[5]方法 | 0.4259 | 1.9 |
| | **本文方法** | **0.4237** | **1.4** |
| **50%** | 小数据量法 | 0.4310 | 3.1 |

| | **本文方法** | **0.4266** | **2.1** |
| **标准值[13]** | | 0.4180 | - |

### 4.3 实验结论

1. **准确性**：本文方法计算Lorenz系统的LE误差仅为2.3%，显著优于传统小数据量法(6.8%)和文献[5]方法(6.6%)
2. **鲁棒性**：即使在50%噪声水平下，本文方法的误差(2.1%)仍低于其他方法在10%噪声下的误差
3. **参数自适应**：信息熵和HQ准则能够根据系统特性自动确定最优参数，无需人工干预

## 五、主要结论

1. **信息熵联合优化重构参数**：将信息熵应用于相空间重构参数的确定，保证了嵌入维数 $m$ 和时间延迟 $\tau$ 之间的相互联系性，扩充了两个重构参数的整体性关系，实现了对重构参数的优化求解，同时保持重构后的动力学关系。

2. **HQ准则自动确定邻近点个数**：利用HQ准则确定邻近点个数，可以消除引入质量差的邻近点和伪邻近点对计算的不利影响，有效增加了计算准确性。

3. **方法可行性验证**：仿真实验表明，改进的小数据量法在计算最大Lyapunov指数时具有良好的准确性，对噪声具有良好的鲁棒性。

## 六、批判性评价

### 6.1 优点

1. **理论框架清晰**：信息熵与相空间重构的结合具有明确的数学基础，条件熵 $H(X_{m+1}|X_1,\ldots,X_m) \to 0$ 的物理意义明确
2. **方法系统性**：同时解决了相空间重构和邻近点选取两个关键问题，而非孤立地改进某一方面
3. **实验验证充分**：在经典Lorenz系统和Henon系统上进行了验证，并测试了多种噪声水平
4. **工程实用性强**：小数据量法本身适用于不完全数据，改进后更适合实际工程应用

### 6.2 局限性与不足

1. **遗传算法的计算开销**：遗传算法虽然避免了传统优化算法的缺点，但本身计算量较大，对于实时应用可能存在效率问题
2. **参数设置经验性**：遗传算法中的群体规模、交叉概率、变异概率等仍需经验设定
3. **HQ准则中D值的选取**：$D = 8$ 的选取缺乏严格的理论推导，不同系统可能需要不同的D值
4. **测试系统有限**：仅在Lorenz和Henon两个经典系统上验证，对于更复杂的实际工程信号（如轴承故障信号、心电信号等）的适用性有待进一步验证
5. **高维系统未涉及**：对于高维混沌系统（如超混沌系统），该方法的有效性尚未验证

### 6.3 改进方向

1. 探索更高效的优化算法（如粒子群优化、差分进化等）替代遗传算法，提高计算效率
2. 研究HQ准则中权重参数 $D$ 的自适应选取方法
3. 在更多实际工程数据集上验证方法的普适性
4. 将该方法扩展到多变量时间序列和高维混沌系统

## 八、关键公式速查

### 8.1 信息熵相关

**信息熵**：
$$H(X) = -\sum_{i=1}^{n} p(x_i) \lg p(x_i)$$

**联合熵**：
$$H(X, Y) = -\sum_{i=1}^{n}\sum_{j=1}^{k} p(x_i, y_j) \lg p(x_i, y_j)$$

**条件熵**：
$$H(X|Y) = H(X, Y) - H(Y)$$

### 8.2 相空间重构优化模型

**目标函数**：
$$\min H(m, \tau) = H(X_1, X_2, \ldots, X_m, X_{m+1}) - H(X_1, X_2, \ldots, X_m)$$

其中 $X_j = x(n + (j-1)\tau), \quad j = 1, 2, \ldots, m+1$

### 8.3 HQ准则

$$\Phi(K) = \ln\sigma^2(K) + K \cdot \frac{D \cdot \ln(\ln N)}{N}$$

**归一化均方误差**：
$$\sigma^2 = \frac{1}{l \cdot n_a} \sum_{i=1}^{l} \sum_{j=1}^{n_a} \left( \frac{x[v(i)+j-1] - \bar{x}[v(i)+j-1]}{(1/N)\sum_{i=1}^{N}[x(i)-\bar{x}]^2} \right)^2$$

### 8.4 测试系统

**Lorenz系统**：
$$\begin{cases} x' = -\sigma(x - y) \\ y' = -xz + rx - y \\ z' = xy - bz \end{cases}$$

**Henon映射**：
$$y_{i+1} = 1 - ay_i^2 + by_{i-1}$$
