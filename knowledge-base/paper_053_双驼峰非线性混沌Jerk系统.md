## 二、研究背景与问题

### 2.1 研究背景

**Jerk系统的物理意义**：
Jerk（加加速度）定义为加速度对时间的变化率，即力的变化率。Jerk系统是一类特殊的三阶自治常微分方程系统，形式为：

$$\dddot{x} = J(x, \dot{x}, \ddot{x})$$

其中 $J$ 为jerk函数。Jerk系统在自然界和工程领域广泛存在：
- **机械工程**：旋转和滑动物体模型、机械臂、运输系统
- **航空航天**：航天器姿态控制、轨道机动
- **神经科学**：多关节器官运动建模（如手臂运动）
- **娱乐设施**：过山车等游乐设施中的急动设计

**Jerk系统的研究现状**：
- Gottlieb (1996) 首次提出jerk系统可以产生混沌响应
- Sprott 列举了多种可产生混沌和多稳态的jerk系统
- 已有研究涵盖：立方非线性、正弦非线性、双曲正弦非线性、二次非线性、忆阻器-based jerk系统等

### 2.2 研究动机与问题

**现有研究的不足**：
1. 大多数jerk系统采用简单的单峰非线性（如立方、正弦等）
2. 双峰（bimodal）非线性在物理系统中普遍存在（如Ikedasystem），但在jerk系统中研究较少
3. 缺乏对非线性形状参数调控混沌行为的系统研究

**本文核心问题**：
> 如何设计一个具有双驼峰（bimodal）非线性的新型jerk系统，使其能够通过调控非线性形状参数产生混沌行为，并易于在电子电路中实现？

### 2.3 双驼峰非线性的物理意义

双驼峰非线性在自然界中广泛存在：
- **神经网络**：激活函数（如tanh）的饱和特性
- **电子电路**：非理想运算放大器的特性曲线
- **磁性系统**：顺磁和铁磁系统的磁化曲线

## 三、核心方法与创新点

### 3.1 系统模型

**三阶Jerk微分方程**：

$$\dddot{x} + a\ddot{x} + \dot{x} - bG(x) = 0$$

其中 $a, b > 0$ 为系统参数，$G(\cdot)$ 为非线性函数。

**状态空间形式**：

$$\begin{cases}
\dot{x}_1 = x_2 \\
\dot{x}_2 = x_3 \\
\dot{x}_3 = -ax_3 - x_2 + bG(x_1)
\end{cases}$$

### 3.2 双驼峰非线性函数（核心创新）

**非线性函数形式**：

$$G(u) = -nu + m\tanh(lu)$$

其中 $n, m, l > 0$ 为控制非线性形状的参数。

**约束条件**：$n < ml$（保证双驼峰特性）

**物理意义**：
- **线性部分** $-nu$：常见于自然系统（如电路的电流-电压关系、放大器线性区增益）
- **非线性部分** $m\tanh(lu)$：描述饱和型非线性（如神经网络激活函数、非理想运放特性）

**双驼峰特性**：
- 通过调节 $n, m, l$ 可以在保持双峰形态的前提下改变非线性的具体形状
- 图1展示了4组不同参数下的非线性函数形态

### 3.3 主要创新点

| 创新点 | 说明 |
|--------|------|
| **新型双驼峰非线性** | 首次将 $-nu + m\tanh(lu)$ 形式的非线性引入jerk系统 |
| **参数调控混沌** | 系统可通过调控非线性形状参数（$n, m, l$）产生混沌，保持双峰形态 |
| **解析Hopf分岔条件** | 获得了Hopf分岔发生的闭式数学条件 |
| **硬件电路验证** | 使用通用运放和DAQ系统在LabView环境中实现了硬件验证 |
| **噪声鲁棒性分析** | 实验研究了噪声、波动、参数失配等物理环境的影响 |

## 四、实验设计与结果

### 4.1 理论分析

#### 4.1.1 对称性
系统方程在变换 $(x_1, x_2, x_3) \rightarrow (-x_1, -x_2, -x_3)$ 下保持不变，因此系统具有对称性。

#### 4.1.2 耗散性
体积收缩率：$\nabla \cdot \mathbf{f}(x) = -a$

由于 $a > 0$，系统为耗散系统，相空间体积指数收缩：$V(t) = V(0)e^{-at}$，轨道渐近趋于奇怪吸引子。

#### 4.1.3 不动点分析
- **平凡不动点**：$FP_0 = (0, 0, 0)$ — 始终不稳定
- **非平凡不动点**：$FP_{1,2} = (\pm p, 0, 0)$ — 由超越方程 $np = m\tanh(lp)$ 的解确定

**Hopf分岔条件**（核心解析结果）：

$$a_{HB} = b[n - lm\text{sech}^2(lp)]$$

其中 $a_{HB}$ 为Hopf分岔临界值。

### 4.2 数值实验

**仿真设置**：
- 算法：四阶Runge-Kutta
- 步长：$h = 0.01$
- 初始条件：$\{x_1(0), x_2(0), x_3(0)\} = \{0.5, 0.3, 0.1\}$
- 默认非线性参数：$n = 2.2, m = 1, l = 10$

#### 4.2.1 两参数空间分析（$a$-$b$ 空间）

| 区域 | 动力学行为 | 特征 |
|------|-----------|------|
| 蓝色区域 | 不动点 | 无振荡 |
| 绿色区域 | 周期振荡 | 稳定极限环 |
| 红色区域 | 混沌 | 正Lyapunov指数 |
| 白色区域 | 无界解 | 系统发散 |

#### 4.2.2 单参数分岔分析

**以 $b$ 为控制参数**（固定 $a = 0.7$）：
- $b \approx 0.316$：Hopf分岔，周期-1振荡出现
- $b \approx 0.413$：进入混沌区域
- 分岔图、LE谱、Kaplan-Yorke维度三者一致

**以 $a$ 为控制参数**（固定 $b = 0.3$）：
- 与 $b$ 变化相反：小 $a$ 时混沌，增大 $a$ 进入稳定不动点
- $a \approx 0.66$：逆Hopf分岔

#### 4.2.3 Lyapunov指数与维度

Kaplan-Yorke维度公式：

$$D_{KY} = j + \frac{\sum_{i=1}^{j} L_i}{|L_{j+1}|}$$

其中 $L_i$ 为Lyapunov指数，$j$ 满足 $\sum_{i=1}^{j} L_i \geq 0$ 且 $\sum_{i=1}^{j+1} L_i < 0$。

### 4.3 非线性形状参数的影响

**研究参数 $n, m, l$ 对系统动力学的影响**：

| 参数变化 | 影响 |
|----------|------|
| $n$ 增大 | 改变线性部分斜率，影响不动点位置 |
| $m$ 增大 | 增强非线性饱和效应 |
| $l$ 增大 | 改变tanh函数的陡峭程度 |

**关键发现**：
- 在保持 $n < ml$ 约束下，系统可在宽参数范围内产生混沌
- 非线性形状的变化直接决定系统是否进入混沌区域

### 4.4 硬件电路实验

#### 4.4.1 电路设计

**核心电路元件**：
- 运算放大器（op-amp）：实现积分、加法、反相等功能
- 模拟乘法器（AD633JN）：实现非线性项
- 精密电位器：调节参数 $a$ 和 $b$

**电路实现的关键方程**：

$$f(V_1) = -\frac{R_5}{R_4}V_1 + \frac{R_5}{R_3}V_{sat}\tanh\left(\omega \frac{R_2}{R_1}V_1\right)$$

**无量纲化对应关系**：
- $x_1 = V_1/V_{sat}$, $x_2 = V_2/V_{sat}$, $x_3 = V_3/V_{sat}$
- $a = R/R_a$, $b = R/R_7$
- $n = R_5/R_4$, $m = R_5/R_3$, $l = R_2/R_1$

#### 4.4.2 实验参数

| 元件 | 参数值 |
|------|--------|
| $R_1$ | 1.8 kΩ |
| $R_2$ | 18 kΩ |
| $R_3$ | 84.2 kΩ |
| $R_4$ | 19.5 kΩ |
| $R_5$ | 10 kΩ |
| $R_6$ | 1 kΩ |
| $R_8$ | 1 kΩ |
| $R$ | 10 kΩ |
| $C$ | 0.1 μF |

#### 4.4.3 实验结果

**时域波形与相图**：
- 实验观测到的时序图和相平面图与数值模拟结果高度一致
- 在 $V_1$-$V_2$、$V_2$-$V_3$、$V_3$-$V_1$ 平面均观察到混沌吸引子

**实验分岔图**：
- 使用DAQ系统和LabView编程获取实验分岔图

- 实验分岔图与数值分岔图（图4a）高度吻合

**物理环境鲁棒性**：
- 实验验证了系统在噪声、波动、参数失配等实际物理环境下的稳定性
- 结果表明系统具有良好的物理可实现性和鲁棒性

## 五、主要结论

### 5.1 核心结论

1. **新型混沌Jerk系统**：提出了具有双驼峰非线性 $G(u) = -nu + m\tanh(lu)$ 的新型jerk系统，在保持双峰形态的前提下可通过参数调控产生混沌

2. **完整理论分析**：
   - 证明系统具有对称性
   - 证明系统为耗散系统（$\nabla \cdot \mathbf{f} = -a < 0$）
   - 获得Hopf分岔的解析条件：$a_{HB} = b[n - lm\text{sech}^2(lp)]$

3. **丰富动力学行为**：
   - 通过两参数和单参数分岔图、LE谱、KY维度全面刻画了系统动力学
   - 识别了不动点、周期振荡、混沌、无界解等多种动力学区域

4. **非线性形状调控**：系统混沌行为对控制非线性形状的参数 $n, m, l$ 敏感，为混沌控制提供了新途径

5. **硬件验证成功**：使用通用运放和DAQ系统在LabView环境中实现了系统，实验结果与理论/数值分析高度一致

### 5.2 应用价值

- **混沌信号源**：可作为易于集成的混沌发生器，用于通信、加密等领域
- **集成电路设计**：电路仅使用通用电子元件，易于IC实现
- **物理系统建模**：为理解自然界中双驼峰非线性系统的动力学提供参考

3. **同步方案设计**：设计合适的同步控制器，验证其在保密通信中的应用
4. **FPGA实现**：将系统移植到FPGA平台，提高集成度和实用性
5. **参数优化**：使用优化算法（如差分进化）寻找使LE最大的最优参数组合

$$\begin{cases}
\dot{x}_1 = x_2 \\
\dot{x}_2 = x_3 \\

$$G(u) = -nu + m\tanh(lu)$$

### 8.4 Hopf分岔条件

$$a_{HB} = b[n - lm\text{sech}^2(lp)]$$

### 8.5 耗散性

体积收缩率：$\nabla \cdot \mathbf{f} = -a < 0$

相空间体积演化：$V(t) = V(0)e^{-at}$

### 8.6 Kaplan-Yorke维度

$$D_{KY} = j + \frac{\sum_{i=1}^{j} L_i}{|L_{j+1}|}$$
