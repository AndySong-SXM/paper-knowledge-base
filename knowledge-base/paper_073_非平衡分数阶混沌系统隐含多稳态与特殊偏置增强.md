## 二、研究背景与问题

### 2.1 研究动机

混沌系统自Lorenz发现第一个混沌吸引子以来，在气象学、金融学、生物学和电子电路等领域得到了广泛应用。为了获得更复杂的混沌系统，研究者们不断追求高维混沌系统。分数阶系统能够更真实地反映现实世界，且整数阶只是分数阶的特例，因此对分数阶混沌系统的研究具有重要理论意义。

### 2.2 核心科学问题

1. **无平衡点混沌系统**：传统混沌系统通常依赖不稳定平衡点产生自激吸引子，但无平衡点系统能够产生隐藏吸引子，这类系统具有更高的灵敏度和更丰富的动力学行为。
2. **偏置增强（Offset-Boosting）**：现有研究中的偏置增强大多通过改变初始值实现，对工程应用存在潜在威胁；少数通过参数控制的研究也仅能实现单方向偏移，且吸引子形状不变。
3. **隐藏多稳态**：现有对多稳态的研究主要集中在自激吸引子的多稳态上，对无平衡点系统中隐藏吸引子的多稳态研究较少。

### 2.3 论文定位

本文基于Sprott系统构建了一个新的五维分数阶混沌系统，该系统无平衡点，能够产生隐藏吸引子，并具有特殊的三方向偏置增强和隐藏多稳态现象。通过Adomian分解算法进行分数阶求解，并利用FPGA完成了硬件实现验证。

## 三、核心方法与创新点

### 3.1 系统模型构建

基于Sprott系统（式2），扩展为五维分数阶混沌系统（式3）：

$$
\begin{cases}
D^q x = a y \\
D^q y = -x - yz + b w \\
D^q z = 1 - y^2 \\
D^q w = c z + \text{sgn}(x) - x \\
D^q u = w - u
\end{cases}
$$

其中 $x, y, z, w, u$ 为系统状态变量，$a, b, c$ 为系统参数，$q$ 为分数阶阶次（$0 < q < 1$）。采用Caputo分数阶微分定义。

**系统特征**：
- 方程右侧含符号函数 $\text{sgn}(x)$，引入非线性不连续性
- 第五维 $u$ 通过 $w$ 耦合，形成单向链式结构
- 无平衡点（令右侧为零无解），因此所有吸引子均为**隐藏吸引子**

### 3.2 Adomian分解算法求解

采用Adomian分解法对分数阶系统进行数值求解，将系统分解为线性项、非线性项和常数项，通过递推迭代获得各级近似解。

### 3.3 核心创新点

| 创新点 | 具体描述 | 新颖性 |
|:---|------|:---:|
| **无平衡点5D分数阶混沌系统** | 基于Sprott系统扩展，引入符号函数和额外维度，无任何平衡点 | ⭐⭐⭐ |
| **特殊三方向偏置增强** | 单一控制参数 $n$（加入第4个方程）同时使 $x, w, u$ 三个变量产生偏移，且吸引子**形状随之改变** | ⭐⭐⭐⭐ |
| **隐藏吸引子多稳态** | 在无平衡点系统中发现对称/非对称共存吸引子（周期-1、周期-2、周期-3、混沌共存） | ⭐⭐⭐ |
| **间歇混沌** | 在固定参数下系统在混沌态和周期态之间交替切换 | ⭐⭐ |
| **复杂度引导的初始值选择** | 基于C₀复杂度和SE复杂度分析，选择使系统复杂度最高的初始值 | ⭐⭐ |

### 3.4 偏置增强机制（最具创新性）

在系统(3)的第四个方程中引入偏置控制器 $n$：

$$D^q w = c z + \text{sgn}(x) - x - (u + n)$$

- **已有研究的局限**：偏置增强通常仅影响单个变量，且吸引子形状不变，仅位置平移
- **本文的突破**：单一参数 $n$ 同时控制 $x, w, u$ 三个方向偏移，且**吸引子结构随 $n$ 变化**——当 $n$ 取不同值时（如 $n = -75, -50, -30, 0, 5, 35, 55, 75$），吸引子不仅平移，其形状也发生演化
- 对称性：$n$ 取正负值时吸引子结构对称
- 该现象在以往文献中**未见报道**

## 四、实验设计与结果

### 4.1 动力学分析方法

| 方法 | 目的 | 发现 |
|:---|------|------|
| Lyapunov指数谱 | 验证混沌特性 | 系统存在正Lyapunov指数，确认混沌 |
| 相图 | 可视化吸引子结构 | 隐藏吸引子具有复杂拓扑结构 |
| SALI (Smaller Alignment Index) 测试 | 区分混沌与有序 | SALI趋于0，进一步确认混沌 |
| 分岔图 | 分析参数对动力学的影响 | 以阶次 $q$ 和参数 $b$ 为分岔参数，观察到周期窗口和混沌区域 |
| 双参数分岔 | 分析参数耦合影响 | 揭示参数空间中混沌与周期的分布 |

### 4.2 间歇混沌

固定参数 $a = 0.9, b = 3, c = 8, q = 0.95$，初始值 $(1, 1, 1, 1, 1)$，观察到：
- $t \in [0, 142.3\text{s}]$：混沌态
- $t \in [142.3, 545.3\text{s}]$：周期态（持续约500s）
- $t \in [545.3, 645.2\text{s}]$：再次进入混沌态（约100s）
- $t > 645.2\text{s}$：永久性周期态

表明系统在固定参数下具有**不可预测的状态切换**行为。

### 4.3 隐藏多稳态

固定参数 $a = 1, b = 3, c = 8, q = 0.95$，通过改变初始值 $(x(0), 1, 1, 1, 1)$ 和 $(1, 1, 1, 1, u(0))$：

| 初始条件 | 共存吸引子类型 |
|:---|------|
| $x(0) = \pm 2$ | 对称周期-2共存 |
| $x(0) = \pm 1.5$ | 对称周期-1共存 |
| $x(0) = \pm 1$ | 对称周期-3共存 |
| $x(0) = -2$ 和 $x(0) = 0.5$ | 非对称周期-1与周期-3共存 |
| $x(0) = -2$ 和 $x(0) = 0.2$ | 非对称周期-1与周期-2共存 |
| $u(0) = 1, 6, -0.3$ | 非对称周期-2、周期-3与混沌共存 |

**关键发现**：无平衡点系统的隐藏多稳态比自激吸引子的多稳态更灵活，为安全通信提供更多可能性。

### 4.4 复杂度分析

采用两种复杂度算法：
- **C₀复杂度**：将序列分为规则部分和非规则部分，计算非规则部分的占比
- **SE复杂度（谱熵复杂度）**：基于傅里叶变换的频谱熵

通过三维复杂度图分析初始值对复杂度的影响：
- $y(0)$ 和 $w(0)$ 对系统复杂度几乎无影响
- $x(0)$ 和 $u(0)$ 共同影响系统复杂度
- 当 $x(0) \approx u(0) \approx 1$ 时系统复杂度最高

### 4.5 FPGA硬件实现

采用FPGA（现场可编程门阵列）实现系统(3)的数字电路：
- 离散化步长 $d = 0.01$
- 计算机通过DAC将信号传输至FPGA
- 示波器观察相图
- 实验结果与数值仿真**完全一致**，验证了系统的物理可实现性

## 五、主要结论

1. 基于Sprott系统构建了一个新的五维分数阶混沌系统，该系统**无平衡点**，所有吸引子均为隐藏吸引子。
2. 通过Lyapunov指数、相图和SALI测试验证了系统的混沌特性。
3. 发现了**间歇混沌**现象：系统在固定参数下自动在混沌与周期之间切换。
4. 发现了**特殊的三方向偏置增强**：单一控制参数使系统同时沿 $x, w, u$ 三个方向偏移，且吸引子形状随之改变，该现象在以往文献中未见报道。
5. 通过改变初始值揭示了系统的**隐藏多稳态**：包括对称/非对称的周期共存和混沌共存。
6. 基于C₀和SE复杂度算法，分析了初始值对系统复杂度的影响，筛选出最优初始值。
7. FPGA硬件实验验证了数值仿真的正确性，证明了系统的物理可实现性。
8. 该系统具有高复杂度和不可预测性，特别适用于**安全通信**领域。

### 6.2 不足与局限

| 方面 | 评价 |
|:---|------|

## 八、关键公式速查

### 系统方程（Caputo分数阶）

$$\begin{cases} D^q x = a y \\ D^q y = -x - yz + b w \\ D^q z = 1 - y^2 \\ D^q w = c z + \text{sgn}(x) - x \\ D^q u = w - u \end{cases}$$

### 偏置增强控制方程

$$D^q w = c z + \text{sgn}(x) - x - (u + n)$$

参数 $n$ 为偏置控制器，控制 $x, w, u$ 三方向偏移。

### 参数设置

- 典型混沌参数：$a = 1, b = 3, c = 8, q = 0.95$
- 间歇混沌参数：$a = 0.9, b = 3, c = 8, q = 0.95$
- 初始值：$(1, 1, 1, 1, 1)$

### C₀复杂度定义

$$C_0 = \frac{\sum_{k=0}^{S-1} |A(k) - \tilde{A}(k)|^2}{\sum_{k=0}^{S-1} |A(k)|^2}$$

其中 $A(k)$ 为原始序列，$\tilde{A}(k)$ 为规则部分。
