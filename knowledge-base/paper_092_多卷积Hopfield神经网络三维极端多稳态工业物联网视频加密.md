## 🎯 研究动机与创新点

IIoT 监控产生大量含敏感个人与商业信息的视频数据，传输安全措施不足导致泄密事件频发。混沌系统因初值/参数敏感性与类噪声特性适合视频加密；忆阻器可模拟电磁辐射对神经元的影响；HNN 因高度非线性可产生类似大脑的混沌动力学。已有忆阻 HNN 多涡卷研究停留在 1-D/2-D 多稳态，**三个方向的多稳态现象尚未见报道**。本文贡献：

1. **改进多分段非线性非理想磁控忆阻器模型**（式1-3）：忆导 W(φ)=a+bφ，内部状态 φ̇ = cv − d·f(φ)，f(φ) 用 sign 函数构造奇（f1，N 段）/偶（f2，M 段）两种分段形式，整数参数 N、M 控制段数——模型简单、利于硬件资源分配。
2. **电磁辐射下三个递进场景的 MHNN 系统**（式5/6/7）：单忆阻器→1-D 多涡卷+1-D 初值偏移增强；双忆阻器→2-D 多涡卷+2-D 偏移增强；三忆阻器→**3-D 多涡卷 + 3-D 初值偏移增强（神经网络中首次报道）**，三种场景均观察到极端多稳态。
3. **基于 MHNN 的 IIoT 企业视频加密方案**并在树莓派（Raspberry Pi）平台实现：逐帧加密 46 s 工厂监控视频，信息熵 7.9973。
4. **FPGA 数字硬件实现**（AX7020 / Zynq-7020），示波器相图与 MATLAB 仿真一致，验证可行性。

## 🔧 核心方法

### 忆阻器模型（式1-3）

- i = W(φ)v = (a + bφ)v，φ̇ = cv − d·f(φ)，a、b、c、d 可调。
- 分段函数：f1(φ)（奇，N∈{1,2,3,…}）在 φ=2i−1 和 φ=2i+1 处折叠；f2(φ)（偶，M）在 φ=0、±2j 处折叠，sgn(·) 为符号函数。
- 指纹验证（Fig.1，a=0.06, b=0.02, c=1.5, d=1.5，V_m=A·sin(Ft)）：幅值增大→迟滞环面积增大；频率升高→环收缩过原点，高频退化线性——三大忆阻指纹成立。

### 三个场景的 MHNN 系统

3 神经元 tanh-HNN 基础（式4）：C ẋ_i = −x_i/R_i + Σ w_ij·tanh(x_j) + I_ext。三场景分别在神经元 1 / 神经元 1+2 / 全部 3 个神经元上施加忆阻器电磁辐照：

- **场景 1（式5，4D）**：k1∈[−0.1, 0.1] 时 LE1 恒 >0（混沌）；N=1 时图解法（H1、H2 曲线交点，式8）得 **9 个平衡点**——E2,5,8 为不稳定 index-1 鞍点（λ1=2.2755, λ2=−1.1876, λ3,4=±2.1057i），其余 6 个为 index-2 鞍焦点（含正实部共轭复根 ±2.7789i），对应三对双涡卷；随 N 增大平衡点增多，涡卷沿 φ1 轴 1-D 扩展。初值 [x0, 0.1, 0.1, 0±i]（i∈{−4,−2,0,2,4}）→ 吸引盆中 5 个色区 ⇔ 5 个共存双涡卷（**1-D 初值偏移增强 / 极端多稳态**）。
- **场景 2（式6，5D）**：M1=M2=0 时 12 个平衡点 ⇔ 2×2 双涡卷（1、2 平面各扩展）；2-D 偏移增强初值 [0.1,0.1,0.1,0±i,0±j]（i,j∈{−2,0,2}）→ 平面上 **9 个共存吸引子**。
- **场景 3（式7，6D）**：三平面（φ1−φ3、φ2−φ1、φ3−φ2）分解图解法；M1=M2=0、N3=0 时 2×2×1 双涡卷；3-D 偏移增强初值 [0.1,0.1,0.1,0±i,0±j,0±k]（i,j,k∈{−2,−1,0,1,2}）→ **沿三个方向无限扩展的共存混沌吸引子**。

Table 2 对比：本文是唯一"任意方向可扩展 + 3-D 吸引子 + 整数控制参数 + 3-D 初值偏移 + 视频加密"全占的系统（Hu & Wang 2024、Lai 2024b、Lai 2022 均为 1-D/2-D 且方向不可扩展）。

### IIoT 视频加密方案（第 4 节）

- 场景链路：监控摄像头采集 → 终端加密 → 代理服务器分发 → 授权设备密钥解密。
- 平台：笔记本作发送端（192.168.20.195）+ 两台树莓派作中转/接收（论文中中转 IP 误写为 196.168.20.46）；视频源为 YouTube-8M 工厂模块视频，46 s，灰度，帧 640×318 统一缩到 256×256。
- 每帧加密三步：
  1. **混沌序列生成**：密钥（初始值 [0.1 0 0 0.1 0.1 0.1]，对应式7 的 6 个初值）用 ode45 求解系统(7) 得状态序列 X；
  2. **二维置乱**：对每个像素 (i,j) 由混沌序列生成置乱位置 k，交换 A(i,j) 与 A(k(1),k(2))；
  3. **2p8 扩散**：X 投影到 [0,255] 得 S，拆成 S1、S2 两个子序列，C(i,j) = A1(i,j) ⊕ S1(i,j) ⊕ S2(i,j)。
- 解密端持密钥逆向执行。

### FPGA 实现（第 5 节）

平台 ALINX AX7020（XC7Z020-2CLG400I）+ Vivado 2018.3；IEEE-754 单精度浮点 + 14 位定点（1 符号+4 整数+9 小数）；**RK-4 离散化、步长 0.001**；时钟周期 108×20 ns；DAC AN9767 + 示波器 GA1102CAL。实现了场景 1、2 的 1-D/2-D 多涡卷，示波器相图与 MATLAB 仿真一致。

## ⚠️ 不足与可借鉴之处

**不足**：
1. **加密结构单薄且较前作倒退**：仅帧内 2D 置乱 + 双序列 XOR 扩散，无 SHA-256/哈希密钥绑定、无 NIST 测试、无已知/选择明文攻击分析、无抗噪/裁剪鲁棒性测试——同团队 paper_091（Kong 2024）已做 SHA-256 明文绑定 + NIST 15 项全过，本文反而退回朴素结构。
2. **逐帧独立加密的密钥复用风险未讨论**：所有帧共用同一混沌初值密钥，若密钥流按帧重置，多帧共用密钥流下的已知明文/重放分析完全未涉及；也未利用视频时域冗余特性（I/P 帧、运动向量）。
3. 测试样本太少：只测第 100/300/500 三帧、仅灰度示例、帧尺寸降到 256×256；熵只报 7.9973 无逐帧统计。
4. 极端多稳态仅作动力学现象展示，**初值偏移未进入密钥设计**（白白浪费了三维密钥维度）。
5. FPGA 只验证动力学相图一致，未做加密算法上板、无 LUT/DSP 资源数据；RK4+0.001 步长的实时吞吐有限；且 FPGA 部分与树莓派加密部分脱节（两套独立实验）。
6. 细节瑕疵：中转树莓派 IP 写成 196.168.20.46；"doublescorll" 等拼写错误。

**可借鉴**：
1. **极简多分段 sign 函数忆阻器**：整数段数 N/M 直接控制涡卷数，sign 函数硬件实现代价低，RK4 可解——适合资源受限平台（STM32 亦可参考）。
2. **1D→2D→3D 递进的系统化构造套路**（场景 1/2/3 同框架逐层加忆阻器）与 Table 2 多维度对比表写法，可直接复用于综述或本子的"研究现状"部分。
3. **3-D 初值偏移增强为神经网络中首次报道**，可作为"多维极端多稳态"立论的最新引用依据（2025 年）。
4. **树莓派 sender-broker-receiver 轻量边端加密链路**，与 cipherflow 产品化方向（边缘设备数据加密）高度契合，工程部署细节（帧切分、代理转发）有参考价值。
5. FPGA 数值方案的稳妥默认配置：RK4 + IEEE-754 单精度 + 14 位定点输出，适合连续混沌上板快速复现。
