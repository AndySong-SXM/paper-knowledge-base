## 🎯 研究动机与创新点

现有多涡卷混沌系统（多项式函数法）普遍存在四个问题：模型复杂（多项式项数多、线性/非线性项多）、吸引子拓扑单一（同形态涡卷简单排列）、混沌信号不可控、电路实现资源消耗大。本文提出**扩展多涡卷混沌系统 EMSCS**（Expanded Multi-Scroll Chaotic System），核心创新：

1. **极简 4 维模型**：仅 8 项、1 个非线性项 + 1 个常数项 + 6 个线性项。基础系统(1)仅 1 非线性 + 1 常数 + 4 线性项，通过多段函数 k(z) 改造 ẋ 并增加一维 ẇ = gy − hw 即得多涡卷系统。
2. **"扩展"（expanded）形态**：涡卷沿每个相平面**单向**扩展（非网格状），大小递增；参数 a→3.2 时还出现**嵌套多涡卷吸引子**（nested multi-scroll attractor），形态介于单涡卷与扩展多涡卷之间，文献罕见。
3. **整个吸引子的幅度控制 + 偏置增强**：单参数 b 同步控制 x 信号的幅度与正向偏置（改变平衡点 x* = (cz*+d)/b）；双参数 g、l 对 w 信号实现部分幅度控制 + 任意位置线性偏置，可把单极性信号变为任意位置的双极性信号。是对**整个多涡卷吸引子**的控制，而非逐个涡卷。
4. **低资源电路实现**：模拟电路仅用 AD633（增益 0.1）+ LM741 + 电阻电容，4 个开关 S₁₋₄ 切换涡卷数（N=0→2 涡卷，N=1→3，N=2→4，N=3→5）。6 涡卷只需 14 个运放（对比文献[30]的 21 个）。
5. **遥感图像加密应用**：针对遥感图像传输易受噪声、数据丢失干扰的特点，设计单轮"分区+整体"置乱 + XOR 扩散算法，鲁棒性测试含 50% 数据丢失场景。

## 🔧 核心方法

### 系统模型

基础系统（α=0.8, β=0.5, d=2 时产生单涡卷混沌吸引子）：

```
ẋ = −αxz
ẏ = x − z − d
ż = y − βz
```

EMSCS 系统（式 3）：

```
ẋ = −a·x·k(z)
ẏ = b·x − c·z − d
ż = e·y − f·z
ẇ = g·y − h·w
```

多段非线性函数（式 4）：

```
k(z) = z − Σₙ₌₀..N [ μ·sgn(z) + ξ·(sgn(z+n) + sgn(z−n)) ]
```

N 为偶数时 μ=−1，n 取奇数则 ξ=0、取偶数则 ξ=1；N 为奇数时 μ=0，n 取偶数 ξ=0、取奇数 ξ=1。k(z) 产生 N+2 段 ⇒ 系统产生 **N+2 个涡卷**。

典型参数：a=2, b=10, c=3.7, d=20, e=10, f=5, g=10, h=10, N=1，初值 [1,1,1,1] ⇒ 扩展 3 涡卷。不同涡卷数对应 c 值：N=0→c=4.5（2 涡卷），N=1→c=3.7（3 涡卷），N=2→c=3.0（4 涡卷），N=3→c=2.3（5 涡卷）。

平衡点 S₁ = {((cz+d)/b, fz/e, z, gfz/(eh)) | k(z)=0}（index-2 不稳定鞍焦点）和 S₂ = (0, −df/(ce), −d/c, −dfg/(ceh))。特征值满足 Shil'nikov 条件 |δ/γ|<1 且 γδ<0（如扩展 3 涡卷 5 个平衡点的特征值均含 −10 实根与共轭复根 1.1794±7.2778i 等）。

### 加密算法（单轮）

- **密钥**：K = {a, b, c, e, f, x(0), y(0)}，精度 10⁻¹⁵；密钥空间 (10¹⁵)⁷ > 2³⁴⁸。
- **序列生成**：RK4 步长 ΔT=0.002 迭代 EMSCS，每 2000 次迭代加微扰 φₙ += ΔT·sin(φₙ) 防周期化；舍去前 H₀ 个暂态；序列×10¹⁰ 重排为 M×N 混沌矩阵。
- **置乱（分区+整体）**：像素矩阵与混沌矩阵同步扫描分四子块，子块 I–IV 分别用 {x*},{y*},{z*},{w*} 矩阵元素取 floor 后 mod M/N 得新坐标交换；随后整体置乱一轮（{x*} 元素 + 行号 i）。
- **扩散**：按 {x*} 计算目标坐标 (u,v)，Θ=P₁(u,v)，P₁(u,v)=P₁(i,j)⊕P₁(u,v)，P₁(i,j)=Θ（像素值互换 + XOR）。
- **计算复杂度**：O(7MN)，低于文献对比的 O(8MN+3MN·log MN/3+3M+3N)、O(14MN)、O(18MN)。

### 电路实现

AD633/LM741，±15V 供电，τ₀=100 时间尺度变换；k(z) 由运放+电阻网络实现（R₁₃₋₁₇=10kΩ, R₁₈=1kΩ, R₁₉₋₂₅=13.5kΩ, V₁₋₆=±1V/±2V/±3V），开关切换 N；R₃ 电位器调 c（22.222kΩ→2 涡卷，27.027kΩ→3 涡卷…）。

## 📊 实验与性能分析

### 动力学

- 分岔图/LE（Wolf 法，步长 0.001）：a∈[1.4,3.2] 范围内产生扩展 3 涡卷混沌；a=3.2 出现嵌套多涡卷。
- 样本熵（SE）对比：EMSCS 的 SE 值更大且标准差更小（复杂振荡遍及所有相平面）。

### NIST SP800-22

借用 Lai 等的 PRNG（IEEE 754 浮点第 28–35 位取 8 比特），120 条序列 × 10⁶ 比特，x/y/z/w 四路全部 15 项测试通过（P-value_T ≥ 0.0001，含 148 子项 Non-Overlapping Template、8 子项 Random Excursions、18 子项 Random Excursions Variant 的最坏值）。

### 加密安全性（USC-SIPI 遥感图像库）

| 指标 | 结果 |
|------|------|
| 相关系数 CC | 三方向均 ≈0（水平 0.0034 / 垂直 0.0003 / 对角 0.0037，平均量级 10⁻³） |
| 信息熵 | 7.9972–7.9998（256² 灰度 ~7.997，1024² 彩色 7.9998） |
| NPCR | 99.5911%–99.6150%（512² 彩色平均 99.6082%，1024² 平均 99.6093%/99.6097%） |
| UACI | 33.3940%–33.4899%（平均 ~33.45，接近理想 33.4635%） |
| 密钥敏感性 | 7 个密钥各加 10⁻¹⁵ 均完全解密失败 |
| 密钥空间 | (10¹⁵)⁷ > 2³⁴⁸（对比文献 2¹⁸⁶–2²⁰⁷） |
| 鲁棒性 | 2% 高斯噪声、2% 椒盐噪声解密清晰；3.8%/20%/50% 数据丢失仍可恢复主要信息 |

## ⚠️ 不足与可借鉴之处

**不足**：
1. **密钥与明文无关**：静态密钥 + 单轮结构，抗选择明文/已知明文攻击能力弱（论文未做此类攻击测试）。
2. 鲁棒性只有定性图片展示，无 PSNR/SSIM 定量数据。
3. "遥感图像加密"实际用的是 USC-SIPI 通用测试图，未针对遥感图像特性（大幅面、多光谱、压缩格式）做适配。
4. 硬件仅模拟电路实现，无 FPGA/DSP 数字实现；数字混沌有限精度问题未讨论。
5. 密钥空间 (10¹⁵)⁷ 的估计假设连续参数可达 10⁻¹⁵ 精度，实际数字实现达不到。

**可借鉴**：
1. **"少项极简系统 + 多段函数改造"的构造范式**：8 项 1 非线性即可生成可控多涡卷，比自己堆非线性项更省电路资源。
2. **整个吸引子的单参数幅度/偏置联控**（b 参数），适合工程信号调理（单极性→双极性）。
3. **开关切换涡卷数的电路设计**（S₁₋₄ + 电位器），把"涡卷数"变成硬件可选配置。
4. 置乱与扩散共用同一混沌矩阵同位置数据的坐标推导方式，实现简单、复杂度 O(7MN) 较低。

## 🔗 与知识库的关联

- **032号（Jerk 系统多涡卷 DSP）**：同属"简洁控制函数生成多涡卷"路线，但 032 用符号函数、(N+2) 涡卷规律、DSP 数字实现；本文用多段多项式函数、N+2 涡卷、模拟电路，且多了幅度/偏置联控。
- **015/028号（Yan 分形过程多涡卷）**：分形变换路线涡卷按 C₁×2ⁿ 翻倍、形态多变（燕子形等）；本文多项式路线涡卷单向扩展、可嵌套，是"特殊形态多涡卷"的另一种构造思路。
- **089号（双神经网络异质耦合 DNNHCMS）**：089 用忆阻器段数 N 控制涡卷数（N+1），本文用 k(z) 段数 N 控制（N+2）——"段数→涡卷数"的映射思路一致，可对比忆阻突触与多项式函数的硬件代价。
- **008/010/024号（CML 时空混沌加密）**：时空混沌靠格点耦合扩散，本文低维 ODE 靠多涡卷拓扑增加复杂度，复杂度来源不同。
- **034号（香农熵随机性测试）**：本文 NIST 测试借用了 034 作者之一 Agaian 合作者的 PRNG 框架，可对照分块熵测试方法。
