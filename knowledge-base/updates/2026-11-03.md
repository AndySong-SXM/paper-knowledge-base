### 核心内容摘要

- **2D-CCS 通用框架（式 1）**：x₁(i+1)=(p₁·x₁(i)+F(x₂(i))) mod M，x₂(i+1)=(F(x₁(i))+p₂·x₂(i)) mod M——"循环编织"两行构造，任意 1D 种子映射 F 升维为 2D。
- **超混沌解析充分条件（式 2）**：|p_k| > max|f'(x)|+1，经 Gershgorin 圆盘定奇异值区间 → Weyl 奇异值不等式 → σ≥|λ| 链证明双 LE 为正——团队从"构造"（006 帕斯卡矩阵）走向"可证明构造"的进化。
- **三个实例**：2D-FCCM 分数余弦耦合映射（阈值 22.5396，p∈[23,122]）；2D-LCCM Logistic b=4（阈值 5，p∈[6,105]）；2D-SCCM 正弦（阈值 π+1，p∈[5,104]）。
- **随机性与复杂度**：TestU01 八电池全过（BigCrush 160/160 @ ~10 Tb，库内最高报告口径）；CD 1.90–1.97；I=32 时 IE 9.9773–9.9783；分维度 CD/IE 对比表（vs Bao/Huang/Kong 三款 2D 映射）。
- **NR-OFDM-DCSK 通信**：P 样本重复 + 均值滤波（噪声方差 ×1/P）+ 循环移位置乱（密钥空间 N!×β!）；闭式 BER（式 35）仅依赖 β/P 与 N/(N−1)；DBR=(N−1)/N（N=128 时 99.22%）；复杂度 O(Nβ log₂N)。多径下 Eb/N0<10 dB 全面最优，高 SNR 段输给 FH-OFDM-DCSK。

### 不足与借鉴

- 不足：①超混沌证明只证"正性"无 LE 数值下界（σ₂ 可任意接近 1，弱超混沌空洞化）；②条件式 2 保守——FCCM 需 |p_k|>22.5396，大 p+mod 1 隐含 7+ bit 定点字长需求，全文未提定点实现；③"抗退化"声明越界——TestU01 是随机性测试，不测有限精度轨道周期，以随机性代理退化（与 125 笔记 mod 1 批评同构）；④安全性单薄——置乱图案两条定长混沌序列跨操作复用，N!×β! 是组合上界而非有效安全位数，无任何已知明文/选择明文攻击分析；⑤对比公平性存疑——对照映射"第一维 mod 1"对齐可能引入对本方有利的分布偏差，无单次方差报告；⑥均值滤波代价未量化——P 增大则每比特独立混沌样本减少，衰落分集恶化（Fig. 13 高 SNR 输 FH-OFDM-DCSK 即代价实证）；⑦无 FPGA/DSP 实现（TCAS-I 刊出却无硬件节，吞吐/定点/接口成本全缺席）；⑧编校瑕疵——式 13/14 分母 (x+0.1)² 与式 19a (x̃+0.1) 一次方排印不一致（22.5396 阈值反推分母应为 x²+0.1 形式）。
- 借鉴：①**"参数化超混沌保证"三段式解析证明模板**（Gershgorin→Weyl→σ≥|λ|）——比 006/014 更系统的工具链，下一步应追求 LE 数值下界；②**"循环编织"升维配方**——两行即得 2D 超混沌，可作混沌课程"从 1D 到 2D"最简教具，与 006 状态无关 Jacobian 形成两路线对照；③TestU01 八电池全表口径（含数据规模列、p∈[0.001,0.999] 通过准则）为混沌 PRNG 报告目前库内最高标准；④CD+IE 双指标分维度对比表可作混沌系统评测 checklist 移植；⑤**BER 公式结构洞察**（β/P 重合律 + N/(N−1) 饱和律）——通信实验应扫 β/P 而非独立扫，实验设计方法论可迁移至 115/117/124/125 的 DCSK 族实验；⑥"均匀轨迹⇒小 Var ⇒低 BER"方差-期望桥梁论证是混沌系统面向通信优化的标准写法范本。
