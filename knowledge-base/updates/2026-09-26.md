- **作者**：Yuxuan Liu, Xingbin Liu（通讯）（西南大学，重庆）
- **期刊**：Chaos, Solitons and Fractals, 2026, Vol. 210, Art. 118579（SCI 一区，DOI: 10.1016/j.chaos.2026.118579）
- **来源**：坚果云"01-文献库"**云盘新上传选文**（/2026-Eng-Liu-基于二维-CICFM的图像加密算法，采用跨粒度正弦-约瑟夫耦合置换及双向交织位平面扩散.pdf，6,381,081 字节 / 21 页，2026-09-25 上传；经 pubDIRBrowse API 比对确认为 09-25 运行之后的新上传，pubDIRLink 取得 dl-pubdir 签名链接直接下载成功，字节数一致）
- **笔记**：[paper_097_二维CICFM跨粒度正弦约瑟夫耦合置乱双向交织位平面扩散图像加密.md](../paper_097_二维CICFM跨粒度正弦约瑟夫耦合置乱双向交织位平面扩散图像加密.md)

核心内容：构造 **2D-CICFM**——耦合无限坍缩映射 sin(a/x) 与 fuch 映射 cos(1/x)，加 π⁵ 大超越数偏移后 mod 1（式 1），$a\in(0,20]$ 全程无周期窗、状态均匀覆盖 [0,1]、LE1/LE2 双正（超混沌）。密钥生成：8 位平面按 4 周期角度旋转预处理 → SHA256 → 8 块归一化 → 式 (5) 组合 + **Sigmoid 映射**锁进 (0,20) 超混沌工作区，密钥空间 2²⁵⁶。加密三阶段：①正弦-约瑟夫耦合置乱——bit 级行/列正弦置乱（式 7-8，幅度 $A_k$ 混沌调制）与 byte 级行/列约瑟夫环置乱（起点/步长混沌、方向由行列奇偶决定）交替执行，位平面按高低位交织序 ρ=(1,8,2,7,3,6,4,5) 重排；②8 路径螺旋扫描将位平面转 1D 字节向量；③**双向交织位平面扩散**——环形耦合 XOR（k_prev/k_next 环，式 10）正向一遍 + 反向一遍即全局雪崩。指标：NIST 15 项 ×100 条 ×10⁶ bit 全过（97–100%）；相关性 ≤0.0069；平均信息熵 7.99936；NPCR/UACI 均值 99.6095%/33.4675% 且 10/10 过假设检验、std 为五个方案最小；抗噪（0.1–0.5 密度仍可辨识）、75% 裁剪仍可解密；时间 O(8MN)、空间 O(14MN)，加密 1024² 仅 0.9338 s。

不足：**LE 只有图无数值表**，且映射含 1/x、1/y² 奇点导数无界，Wolf 类 LE 计算适定性存疑；确定性明文相关密钥（无 nonce，非语义安全，无 KPA/CPA 分析）；"正弦置乱"实为 4 周期移位模式（sin(π(c−1)/2)∈{0,1,0,−1}），名不副实，置换双射性/等价密钥未分析；Joseph 方向奇偶模式固定，选择明文攻击面未评估；**有限精度抗退化只是口头声明**（无 Brent/TestU01，NIST 只测 10⁶ bit）；彩色按通道独立处理无通道耦合；无硬件实现；抗噪数值无横向对比（10% 噪声 PSNR 仅 14.58 dB）。可借鉴：π⁵ 大偏移 + mod 1 的复杂度放大一体手法；**位平面旋转预处理 + SHA256**（可升级 096 式直接哈希方案）；Sigmoid 锁工作区；高低位交织序；8 路径螺旋扫描；环形耦合双向扩散；NPCR/UACI"临界值 + 通过率 + std"三件套写作模板。
