### 核心内容摘要

- **选题轴 = 离散化 + 忆阻 EMI**：首次在离散时间双神经元 HNN 中引入忆阻电磁感应效应（此前离散 HNN 混沌不含忆阻 EMI）；动机是连续 HNN 的 RK4 四迭代/步 FPGA 开销大，Euler 一步求解的离散模型硬件门槛低。
- **核心机制 = 忆阻器内态函数工程**：忆阻器 W=tanh φ、内态方程 φ′=φ+εv+F(φ)，其中 F 取**多段三角波函数**（奇段 F_Odd 参数 M / 偶段 F_Even 参数 L，p=1、q=0.01 固定）；三角波负斜率交点把种子吸引子的不动点"复制"成多份 → **(2M+1)/(2L+2) 条/波数可配置**的多条纹/波超混沌。选三角波弃锯齿波的理由：导数可数值表达 ⇒ Jacobi 法可直接算 LE。
- **DMT-HNN（3 维）**：x′=μx+g₁₁sin x+g₁₂sin y+k·y·tanh φ；y′=μy+g₂₁sin x+g₂₂sin y；φ′=φ+εy+F(φ)。种子为 Bao 组 TCAS-I 2024 多面体超混沌（引 [25]）。不动点用曲线求交法（Y=−F(ψ)/ε → H₁/H₂ 隐函数求交），种子 21 个不动点 → 多条纹 56 个。
- **两组参数**：条纹组 (g₂₁,g₂₂)=(−2,2)（k∈[0,3] 双正 LE 超混沌为主 + 周期窗）；波组 (−4,4)（全程超混沌、前两个 LE 更高）。M/L=0,1,2 → 1/3/5 与 2/4/6 条/波；ϕ-x 平面波/翼、ϕ-y 平面扭曲条纹/波。
- **ε 旋钮与共存**：减小 ε 多条纹/波吸引子连续分解为共存单条/波吸引子（φ₀ 周期-2 偏移切换，台阶高度 2）；ε=0.2 条纹三/四共存、ε=0.08 波三/四共存；吸引盆仅沿 φ₀ 方向可切换（三条直线边界）。
- **五熵联测**（长度 10⁴）：条纹组 SampEn 1.6085–1.6136 / DispEn 1.9632–1.9770 / AttnEn 1.8077–1.8828；波组 SampEn 1.6858–1.7143 / DispEn 2.1176–2.1288 / AttnEn 1.9539–1.9918——**波组全面优于条纹组，形态配置不牺牲随机性**。
- **FPGA + PRLG**：Zynq XC7Z020，PS(ARM 初始化)/PL(Verilog 迭代核) 经 AXI 协同，AN9767 DAC 示波器采集全部形态相图；硬件伪随机电平发生器 P=⌊X_m×10¹³⌋ mod 2⁸ 经 DAC 输出模拟电平；**NIST SP 800-22 两组 PRLG × 15 项全过**（最低通过率 L=1 Serial 0.9650，最低 P-value M=1 Universal 0.0308，余量不大）；应用闭环仅"PRLG 电平 + XOR 传输"示波器演示。

### 不足与借鉴

- 不足：①应用最弱——XOR 电平传输不构成密码系统，无密钥空间/安全性分析；②PRLG 量化硬伤——⌊X_m×10¹³⌋ mod 2⁸ 需 ~43 bit 十进制精度，**定点 FPGA 无法实现该公式，全文未交代硬件口径**；③LE 只画前两个、无数值表/ Kaplan–Yorke 维/数值不动点表；④"鲁棒性更好"无定量（无 K-S、无扰动漂移，对照 121）；⑤FPGA 无资源/时钟/功耗/定点位宽报告；⑥共存是 φ₀ 周期-2 偏移的平凡投影（直线吸引盆），未挂钩密钥；⑦p、q 固定不讨论，M/L 只到 2；⑧Sec IV-C 正文 ε=0.2 vs 图注 0.08 笔误；⑨无与同类（105/106、[25][26]）的熵/LE 对比表；⑩ADC/DAC 链路偏置抖动对一次一密安全性的影响未讨论。
- 借鉴：①"忆阻器内态函数工程"——状态函数从验证件升格为构造件，负斜率交点数=吸引子形态数，可迁移至库内 104/109/116；②可微性约束反向决定模型选型（三角波 vs 锯齿波）的写法可入课堂；③ε 连续调节"叠加↔共存"的演化序列（Fig 10）是讲多稳态连续谱的最佳课件素材；④五熵联测 + 测试长度口径的实验模板；⑤"量化→DAC 电平→ADC 回收→NIST"物理熵源验证管线结构可复用（量化公式需改进）；⑥PS/PL + AXI + DAC 示波器采集的 Zynq 混沌实验标准骨架；⑦Fig 3"扁平→拉伸→复制"生成机制图解法。
