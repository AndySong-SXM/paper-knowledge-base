### 核心内容摘要

- 双层异构 AKA：SM↔MTU 层用 PUF + 模糊提取器（轻量，哈希/异或/PUF 运算），MTU↔RTU 层用 RLWE（后量子）。注册阶段 SM 以 PID_sm = ID_sm ⊕ RN_sm 向 MTU 注册 CRP (Ci, Ri)；MTU/RTU 在 R_q = Z_q[x]/(f(x)) 上由 χ_p 高斯采样生成主密钥对与 Lyubashevsky 风格签名密钥。
- SM-MTU 认证：掩码响应 M_mt = Ri ⊕ N_mt、校验哈希 H_mt = h(Ri‖M_mt)；认证通过后挑战滚动更新 Ci+1 = Ci ⊕ Ri，FE.Gen/FE.Rep 从 Ri+1 提取会话密钥；带密钥确认 KC 与失败重协商分支（重协商从协议起点重启）。
- MTU-RTU 认证：p_m = a·s_m + 2·e_m，k_m = (s_m+sM_m)·pM_r，Cha + Mod2 协调，签名 z_m = y_m + c_m·m1、c_m = H(A·y_m, α_m)；会话密钥 sk = h(PID_m, ID_m, p_m, w_m, σ_m, α_m, p_r, w_r, σ_r, α_r)；k_m − k'_m 为小量保证协调可行（NewHope 式结构）。
- 安全：ProVerif 验证通过；ROM 下 7-Game 归约，Adv ≤ q²_hash/2^κ + (q_exe+q_send)/q + (q_exe+q_send)·Adv_RLWE；7 条 informal 命题（冒充/重放/篡改/侧信道/MITM/前后向保密/ML 攻击）。
- 性能：MIRACL @ Intel i7，11–12 ms / 628 B；延迟分布 0.1–0.5 s；Wi-Fi radio model 能耗 ≈16.6 J/节点，声称较已有格基方案低约 30%。

### 不足与借鉴

- 符号冲突硬伤：σ_m 兼指 Mod2 比特与签名、w_m 兼指挑战值与承诺、β/σ 混用，协议可读性差。
- 归约不严谨：Game 1–4 声称差值为 0（应为 ≤ Adv_RLWE），最终界与 Game 序列不自洽。
- 无具体 RLWE 参数（环维数 n、模数 q、噪声宽度、安全级别），不可复现；未对标 NIST 标准化 ML-KEM（Kyber）。
- 性能在桌面 i7 实测而延迟/能耗靠仿真，16.6 J/节点对单次认证偏高；时间戳新鲜性依赖时钟同步。
- 可借鉴：异构分层 PQC 部署（受限端对称/PUF + 网关端后量子）；CRP 每会话滚动更新抗 ML 建模；ProVerif + ROM Game + informal 命题三层论证范式；Mod2 协调 + 主密钥混合的密钥交换构造。
