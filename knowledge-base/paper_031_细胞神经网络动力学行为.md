## 2. 研究背景与问题

### 2.1 细胞神经网络(CNN)概述

细胞神经网络(Cellular Neural Network, CNN)理论由 **Chua和Yang于1988年** 首次提出。CNN因其规则的结构和局部的连接性质，非常适合超大规模集成电路(VLSI)实现，在以下领域具有广泛应用前景：

- **图像处理**：需要网络收敛于稳定平衡点
- **模式识别与控制**：需要网络收敛于稳定平衡点
- **保密通信**：需要网络具有混沌吸引子或极限环解
- **物理学**：需要网络具有混沌吸引子或极限环解

### 2.2 核心问题

CNN的应用在很大程度上取决于其动力学行为。不同应用场景对CNN的动态特性有截然不同的需求：

- **图像处理/模式识别** → 需要稳定平衡点
- **保密通信/物理学** → 需要混沌吸引子或极限环

因此，**如何通过调节系统参数来控制CNN的动力学行为**，是一个具有重要理论和应用价值的问题。

### 2.3 混沌吸引子的分类

论文将混沌吸引子分为两类：
1. **双曲吸引子**：如Lorenz类型吸引子
2. **准吸引子(Quasi-attractor)**：包含不同类型的周期轨道，其中结构不稳定同宿Poincaré轨道可以是非传递的。在实际中具有广泛的应用价值。准吸引子意味着吸引子的结构敏感地依赖于参数的微小改变。

## 3. 核心方法与创新点

### 3.1 三阶CNN动态模型

论文研究如下三阶CNN动态模型：

$$\frac{dx_j}{dt} = -x_j + f(x_j) + \sum_{k=1}^{3} S_{jk}x_k, \quad (j=1,2,3)$$

其中 $x_j$ 是状态变量，$f(x_j)$ 是输出函数，满足：

$$f(x_j) = \frac{1}{2}(|x_j + 1| - |x_j - 1|)$$

这是一个**分段线性函数**（饱和函数），当 $|x_j| \leq 1$ 时 $f(x_j) = x_j$，当 $|x_j| > 1$ 时 $f(x_j)$ 饱和。

### 3.2 简化模型

令 $\alpha_1 = \alpha_2 = \alpha_3 = 0$；$S_{13} = S_{31} = S_{22} = 0$；$I_j = 0$；$S_{21} = S_{23} = 1$，则系统简化为：

$$\frac{dx_1}{dt} = -x_1 + f(x_1) + S_{11}x_1 + S_{12}x_2$$

$$\frac{dx_2}{dt} = -x_2 + x_1 + x_3$$

$$\frac{dx_3}{dt} = -x_3 + S_{32}x_2 + S_{33}x_3$$

### 3.3 核心创新点

1. **参数调控策略**：通过调节非线性扰动部分的联接权参数 $\alpha_1$（即 $S_{11}$），实现对CNN动力学行为的全面控制
2. **线性子系统稳定性分析框架**：将CNN的动力学行为与线性子系统的系数矩阵特征根联系起来，建立了系统的分析框架
3. **分区域参数扫描**：系统性地研究了线性子系统稳定/不稳定两种情况下参数调节的影响

### 3.4 分析方法

- **数值仿真**：使用四阶Runge-Kutta算法（步长 $h=0.005$）
- **特征根分析**：通过计算线性化系数矩阵的特征方程 $\det(A_{eig} - \lambda E) = 0$ 的根来判定系统动态特性
- **相图分析**：在 $x_1$-$x_2$ 和 $x_1$-$x_3$ 平面上绘制相轨迹

## 4. 实验设计与结果

### 4.1 实验一：线性子系统稳定时的参数调节

**参数设置**：$S_{33} = 0$，$\alpha_1 = -3.6805$，$S_{11} = -0.2179$，$S_{12} = 8.342$，$S_{32} = -11.925$

**线性子系统系数矩阵**：

$$A_{eig} = \begin{bmatrix} S_{11}-1 & S_{12} & 0 \\ 1 & -1 & 1 \\ 0 & S_{32} & -1 \end{bmatrix}$$

**特征根**：$\lambda_1 = -1.6689$，$\lambda_{2,3} = -0.7745 \pm 1.9580i$（实部均为负）

**结果**：运动轨迹收敛于稳定平衡点。即使将 $\alpha_1$ 调至100，系统仍保持稳定。

**关键发现**：当线性子系统稳定时，调节非线性扰动部分的联接权参数 $\alpha_1$ **基本不影响**CNN的动态特性，即稳定的系统对扰动参数的变化不敏感。

### 4.2 实验二：线性子系统不稳定时的参数调节

**参数设置**：$S_{33} = 1$，其余参数不变

**线性子系统特征根**：$\lambda_1 = -2.5593$，$\lambda_{2,3} = 0.1707 \pm 2.3760i$（含正实部）

**结果**：系统变为不稳定。

**关键发现**：当线性子系统不稳定时，调节 $\alpha_1$ 可以产生丰富的动力学行为：

| $\alpha_1$ 值 | 动力学行为 |
|:---:|:---|
| $\alpha_1 = 100$ | 对称双涡旋混沌吸引子 |
| $\alpha_1 = 20$ | 双涡旋混沌吸引子 |
| $\alpha_1 = 2$ | 单涡旋混沌吸引子 |
| $\alpha_1 = 1.7$ | 不稳定周期-2 |
| $\alpha_1 = 1.456$ | 不稳定周期-1 |
| $\alpha_1 = 1$ | 稳定平衡点(0,0) |
| $\alpha_1 = 0.693$ | 临界周期-1 |
| $\alpha_1 = 0.689$ | 不稳定高周期 |
| $\alpha_1 = 0.5$ | 不稳定轨道 |
| $\alpha_1 = -5.5$ | 不稳定高周期 |
| $\alpha_1 = -5.6$ | 临界周期-1 |
| $\alpha_1 = -5.7$ | 稳定高周期 |
| $\alpha_1 = -10$ | 稳定平衡点 |

## 5. 主要结论

1. **线性子系统稳定时**：调节非线性扰动部分的联接权参数 $\alpha_1$ 基本不影响CNN的动态特性，稳定的系统对扰动参数的变化不敏感。

2. **线性子系统不稳定时**：调节 $\alpha_1$ 可以产生丰富的动力学行为，包括：
   - 混沌吸引子（对称双涡旋、单涡旋）
   - 不稳定周期轨道（周期-1、周期-2）
   - 稳定平衡点
   - 稳定/不稳定高周期轨道
   - 临界状态

3. **参数区间特性**：
   - 使系统处于**混沌态**和**稳定态**的参数 $\alpha_1$ 区间较宽
   - 使系统处于**极限环**和**高周期**的参数 $\alpha_1$ 区间较窄，不易实现精确控制

4. **特征根判据**：
   - 至少一个正特征根或正实部特征根 → 混沌或不稳定
   - 所有特征根为负或负实部 → 稳定平衡点
   - 至少一个零特征根或零实部特征根 → 极限环

5. **混沌参数范围宽广**：在很大的参数范围内（$\alpha_1 > 1.456$ 或 $\alpha_1 \in (-5.5, 0.689)$ 附近），CNN表现为混沌行为。

## 6. 批判性评价

### 6.1 优点

1. **方法简洁有效**：仅通过调节一个参数 $\alpha_1$ 就能实现CNN动力学行为的全面控制，方法简单直观
2. **分析框架清晰**：将CNN动力学行为与线性子系统特征根联系起来，建立了系统的理论分析框架
3. **参数扫描系统**：对 $\alpha_1$ 进行了较系统的参数扫描，展示了丰富的动力学行为分岔图景
4. **应用导向明确**：明确指出了不同应用场景（图像处理 vs 保密通信）对CNN动力学行为的不同需求

### 6.2 不足

1. **Lyapunov指数缺失**：论文承认由于输出函数 $f(x)$ 的不连续性，计算Lyapunov指数比较困难，但这是量化混沌强度的标准工具，其缺失削弱了分析的严谨性
2. **理论分析不够深入**：主要依赖数值仿真和特征根分析，缺乏严格的数学证明（如分岔条件的解析推导）
3. **参数空间探索有限**：仅调节了 $\alpha_1$ 一个参数，未探索多参数联合调节的效果
4. **无硬件验证**：未提供电路实现或硬件验证，仅停留在数值仿真层面
5. **混沌判定标准不够严格**：仅通过相图观察判定混沌，缺乏定量指标（如Lyapunov指数、分形维数等）
6. **非线性区域分析简化**：当 $|x_j| > 1$ 时直接用线性化近似处理，忽略了饱和非线性的影响

### 6.3 历史意义

- 这是**较早系统研究CNN参数调控与混沌产生关系**的中文工作之一
- 为利用神经网络构造混沌数学模型提供了思路
- 论文发表在《物理学报》2003年，正值CNN混沌研究的发展期

### 6.4 与后续工作的关联

- 本文的三阶CNN模型是后续**忆阻器CNN混沌系统**（如009号Kong et al. 2024）的基础框架
- 参数调控策略与后续**离散忆阻器CNN**（如011号He et al. 2024）的耦合参数调节思想一脉相承
- CNN中的混沌产生机制为后续**时空混沌系统**（如008号Tao et al. 2020的CML）提供了理论基础

## 8. 关键公式速查

### 8.1 三阶CNN动态方程

$$\frac{dx_j}{dt} = -x_j + f(x_j) + \sum_{k=1}^{3} S_{jk}x_k, \quad (j=1,2,3)$$

### 8.2 CNN输出函数（分段线性）

$$f(x_j) = \frac{1}{2}(|x_j + 1| - |x_j - 1|) = \begin{cases} 1, & x_j > 1 \\ x_j, & |x_j| \leq 1 \\ -1, & x_j < -1 \end{cases}$$

### 8.3 简化模型

$$\frac{dx_1}{dt} = -x_1 + f(x_1) + S_{11}x_1 + S_{12}x_2$$
$$\frac{dx_2}{dt} = -x_2 + x_1 + x_3$$
$$\frac{dx_3}{dt} = -x_3 + S_{32}x_2 + S_{33}x_3$$

### 8.4 线性子系统系数矩阵

$$A_{eig} = \begin{bmatrix} S_{11}-1 & S_{12} & 0 \\ 1 & -1 & 1 \\ 0 & S_{32} & S_{33}-1 \end{bmatrix}$$

### 8.5 特征方程

$$\det(A_{eig} - \lambda E) = 0$$

### 8.6 动力学行为判定准则

- **混沌/不稳定**：$\exists \lambda_i > 0$ 或 $\text{Re}(\lambda_i) > 0$
- **稳定平衡点**：$\forall \lambda_i < 0$ 或 $\text{Re}(\lambda_i) < 0$
- **极限环**：$\exists \lambda_i = 0$ 或 $\text{Re}(\lambda_i) = 0$
