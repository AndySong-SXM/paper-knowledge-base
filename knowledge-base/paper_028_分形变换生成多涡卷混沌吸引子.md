## 二、研究背景与问题

### 2.1 研究背景

**分形与混沌的紧密联系**：
- 分形和混沌是紧密绑定的两个领域，相关研究已相当成熟
- 但很少有研究关注将分形与混沌系统结合以生成多涡卷混沌吸引子的可能性

**隐藏吸引子的重要性**：
- 自激吸引子：吸引域的吸引盆与平衡点的任意开邻域相交
- 隐藏吸引子：无法通过标准计算程序定位，难以预测其存在
- 隐藏吸引子在理论问题和实际工程应用中发挥重要作用

**多涡卷混沌系统的应用价值**：
- 比一般混沌系统具有更高的复杂度
- 在混沌通信安全、混沌密码分析、图像加密等领域有重要应用

### 2.2 现有方法的局限性

**传统多涡卷生成方法的问题**：
| 方法类型 | 代表工作 | 局限性 |
|---------|---------|--------|
| 分段线性函数 | Wang et al. (2019) | 非光滑系统，复杂度低，涡卷数难调节 |
| 阶跃函数 | Yalcin et al. (2002) | 同上 |
| 正弦函数 | Tang et al. (2001) | 同上 |
| 切换流形 | Huan et al. (2012) | 同上 |
| 时延饱和序列 | Lu et al. (2006) | 同上 |

**分形变换方法的优势**：
- Bouallegue et al. (2011)：提出Julia分形过程生成多涡卷吸引子，但算法难以理解
- Xiao et al. (2018)：将Julia分形与忆阻混沌系统结合
- Yan et al. (2021)：设计忆阻混沌系统生成分形多涡卷吸引子

### 2.3 本文研究问题

1. 如何设计一个无平衡点系统产生隐藏多涡卷吸引子？
2. 如何将分形变换与混沌系统结合生成多种拓扑结构的多涡卷吸引子？
3. 如何通过抛物线变换和三角变换生成不同类别的混沌吸引子？
4. 如何验证分形变换对系统复杂度的提升效果？

## 三、核心方法与创新点

### 3.1 种子系统模型（无平衡点4D系统）

**系统方程**：
```
ẋ = ay + bxz
ẏ = -cx + yzw
ż = d - |x|
ẇ = gz
```

**参数设置**：
- 固定参数：b = 15, d = 1, g = 5
- 可调参数：a 和 c 用于生成多涡卷吸引子

**系统特性分析**：

| 特性 | 分析结果 |
|------|---------|
| **散度** | ∇·f = z(b+w)，当b=15时系统为耗散型 |
| **平衡点** | 无平衡点（方程组无解） |
| **对称性** | 关于z-w平面对称，P: (x,y,z,w) → (-x,-y,z,w) |
| **吸引子类型** | 隐藏吸引子 |

**无平衡点证明**：
```
ay + bxz = 0
-cx + yzw = 0
d - |x| = 0  → x = ±1
gz = 0       → z = 0
```
由第三式得x=±1，但由第四式得z=0，代入第一式得ay=0，若a≠0则y=0，再代入第二式得-cx=0，即x=0，与x=±1矛盾。因此系统无平衡点。

### 3.2 分形变换算法（核心创新）

**基于Julia迭代的改进算法**：

Julia迭代映射定义为：
```
Z_{n+1} = Z_n² + Z_c
```

设 Z_{n+1} = x_{n+1} + iy_{n+1}, Z_n = x_n + iy_n, Z_c = 0，则：
```
x_{n+1} = x_n² - y_n²
y_{n+1} = 2x_n y_n
```

**分形变换开关函数 P_J**：

对于输入序列 (x_n, y_n)，输出 (x_{n+1}, y_{n+1}) 根据 x_n 的符号决定：

**当 x_n ≥ 0 时**：
```
x_{n+1} = √(x_n² + y_n²) + x_n / 2
y_{n+1} = y_n / (2x_{n+1})
```

**当 x_n < 0 时**：
```
x_{n+1} = 2y_{n+1}
y_{n+1} = -√(x_n² + y_n²) - x_n / 2
```

**多次分形变换的涡卷数规律**：

| 分形次数 n | 涡卷数 C |
|-----------|---------|
| 0 (种子系统) | C₁ |
| 1 | C₁ × 2 |
| 2 | C₁ × 4 |
| 3 | C₁ × 8 |
| n | C₁ × 2ⁿ |

### 3.3 多种分形系统设计

#### 3.3.1 多环混沌吸引子系统

**三次分形变换系统**：
```
(u₁, v₁) = P_J(x₁, y₁)
(u₂, v₂) = P_J(u₁, v₁)
(u₃, v₃) = P_J(u₂, v₂)
```

**改进系统（含arctan函数）**：
```
(u₁, v₁) = P_J(x₁ + arctan(x₁), y₁ + arctan(y₁))
(u₂, v₂) = P_J(x₁, y₁)
(X, Y) = P_J(2v₂, 2u₁)
```

#### 3.3.2 分离涡卷吸引子系统

**分离因子k控制的分形系统**：
```
(u₁, v₁) = P_J(x₁ + arctan(x₁), y₁ + arctan(y₁))
(u₂, v₂) = P_J(x₁ + k, y₁ - k)
(u₃, v₃) = P_J(u₂, v₂)
```

**分离过程三阶段**：
1. **初始状态** (k=0)：多环吸引子
2. **完整状态** (k=0.5)：接近分离阈值
3. **分离状态** (k=1)：完全分离的吸引子

**首次发现的燕子形吸引子**：当k=1时，产生四个燕子形分离吸引子。

#### 3.3.3 嵌套混沌吸引子系统

**嵌套多环吸引子系统**：
```
(u₁, v₁) = P_J(x₁ + arctan(x₁), y₁ + arctan(y₁))
(u₂, v₂) = P_J(x₁, y₁)
(u₃, v₃) = P_J(2u₁ - 2u₂, 2v₁ - 2v₂)
(u₄, v₄) = P_J(u₃, v₃)
```

**嵌套与分离混合系统**：
```
(u₁, v₁) = P_J(x₁ + arctan(x₁), y₁ + arctan(y₁))
(u₂, v₂) = P_J(x₁, y₁)
(u₃, v₃) = P_J(2u₁ - 2u₂, 2v₁ - 2v₂)
(u₄, v₄) = P_J(2u₃ - 2u₄, 2v₃ + 2v₄ + k)
```

### 3.4 抛物线变换与三角变换（新型变换方法）

#### 3.4.1 三角变换

**三角变换映射 T**：
```
x_{n+1} = 6x_n - 6(x_n² - y_n²)
y_{n+1} = 6y_n - 12x_n y_n
```

**三角变换分形系统**：
```
(u₁, v₁) = P_J(arctan(x₁), arctan(y₁))
(u₂, v₂) = P_J(2x₁, 2y₁)
(X, Y) = T(2v₂, 2u₁)
```

#### 3.4.2 抛物线变换

**抛物线变换映射 T**：
```
x_{n+1} = 6x_n(1 - x_n)
y_{n+1} = 6y_n
```

## 四、实验设计与结果

### 4.1 种子系统动力学分析

**Lyapunov指数谱与分岔图**：
- 参数a ∈ [0,1]范围内系统始终保持混沌状态
- 当a ∈ [0.131, 0.624) ∪ (0.624, 1]时，存在两个正Lyapunov指数（超混沌）

**典型吸引子**：

| 参数a | 参数c | 吸引子类型 | LE值 |
|-------|-------|-----------|------|
| 0.9 | 1 | 混沌 | (0.1587, 0.0072, -0.0043, -0.1542) |
| 0.2 | 1 | 超混沌 | (0.0344, 0.0185, -0.0035, -0.0286) |
| 0.02 | 1 | 多涡卷 | 双涡卷 |
| 0.05 | 1 | 多涡卷 | 三涡卷 |
| 0.95 | 0.025 | 多涡卷 | 四涡卷 |

### 4.2 极端多稳定性分析

**初始值y(0)变化时的共存吸引子**：

| y(0) | 吸引子类型 | 颜色标记 |
|------|-----------|---------|
| 0.1 | 双涡卷隐藏吸引子 | 浅蓝 |
| -0.9 | 三涡卷隐藏吸引子 | 浅蓝 |
| 0.43 | 多涡卷隐藏吸引子 | 红色 |
| -0.5 | 多涡卷隐藏吸引子 | 浅黄 |

**吸引域分析**：在x(0)-y(0)平面上，不同颜色区域对应不同吸引子，双涡卷吸引子的吸引域最大。

**初始偏移增强行为**：
- 固定参数：a=0.2, c=1
- 初始条件：(-0.1, -0.1, -0.1, w(0))
- w(0)取值：0, 0.5, 1, 1.5, 2, 2.4
- 结果：六个共存的隐藏混沌吸引子

### 4.3 分形变换生成多涡卷吸引子

#### 4.3.1 多环吸引子

**参数设置**：a=0.005, c=1, 初始值(-0.1,-0.1,-0.1,-0.1)

| 分形次数 | 涡卷数 | 图示 |
|---------|--------|------|
| 1次 | 2×C₁ | 双环 |
| 2次 | 4×C₁ | 四环 |
| 3次 | 8×C₁ | 八环 |

**参数变化效果**：
- a=0.1, c=0.1时：不同拓扑结构的多环吸引子
- a=1, c=0.1时：嵌套多环吸引子

#### 4.3.2 分离吸引子

**参数设置**：a=0.2, c=0.02, 初始值(-0.1,-0.1,-0.1,-0.1)

| 分离因子k | 状态 | 吸引子特征 |
|----------|------|-----------|
| 0 | 初始状态 | 多环吸引子 |
| 0.5 | 接近阈值 | 开始分离 |
| 1 | 完全分离 | 四个燕子形吸引子 |

**不同参数下的分离吸引子**：
- a=0.02, c=1, k=1：八个单涡卷分离吸引子
- a=0.02, c=1, k=3：十六个四涡卷分离吸引子

#### 4.3.3 嵌套吸引子

**四次分形变换**：两个不同形式的多环吸引子嵌套
**五次分形变换**：更复杂的嵌套结构

**嵌套与分离混合**：
- 参数g=15, f=-15, j=1, k=-1：四个相同形式的嵌套分离吸引子
- 参数g=11, f=-11, j=2.7, k=-2.7：两种不同形式的吸引子（一个嵌套双吸引子，两个相同嵌套分离吸引子）

### 4.4 复杂度分析（谱熵SE）

**谱熵定义**：
```
SE = -Σ P_j ln(P_j)
```
其中P_j为相对功率谱概率，j为频率点。

**复杂度对比结果**：

| 系统类型 | SE复杂度 |
|---------|---------|
| **本文工作** | |
| 种子系统 | 0.5560 |
| 一次分形 | 0.9536 |
| 两次分形 | 0.9537 |
| 三次分形 | 0.9542 |
| 三角变换 | 0.9533 |
| 抛物线变换 | 0.9525 |
| 嵌套多环 | 0.9516 |
| 分离多涡卷 | **0.9579** |
| **对比文献** | |
| 分数阶多涡卷[45] | 0.6876 |
| 忆阻HR神经元模型[46] | 0.5209 |
| 时延多涡卷[47] | 0.6764 |
| 网格复合多涡卷[48] | 0.7005 |
| 忆阻隐藏混沌系统[49] | 0.7900 |
| 非哈密顿保守系统[50] | 0.9500 |

**关键发现**：
- 种子系统经过分形变换后复杂度从0.5560提升至0.95+
- 分离涡卷吸引子具有最高复杂度(0.9579)
- 分形变换方法显著优于传统多涡卷生成方法

### 4.5 MCU硬件实现

**硬件平台**：
- 微控制器：STM32F407ZGT6 (ARM Cortex-M4 32位RISC核心)
- D/A转换器：AD5689 (16位双通道)
- 示波器：RIGOL DS2102A

**离散化方法**：欧拉算法
```
x(n+1) = x(n) + h(ay(n) + bx(n)z(n))
y(n+1) = y(n) + h(-cx(n) + y(n)z(n)w(n))
z(n+1) = z(n) + h(d - |x(n)|)
w(n+1) = w(n) + h(gz(n))
```
其中离散化步长h=0.0001

**硬件实现结果**：
成功捕获了以下吸引子：
1. 种子系统多涡卷吸引子 (a=0.02, c=1)
2. 种子系统多涡卷吸引子 (a=0.05, c=1)
3. 一次分形变换多环吸引子 (a=0.005, c=1)
4. 三次分形变换多环吸引子 (a=0.005, c=1)
5. 分离涡卷吸引子 (k=1, a=0.2, c=0.02)
6. 分离涡卷吸引子 (k=3, a=0.02, c=1)
7. 嵌套吸引子 (a=0.1, c=0.1)
8. 嵌套分离吸引子 (a=0.1, c=0.1)
9. 三角变换吸引子 (a=0.005, c=0.1)
10. 抛物线变换吸引子 (a=0.1, c=0.1)

**验证结论**：硬件实验结果与MATLAB数值仿真基本一致，证明了物理可实现性。

## 五、主要结论

### 5.1 核心贡献总结

1. **提出新型无平衡点4D混沌系统**
   - 系统 exhibits 隐藏吸引子、超混沌、多涡卷吸引子、极端多稳定性、初始偏移增强行为
   - 通过调节参数a和c可生成不同数量的涡卷

2. **建立分形变换与混沌系统结合的通用框架**
   - 基于Julia迭代改进的分形变换算法
   - 涡卷数遵循 C = C₁ × 2ⁿ 的规律

3. **生成多种新型多涡卷吸引子拓扑结构**
   - 多环吸引子
   - 分离涡卷吸引子（首次发现燕子形吸引子）
   - 嵌套吸引子
   - 嵌套与分离混合吸引子

4. **引入抛物线变换和三角变换**
   - 两种新型非线性变换方法
   - 生成不同形式和行为的吸引子

5. **验证分形变换显著提升系统复杂度**
   - SE复杂度从0.5560提升至0.95+
   - 优于现有文献报道的多涡卷系统

6. **完成STM32硬件平台实现**
   - 验证了数值仿真的正确性
   - 证明了物理可实现性

### 5.2 应用前景

- **图像加密**：高复杂度混沌序列适合作为加密密钥
- **通信安全**：多涡卷吸引子提供更高的安全性
- **信息隐藏**：多种拓扑结构的吸引子可用于信息隐藏

## 八、关键公式速查

### 8.1 种子系统方程

```
ẋ = ay + bxz
ẏ = -cx + yzw
ż = d - |x|
ẇ = gz
```

参数：b=15, d=1, g=5（固定）；a, c（可调）

### 8.2 散度计算

```
∇·f = ∂f₁/∂x + ∂f₂/∂y + ∂f₃/∂z + ∂f₄/∂w = z(b + w)
```

### 8.3 Julia分形变换

**复数形式**：
```
Z_{n+1} = Z_n² + Z_c  (Z_c = 0)
```

**实数形式**：
```
x_{n+1} = x_n² - y_n²
y_{n+1} = 2x_n y_n
```

**开关函数 P_J**：

当 x_n ≥ 0：
```
x_{n+1} = √(x_n² + y_n²) + x_n/2
y_{n+1} = y_n / (2x_{n+1})
```

当 x_n < 0：
```
x_{n+1} = 2y_{n+1}
y_{n+1} = -√(x_n² + y_n²) - x_n/2
```

### 8.4 涡卷数公式

```
C = C₁ × 2ⁿ
```
其中C₁为种子系统涡卷数，n为分形次数。

### 8.5 三角变换

```
x_{n+1} = 6x_n - 6(x_n² - y_n²)
y_{n+1} = 6y_n - 12x_n y_n
```

### 8.6 抛物线变换

```
x_{n+1} = 6x_n(1 - x_n)
y_{n+1} = 6y_n
```

### 8.7 谱熵(SE)复杂度

```
SE = -Σ_{j=0}^{N/2-1} P_j ln(P_j)
```

其中P_j为相对功率谱概率，j为频率点。

### 8.8 欧拉离散化

```
x(n+1) = x(n) + h(ay(n) + bx(n)z(n))
y(n+1) = y(n) + h(-cx(n) + y(n)z(n)w(n))
z(n+1) = z(n) + h(d - |x(n)|)
w(n+1) = w(n) + h(gz(n))
```

步长h=0.0001
