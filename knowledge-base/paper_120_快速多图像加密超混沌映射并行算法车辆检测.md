## 一、核心思想

面向车联网/智能交通场景（车辆检测数据集批量图像的隐私保护），提出"**并行化 + 多图捆绑**"的双轮加速方案：

1. **新混沌发动机**：三维离散忆阻指数映射（3D-DMEM，three-dimensional discrete memristive exponential map）——指数型离散忆阻器 + 三维耦合，产生双翼/四翼超混沌吸引子；
2. **多图并行加密**：把多幅图像按位平面/块维度展开成数据矩阵，一次混沌迭代并行扩散多图；
3. **性能目标**：加密吞吐 2285.67 KB/s（IoTJ 同期方案中最高档位），兼顾车辆检测精度不损失。

## 二、混沌系统（3D-DMEM）

- 指数型离散忆阻器：M(n) = exp(α·x(n)) 形式的忆阻增益，内部状态由输入驱动；
- 三维状态耦合：x/y/z 三通道交叉反馈，其中一通道含忆阻注入项；
- 超混沌判定：2 个正 Lyapunov 指数（QR 法）；
- 混沌区间：参数 α 等扫描给出大范围超混沌平台。

## 三、并行多图加密流程

- **输入打包**：N 幅图像按块展开为长数据流；
- **置乱**：3D-DMEM 序列排序置换；
- **扩散并行化**：多线程/分块并行复数模扩散；
- **密钥**：初值 + 参数组合，密钥空间 2⁵¹⁹；
- **车辆检测验证**：加密→传输→解密→YOLOv8 检测精度对照，解密后检测 mAP 无损。

## 四、实验指标汇总

| 指标 | 结果 |
|---|---|
| 密钥空间 | 2⁵¹⁹ |
| 加密速度 | 2285.67 KB/s |
| 信息熵 | ≈7.999 |
| 相邻像素相关 | 接近 0 |
| NPCR/UACI | 达标（文中给出） |
| 检测精度 | 解密后 YOLOv8 mAP 与明文一致 |

## 五、不足

1. 并行加速依赖 CPU 多线程，无 FPGA/GPU 硬件实现闭环；
2. 忆阻器为指数模型，物理电路对应性弱于正弦/余弦忆阻；
3. 多图捆绑长度与混沌周期退化问题未深入讨论；
4. 车辆检测场景仅作应用验证，加密与检测系统未做联合优化。

## 六、可借鉴之处

1. "加密吞吐"作为一等公民指标与安全性并列（多数混沌加密论文回避速度）；
2. 多图并行打包 + 并行扩散的工程写法可直接复用；
3. 加密→下游任务（检测）无损验证是应用型加密论文的新评估范式。
