## 一、核心思想

面向车联网车辆检测场景的批量图像隐私保护，提出"检测驱动选择性加密 + 并行化扩散"方案：

1. **新混沌发动机**：3D-DMEM（三维双忆阻指数映射）——双忆阻指数函数 M₁ = e^{πq_n}、M₂ = e^{−πq_n} 与余弦项融合构造三维映射（x_{n+1} = a·cos(y·e^{πq} + b·x) 结构），三个正 Lyapunov 指数、无周期窗；NIST SP 800-22 十五项全过（1.2×10⁸ bit）；STM32F103 + TLV5618 硬件验证。
2. **双用户密钥协同**：K_u2 驱动 K₁（circshift + xor 轮函数），派生 5 组轮密钥，密钥空间 2⁵¹⁹。
3. **加密流程**：YOLOv8 检测车辆目标 → 重排分四块（不依赖检测精度）→ 三轮并行交替扩散（bit 级 XOR+circshift 与像素级模加链交替，parfor 四路）→ 一轮象限掩码 + 排序索引双层置乱。
4. **性能**：平均并行加密速度 2285.67 KB/s（i7-14650HX 四线程）。

## 三、不足

1. 摘要与贡献点 ES 数据不一致（2285.67 vs 2244.19 KB/s）；
2. 测速平台为桌面 16 核 CPU，却宣称面向资源受限设备；
3. 密钥协同 F 函数为线性结构，安全增益缺乏形式化论证；
4. 检测漏检时效率优势退化未讨论；
5. 关键表格图像化，不可复核；
6. 无抗量子性（未来工作拟集成后量子 KEM）。

## 四、可借鉴之处

1. 检测驱动选择性加密流水线（可迁移到 ROI 医疗加密/车牌脱敏）；
2. bit 级 + 像素级交替扩散结构；
3. 取值顺序与放置区域解耦的双层置乱；
4. ES-STS/STP/FTP 三档分层测速写法。
