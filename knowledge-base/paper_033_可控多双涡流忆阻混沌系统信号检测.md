## 2. 研究背景与问题

### 2.1 研究背景

混沌现象自 Lorenz（1963）发现以来，因其内在伪随机性在预测、图像加密、神经网络、安全通信等领域展现了广泛的应用前景。然而，传统混沌系统存在动力学行为有限、参数可调性不足的问题，因此增强混沌动力学成为活跃的研究方向。

忆阻器作为具有 exceptional 非线性和记忆特性的紧凑型电子元件，当耦合到简单系统中构建忆阻混沌系统（MCS）时，能够最大限度地增强动力学行为（如超混沌、多涡卷、共存吸引子、隐藏吸引子、吸引子自复制等）。

### 2.2 研究问题

现有 MCS 研究中，**多涡卷生成**和**空间可控吸引子**受到相对较少的研究关注。同时，MCS 在**弱信号检测**方面的应用仍然有限——典型方法基于阈值敏感的幅度调整，只能检测弱信号的存在，但无法提取额外的有用信息（如频率）。

### 2.3 核心挑战

1. 如何系统性地构建可在线性（1D）、平面（2D）和空间（3D）维度上产生可控多双涡流吸引子的忆阻混沌系统？
2. 如何利用多涡卷混沌系统的同步特性实现低信噪比条件下的弱信号频率检测？

## 3. 核心方法与创新点

### 3.1 系统构造方法

**种子系统**：选择简单的 jerk 系统作为基础

$$
\begin{cases}
\dot{x} = y \\
\dot{y} = z \\
\dot{z} = -a(x + y + z) + \text{sgn}(x)
\end{cases}
$$

其中 $a = 0.6$，该系统仅产生一个双涡流吸引子。

**忆阻器模型**：采用磁通控制的忆阻器

$$
\begin{cases}
i = (b + c|u|)v \\
\dot{u} = v - k(u - \xi(u))
\end{cases}
$$

其中 $\xi(u)$ 为多重符号函数，由 $\xi_1(u)$ 和 $\xi_2(u)$ 组成：

$$
\xi_1(u) = \sum_{q=1}^{Q_u} \text{sgn}(u - 2q + 1) + \sum_{q=1}^{Q_u} \text{sgn}(u + 2q - 1)
$$

$$
\xi_2(u) = \text{sgn}(u) + \sum_{p=-P_u}^{P_u} \text{sgn}(u + 2p)
$$

### 3.2 渐进式耦合机制（核心创新）

**1D-MDSMCS**：沿 $y$ 轴扩展一个忆阻器

$$
\begin{cases}
\dot{y} = z - (b_1 + c_1|u|)x \\
\dot{u} = x - k_1(u - \xi(u))
\end{cases}
$$

**2D-MDSMCS**：在 1D 基础上嵌入第二个忆阻器

$$
\begin{cases}
\dot{y} = (b_2 + c_2|w|)z - (b_1 + c_1|u|)x \\
\dot{w} = z - k_2(w - \xi(w))
\end{cases}
$$

**3D-MDSMCS**：在 2D 基础上装备第三个忆阻器

$$
\begin{cases}
\dot{y} = (b_2 + c_2|w|)z - (b_1 + c_1|u|)x - (b_3 + c_3|g|)y \\
\dot{g} = y - k_3(g - \xi(g))
\end{cases}
$$

> **关键设计思想**：三个忆阻器分别与变量 $x$、$z$、$y$ 相关，互不影响 $u$ 轴、$w$ 轴和 $g$ 轴上的平衡点结构，因此 2D 和 3D 系统具有与 1D 相同的双涡流产生机制。

### 3.3 双涡流数量控制公式

| 参数设置 | 双涡流数量 |
|---------|-----------|
| $P_i = 0$ | $2$ |
| $Q_i = 1$ | $3$ |
| $P_i = 1$ | $4$ |
| $Q_i = 2$ | $5$ |
| ... | ... |
| $P_i = N-1$ | $2N$ |
| $Q_i = N$ | $2N+1$ |

当 $P_i/Q_i \to \infty$ 时，3D-MDSMCS 可产生**无穷多个双涡流吸引子**。

### 3.4 弱信号检测方法（首次提出）

基于主从同步框架：
- **主系统** $F_1(\cdot)$ 和 **从系统** $F_2(\cdot)$ 为两个相同参数但不同初始条件的 3D-MDSMCS
- 从系统引入**改进误差反馈控制器** $v(\cdot)$
- 含噪声的弱信号 $s(t) = r(t) + \vartheta(t)$ 注入从系统的 $g$ 轴
- 对同步后的第六个误差变量 $e_6(t)$ 进行 FFT，提取测试信号频率

**同步稳定性条件**：

$$k_{\min} > L_{\max}$$

其中 $k_{\min} = \min(k_7, k_8 + \sin(t), k_9, k_{10}, k_{11}, k_{12})$，$L_{\max}$ 为主系统的最大 Lyapunov 指数。

### 3.5 核心创新总结

1. **渐进式忆阻器耦合**：首次提出通过耦合 1/2/3 个相同结构忆阻器到 jerk 系统，实现 1D/2D/3D 多双涡流吸引子的可控生成
2. **维度可扩展性**：同一系统通过开关切换实现三种维度形式，而非三个独立系统
3. **偏移增强（Offset Boosting）**：在多涡流系统中实现罕见的二维空间偏移控制
4. **弱信号频率检测**：首次将多涡卷混沌系统与同步理论结合用于低 SNR 条件下的频率检测

## 4. 实验设计与结果

### 4.1 平衡点分析

- 1D-MDSMCS 和 2D-MDSMCS 的平衡点通过几何方法（曲线交点）分析
- 所有平衡点均为**鞍焦点指标 2（SF2）**类型
- 特征值结构：一个负实根 + 一对具有正实部的共轭复数对
- 每个涡流对应一个独立的 SF2 平衡点

### 4.2 动力学行为验证

| 动力学现象 | 验证方法 | 关键发现 |
|-----------|---------|---------|
| **幅度控制（PAC）** | 相图 + 时间序列 | $k_1$ 增大时 $u$ 轴幅度减小，其他轴不变 |
| **共存吸引子** | 分岔图 + LE + 吸引域 | 1D 系统产生 8 个共存双涡流；2D 产生 9 个；3D 产生 12 个 |
| **偏移增强** | 相图 + 时间序列 | 通过常数 $d_2, d_3$ 实现 1D 和 2D 偏移控制 |
| **混沌持续性** | LE 谱 | $L_1 > 0$ 在 $k_3 \in [0, 3]$ 全范围保持 |

### 4.3 电路实现

- **仿真平台**：NI Multisim 14.0
- **核心器件**：TL082CD 运算放大器（±15V）、1N4148 二极管、AD633JN 乘法器
- **硬件平台**：STM32F103VET6 微控制器 + TLV5618 DAC
- **三种维度切换**：通过拨动开关 $L_1, L_2, L_3$ 实现
- **验证结果**：虚拟示波器和实际示波器观测到的吸引子与数值分析一致

### 4.4 弱信号检测结果

| 方法 | 同步时间 | SNR | 误差率 | 频率检测能力 |
|------|---------|-----|-------|------------|
| Method I (Dong 2023) | $T_1 < 20$s | −33 dB | 0.029% | 单频 |
| Method II (Yan 2025) | $T_2 < 7$s | −38 dB | 0.05% | 多频 |
| Method III (Li 2016) | — | −27 dB | 0.0029% | 单频 |
| Method IV (Zhao 2025) | — | −42 dB | 0.82% | 单频 |
| **本文方法** | **$T_5 < 5$s** | **−47 dB** | **0.0026%** | **多频** |

> **关键优势**：SNR 达到 −47 dB（所有方法中最低），同步时间最短（< 5s），误差率最低（0.0026%），且支持多频同时检测。

## 5. 主要结论

1. **系统构造成功**：通过渐进式耦合 1-3 个忆阻器到 jerk 系统，成功构建了可产生 1D/2D/3D 可控多双涡流吸引子的忆阻混沌系统
2. **丰富的动力学行为**：系统展现了共存吸引子、偏移增强、幅度控制等多种非线性动力学现象
3. **偏移增强的独特性**：在多涡流系统中实现了罕见的二维空间偏移控制，使不同参数的多双涡流吸引子可进行二维空间平移
4. **电路可行性**：Multisim 仿真和 STM32 硬件实现均验证了理论结果
5. **弱信号检测突破**：首次将多涡卷混沌系统与同步理论结合用于弱信号检测，在 −47 dB SNR 下实现精确频率提取，优于现有所有方法

## 6. 批判性评价

### 6.1 优势

1. **构造方法优雅**：渐进式耦合设计思路清晰，1D→2D→3D 的维度扩展自然统一，避免了为每种维度设计独立系统的冗余
2. **双涡流数量公式明确**：$P_i/Q_i$ 参数与涡流数量之间的对应关系简洁实用，便于工程应用中的精确控制
3. **应用创新性强**：将多涡卷混沌系统用于弱信号频率检测是新颖的交叉应用方向，突破了传统方法仅能检测信号存在的局限
4. **实验验证完整**：从数值仿真→Multisim 电路仿真→STM32 硬件实现，形成了完整的验证链条
5. **性能指标优越**：−47 dB SNR 和 0.0026% 误差率在弱信号检测领域具有显著竞争力

### 6.2 不足与局限

1. **同步控制器设计缺乏严格证明**：虽然引用了 Wang 的稳定性分析框架，但时变项 $\sin(t)$ 的引入对同步稳定性的影响未做充分的理论分析
2. **噪声模型单一**：仅考虑了高斯白噪声，未验证在有色噪声、脉冲噪声等更复杂噪声环境下的性能
3. **多频检测上限未明确**：虽然展示了三频检测，但系统同时检测频率数量的理论上限未讨论
4. **实际工程参数缺失**：未讨论实时检测的延迟、计算复杂度、以及在实际信号处理场景中的部署可行性
5. **与现有忆阻器多涡卷系统的对比不够深入**：未与 014 号论文（Huang et al., 2022 N维非退化离散忆阻超混沌映射）等高维构造方法进行理论层面的对比分析

### 6.3 改进建议

1. 补充时变同步控制器的 Lyapunov 稳定性严格证明
2. 扩展噪声模型至非高斯场景，验证方法的鲁棒性
3. 探讨将离散化版本部署到 DSP/FPGA 进行实时检测的可行性
4. 分析多频检测的理论上限与计算复杂度关系

## 8. 关键公式速查

### 8.1 种子系统（Jerk 系统）

$$\dot{x} = y, \quad \dot{y} = z, \quad \dot{z} = -a(x+y+z) + \text{sgn}(x), \quad a = 0.6$$

### 8.2 忆阻器模型

$$i = (b + c|u|)v, \quad \dot{u} = v - k(u - \xi(u))$$

### 8.3 多重符号函数

$$\xi_1(u) = \sum_{q=1}^{Q_u} \text{sgn}(u - 2q + 1) + \sum_{q=1}^{Q_u} \text{sgn}(u + 2q - 1)$$

$$\xi_2(u) = \text{sgn}(u) + \sum_{p=-P_u}^{P_u} \text{sgn}(u + 2p)$$

### 8.4 3D-MDSMCS 完整方程

$$\begin{cases}
\dot{x} = y \\
\dot{y} = (b_2 + c_2|w|)z - (b_1 + c_1|u|)x - (b_3 + c_3|g|)y \\
\dot{z} = -a(x+y+z) + \text{sgn}(x) \\
\dot{u} = x - k_1(u - \xi(u)) \\
\dot{w} = z - k_2(w - \xi(w)) \\
\dot{g} = y - k_3(g - \xi(g))
\end{cases}$$

### 8.5 双涡流数量公式

$$N_{\text{scroll}} = \begin{cases} 2N & \text{当 } P_i = N-1 \\ 2N+1 & \text{当 } Q_i = N \end{cases}$$

### 8.6 同步稳定性条件

$$k_{\min} > L_{\max}$$

### 8.7 SNR 计算公式

$$\text{SNR} = 10 \times \lg \frac{P_{r(t)}}{P_{\vartheta(t)}}$$

### 8.8 检测误差率

$$\varepsilon = \frac{|f - f_0|}{|f_0|} \times 100\%$$
