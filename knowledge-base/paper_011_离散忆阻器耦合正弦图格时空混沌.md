## 2. 研究背景与问题

### 2.1 研究背景

**离散忆阻器的发展**：离散忆阻器作为一类新型广义忆阻器，满足Chua提出的三个指纹特征（pinched hysteresis loop、零交叉特性、记忆性），其输入输出为离散信号，使用差分算子建模。相比连续忆阻器，离散忆阻器天然适合引入离散系统（如混沌映射、离散神经元网络等）。

**离散忆阻器混沌映射的研究现状**：
- 已有大量工作将离散忆阻器引入混沌映射以提升复杂性，包括：离散忆阻器Sine映射、离散忆阻器Hénon映射、离散忆阻器超混沌映射、局部有源离散忆阻器超混沌映射、三角函数耦合离散忆阻器超混沌映射等
- 分数阶离散忆阻混沌映射也有报道（引入Caputo-like分数差分和G-L分数差分）
- **核心挑战**：离散忆阻器中存在累加器或分数阶累加器，可能导致系统发散。如何设计既性能优良又不发散的离散忆阻器混沌映射值得进一步研究

**时空混沌系统**：
- 时空混沌系统是非线性科学的重要分支，在连续域中同时对时间和空间微分，具有更大的密钥空间、更长的周期和更好的随机性
- 离散情形下，耦合映射格子（CML）被广泛应用，其中空间线性耦合和混合线性-非线性耦合被引入
- 耦合Logistic映射格子和Sine映射格子是文献中常见的系统
- **关键空白**：忆阻器具有输入输出端子，可作为非线性系统中的耦合器。已有离散忆阻器耦合神经网络的研究（展示了chimera state等复杂动力学），但**尚无离散忆阻器耦合的时空混沌格子映射的报道**

**电路实现现状**：
- 离散混沌映射的电路实现主要采用数字电路技术（FPGA、DSP、数字集成电路）
- 离散忆阻器混沌映射已有FPGA实现
- **关键空白**：尚无离散忆阻器混沌映射的模拟电路实现报道，为离散信号设计模拟电路仍是一个挑战

### 2.2 核心问题

1. 如何将离散忆阻器作为耦合器引入Sine映射格子，构建时空混沌系统？
2. 如何解决离散忆阻器累加操作导致的可能发散问题？
3. 所构建系统的动力学特性如何？能否产生任意数量的正Lyapunov指数？
4. 能否通过模拟电路和数字电路验证系统的物理可实现性？

## 3. 核心方法与创新点

### 3.1 离散忆阻器模型

采用正弦型离散忆阻器（源自Bao et al., 2021）：

$$v(t_n) = M(q(t_n)) \cdot i(t_n)$$
$$M(q(t_n)) = k \sin(\pi q(t_n))$$
$$q(t_{n+1}) = q(t_n) + i(t_n)$$

其中 $i(t_n)$ 为输入，$v(t_n)$ 为输出，$q(t_n)$ 为内部状态变量（与电荷相关），$k = 1.5$。通过输入信号 $i(t_n) = A\sin(\omega n)$（$A=0.01, q(t_0)=0.55$）验证滞后回线，确认其忆阻器特性。

### 3.2 Sine映射耦合格子（基础框架）

经典CML框架：

$$x_1(n+1) = \psi f(x_1(n)) + (1-\psi) f(x_2(n))$$
$$x_i(n+1) = \psi f(x_i(n)) + (1-\psi) f(x_{i+1}(n))$$
$$x_m(n+1) = \psi f(x_m(n)) + (1-\psi) f(x_1(n))$$

本文采用Sine映射替代Logistic映射：$f(x_i(n)) = a \sin(\omega x_i(n))$

**优势**：更高的复杂性、优雅的结构、便于理论分析。由于Jacobian矩阵是非退化矩阵，当 $x^{n+1} = f(x_i(n))$ 是混沌系统时，系统具有 $m$ 个正Lyapunov指数。

### 3.3 核心创新：离散忆阻器Sine映射格子（DMSML）

**关键设计思想——差分输入防发散**：

$$x_i(n+1) = a\psi \sin(\omega x_i(n)) + (1-\psi) k [x_{i+1}(n) - x_{i+1}(n-1)] \sin(\pi q_i(n))$$
$$q_i(n+1) = q_i(n) + x_{i+1}(n) - x_{i+1}(n-1)$$

**核心创新点**：
- **差分输入机制**：使用 $x_i(n) - x_i(n-1)$ 作为离散忆阻器的输入，而非直接使用 $x_i(n)$。原因：$x_i(n)$ 通常大于零，累加操作会导致发散；差分可以自我平衡，避免发散
- **忆阻器作为耦合器**：离散忆阻器替代传统CML中的线性耦合项 $(1-\psi)f(x_{i+1}(n))$，实现非线性忆阻耦合
- **维度扩展**：引入 $m$ 个离散忆阻器后，系统从 $m$ 维扩展为 $3 \times m$ 维（$m$ 个状态变量 + $m$ 个忆阻器状态 + $m$ 个延迟项）

### 3.4 标准化模型

将系统写成 $x(n+1) = F(x(n))$ 形式，引入 $y_i(n) = x_i(n-1)$：

$$\mathbf{x}_n = [x_1(n), \cdots, x_m(n), q_1(n), \cdots, q_m(n), y_1(n), \cdots, y_m(n)]$$

系统为 $3m$ 维离散系统。

### 3.5 理论分析

**固定点分析**：
- 固定点满足 $x_i^{(e)} = y_i^{(e)}$ 和 $\frac{1}{a\psi} x_i^{(e)} = \sin(\omega x_i^{(e)})$
- $q_i^{(e)} = C_i$（任意实常数）→ **无穷多个固定点**
- 固定点数量取决于参数 $\psi$ 和 $\omega$ 的取值
- 无穷多个固定点意味着系统可具有无穷多个共存吸引子和隐藏吸引子

**耗散性分析**：
$$\text{div}V = \sum_{i=1}^{m} [a\psi\omega \cos(\omega x_i) + 1]$$
- $\text{div}V < 0$：高维耗散超混沌系统
- $\text{div}V = 0$：高维保守系统
- $\text{div}V > 0$：高维不稳定系统

**Lyapunov指数分析**：
- Jacobian矩阵为 $3m \times 3m$ 的分块矩阵 $J = [A, B, C; D, E, F; G, H, Q]$
- **关键结论（Remark 1）**：由于格子结构，系统至少具有 $m$ 个正Lyapunov指数
- 原点处的特征值：$\lambda_i = 1$，$\lambda_{m+i} = a\psi\omega$，$\lambda_{2m+i} = 0$（$i = 1, \cdots, m$）

### 3.6 两个示例系统

**单忆阻器模型（3维）**：
$$x(n+1) = a\psi \sin(\omega x(n)) + (1-\psi) k (x(n) - y(n)) \sin(\pi q(n))$$
$$q(n+1) = q(n) + x(n) - y(n)$$
$$y(n+1) = x(n)$$

参数：$a=1, \psi=0.9, k=1.5, \omega=5$，展示无穷多个共存混沌吸引子。

**双忆阻器模型（6维）**：
两个Sine映射通过两个离散忆阻器交叉耦合，展示超混沌行为和共存吸引子。

### 3.7 电路实现

**模拟电路（Psim仿真）**：
- 首次实现离散忆阻器混沌映射的模拟电路
- 包含数学计算电路和采样保持电路两部分
- 需要外部方波信号驱动采样保持模块（20kHz, 0.5V）
- 需要直流电源激活电路
- 单忆阻器和双忆阻器模型的Psim仿真结果与Matlab数值仿真一致

**数字电路（DSP实现）**：
- 处理器：TMS320
- D/A模块：DAC1008
- 数字信号转换为模拟信号在示波器上观察
- 实现结果验证了系统的物理可实现性

**Knowm忆阻器验证**：
- 将Sine忆阻器替换为离散化的Knowm忆阻器模型
- 验证了使用物理忆阻器器件替代数学模型的可行性
- Knowm忆阻器混沌吸引子分布更广泛

## 5. 主要结论

1. **首次提出离散忆阻器耦合的时空混沌映射**：将离散忆阻器作为耦合器引入Sine映射格子，构建了 $3 \times m$ 维时空混沌系统
2. **差分输入防发散机制**：使用状态变量差分 $x_i(n) - x_i(n-1)$ 作为忆阻器输入，有效解决了累加操作导致的发散问题
3. **任意数量正Lyapunov指数**：系统具有至少 $m$ 个正LE，且大部分大于 0.1，具备强超混沌特性
4. **无穷多个共存吸引子**：由于无穷多个固定点，系统展示无穷多个共存吸引子和隐藏吸引子
5. **首次实现离散忆阻器混沌映射的模拟电路**：通过Psim软件设计并验证了模拟电路的可行性
6. **DSP数字电路验证**：在TMS320平台上成功实现，验证了物理可实现性
7. **物理器件可行性**：通过Knowm忆阻器替代Sine忆阻器，验证了使用物理忆阻器器件的可行性
8. **复杂度不随维度增长**：SampEn和正LE均值分析表明，复杂度不随系统维度增加而增长，但高维系统可产生更多时间序列

## 6. 批判性评价

### 6.1 优势

1. **首创性强**：首次将离散忆阻器作为耦合器引入时空混沌格子映射，填补了该方向的研究空白
2. **理论分析完整**：固定点、耗散性、Lyapunov指数、特征值等理论分析较为系统
3. **差分输入设计巧妙**：简洁有效地解决了离散忆阻器累加发散的核心难题
4. **多层面验证**：从数值仿真到模拟电路（Psim）到数字电路（DSP）再到物理器件（Knowm），验证层次丰富
5. **维度可扩展性好**：系统维度 $3m$ 可根据需要灵活调整，正LE数量随维度线性增长
6. **发表期刊级别高**：IEEE TCAS-I 是电路与系统领域的顶级期刊

### 6.2 不足与局限

1. **缺乏实际应用验证**：论文仅展示了动力学分析和电路实现，未给出具体的加密或其他信息安全应用实例（如NPCR/UACI等加密性能指标）
2. **模拟电路的局限性**：
   - 需要外部方波信号驱动，增加了系统复杂度
   - 迭代速度受方波频率限制
   - 需要直流电源激活
3. **复杂度不随维度增长**：虽然正LE数量增加，但SampEn和正LE均值分析表明单序列复杂度不随维度增长，这意味着高维化的收益主要体现在序列数量而非单序列质量上
4. **参数空间分析不够深入**：仅展示了少数参数组合下的结果，缺乏对完整参数空间的系统性探索
5. **Knowm忆阻器验证较为初步**：仅展示了混沌吸引子图，缺乏与Sine忆阻器版本的定量对比分析
6. **与已有CML改进方案的对比缺失**：未与MDCML、NCMLP等改进CML方案进行混沌性能的定量对比

### 6.3 改进建议

1. 补充图像加密等实际应用案例及安全性分析
2. 探索无需外部驱动信号的纯模拟电路实现方案
3. 进行更系统的参数空间分析（如分岔图的完整参数扫描）
4. 与其他CML改进方案（动态耦合、非邻接耦合等）进行定量对比
5. 研究复杂度不随维度增长的根本原因及可能的改进方案

## 8. 关键公式速查

### 8.1 离散忆阻器模型

$$v(t_n) = M(q(t_n)) \cdot i(t_n), \quad M(q(t_n)) = k\sin(\pi q(t_n)), \quad q(t_{n+1}) = q(t_n) + i(t_n)$$

### 8.2 Sine映射

$$f(x_i(n)) = a\sin(\omega x_i(n))$$

### 8.3 离散忆阻器Sine映射格子（核心模型）

$$x_i(n+1) = a\psi\sin(\omega x_i(n)) + (1-\psi)k[x_{i+1}(n) - x_{i+1}(n-1)]\sin(\pi q_i(n))$$
$$q_i(n+1) = q_i(n) + x_{i+1}(n) - x_{i+1}(n-1)$$

### 8.4 标准化形式（引入 $y_i(n) = x_i(n-1)$）

$$x_i(n+1) = a\psi\sin(\omega x_i(n)) + (1-\psi)k[x_{i+1}(n) - y_{i+1}(n)]\sin(\pi q_i(n))$$
$$q_i(n+1) = q_i(n) + x_{i+1}(n) - y_{i+1}(n)$$
$$y_i(n+1) = x_i(n)$$

### 8.5 固定点条件

$$x_i^{(e)} = y_i^{(e)}, \quad \frac{1}{a\psi}x_i^{(e)} = \sin(\omega x_i^{(e)}), \quad q_i^{(e)} = C_i$$

### 8.6 耗散性判据

$$\text{div}V = \sum_{i=1}^{m}[a\psi\omega\cos(\omega x_i) + 1]$$

### 8.7 Jacobian矩阵分块结构

$$J = \begin{bmatrix} A & B & C \\ D & E & F \\ G & H & Q \end{bmatrix}_{3m \times 3m}$$

其中：
- $A$：对角矩阵，$A_{ii} = a\psi\omega\cos(\omega x_i)$
- $B$：循环矩阵，$B_{ij} = (1-\psi)k\pi(x_j - y_j)\cos(\pi q_i)$（当 $j$ 为 $i$ 的下一个节点时）
- $C$：对角矩阵，$C_{ii} = -(1-\psi)k\pi\cos(\pi q_i)$
- $D$：循环单位矩阵（移位）
- $E = Q = H = 0$
- $F = -D$
- $G = I$（单位矩阵）

### 8.8 原点特征值

$$\lambda_i = 1, \quad \lambda_{m+i} = a\psi\omega, \quad \lambda_{2m+i} = 0 \quad (i = 1, \cdots, m)$$

### 8.9 Knowm忆阻器离散化模型

$$i(t_n) = \left(\frac{x}{R_{ON}} + \frac{1-x}{R_{OFF}}\right)v(t_n)$$
$$x(t_{n+1}) = x(t_n) + \frac{h}{\tau}\left[\frac{1}{1+e^{-\beta(v(t_n)-v_{ON})}}(1-x(t_n)) - \left(1 - \frac{1}{1+e^{-\beta(v(t_n)+v_{OFF})}}\right)x(t_n)\right]$$
