## 二、研究背景与问题

### 2.1 研究背景

混沌作为一种**非周期、类随机以及初值敏感**的非线性动力学现象，是保密通信重要的传输载体。自20世纪混沌现象和混沌同步相继被发现和提出以来，将混沌应用于保密通信成为日渐关注的问题。

### 2.2 核心问题

在已提出的混沌保密光通信方案中，**接收端都需要采用与发射端参数完全一致的激光器**来产生同步的混沌载波。这种同步方式存在两大问题：
1. **结构复杂**：需要参数完全一致的激光器对
2. **实现难度大**：难以在实际中大规模应用

### 2.3 前置工作

2019年，上海交通大学（同一课题组）使用光电光混沌的加密方式，通过**神经网络建模**的方法获得加密信号和混沌载波之间的函数关系，提出了在数字域上实现混沌同步解密的方案。实验采用10GHz带宽的混沌信号，通过训练后的神经网络实现了对20和32Gbit/s信号的解密。但**只是进行了离线实验验证**，没有实时实现。

### 2.4 本文目标

使用电路混沌对基于神经网络的同步进行**实时验证**，基于FPGA实现混沌信号生成、加密和神经网络同步解密的完整闭环。

## 三、核心方法与创新点

### 3.1 系统架构

本文提出了一套完整的混沌保密通信系统，包含三个核心模块：

```
发射端                          接收端
┌──────────────┐              ┌──────────────────────┐
│ FPGA         │              │ ADC → DDR3 SDRAM      │
│ ├─ Lorenz    │   混沌加密    │ ├─ 神经网络同步        │
│ │  混沌生成  │ ──────────→  │ │  (64-20-1 FCNN)     │
│ └─ DAC输出   │   信号        │ └─ 减法解密            │
└──────────────┘              │ └─ DAC输出解密信号     │
      ↑                        └──────────────────────┘
   AWG(10Mbit/s NRZ)
```

### 3.2 混沌信号生成（基于FPGA）

- **混沌系统**：采用洛伦兹混沌系统，参数 $a=10, b=28, c=8/3$
- **离散化**：将连续状态方程离散化后使用DSPBuilder工具箱搭建硬件模型
- **实现平台**：FPGA（Altera Stratix V 5SGXEA7K2F40C2）
- **混沌信号带宽**：100MHz
- **掩盖比例**：混沌信号与传输信号幅度峰峰值之比为 8:1

**洛伦兹状态方程**：

$$\frac{dx}{dt} = a(y - x)$$

$$\frac{dy}{dt} = bx - y - xz$$

$$\frac{dz}{dt} = xy - cz$$

### 3.3 神经网络同步方法（核心创新）

**创新点**：用全连接神经网络替代传统参数一致激光器同步方式

- **网络结构**：64-20-1 全连接神经网络（FCNN）
  - 输入层：64个神经元
  - 隐藏层：20个神经元（1层）
  - 输出层：1个神经元
- **激活函数**：ReLU

$$f(x) = \begin{cases} x, & x \geq 0 \\ 0, & x < 0 \end{cases}$$

- **训练方式**：离线监督学习
  - 训练数据：125万个数据点（80%训练集，20%测试集）
  - 迭代次数：100
  - 学习率：0.001
  - 输入：混沌加密信号（耦合器输出）
  - 目标输出：混沌信号（DAC输出，示波器采集）
- **同步原理**：神经网络学习加密信号与混沌载波之间的函数关系 $y_c = f(y_e)$，从而从加密信号中恢复混沌载波

### 3.4 FPGA硬件实现

- **工具链**：Matlab/Simulink → DSPBuilder → SignalCompiler → Quartus II → FPGA
- **数据格式**：4Q20定点小数（4位整数 + 20位小数）
- **系统时钟**：100MHz
- **存储**：2Gbyte DDR3 SDRAM
- **数据采集**：ADC (EV8AQ160, 5.0GS/s, 单通道312.5MS/s, 8bit精度)
- **信号输出**：DAC (AD9739, 2.5GS/s)
- **控制逻辑**：Verilog HDL状态机 + FIFO
- **流水线设计**：输入层→隐藏层→输出层串行流水线处理

### 3.5 核心创新总结

1. **首次实时验证**：首次将基于神经网络的混沌同步方法在FPGA上实现实时加密解密
2. **简化同步结构**：用训练好的神经网络模型替代参数一致的激光器，极大简化接收端结构
3. **无需同步信道**：不需要额外的同步信道，降低被窃取破译的风险
4. **点对多点潜力**：为点对多点的实时混沌保密通信提供了可能

## 四、实验设计与结果

| **DSPBuilder仿真** | 高相似度 | 0 | 功能仿真验证 |

### 4.4 关键实验观察

1. 混沌信号带宽100MHz，掩盖比例8:1可完全隐藏传输信号
2. 神经网络同步的混沌波形与目标混沌波形高度吻合
3. 解密信号与原始信号的相关曲线峰值尖锐，旁瓣低
4. 实时测试中误码率受限于ADC采样精度（8bit），但仍达到6.4×10⁻⁴

## 五、主要结论

1. **可行性验证**：成功实现了基于FPGA的混沌神经网络同步实时系统，对10Mbit/s NRZ信号进行了实时加密与解密
2. **结构简化**：神经网络同步方法极大简化了混沌保密通信系统的同步结构，无需参数一致的激光器对
3. **安全性提升**：不需要额外同步信道，降低了信息被窃取破译的风险
4. **扩展潜力**：为点对多点实时混沌保密通信提供了可能
5. **局限性**：电路混沌带宽有限（100MHz），难以加密高速率信号；全光混沌具有更宽的带宽和更复杂的非线性动力学特性，是未来方向

## 六、批判性评价

### 6.1 优势

1. **工程实用性强**：完整实现了从混沌生成到加密解密的硬件闭环，具有明确的工程应用价值
2. **创新思路清晰**：用神经网络学习替代传统参数同步，思路简洁有效
3. **资源效率高**：FPGA资源使用率低（ALM仅8%），留有大量扩展空间
4. **实验验证充分**：包含离线训练、DSPBuilder仿真、FPGA实时测试三个层次的验证

### 6.2 不足与局限

1. **信号速率低**：仅实现10Mbit/s信号加密，远低于2019年同课题组的32Gbit/s离线实验，实时化带来显著速率下降
2. **混沌系统单一**：仅使用洛伦兹系统，未探索其他混沌系统（如超混沌、忆阻混沌等）的效果
3. **神经网络结构简单**：64-20-1的单隐藏层网络可能限制了同步精度，未探索更深层网络
4. **安全性分析缺失**：未进行NIST随机性测试、密钥空间分析、抗攻击性能评估等标准安全性测试
5. **信道噪声未考虑**：实验在理想条件下进行，未考虑实际通信信道中的噪声和衰减
6. **误码率偏高**：实时测试误码率6.4×10⁻⁴，虽在可接受范围但不够理想
7. **期刊级别一般**：发表于中文普通期刊，学术影响力有限

### 6.3 与知识库已有论文的关联

- **与009号论文（Kong et al., 2024）对比**：009号论文在FPGA上实现了分数阶忆阻HNN混沌系统的图像加密，同样使用FPGA平台但面向图像加密场景，系统更复杂（5D超混沌+多涡卷+极端多稳态），而本文面向信号级加密通信
- **与011号论文（He et al., 2024）关联**：011号论文的DMSML系统也涉及DSP数字电路验证（TMS320），与本文的FPGA实现形成互补
- **与004号论文（Liu et al., 2024）关联**：004号论文使用TMS320F28335 DSP实现离散忆阻器超混沌映射的图像加密，本文使用FPGA实现洛伦兹混沌的信号加密，两者硬件平台不同但目标相似
- **与025号论文（Lorenz, 1963）关联**：本文直接使用洛伦兹系统作为混沌源，是025号奠基性论文的工程应用

## 八、关键公式速查

### 8.1 洛伦兹状态方程

$$\frac{dx}{dt} = a(y - x), \quad \frac{dy}{dt} = bx - y - xz, \quad \frac{dz}{dt} = xy - cz$$

参数：$a = 10, b = 28, c = 8/3$

### 8.2 ReLU激活函数

$$f(x) = \begin{cases} x, & x \geq 0 \\ 0, & x < 0 \end{cases}$$

### 8.3 相关系数（解密信号质量评估）

$$r = \frac{\sum_{i=1}^{n}(x_i - \bar{x})(y_i - \bar{y})}{\sqrt{\sum_{i=1}^{n}(x_i - \bar{x})^2 \sum_{i=1}^{n}(y_i - \bar{y})^2}}$$

其中 $x_i$ 和 $y_i$ 分别为解密信号与原始传输信号，$\bar{x}$ 和 $\bar{y}$ 分别为均值。

### 8.4 混沌掩盖加密

$$y_e = y_c + s$$

其中 $y_e$ 为加密信号，$y_c$ 为混沌载波，$s$ 为传输信号。

### 8.5 神经网络解密

$$\hat{y}_c = \text{NN}(y_e), \quad \hat{s} = y_e - \hat{y}_c$$

其中 $\hat{y}_c$ 为神经网络同步恢复的混沌信号，$\hat{s}$ 为解密后的信号。
