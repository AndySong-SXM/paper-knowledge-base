## 一句话定位

Bao–Hua 团队继二维离散双神经元 HNN 种子图（Bao 2024a, TCAS-I）之后的离散忆阻 HNN 续作：把两个带分段线性内部状态函数（PWL-SF）的**局部活跃离散忆阻器**嵌入二维正弦激活 HNN 种子图，构造 4 维 DTM-HNN，利用不动点"镜像扩展"机制生成可编程规模的网格多面体超混沌吸引子与均匀共存吸引子，并在 Zynq7020 上做了"双空间分布态切换 + 轻量级滑动窗后处理"的硬件 PRNG（473 Mbps，NIST 全过）。

## 系统模型

### 离散忆阻器（式 1-5）

- 连续原型（Euler 来源）：i = W(φ)v = **φv**（线性忆导，比 Lin 2023a 模型更简），dφ/dt = εv + F(φ)。F(φ) 为内部 PWL 状态函数，ε 为缩放因子。
- 两种锯齿波 PWL-SF：
  - 奇段 F_Odd(ξ) = −ξ + Σ_{m=1..M}[sgn(ξ+2m−1)+sgn(ξ−2m+1)]（式 2，M=2 时 5 个负斜率穿越）；
  - 偶段 F_Even(ξ) = −ξ + sgn(ξ) + Σ_{l=1..L}[sgn(ξ+2l)+sgn(ξ−2l)]（式 3，L=2 时 6 个负斜率穿越）。
- Euler 离散化（式 4）：i_n = φ_n v_n；φ_{n+1} = φ_n + εv_n + F(φ_n)。
- 局部活跃性：DC V-I 图（φ_{n+1}=φ_n=ψ）有多段负斜率区域，(ε,M)=(0.2,2) 与 (ε,L)=(0.2,2) 均呈多局部活跃区。

### 种子图与 DTM-HNN（式 6-7）

- 种子图（Bao 2024a）：x_{n+1}=μx_n+g11 sin x_n+g12 sin y_n；y_{n+1}=μy_n+g21 sin x_n+g22 sin y_n。μ∈(0,1) 神经元衰减，g 为突触权重。μ=0.8、(2,2,−2,2) 时种子图呈多面体超混沌吸引子。
- 4 维 DTM-HNN（式 7，两个忆阻器分别自反馈耦合到 x、y 神经元）：

  x_{n+1} = μx_n + g11 sin x_n + g12 sin y_n + k·z_n·x_n
  y_{n+1} = μy_n + g21 sin x_n + g22 sin y_n + k·u_n·y_n
  z_{n+1} = z_n + εx_n + F1(z_n)
  u_{n+1} = u_n + εy_n + F2(u_n)

  k=0.01 为耦合强度；(ε, M1/L1, M2/L2) 称忆阻器参数。

### 不动点与 Jacobian（式 8-12）——本文最漂亮的理论点

- k 极小时耦合项视为微扰，不动点 Ω=(X*, Y*, Z*, U*) 满足 F1(Z*)=−εX*、F2(U*)=−εY*（式 9）：**种子图不动点被两个忆阻器沿 z、u 轴"镜像 + ε 缩放"复制**，M/L 增大 → 镜像份数增多 → 网格上不动点数增多。
- 数值解（μ=0.8, 权重 (2,2,−2,2)）：种子不动点 Ω_Seed0=(0,0)（不稳定鞍焦点 USF）、Ω_Seed±=(±2.9991, 0.1596)（两个不稳定鞍点 USP）。
- Jacobian 特征多项式（式 11）：P(λ) = λ²·P_Seed(λ)，即扩展出的不动点只新增两个 λ=0 特征值，**稳定性与种子不动点完全相同**。这把"忆阻器为什么能不改变稳定性地扩展吸引子结构"说透了，可直接用于教学。

## 动力学行为

### 分岔与两类吸引子（ε∈[0,0.4]，Wolf 雅可比 LE 算法）

- (M1,M2)=(1,1)：
  - ε<0.183：**均匀共存**分岔——z0∈{−2,0,2} 三条共存超混沌带（z 向），u0∈{−3,−1,1,3} 四条共存带（u 向，L 型）；各带动态范围随 ε 线性增宽，结构相似；
  - ε=0.183：共存带合并为宽超混沌带，前两个 LE 出现小跳变；
  - ε∈[0.183,0.4]：鲁棒**网格分布**超混沌。
- 网格多面体吸引子（ε=0.2，(z0,u0)=(0,0)）：z-u 平面上 3×3 网格（由 9 个经尺度压缩互联的多面体吸引子组成）；改 (M1/L1, M2/L2) 得 3×4（M1,L2）、4×4（L1,L2）、5×4（M1=2,L2）、5×5（M1=M2=2）网格。z-x 平面为断开 three-N 型、z-y 平面为连通 three-N 型。
- 均匀共存吸引子（ε=0.18）：z 向 3 个 N 型共存、z-u 平面最多 3×3=9 个；(M1,L2)=(1,1) 时 3×4=12 个、(L1,L2)=(1,1) 时 4×4=16 个。**x-y 平面投影与初值无关，始终为单个多面体吸引子**——共现存于 z/u（忆阻器初值）维度。
- 定量刻画：对角距离 Δ=√[(zmax−zmin)²+(umax−umin)²]（式 13）在 ε-μ 平面划出网格分布/均匀共存边界（μ 越大进入网格分布所需 ε 越小）；谱熵显示均匀共存态复杂度高于网格分布态；μ∈[0.4,0.48] 谱熵从约 0.9 骤降至 0.1（混沌→周期突变）。
- Table 1 与同类 HNN 对比：本文 4 维离散 + 双内 PWL-SF，网格**可控**共存与分布；Lai 2023（6 维连续 tanh）无超混沌；Kong 2024（5 维分数阶连续）仅 1 维可控；Su 2025（2 维离散）网格无穷共存但分布不可控。

## FPGA 硬件实现

- 平台：Zynq XC7Z020-CLG400 SoC（Cortex-A9 PS + PL），AXI-DMA（仅读通道）经 AXI-Stream 做 PS→PL 参数下发，支持在线参数配置；PL 内 36 位定点（1 符号 + 3 整数 + 32 小数）。
- 观测：状态量化到 [0,2¹⁴) 经 28 根 GPIO 送 AN9767 双通道 DAC（式 14-15：Out_n=(Z_n≪14)|U_n），示波器回采与数值仿真高度一致（3×3 网格、9 共存、5×5 网格均复现）；板卡经以太网 TCP/IP 远程配置。

## 空间分布型 PRNG（核心应用）

- 设计思想：把**动力学拓扑本身当开关**——ε=0.18（均匀共存态，序列被约束在局部网格区、谱熵高）与 ε=0.2（网格分布态，轨迹跨多个网格区）之间切换；每迭代 Q 的整数倍时用 ε=0.2 迭代一次再切回，实现"跨网格跳跃"。
- 密钥：初始状态 (x0,y0,z0,u0)；预热 L=100 次。
- 轻量级重叠滑动窗后处理（Algorithm 1）：20 位定点状态，8-bit 滑窗步长 1（WIDTH=20 → 13 窗）；z 从 MSB、u 从 LSB 双向取窗异或；seed = C1 ⊕ (iter×C2) ⊕ x[19:0]≪24 ⊕ y[19:0]≪4（C1=0xD1342543DE82EF95 奇数乘法混合常数，C2=0x9E3779B97F4A7C15 黄金比 Weyl 增量）；逐窗 seed=(seed⊕(raw≪8(k mod 8)))×C1 → 循环左移 7 位 → ⊕C2(k+1)；最后 BLOCK 个窗各输出 64-bit（小端 8 字节）。
- 指标：
  - NIST SP 800-22：1000 条 × 10⁶ bit，20 位低定点（1+3+16）下 BLOCK=1 与 BLOCK=13 两组设置 **15 项全部通过**；
  - 密钥敏感性：固定点 LSB 扰动 key+2⁻¹⁶，字节差异率 x0 99.6073% / y0 99.6101% / z0 99.6081% / u0 99.6103%（约 12,451,000/12,500,000 字节）；
  - 吞吐：T=64×BLOCK×f_clk/C_clk（式 16），100 MHz 下 96 Mbps（BLOCK=1）→ 473 Mbps（BLOCK=13）理论，实测 432 Mbps；
  - 资源（BLOCK=13）：BRAM 8/280 (2%)、DSP 31/220 (14%)、FF 3057/106400 (2%)、LUT 4398/53200 (8%)——LUT/FF 大头是 AXI 通信开销；吞吐高于 De la Fraga 2021 (281 Mbps)、Sharobim 2023 (301 Mbps)、Meranza-Castillón 2019 (400 Mbps)、Tang 2025 (36 Mbps)，且 DSP 用量远低于 Sharobim (752)。

## 不足与可借鉴之处

- **随机性主要来自 conditioner 而非混沌源**：Weyl 增量 + 奇数乘法混合 + 重叠滑窗是标准比特混合器，NIST 全过不能单独归因于 DTM-HNN；混沌源对输出熵的实际贡献未量化（无每比特熵估计、无源-处理器贡献分离实验）。借鉴时应把混沌源当 entropy source、conditioner 当密码组件分别论证，避免"混沌 through a blender 就算安全"的叙事。
- 临界值 0.183 只在 (μ, k, 权重)=(0.8, 0.01, (2,2,−2,2)) 下给出；ε 切换对其它参数设置的鲁棒性未验证。
- 密钥只有 4 个 20 位初值（≈80 bit），参数 (ε, M/L, k) 未纳入密钥空间；无密钥空间量化与暴力破解复杂度分析。
- 20 位短字长离散混沌的**短周期/动力学退化**问题完全未讨论（对比知识库 paper_104 之外大量文献关注的有限精度效应），NIST 通过不等于周期够长。
- 谱熵"均匀共存态更复杂"只有现象描述，缺机理解释。
- 止步于 PRNG，未做图像加密整体验证（NPCR/UACI/信息熵均无）；自称面向 secure communications / key generation / HSM，但无协议层演示。
- **可借鉴**：
  1. 不动点镜像扩展机制（式 9 + λ² 因子分解）是讲"忆阻器如何不改稳定性地增殖吸引子结构"的干净范例，适合直接搬进混沌/忆阻讲义与毕设理论章节；
  2. "对角距离"作为网格分布↔均匀共存的定量序参量，比纯看图先进；
  3. 双空间分布态切换的 PRNG 设计思想（拓扑即开关）新颖，可用于"多稳态忆阻系统 + 状态 hopping"的加密方案设计；
  4. 后处理流水线极简（DSP 仅 31、473 Mbps），适合资源受限 IoT 硬件加密；
  5. 硬件栈（Zynq7020 + AXI-DMA + AN9767 + 以太网远配）与 paper_102（Yu, TCAD 2025）同平台，教学/毕设可直接复用该实验链路。
