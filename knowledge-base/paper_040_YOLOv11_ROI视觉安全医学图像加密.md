## 二、研究背景与问题

### 2.1 医学图像加密的现实需求
- 医学图像（X光、CT、MRI）在临床诊断和远程医疗中至关重要
- 云计算平台提升了医学图像存储、传输和处理的效率
- **隐私安全挑战**：未经授权的访问、数据泄露和恶意篡改对患者隐私和临床决策构成严重威胁

### 2.2 现有加密方法的局限性

#### (1) 全图像加密的问题
- 计算成本高，尤其处理高分辨率图像时
- 加密后的图像呈现噪声状，容易引起攻击者注意
- 医学图像中并非所有区域都同等敏感

#### (2) 传统ROI加密的问题
- 依赖传统图像处理或区域分割算法提取ROI
- 鲁棒性差，依赖手动调参
- 泛化能力有限
- 处理高分辨率图像或多类型病变时，准确提取ROI困难
- **核心痛点**：加密后的ROI区域在视觉上与周围区域明显不同，容易被定位和攻击

#### (3) 现有深度学习加密的两类方法
| 类型 | 描述 | 局限 |
|------|------|------|
| **辅助型** | 用神经网络生成算法参数（混沌指针、密钥等） | 仍需传统加密流程 |
| **端到端型** | 直接用深度学习执行复杂非线性变换 | 安全性过度依赖网络模型，缺乏灵活性 |

### 2.3 本文解决的核心问题
> **如何在不暴露加密区域位置的前提下，实现对医学图像敏感区域的高效、安全加密？**

## 三、核心方法与创新点

### 3.1 整体框架概述

本文提出了一种**三层架构**的视觉安全医学图像加密方案：

```
┌─────────────────────────────────────────────────────────────┐
│  第一层：ROI智能提取（改进YOLOv11）                            │
│  ├── 输入：原始医学图像                                        │
│  └── 输出：病变ROI区域坐标                                     │
├─────────────────────────────────────────────────────────────┤
│  第二层：ROI加密（MLBPE多层比特平面加密）                       │
│  ├── 输入：提取的ROI像素序列                                   │
│  ├── 5D忆阻超混沌系统生成伪随机序列                             │
│  └── 输出：噪声状加密ROI图像                                   │
├─────────────────────────────────────────────────────────────┤
│  第三层：视觉隐藏（ROI替换+矩阵编码嵌入）                        │
│  ├── LaMa图像修复生成伪ROI                                     │
│  ├── 构建伪明文图像                                            │
│  └── 矩阵编码将加密ROI嵌入伪明文 → 视觉有意义密文               │
└─────────────────────────────────────────────────────────────┘
```

### 3.2 创新点一：改进YOLOv11模型

#### 3.2.1 原始YOLOv11的C3模块缺陷
- C3模块基于并行卷积层，将输入特征图分为两部分
- **关键问题**：无法动态调整特征权重，限制了复杂背景或多尺度目标的处理性能

#### 3.2.2 DFF模块（Dynamic Feature Fusion）
**来源**：Yang et al. (2026), D-net: dynamic large kernel with dynamic feature fusion

```
DFF模块结构：
┌────────────────────────────────────────┐
│  输入特征图 F₁, F₂                      │
│  ↓                                      │
│  通道注意力：w_ch = Sigmoid(Conv(AVGPool([F₁;F₂]))) │
│  ↓                                      │
│  特征校准：F̂ = Conv(w_ch ⊗ [F₁;F₂])     │
│  ↓                                      │
│  空间注意力：w_sp = Sigmoid(Conv(F₁) ⊕ Conv(F₂)) │
│  ↓                                      │
│  最终输出：F̂ = w_sp ⊗ F̂                 │
└────────────────────────────────────────┘
```

**核心优势**：
- 基于通道和空间注意力的动态权重分配
- 选择性强调重要特征，抑制无关信息
- 提升判别精度

#### 3.2.3 MSDA模块（Multi-Scale Dilated Attention）
**来源**：Jiao et al. (2023), DilateFormer

```
MSDA模块结构：
┌────────────────────────────────────────┐
│  输入特征图 A                           │
│  ↓                                      │
│  线性投影生成 Q, K, V                   │
│  ↓                                      │
│  分为 η=4 个注意力头                    │
│  ├── 头1: 膨胀率 r=1, 感受野 3×3       │
│  ├── 头2: 膨胀率 r=2, 感受野 5×5       │
│  ├── 头3: 膨胀率 r=3, 感受野 7×7       │
│  └── 头4: 膨胀率 r=4, 感受野 9×9       │
│  ↓                                      │
│  SWDA: 滑动窗口内稀疏采样键值对          │
│  ↓                                      │
│  拼接 + 线性层聚合 → 输出               │
└────────────────────────────────────────┘
```

**核心公式**：

$$
B_{ij} = \text{Attention}(q_{ij}, K_r, V_r) = \text{Softmax}\left(\frac{q_{ij} K_r^T}{\sqrt{d_k}}\right) V_r
$$

$$
\Omega_{ij} = \{(i', j') | i' = i + s \times r, j' = j + t \times r, -\frac{\omega}{2} \leq s, t \leq \frac{\omega}{2}\}
$$

**核心优势**：
- 利用自注意力的稀疏性减少计算冗余
- 不同膨胀率捕获多尺度语义信息
- 零填充策略处理边缘查询
- 插入到检测头的分类和回归子网络前，提升小目标检测能力

#### 3.2.4 实验验证（INbreast数据集）

| 指标 | 原始YOLOv11 | 改进YOLOv11 | 提升 |
|------|------------|------------|------|
| Precision | 0.9697 | 0.9716 | +0.19% |
| Recall | 0.9327 | 0.9359 | +0.32% |
| mAP50 | 0.9622 | 0.9633 | +0.11% |
| mAP50-95 | 0.8336 | 0.8373 | +0.37% |

- 训练和验证损失均有所下降
- 边界框回归、预测准确性和分类损失均有改善

### 3.3 创新点二：多层比特平面加密（MLBPE）

#### 3.3.1 5D忆阻超混沌系统（5D-MHS）
**来源**：Dong et al. (2024), Phys. Scr. 99(3):035253

$$
\begin{cases}
\dot{x} = a(y - x) + dyw - k(m + 3nu^2)w \\
\dot{y} = ex - xz + w \\
\dot{z} = fxy - cz \\
\dot{w} = by - gw \\
\dot{u} = w
\end{cases}
$$

**密钥参数**：初始值 $(x_0, y_0, z_0, w_0, u_0)$，共5个

#### 3.3.2 MLBPE四级加密流程

```
Level 1: 像素值 → 8位二进制分解
Level 2: 高4位序列 G₁ = bitshift(bitand(F, 240), -4)
         低4位序列 G₂ = bitand(F, 15)
Level 3: 合并为2ρ长度序列，再次比特平面分解
Level 4: 最终生成8ρ长度二进制序列 → 转十进制
```

**单轮置乱-扩散操作**：

$$
K_1 = \text{mod}(\text{floor}(X_1^* \times 10^{11}), 256)
$$

$$
F_1(1) = E(1) \oplus K_1(V_1(1))
$$

$$
F_1(j_1) = E(V_1(j_1)) \oplus K_1(V_1(j_1)) \oplus F_1(j_1 - 1), \quad j_1 = 2, 3, ..., \rho
$$

### 3.4 创新点三：ROI替换与视觉隐藏策略

#### 3.4.1 核心问题
传统ROI加密方法的密文区域在视觉上与周围区域明显不同，攻击者可通过图像差异分析推断ROI位置。

#### 3.4.2 LaMa图像修复模型
**来源**：Suvorov et al. (2022), WACV

- **特点**：基于傅里叶卷积的分辨率鲁棒大掩膜修复
- **作用**：生成结构自然的伪ROI，替换原始ROI
- **输出**：伪明文图像（与原始明文仅在ROI处不同）

#### 3.4.3 矩阵编码嵌入算法

```python
# 算法伪代码
输入: 加密ROI图像 ER, 伪明文图像 H, 混沌序列 U
输出: 视觉有意义密文图像 CI

1. 将H的每个像素分解为8位，构建二进制矩阵 BH (MN×8)
2. 将ER的每个像素分解为8位，构建二进制矩阵 BE (4ρ×2)
3. 对U进行排序得到索引序列 S
4. for t = 1 to 4ρ:
       q = S(t)
       k1 = [BH(q,1)×1] ⊕ [BE(t,1)×2]
       k2 = [BH(q,1)×1] ⊕ [BE(t,2)×2] ⊕ [BH(q,8)×3]
       if k2 ≠ 0:
           反转 BH(q, k2+5)
5. 将BH每行转为十进制，构建DH矩阵
6. CI = reshape(DH, M, N)
```

**关键特性**：
- 完全可逆，不影响解密
- 加密ROI数据隐蔽嵌入到伪明文图像中
- 最终密文图像视觉上与伪明文图像几乎不可区分

### 4.2 视觉质量评估

| 图像 | ROI尺寸 | PSNRc(dB) | SSIMc | PSNRd(dB) | SSIMd |
|------|---------|-----------|-------|-----------|-------|

**结论**：
- PSNRc > 51 dB：矩阵编码嵌入对伪明文图像影响极小
- PSNRd > 51 dB：解密算法能很好地保留原始医学图像信息
- ROI尺寸增大时PSNR略有下降（更多数据嵌入导致非ROI区域轻微数据损失）

### 4.3 密钥安全性

#### 密钥空间
- 5D-MHS的5个初始值作为密钥
- 总密钥空间：$10^{75} \approx 2^{249}$
- **对比**：远超一般安全要求（$2^{100}$以上）

#### 密钥敏感性
- 对每个密钥施加 $10^{-15}$ 的微小扰动
- NPCR值接近99.61%理想值
- 即使极小密钥变化也导致密文剧烈变化

### 4.4 统计安全性

#### 直方图分析
- 加密ROI图像直方图均匀平坦，覆盖完整灰度范围[0,255]
- 所有χ²值均低于临界阈值284.3359（显著性水平0.1）
- 有意义密文图像直方图与伪明文图像几乎不可区分

#### 像素相关性

| 方向 | 原始ROI | 加密ROI | 伪明文 | 有意义密文 |
|------|---------|---------|--------|-----------|
| 水平(HD) | ~0.995 | ~0.001 | ~0.999 | ~0.999 |
| 垂直(VD) | ~0.990 | ~0.002 | ~0.999 | ~0.999 |
| 对角(DD) | ~0.993 | ~0.003 | ~0.999 | ~0.999 |

**结论**：
- 加密ROI有效打破了原始像素相关性（接近0）
- 有意义密文与伪明文相关性高度一致，隐藏了加密区域

#### 信息熵

| 加密ROI | ~7.99 bits（接近理想值8） |

## 五、主要结论

### 5.1 核心贡献总结

1. **改进YOLOv11模型**：集成DFF动态特征融合模块和MSDA多尺度膨胀注意力机制，提升病变区域检测精度（mAP50-95提升0.37%）

2. **MLBPE多层比特平面加密**：将8位像素信息分解到多个比特平面进行分层处理，通过置乱和扩散操作实现高强度加密

3. **视觉安全ROI替换策略**：利用LaMa图像修复模型生成自然伪ROI，通过矩阵编码将加密ROI嵌入伪明文图像，实现视觉有意义的密文

### 5.2 安全性验证
- ✅ 密钥空间 $10^{75}$，抗暴力破解
- ✅ 密钥敏感性：$10^{-15}$ 扰动导致完全不可解密
- ✅ 统计安全性：直方图均匀、像素相关性接近0、信息熵接近8
- ✅ 差分攻击抵抗：NPCR≈99.55%, UACI≈33.43%
- ✅ 选择明文攻击抵抗：特殊图像测试通过
- ✅ 视觉隐蔽性：密文图像与伪明文图像PSNR>51dB

### 5.3 未来工作方向
- 探索身份感知或基于角色的加密机制，实现不同用户的安全访问控制
- 进一步优化加密算法，提升计算效率和实时性能
- 将算法实现迁移到编译型语言（C/C++）

## 六、批判性评价

### 6.1 优势与亮点

1. **跨学科融合创新**：首次将YOLOv11目标检测、图像修复(LaMa)和混沌加密有机结合，形成完整的视觉安全加密流水线

2. **实用性强**：针对医学图像加密的实际需求（保护敏感区域同时保持图像可用性），方案设计具有明确应用场景

3. **视觉安全概念先进**：不仅追求密码学安全，还追求视觉隐蔽性，这是医学图像加密的特殊需求

4. **检测精度提升验证充分**：在INbreast数据集上进行了详细的对比实验，改进YOLOv11的有效性得到验证

5. **安全性分析全面**：涵盖密钥空间、密钥敏感性、直方图、相关性、信息熵、差分攻击、选择明文攻击等多个维度

### 6.2 局限性与不足

1. **混沌系统非原创**：5D-MHS直接引用Dong et al. (2024)的工作，本文未对混沌系统本身做改进或创新

2. **LaMa模型预训练依赖**：视觉安全效果高度依赖LaMa图像修复模型的质量，若ROI区域结构复杂，修复效果可能不自然

3. **仅针对灰度图像**：实验仅使用1024×1024灰度医学图像，未验证彩色图像的适用性

4. **ROI尺寸限制**：当ROI尺寸较大时（如Img4的209×209），PSNR有明显下降（48.70dB），视觉质量受影响

5. **加密时间仍有优化空间**：相比[56](0.9654s)和[62](0.9893s)，本文加密时间(1.0053s)略慢

6. **缺乏抗裁剪/抗噪声鲁棒性测试**：未评估密文在传输过程中遭受裁剪、噪声污染后的解密质量

7. **YOLOv11改进幅度有限**：各项指标提升在0.2%~0.4%之间，改进效果相对温和

### 8.3 MLBPE加密

### 8.4 安全性评估指标

**PSNR**：
$$\text{PSNR} = 10\lg\frac{M \times N \times 255^2}{\sum_{i=1}^{M}\sum_{j=1}^{N}[J(i,j) - K(i,j)]^2}$$

**SSIM**：
$$\text{SSIM} = \frac{(2\mu_J\mu_K + C_1)(2\sigma_{JK} + C_2)}{(\mu_J^2 + \mu_K^2 + C_1)(\sigma_J^2 + \sigma_K^2 + C_2)}$$

**NPCR**：
$$\text{NPCR} = \frac{1}{M \times N}\sum_{i=1}^{M}\sum_{j=1}^{N} R(i,j) \times 100\%$$

**UACI**：
$$\text{UACI} = \frac{1}{M \times N}\sum_{i=1}^{M}\sum_{j=1}^{N}\frac{|J(i,j) - K(i,j)|}{255} \times 100\%$$

**信息熵**：
$$H = -\sum_{g=0}^{255} p(g)\log_2 p(g)$$

**χ²检验**：
$$\chi^2 = \sum_{i=0}^{255}\frac{(O_i - E_i)^2}{E_i}, \quad E_i = \frac{e}{256}$$
