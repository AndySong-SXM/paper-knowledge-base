## 一句话定位

Bao–Hua–Su 团队"网格超混沌"主线从 PRNG 走向图像加密的本体：把**环面函数 T(x)=(R+r·cos x)·sin(x/p)** 引入二维双神经元 HNN 作异质激活函数，造出多舌（multi-tongued）超混沌种子图；再用**多级阶梯状态扩展法**（multistage step state extension）为种子图并联两个只进不出的二维状态控制器，得到 4 维网格超混沌映射，可同时生成 (2M+1)×(2M+1) 规模的**网格分布**与**网格共存**超混沌吸引子；最后把两类吸引子特征分别"接线"进置乱（方向索引机制）与扩散（DNA 位分解双向扩散），形成通用彩色图像加密算法。是 paper_104（Neural Networks 2026，网格多面体超混沌 PRNG）的对偶续作。

## 系统模型

### 2-D 种子图（式 1-3）——环面激活函数

- 无自连接、异质激活的离散双神经元 HNN（式 1）：x_{n+1} = λx_n + g12·sin(y_n)；y_{n+1} = λy_n + g21·T(x_n)。λ∈(0,1) 神经元内部衰减，g12/g21 耦合权重。
- 环面函数（式 2）：T(x) = (R + r·cos x)·sin(x/p)。R 控制基本环面尺寸，r 控制变形与波动幅度，p 控制频率；三参数联合调节非线性形态。作者卖点：比 sin/cos/tanh 有更强的非线性表达能力，且适合刻画神经元周期性极化特性。
- 具体化（g12=2, g21=1, λ=0.5）：x_{n+1} = 0.5x_n + 2sin(y_n)；y_{n+1} = 0.5y_n + (R + 3cos x_n)·sin(0.2x_n)。

### 不动点与稳定性（式 5-10）

- 不动点（式 5）：S=(X,Y)=(n, 2(R+r·cos n)·sin(n/p))，n 由 n − 4sin(2(R+r·cos n)·sin(n/p)) = 0 数值求解；S=(0,0) 恒为不动点。
- Jacobian（式 7）：J_S = [[0.5, 2cos Y],[T'(X), 0.5]]，T'(X) 见式 8；特征方程（式 9）P(k)=k²−k+0.25−2T'(X)·cos Y，根 k_{1,2}=0.5±√(2T'(X)·cos Y)；|k1|<1 且 |k2|<1 时稳定。
- 分岔演化（(r,p)=(3,5)，R–Y 平面不动点轨迹图）：R 从 1 增大时不动点先处于不稳定态；R∈[3,6] 各不动点在 SP/UP 间反复切换并沿 Y 轴成对新增；FBP（fold）一分二产生 SP+UP 对，SP 经 NBP（Neimark–Sacker）转 UP；R→∞ 时不动点个数从 3 增至无穷。

### 动力学分析（2.2-2.3 节）

- 两张参数平面混合分岔图（(x0,y0)=(1,1)）：(R,p) 面与 (R,r) 面均呈"左上准周期道路到混沌"（SP→QP→MP→CH）；**棕色超混沌块占主导**，混沌块次之；混沌/超混沌块内嵌窄周期窗，超混沌块内还嵌有混沌窗。LE 均用 Jacobian 法计算。
- 多舌超混沌吸引子（(r,p)=(3,5)）：R=11 双舌、R=15 四舌、R=20 六舌、R=25 八舌（x–y 相图），层叠嵌套的多层结构，舌数随 R 增大。

### 4-D 网格超混沌映射（式 11-12）——多级阶梯状态扩展

- 状态扩展（式 11）：

  x_{n+1} = 0.5x_n + 2sin(y_n)
  y_{n+1} = 0.5y_n + (11 + 3cos x_n)sin(0.2x_n)
  u_{n+1} = S(u_n) + k1·x_n
  v_{n+1} = S(v_n) + k2·y_n

- 多级阶梯函数（式 12）：S(n) = Σ_{m=1..M}[sgn(n+2m−1) + sgn(n−2m+1)]，M=1,2,3,… 控制阶梯数。关键性质：**u/v 控制器只吃种子图输出、不回授种子图**，故第三、四维不影响原种子图动力学——网格化过程与种子混沌解耦。
- 临界缩放条件：量得种子序列最大动态幅值 Ax=3.26、Ay=7.31，故 k1c=1/Ax≈0.31、k2c=1/Ay≈0.14。
  - **k > kc**（(k1,k2)=(0.32,0.15), M=2）→ 5×5 **网格分布**双舌超混沌吸引子（u–v 平面种子吸引子沿两轴同步扩展）；改 M 得 (2M+1)×(2M+1) 网格分布。
  - **k < kc**（(k1,k2)=(0.3,0.13), M=2）→ (x0,y0,u0,v0)=(1,1,c1,c2)，c1,c2∈{−4,−2,0,2,4} 生成 5×5=25 **网格共存**吸引子；同理可得任意 (2M+1)² 共存。

## 加密算法（第 3 节）

算法总览：密钥 = 4-D 网格超混沌映射初值 (x0,y0,u0,v0)（+(x0,y0)=(1,1) 时即 (1,1,0,0)）与控制参数 M；置乱吃**网格分布**吸引子，扩散吃**网格共存**吸引子。

### 3.1 种子图随机性测试

- IEEE-754 双精度 → 取 x_n/y_n 二进制第 24–31 位构成 8-bit PBN（式 13）；NIST SP 800-22，10⁶ bit 分 100 样本。
- (R,r,p)=(11,3,5)、(x0,y0)=(1,1)：15 项测试通过率最低 0.9688（x 序列 Runs），P 值全部落在 [0.001,0.999]。

### 3.2 置乱：方向索引机制（对接网格分布吸引子）

- M=1/2/3 对应 3×3/5×5/7×7 网格分布吸引子，映射为 8/16/32 个平面方向索引（图 8）；正文统一用 M=2、16 方向。
- 由 u/v 序列生成与图像同尺寸的 U/V 矩阵；方向索引矩阵 E = ⌊|U×2¹⁴|⌋ mod N_dir + 1（式 14，N_dir=16）；步长矩阵 F = ⌊|V×2¹⁴|⌋ mod max(H,W) + 1（式 15）。
- 目标坐标（式 16）：i'=(i + E_x·F) mod H，j'=(j + E_y·F) mod W；16 个方向对应 (E_x,E_y) 偏移表（表 4，如 E=12 → (2,−1)）。再按 BGR 循环移位确定目标颜色通道 c'（图 11），完成 P_{c,i,j} ↔ P_{c',i',j'} 交换，逐像素遍历全图。
- 对比实验（Peppers 384×512）：Zigzag 中央区残存相关；Arnold（5 轮）/Hilbert 数学上要求边长为 2 的幂的方阵（矩形图需黑边填充），且仍留像素相关；本文方向置乱呈雪花状全局随机。50% 剪切攻击下恢复对比（Baboon）：本文与 Arnold 全局置乱可抗剪，Zigzag/Hilbert 丢一半信息后无法恢复。表 5 五准则对比（全局置乱/隐藏数据结构/任意尺寸/抗剪切/混沌相关）：四项传统法全 No，本文全 Yes。

### 3.3 扩散：对接网格共存吸引子 + DNA 位分解

- 关键观察：16 个网格共存吸引子的初始偏移参数与 16 个方向索引的位移权重存在**乘 2 关系**；把方向索引序列 E' 注入控制器，得到改进 4-D 映射（式 17）：

  u_{n+1} = S(2·E'x_n + 0.1·u_n) + k1·x_n
  v_{n+1} = S(2·E'y_n + 0.1·v_n) + k2·y_n

  即每个像素位置用各自对应的共存吸引子演化——"每个方向一个吸引子"，置乱与扩散通过方向索引闭环耦合。
- 双向扩散（式 19）：前向 SF（i=1 用 (S_c,i + U'_i ⊕ S_c1,i) mod 256；i>1 用 S_c,i + V'_{i−1} ⊕ BP(SF_c,i−1, U'_{i−1}, S_ca,i−1, F'_{i−1})），后向 ST 对称（改用 U'_{i+1} 与 BP(ST_c,i+1,…)）；c1/c2 为 RGB 循环序下的下/上一通道，BP 为 BitProcess 函数（Algorithm 1，借鉴 DNA 位分解；示例参数 f=4, Da=45, Db=78, Dc=180）。三通道顺序执行即得密文。

## 不足与可借鉴之处

- **纯软件仿真，无硬件实现**：与同团队 paper_104（Zynq7020 FPGA PRNG）、paper_101/102（FPGA 图像加密）路线断裂；算法的实时性/资源开销完全未讨论，亦无加密耗时与吞吐对比。
- **密钥空间论证虚高**：2²¹³ 按双精度 10¹⁶/初值估算，但浮点混沌轨道有效熵远低于字面值，且 4 个初值之外参数 (R,r,p,M,k1,k2) 不入钥；无有限精度退化与短周期讨论（paper_104 对 20-bit 定点退化同样未讨论，是团队共性问题）。
- **BitProcess 透明度差**：Algorithm 1 仅以伪代码浮图给出（示例参数 f/Da/Db/Dc），"DNA 位分解"类比松散，复现需自行逆向。
- 方向索引↔共存吸引子偏移的"×2 关系"只在 M=2（16 方向）演示，M 取其它值时置乱方向数（(2M+1)²−1？）与扩散吸引子数如何对齐未说明，**可扩展性存疑**。
- NIST 只测种子图 PBN，未测密文比特流；置乱/扩散的密钥流统计性质分开论证不足。
- 4-D 网格映射无独立的不动点/Jacobian 分析（靠"控制器不回授"一句话豁免）；共存吸引子数量（25 个）相比极端多稳态文献偏少。
- 可借鉴：
  1. **"吸引子特征接线算法结构"的设计哲学**：网格分布吸引子→置乱方向索引、网格共存吸引子→扩散状态偏移，比"混沌序列当 PRNG 输入"的浅组合深一层，是"系统拓扑即密码结构"叙事的干净范例，适合毕设"系统构造—算法设计"一体化写作；
  2. 环面激活函数 T(x)=(R+r·cos x)sin(x/p) 是新的 HNN 异质激活模板，三参数形态可调，可迁移到其它神经网络混沌系统；
  3. 多级阶梯状态扩展法 + 临界缩放 kc=1/A 判据是系统化的网格/共存吸引子生成范式（源出 Bao 2024 TCAS-I [26]），可直接复用；
  4. 方向索引置乱**不受方阵/2 的幂限制**，对遥感、医学等非标尺寸图像友好（对照 paper_090 遥感图像加密与 Arnold/Hilbert 的尺寸痛点）；
  5. 双向扩散 + RGB 通道循环耦合 + BitProcess 的逐像素雪崩结构值得移植验证。
