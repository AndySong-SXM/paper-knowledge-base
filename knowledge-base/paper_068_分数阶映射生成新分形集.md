## 1️⃣ 研究背景与问题

### 1.1 研究背景

- **分数阶微积分**自17世纪下半叶诞生，其核心特征是**记忆效应**（power-law类型），在粘弹性材料建模、热传导等领域展现出比整数阶模型更简洁且更精确的建模能力。
- **分形几何**具有非整数维度，是对欧几里得几何的维度延续。分形已广泛应用于量子力学、宇宙学、图像处理、多孔介质、医学和复杂网络等领域。
- 分数阶算子与分形之间存在深刻的数学联系：分数阶算子通过积分/求和引入"过去"的记忆，而分形通过迭代产生无限精细的结构。

### 1.2 研究问题

传统分形集（经典二次映射 $z \leftarrow z^2 + c$ 的Julia集和Mandelbrot集）在分数阶场景下的推广尚缺乏系统性研究。现有工作要么局限于特定模型，要么仅引入人工记忆而非自然记忆。核心问题：

1. **经典Julia集和Mandelbrot集能否被"分数阶化"？如何做？**
2. **分数阶算子的记忆效应如何影响分形集的结构和维度？**

### 1.3 研究动机

- 将分数阶微积分与分形几何两大非整数理论进行有机融合
- 为分形集的分数阶推广建立系统性的判据
- 探索记忆参数对分形结构的调控作用

## 2️⃣ 核心方法与创新点

### 2.1 分数阶化分形集的三大判据

作者首次提出分形集分数阶推广的**判据**（Criterion）：

1. **(i) 真实性**：推广必须根植于真正的分数阶算子/过程（非局部算子）
2. **(ii) 有效性**：引入的记忆参数不仅深刻改变原始映射的结构，还要确保新映射是良定义的
3. **(iii) 可还原性**：当阶数为特定整数（如1）时，新映射可退化为对应的经典情况

### 2.2 三种分数阶映射构造方法

基于非线性分数阶微分方程 $\frac{d^\alpha x}{dt^\alpha} + G(x(t-\Delta h))\sum \delta(\frac{t}{h} - (k+\varepsilon)) = 0$，推导出三种分数阶映射：

**方法一：分数阶微分映射 (Map 3.3)**

$$z_{n+1} = z_0 + \frac{h^\alpha}{\Gamma(\alpha)} \sum_{k=0}^{n} (n-k+1)^{\alpha-1} (z_k^2 - z_k + c)$$

- 核函数：$\kappa_1^\alpha(n) = n^{\alpha-1}$（幂律记忆）
- 基于Riemann-Liouville/Caputo分数阶导数

**方法二：分数阶差分映射 (Map 3.5)**

$$z_{n+1} = z_0 + \frac{1}{\Gamma(\alpha)} \sum_{k=0}^{n} \frac{\Gamma(n-k+\alpha)}{\Gamma(n-k+1)} (z_k^2 - z_k + c)$$

- 核函数：$\kappa_2^\alpha(n) = \frac{\Gamma(n+\alpha)}{\Gamma(n+1)}$（渐近幂律/下降阶乘律记忆）
- 基于Caputo分数阶差分

**方法三：Grünwald-Letnikov分数阶映射 (Map 3.6)**

$$z_{n+1} = z_n^2 - z_n + c - \sum_{k=1}^{n} \omega_k(\alpha) z_{n-k+1}$$

- 核函数：$\kappa_3^\alpha(n) = -\omega_n(\alpha) = \frac{\Gamma(n+1)\Gamma(-\alpha)}{\Gamma(n-\alpha)}$
- 其中 $\omega_k(\alpha) = \binom{k-\alpha-1}{k} = \frac{-\alpha(1-\alpha)\cdots(k-\alpha-1)}{k!}$

### 2.3 变阶数分数阶映射

进一步引入**变阶数**（variable-order）概念，将常数阶数 $\alpha$ 替换为阶数函数 $\alpha_n = |\sin(n)|$，探索记忆参数随时间变化对分形集的影响。

### 2.4 创新点总结

| 创新点 | 说明 |
|--------|------|
| **判据框架** | 首次提出分数阶化分形集的系统性判据，区分子自然记忆与人工记忆 |
| **三种构造方法** | 系统比较三种分数阶算子（微分/差分/GL导数）生成的分形集 |
| **变阶数推广** | 首次将变阶数分数阶微积分引入分形集生成 |
| **核函数分析** | 通过核函数差异解释不同分数阶映射导致的分形集行为差异 |
| **维度分析** | 定量研究记忆参数α对分形维数的影响 |

## 3️⃣ 实验设计与结果

### 3.1 实验设置

- **计算区域**：Julia集 $\Omega_z = [-1.5, 1.5] \times [-1.5, 1.5]$；Mandelbrot集 $\Omega_c = [-2.5, 1.5] \times [-2.0, 2.0]$
- **参数**：$c = -0.5 + 0.5i$（Julia集）；$T = 200$, $R = 10^{10}$, $\rho = 1500$（逃逸时间算法）
- **分辨率**：$500 \times 500$
- **维度计算**：盒计数法(box-counting)，使用Frederic Moisy的MATLAB函数

### 3.2 分数阶微分映射 (Map 3.3) 结果

当 $\alpha$ 从1降至0时：

| 属性 | 观察结果 |
|------|---------|
| **Julia集** | 保持连通，边缘变平滑，尺寸增大 |
| **Mandelbrot集** | 整体外观保持，但**连通性被破坏** |
| **维度变化** | 两者趋势基本一致：稳步上升，最终趋近约1.9905，伴有微小跳跃（均值幅度 < 0.0008） |

### 3.3 分数阶差分映射 (Map 3.5) 结果

| 属性 | 观察结果 |
|------|---------|
| **Julia集** | 在 $\alpha \in [0.200, 0.962]$ 时维度 $D < 1$（极度碎片化）；$\alpha \in [0.237, 0.942]$ 时 $D = 0$（**集合消失**） |
| **Mandelbrot集** | 外部保持良好，尺寸略微缩小；**海马谷(Seahorse Valley)处萌发毛发状结构** |
| **维度变化** | 稳步下降至 $\alpha = 0.277$，然后出现间歇性大幅跳跃（最大振幅达0.0491） |

### 3.4 Grünwald-Letnikov映射 (Map 3.6) 结果

| 属性 | 观察结果 |
|------|---------|
| **Julia集** | 仅存在于 $\alpha \in [0.938, 1]$；维度在 $[0.938, 1]$ 区间呈线性下降：$D = 32.3\alpha - 30.2$（$R^2 = 0.9226$） |
| **Mandelbrot集** | 尺寸变化不明显，但**边缘逐渐模糊**；连通性被破坏；维度在 $[0.573, 1]$ 稳步下降后出现较大波动 |

### 3.5 变阶数映射结果

使用 $\alpha_n = |\sin(n)|$ 时：

- Julia集 $K_{(3.3)}$、$K_{(3.5)}$、$K_{(3.6)}$ **严重解体**；$K_{(3.3)}$ 和 $K_{(3.5)}$ 的对称性被破坏
- Mandelbrot集关于实轴的**对称性保留**，但 $M_{(3.3)}$ 和 $M_{(3.5)}$ 严重衰减

### 3.6 盒计数维度对比表

|---|:---------:|:---------:|:---------:|:---------:|:---------:|:---------:|
| 0.25 | 1.9903 | — | — | 1.9782 | 1.3656 | 1.4640 |

> 经典Julia集维度参考值：1.7234；Mandelbrot集维度参考值：1.6042。α=1时相对误差分别为0.3598%和1.1906%，在可接受范围内。

### 3.7 核函数对比分析

核函数 $\kappa_1^\alpha$ 和 $\kappa_2^\alpha$ 的定性差异源于**近期记忆**（靠近坐标原点）的不同，当 $\alpha \to 0$ 时差异更显著。正是这种短期记忆的细微差异导致了分形集的显著不同。

核函数 $\kappa_3^\alpha$ 具有更快的衰减速率和更轻的尾部，因此可以被截断以方便计算，且对阶数变化或干扰具有强抵抗力。

## 4️⃣ 主要结论

1. **分数阶分形集的存在性**：通过三种分数阶算子成功构造了新的Julia集和Mandelbrot集，这些集合在不同程度上保持了分形特征（精细、复杂、尺度无关结构）。

2. **记忆效应的影响**：
   - 对Julia集：对称性和连通性严重受损，部分情况下集合完全消失
   - 对Mandelbrot集：对称性（关于实轴）保持良好，抗记忆干扰能力强于Julia集；出现"海马谷毛发"等新细节

3. **三种构造方法对比**：
   - Map (3.3)：Julia集最稳定（保持连通），Mandelbrot集连通性被破坏
   - Map (3.5)：Julia集存在范围最窄，但Mandelbrot集出现有趣的新结构
   - Map (3.6)：Julia集存在范围最窄（仅 $\alpha \in [0.938,1]$），但Mandelbrot集对外观保持最好

4. **变阶数记忆**：与常数阶数的（渐近）幂律记忆效果截然不同，因为前者受阶数函数信息调制。

5. **可扩展性**：方法可推广到高维分形集、超复数映射、耦合系统、交替系统、噪声扰动系统等。

## 5️⃣ 批判性评价

### 5.1 优点

- **系统性**：首次建立分数阶分形集推广的判据框架，有理论高度
- **方法多样性**：覆盖三种主流分数阶算子（连续微分、离散差分、GL导数），比较全面
- **核函数分析视角**：从核函数（记忆的具体体现）角度解释不同映射的行为差异，具有洞察力
- **定量分析**：盒计数维度的系统计算提供了客观的比较基准
- **前沿性**：引入变阶数分数阶微积分，是较新的研究方向

### 5.2 不足

- **深度有限**：对分形集的分形特征（如自相似性、多分形谱等）分析不够深入，主要集中在可视化观察和盒计数维度
- **变阶数部分较浅**：仅使用 $\alpha_n = |\sin(n)|$ 一种函数，结论的普适性有待验证
- **缺乏应用**：虽然提到了保密通信、图像加密等潜在应用，但未给出具体应用方案
- **计算细节**：对数值计算中的收敛性、截断误差等讨论不足
- **理论分析薄弱**：缺乏对分数阶分形集连通性、对称性破缺等性质的严格数学证明
- **Julia集消失现象**：Map (3.5) 和 (3.6) 中Julia集在较大α范围内消失，但未给出充分的理论解释

### 5.3 对后续研究的启示

- 可将分数阶分形集应用于混沌图像加密，利用记忆参数α作为额外的密钥维度
- 核函数分析思路可推广到其他分数阶混沌系统的动力学分析
- 变阶数分形集为构造时变密钥空间提供了新思路

## 7️⃣ 关键公式速查

### 分数阶微分映射 (Riemann-Liouville/Caputo)

$$z_{n+1} = z_0 + \frac{h^\alpha}{\Gamma(\alpha)} \sum_{k=0}^{n} (n-k+1)^{\alpha-1} (z_k^2 - z_k + c)$$

- 核函数：$\kappa_1^\alpha(n) = n^{\alpha-1}$
- 当 $\alpha = h = 1$ 时退化为经典二次映射

### 分数阶差分映射 (Caputo Difference)

$$z_{n+1} = z_0 + \frac{1}{\Gamma(\alpha)} \sum_{k=0}^{n} \frac{\Gamma(n-k+\alpha)}{\Gamma(n-k+1)} (z_k^2 - z_k + c)$$

- 核函数：$\kappa_2^\alpha(n) = \frac{\Gamma(n+\alpha)}{\Gamma(n+1)}$
- 当 $\alpha = 1$ 时退化为经典二次映射

### Grünwald-Letnikov 分数阶映射

$$z_{n+1} = z_n^2 - z_n + c - \sum_{k=1}^{n} \omega_k(\alpha) z_{n-k+1}$$

$$\omega_k(\alpha) = \binom{k-\alpha-1}{k} = \frac{-\alpha(1-\alpha)(2-\alpha)\cdots(k-\alpha-1)}{k!}$$

- 核函数：$\kappa_3^\alpha(n) = -\omega_n(\alpha) = \frac{\Gamma(n+1)\Gamma(-\alpha)}{\Gamma(n-\alpha)}$
- 当 $\alpha = 1$ 时：$\omega_1(1) = -1$，$\omega_k(1) = 0\ (k \geq 2)$，退化为经典二次映射

### 核心分数阶算子定义

**Riemann-Liouville分数阶积分**：
$$I_{0+}^\alpha y(t) = \frac{1}{\Gamma(\alpha)} \int_0^t (t-s)^{\alpha-1} y(s) ds$$

**Caputo分数阶导数**：
$${}^{C}D_{0+}^\alpha y(t) = \frac{1}{\Gamma(n-\alpha)} \int_0^t (t-s)^{n-\alpha-1} y^{(n)}(s) ds$$

**Grünwald-Letnikov分数阶导数**：
$${}^{GL}D_{0+}^\alpha y(t) = \lim_{n \to \infty} \frac{1}{h_n^\alpha} \sum_{k=0}^{n} (-1)^k \binom{\alpha}{k} y(t - k h_n)$$
