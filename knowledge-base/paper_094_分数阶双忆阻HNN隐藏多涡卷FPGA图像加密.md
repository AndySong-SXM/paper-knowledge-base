## 🎯 研究动机与创新点

连续时间分数阶混沌系统做加密有两个公认瓶颈：①数值积分轨迹光滑导致**短期时间自相关 / 拓扑周期性**，裸序列很难过 NIST 的 FFT 与近似熵测试；②单忆阻器 HNN 只能模拟单一神经机制（突触可塑性或电磁感应二选一）。本文在余飞团队 091 号（Kong 2024, Neural Networks）基础上给出"双忆阻 + 隐藏多涡卷 + 全链加密"的升级版。四大贡献：

1. **新型 5D 分数阶双忆阻 HNN（FOMHNN）**：非理想突触忆阻器（多段阶梯忆导 g(ϕ)²，模拟突触可塑性）+ 理想磁控忆阻器（e·sin(Hu)·y，模拟外部电磁辐射）同时调制 3 神经元 HNN；解析证明系统具有**多条平行线平衡点 + 双零特征值**，严格落入隐藏吸引子范畴。
2. **新动力学现象**：ADM 数值求解下发现隐藏网格多涡卷吸引子（涡卷位置与 g(ϕ) 稳定根一一对应）、**长持续暂态混沌**（~4300 s 亚稳混沌后坍缩）、**频率可控空间周期性**（共存吸引子沿 u 轴以 Tu=2π/H 周期自我克隆，H 为"结构密钥"）与分形吸引盆边界的极端多稳态。
3. **FPGA 高精度低功耗实现**：ADM 迭代映射到 Xilinx XC7Z020（IEEE 754 单精度浮点），复现 4 涡卷隐藏吸引子，总功耗仅 **0.244 W**，LUT 占用 12.10%。
4. **自适应彩色图像加密方案**：提出**混沌导数提取器**（提取一阶差分 |ΔX|,|ΔY|,|ΔZ| 的高精度小数部分 + 下采样 D=15 + 三重 XOR 融合）剥离拓扑周期性，10⁶ bit 序列通过 NIST SP 800-22 全部 15 项；加密采用 SHA-256 明文绑定会话密钥（一次一密）+ 3D→1D 全局置乱 + 双向反馈扩散 + **LSB 密钥嵌入实现"无密钥分发"传输**。

## 🔧 核心方法

### 双忆阻器模型（式1–3）

- **突触忆阻器（非理想通用型，式1）**：i₁ = W₁(ϕ)v₁ = k·g(ϕ)²·tanh(y)，D^q ϕ = −c·g(ϕ) + d·tanh(y)。**g(ϕ)² 平方项保证忆导严格非负**（满足物理无源性）；−c·g(ϕ) 泄露项定义非理想性。g(ϕ) = ϕ − f₁(ϕ) 或 ϕ − f₂(ϕ)（式2），f₁/f₂ 为 tanh 叠加的多段阶梯函数：M、N 控制涡卷数（奇/偶），m 控步宽，n 控陡度（n 越大越接近阶跃）——借鉴 Lai et al. 的网格多涡卷生成法。
- **辐射忆阻器（理想磁控型，式3）**：i₂ = W₂(u)v₂ = e·sin(Hu)·y，D^q u = y。u 为 y 的分数阶积分（法拉第电磁感应定律），H 内部频率增益（默认 1），e 辐射强度。
- 忆阻指纹验证（Fig.1）：q=0.95, M=0, m=1, n=30, c=1, d=3.5, k=1, e=0.5 下两类忆阻器均呈紧磁滞回线（PHL 过原点、随频率收缩、随幅值扩张）。

### 5D FOMHNN 系统方程（式5–6）

```
D^q x = −x + 0.8·tanh(x) − k·g(ϕ)²·tanh(y)
D^q y = −y − 1.2·tanh(y) + tanh(z+1) + e·sin(Hu)·y
D^q z = −z + 4·tanh(x) + tanh(z+1) − I_dc        (I_dc = 1)
D^q ϕ = −c·g(ϕ) + d·tanh(y)
D^q u = y
```

突触权矩阵 W（式6）：w₁₁=0.8，**w₁₂=−k·g(ϕ)²**（静态权重被忆导替换，构成神经元 2→1 的动态抑制突触），w₁₃=0，w₂₁=0，w₂₂=−1.2，w₂₃=1，w₃₁=4，w₃₂=0，w₃₃=1。电磁辐射项 e·sin(Hu)·y 只加在神经元 2（局部辐照场景）；−I_dc 超极化电流与 tanh(z+1) 的 +1 移位把 z 子系统平衡点移到 z=−1——这是构造隐藏吸引子的关键设计。

### 平衡点与隐藏吸引子的严格证明（式7–11）

令各导数为 0 解代数方程组：y=0 ⇒ g(ϕ)=0（多段阶梯函数有多个离散根 ϕ*_j）；tanh(z+1)=0 ⇒ z=−1；−x+0.8·tanh(x)=0 由 F′(x)=1−0.8·sech²(x)≥0.2>0 证 x=0 唯一根；u 仅以 e·sin(u)y 形式出现，y=0 时该项恒零 ⇒ **u=C 为任意常数**。平衡集（式8）：

```
E = { (0, 0, −1, ϕ*_j, C) }   —— 多条平行线平衡点（ϕ* 离散 × u 连续）
```

Jacobian 在 E 上的特征方程 (λ+0.2)·λ²·(λ−(e·sin C−2.2))·(λ+c·g′(ϕ*_j))=0（式10），特征值（式11）：

```
λ₁ = −0.2；λ₂ = λ₃ = 0（双零）；λ₄ = e·sin(C) − 2.2 ∈ [−2.7, −1.7]（恒负）；λ₅ = −c·g′(ϕ*_j)
```

M=0 时 g(ϕ)=0 有 5 根 ϕ*≈{−2,−1,0,1,2}：ϕ*∈{0,±2} 处 g′>0（λ₅<0，稳定线），ϕ*≈±1 处 g′<0（λ₅>0，鞍状线）——**平衡线沿 ϕ 轴稳定/鞍状交替**。关键：所有平衡点共有双零特征值 ⇒ 非双曲退化，Grobman–Hartman 定理失效，不稳定性被限制在低维中心流形。再补数值验证：沿线平衡点均匀取 100 点 × 5 方向 10⁻³ 扰动 = 1000+ 初值，轨迹或逃逸或收敛到混沌盆外的周期环，无一从孤立不稳定平衡点激发混沌——满足 Leonov–Kuznetsov 隐藏吸引子定义（混沌吸引子经退化平衡点的全局分岔涌现）。

### ADM 数值求解（式12–18）

系统写为算子形式 D^qX = LX + NX + C（式12，L 线性/N 非线性/C 常数），非线性项做 Adomian 多项式分解（式15–16，如 tanh：A₀=tanh(x₀)，A₁=x₁·sech²(x₀)），施 Riemann–Liouville 分数阶积分算子 J^q（式17）得迭代格式（式18）。**截断 N=6、步长 h=0.01，局部截断误差 O(h^((N+1)q))**；与 Adams–Bashforth–Moulton 预估校正法交叉验证一致。分数阶 LE 用 Benettin–Wolf 算法（变分方程 + Gram–Schmidt 周期正交化）严格计算。

### 动力学现象

1. **网格多涡卷隐藏吸引子（Fig.3）**：q=0.95, k=0.7, e=0.5, c=1, d=3.5, IC=[0.1,0,0,0,0]；f₁(ϕ)/M=1 → **5 涡卷**，f₂(ϕ)/N=1 → **4 涡卷**。机制：g(ϕ)=0 的稳定根（g′>0）即涡卷中心，鞍根（g′<0）为排斥边界——**涡卷拓扑由平衡线交替稳定性严格决定**，空间位置可设计。硬件代价讨论：M/N 增大只线性增加 tanh 项（FPGA 上并行展开，DSP/LUT 面积增加而单步延迟不变）。
2. **长持续暂态混沌（Fig.4）**：u(0)=8.16 时轨迹在 ϕ 方向亚稳混沌漫游 **4000+ 秒**，t≈4300 s 突然坍缩到稳定平衡点；h=0.005/0.001 缩小步长复现（坍缩时刻漂移但现象稳健）——证明非数值伪影。
3. **分岔与 MLE（Fig.5）**：k∈[1.7,3.2] 扫描 umax，倍周期/逆倍周期通路，局部放大见分形细密结构与周期窗；(k,u₀) 平面 **501×501 网格** 2D 扫描（每点 10000 步弃前 8000 步），动力学态图（P0–P16/CM）与 2D MLE 云图几何吻合；固定 k 沿 u₀ 轴动力学态高度交织——纯初值决定的极端多稳态。
4. **极端多稳态与分形吸引盆（Fig.6）**：k=1.5, e=0.5, n=50 时捕获 **11 个共存隐藏吸引子**（Period-1/Period-3 极限环 + 混沌混合），沿 u 轴呈 2π 平移对称复制；(u₀,ϕ₀)∈[−4,4]×[−3,3] 的 501×501 吸引盆边界高度交织分形——初值微扰即跨盆。
5. **频率可控空间周期性（式19，Fig.7）**：理想忆阻器正弦项使向量场对 u 平移不变，空间周期 **Tu=2π/H**——H=1→Tu=2π≈6.28，H=2→Tu=π（共存吸引子密度翻倍），**H=π（无理数）→Tu=2（整数周期）**。加密意义：H 作为结构密钥调共存吸引子密度，直接扩大暴力破解复杂度。

### FPGA 实现（第 4 节）

- 平台：ALINX AX7020（Xilinx XC7Z020-2CLG400I），Vivado 2018.3，50 MHz；ADM 多项式系数软件预计算后传入 FPGA 迭代模块，经 DAC 出示波器。
- **IEEE 754 单精度浮点**（1+8+23 bit）+ floating-point IP v7.1（tanh/sin 也走 IP 核），防定点截断致混沌退化。
- 复现 4 涡卷隐藏吸引子（Fig.9）：混沌系统初值敏感性决定点对点误差无意义，改比几何边界——FPGA 与 MATLAB 相图的涡卷幅值最大/最小值偏差可忽略（受 DAC 分辨率与单精度截断限制）。
- 资源（Table 2）：LUT 6438（**12.10%**）、LUTRAM 427（2.45%）、FF 12039（11.31%）、**DSP 98（44.55%）**、IO 34、BUFG 1。
- 功耗（Fig.10）：**总计 0.244 W**（静态 0.108 W/44% + 动态 0.136 W/56%，动态中布线 28%、DSP 23%）——边缘计算适用的超低功耗混沌源。

### 加密方案（第 5 节，5 步）

- **Step 1 哈希密钥生成**：SHA-256(P) 得 256 bit H → 分 4 个 8 字节块块内 XOR 得 4 个自适应种子 → 代数映射为 FOMHNN 初值 (y₀,z₀,u₀) 与耦合强度 k（保证落入混沌区）——明文绑定的"一次一密"。
- **Step 2 混沌导数提取器（核心创新）**：连续分数阶系统因数值积分有短期自相关/拓扑周期性，裸难过 NIST 的 FFT 与近似熵项。本文不直接用状态变量，而提取**一阶差分 |ΔX|,|ΔY|,|ΔZ| 的高精度小数部分**，配**下采样 D=15** 剥离周期包络，再三重 XOR 融合成均匀分布的 SeqX/SeqY/SeqZ。
- **Step 3 3D→1D 全局置乱**：彩色图 P（M×N×3）拉平成长度 L 的 1D 向量，SeqX 升序排序索引全局置乱——同时打破单通道内与 RGB 通道间相关性。
- **Step 4 双向反馈扩散（式20–21）**：前向 C_fw(i)=P_perm(i)⊕SeqY(i)⊕C_fw(i−1)；后向 C_bw(i)=C_fw(i)⊕SeqZ(i)⊕C_bw(i+1)。选 XOR 而非模加以规避进位传播延迟，双向级联保证雪崩。
- **Step 5 LSB 密钥嵌入**：不经信道传密钥，直接把 H 嵌入密文前 256 像素的 LSB（像素值至多 ±1，视觉不可察）——实现"无密钥分发"（ciphertext-key-extractable）传输。解密对称：提 LSB 恢复 H → 再生三序列 → 逆后向扩散 → 逆前向扩散 → 逆置乱，无损重建。

### 抗攻击与鲁棒性

- **CPA/KPA/CCA（论证性）**：会话密钥由当前明文 SHA-256 唯一绑定，单比特改动触发完全不同混沌轨道；已知一对明密文对其他图像无效；篡改密文会破坏 LSB 内嵌哈希导致解密流完全不相关。
- **抗噪（Fig.14，Table 6）**：椒盐噪声 10%→PSNR 16.16 dB/SSIM 0.5266；30%→11.83/0.2341；50%→10.16/0.1088，面部轮廓仍可辨——逆扩散+全局逆置乱把局部噪声均匀稀释到全图。
- **无**密钥敏感性定量实验、**无**抗裁剪/数据丢失实验。

## ⚠️ 不足与可借鉴之处

**不足**：
1. **"无密钥传输"存在夸大且与鲁棒性声明自相矛盾**：LSB 嵌入把 SHA-256(P) 放在密文前 256 像素——Kerckhoffs 原则下嵌入位置公开，攻击者可直接提取 H；所谓 KPA 免疫论证（"拥有明密文对推不出其他图的密钥"）成立，但攻击者**拥有明文 P 即可自行算出 H=SHA-256(P) 并重现全部三条混沌序列**，"comprehensive immunity to known-plaintext attacks"的措辞过强；且确定性映射（同图必得同密文）不满足语义安全。更致命的是**单点故障**：前 256 像素 LSB 一旦受损，H 无法恢复 ⇒ 解密彻底失败——这与 50% 噪声下仍可恢复的鲁棒性叙事直接冲突（50% 椒盐几乎必然污染密钥区），论文对此只字未提，也无纠错/冗余备份设计（对照 093 号至少用了三重重复码保护 LSB 标注）。
2. **加密实验标配缺项**：无密钥敏感性测试（初值/参数 ±10⁻¹⁵ 解密失败率）、无抗裁剪/数据丢失实验（093 有 1/8 裁剪、091 也无）、无吞吐率 Mbps 与并行性分析；"<0.25 s"在 i5 MATLAB 下并不算快。
3. **分数阶+ADM+下采样的隐性成本**：生成长度 L 的序列需 15×L 步 ADM 积分（每步 6 阶截断多项式、含 tanh/sin），计算开销远高于离散混沌映射；论文未与离散方案做效率对照，"suitable for real-time applications"的成色存疑。
4. **指标表述选择性**：摘要只报最优的 512² NPCR 99.6114/UACI 33.4910，但 Mandril 256² 的 NPCR 99.5997 **低于**理论值 99.6094；UACI 33.4910 与理论值偏差 0.0275，反而比 091 的 33.4671（偏差 0.0036）更远——"optimal resistance"的宣称打了折扣。
5. **NIST 只测单条 10⁶ bit 序列**：未按通行做法做多序列通过率/比例区间检验，统计效力弱于 093（4 个吸引子 × 10⁶ bit）。
6. **FPGA 只验证了混沌源**：4 涡卷相图上板，但 PRNG（导数提取器）与完整加密链路未上板——"预留芯片面积给加密模块"仅是口头展望（091 至少做了加密状态机上板，本文在硬件闭环上反而退了半步）。
7. **双零特征值平衡线的数值敏感性未充分讨论**：λ₂=λ₃=0 意味着沿平衡线方向无回复力，长期积分漂移与分数阶记忆截断误差的累积影响只靠 ABM 交叉验证兜底；暂态混沌坍缩时刻对步长敏感（作者已承认），工程复现的确定性边界未给出。
8. 电磁辐射建模的生物物理合理性薄弱：e·sin(Hu)·y 是数学构造而非神经生理学模型，"脑启发"叙事主要是为了动机包装。

**可借鉴**：
1. **混沌导数提取器（Chaotic Derivative Extractor）**：一阶差分 + 取高精度小数部分 + 下采样（D=15）+ 多路 XOR 融合——专治连续（分数阶）混沌的拓扑周期性/短期自相关，让 FFT 与近似熵测试过关。这是任何"连续混沌 → 密码级 PRNG"管线都可移植的通用后处理范式，比单纯截位/取小数更进一步。
2. **双忆阻功能解耦建模**：一个忆阻器管突触可塑性（多段阶梯 g(ϕ) → 涡卷数/位置可设计），一个管电磁辐射（正弦 sin(Hu) → u 轴平移对称 + Tu=2π/H 频率可调空间周期）——把"多涡卷"与"多稳态密度"拆给两个独立旋钮，**H 作为结构密钥调吸引子密度**是密钥空间设计的新维度（093 用忆阻初值/幅值/权矩阵，本文用 H，可互补）。
3. **隐藏吸引子的完整论证模板**：解析平衡集（线平衡点）→ 特征值分解出双零根 → 判定非双曲退化 → 1000+ 邻域扰动数值排除自激路径 → 援引 Leonov–Kuznetsov 定义。比"算个特征值就宣称 hidden"的常规做法多一步数值证伪，审稿更稳。
4. **g(ϕ) 零点稳定性 ↔ 涡卷中心的解析对应**：稳定根（g′>0）即涡卷中心、鞍根（g′<0）即排斥边界，Fig.3 虚线对齐展示——多涡卷"可设计性"论证的清晰范式（091 也有类似映射 4N+1↔2N+1，本文的几何对应更直观）。
5. **分数阶混沌 FPGA 低功耗标杆**：0.244 W 总功耗 + 12% LUT + ADM 系数预算外移 + IEEE 754 单精度 + DAC 示波器闭环——边缘设备混沌源叙事的完整工程链；资源余量论证（DSP 44% 后仍剩 LUT 88%）的写法可学。
6. **LSB 密钥嵌入的"密文自含密钥"框架**：虽然安全性论证有漏洞（见不足 1），但作为**免密钥分发的工程模式**值得在威胁模型较弱场景（如内部协同、对照 093 的医生标注嵌入）讨论其适用边界——写本子时可作为"便捷性-安全性权衡"的典型案例。
