## 研究动机与创新点

1. **多段线性忆阻器模拟神经突触**：提出新型多段线性忆阻器模型，忆导 W(ϕ)=a+bϕ，内部磁通方程 ϕ̇ = cv − d·f(ϕ)，其中 f(ϕ) 为 N 阶分段线性奇函数，斜率 m_i=(−1)^i·m₀，分段点 E_i=(2i−1)E₁ 对称分布。N=3, m₀=−0.4, E₁=0.5, a=1.8, b=0.05, c=0.7, d=7 时验证捏滞回线（PHL）、非易失性（POP 与 ϕ 轴 4 个负斜率交点）与多稳态。
2. **双神经网络异质耦合（DNNHCMS）**：两个结构不同的三神经元 Hopfield 网络（权矩阵 W_L、W_R 相异，见原文 Eq.(6)），用忆阻器作 N2–N4 跨网络突触连接，耦合电流 ρ·W(ϕ)·v 从 N2 减去、向 N4 注入，构成 7 维系统。**耦合强度 ρ 决定动力学特性**；涡卷数量由忆阻器分段参数 N 控制（N=0→1 涡卷，N=5→6 涡卷）。
3. **极端多稳态 + 振幅控制**：仅改变忆阻器初值 ϕ(0) 即可在同一相空间不同位置产生任意多个拓扑结构一致的共存吸引子（N→∞ 时无穷多），且参数 c 可调实现振幅控制；分岔图呈阶梯状，每级台阶对应一个独立吸引子，吸引域与吸引子一一对应。
4. **电路级验证完整**：Multisim 模拟电路仿真 + STM32F103 数字实现（Keil 平台）+ FPGA（Vivado，5369 LUTs / 332 FFs / 24 BRAMs / 18 DSPs，最大时钟 29.90 MHz），三种手段均复现数值仿真的 3/4 涡卷吸引子。
5. **10 个明文相关动态 S 盒的图像加密方案**：每轮置乱-扩散中由混沌序列动态选盒做代换，减少冗余计算；并提出 **DNNHCMS 初值边界约束映射**，结合 SHA-512 把明文哈希与外部密钥耦合，避免系统因初值选取不当跌入周期轨道，显著增强明文敏感性、抗差分攻击能力。

## 核心方法

### 系统模型（Eq.7，7 维）

```
ẋ1 = −x1 + 1.1·tanh(x1) − 1.9·tanh(x3)
ẋ2 = −x2 − 15·tanh(x1) + 4.5·tanh(x3) − ρ(a+bϕ)(x2−y1)
ẋ3 = −x3 + 3.8·tanh(x1) + 0.7·tanh(x2) + 1.9·tanh(x3)
ẏ1 = −y1 − 0.7·tanh(y1) − 9.5·tanh(y3) + ρ(a+bϕ)(x2−y1)
ẏ2 = −y2 + 0.9·tanh(y1) + 1.6·tanh(y2) + 2.15·tanh(y3)
ẏ3 = −y3 + 0.3·tanh(y1) − 1.8·tanh(y2) + 2.5·tanh(y3)
ϕ̇  = c(x2−y1) − d·f(ϕ)
```
数值仿真：MATLAB R2021b，RK4，步长 h=0.01，Gram-Schmidt 正交化计算 Lyapunov 指数；涡卷数 = N+1（N 从 0 增至 5，1→6 涡卷）。

### 加密流程（Fig.19/20，双密钥同步置乱-扩散）

1. **密钥生成**：明文图像 P → SHA-512 → 64 字节两两相加得 32 个十进制明文信息 {h₁…h₃₂}；与外部密钥 {K₁…K₇} 经 Eq.(20) 得明文相关密钥 {Kh₁…Kh₇}（即 Cipher 2）；再经 Eq.(21) 得四组内部初值 IV₁–IV₄（每组仅 x₁(0)∈(−1,1)、ϕ(0)∈(−3,3) 为动态键，其余 5 个初值固定 0.1）。
2. **动态 S 盒（10 个）**：IV₂ 驱动 DNNHCMS 迭代（弃前 3500 点），7 维序列重构成长度 40005 的 s2 → 去尾 5 点 → 10 段 × 4000 → ×10¹⁰ 取整 mod 256 → 保唯一元素 → **九宫换位算法**[43]消除不动点与反不动点 → 10×256 S 盒矩阵。
3. **加密主循环**：IV₁/IV₃/IV₄ 各生成一组 7 维序列（弃 3500 暂态）→ 重构为 s1/s3/s4 → Eq.(26) 得置乱序列 PS、扩散序列 DS1/DS2、选盒控制序列 SCS；对每个像素：按 PS(i) 步长在循环序列上按步长奇偶前后选取目标像素 → 当前像素与目标像素同时做 (A+B) mod 256 扩散 → SCS 动态选 S 盒代换 → 交换两像素位置。
4. **解密**：逆序逆运算（算法结构对称，见原文解密算法）。

### 加密方案安全性（Table 12–18）
- **密钥空间**：单组初值 2×10¹⁵ × 6×10¹⁵ ≈ 2¹⁰³，四组独立初值 → **2⁴¹²**，远超 2¹⁰⁰ 安全界限。
- **NIST SP800-22**：15 项测试全部 Pass（最低 p 值 0.0266）。
- **卡方检验**：7 幅测试图全部 Pass（α=0.05）。
- **相邻像素相关性**（2000 对采样，Table 14）：密文水平/垂直/对角/反对角相关系数均 ≈0（如 Baboon 水平 0.74694→0.00207，Peppers 垂直 0.98173→−0.04320）。
- **信息熵**：GSE 全部 ≈7.9993–7.9994；LSE 全部落在理想区间 (7.901515698, 7.903422936) 内。
- **差分攻击（NPCR/UACI）**：100 次独立实验平均，NPCR 99.6066%–99.6108%（阈值 N*₀.₀₅=99.5893%），UACI 33.4518%–33.4796%（临界区间 33.3730%–33.5541%），全部 Pass。
- **密钥敏感性**：7 个外部密钥各加 10⁻¹⁵ 扰动，密文对 NPCR 99.59%–99.64%、UACI 33.42%–33.48%，全部 Pass。
- **鲁棒性**：1/32、1/16、1/4 裁剪及 1%/5%/10% 椒盐噪声下均可恢复有效信息。
- **效率**：512×512 灰度图加密 0.256 s / 解密 0.242 s；512×512×3 彩图加密 0.838 s / 解密 0.788 s；时间复杂度 O(MN)。对比文献 [31] 3.9 s、[67] 5.521 s，速度优势显著。
- **综合对比（Table 18）**：在相关性、熵、加密时间、明文敏感性、密钥空间五指标上整体最优或并列最优。

### 硬件实现
- **模拟电路**：Multisim 仿真，Rρ=5 kΩ、Ra=5.56 kΩ、Rb=1000 kΩ、Rc=14.29 kΩ、Rd=1.43 kΩ、C=20 nF、Ea=1 V、VCC=15 V、τ=0.2 ms。
- **STM32F103** + Keil，DAC8552 输出观察。
- **FPGA**（Vivado）：tanh 用 ROM-LUT 实现，FSM 调度，5369 LUTs（30.51%）、332 FFs、24 BRAMs（40%）、18 DSPs（22.5%），动态功耗 0.019 W、静态 0.094 W，最高时钟 29.90 MHz。

## 不足与可借鉴之处

1. **S 盒 DU=12 略偏高**（最优文献可达 10），差分特性有提升空间；LP=0.1328 也略高于文献 [50] 的 0.1250。
2. **"异质"主要靠拓扑连接与权矩阵差异近似**，未考虑神经元异质性、非均匀时间尺度、外部噪声等复杂因素（作者自己在结论中承认，列为未来工作）。
3. **加密结构为单轮同步置乱-扩散**，没有形式化的多轮轮函数设计；抗已知明文/选择明文的理论分析偏经验性（仅靠统计测试）。
4. **可借鉴**：
   - 忆阻器分段参数 N 直接控制涡卷数量的"参数-拓扑"映射关系，可用于其他多稳态系统设计；
   - 初值边界约束映射（SHA-512 + 吸引域分布先验）是防止混沌加密系统跌入周期轨道的通用范式，值得移植到自己的加密方案设计；
   - 九宫换位消不动点 + 混沌序列保唯一直接构造 S 盒的工程做法简单有效；
   - 同一模型贯通"忆阻器→动力学→模拟/数字电路→加密应用"的完整叙事结构，可仿照用于论文写作。
