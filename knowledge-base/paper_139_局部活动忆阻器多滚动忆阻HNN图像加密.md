## 二、研究动机与方案定位

- **动机**：局部活动（local activity）被认为是复杂性的起源（Chua），忆阻器具备类突触的兴奋/抑制 mimicry 能力；现有忆阻 HNN 构造多滚动吸引子一般用符号函数、绝对值函数、多分段函数等非光滑元件，而 **Sigmoid 函数光滑连续、易于模拟电路实现，却从未被用于神经网络多滚动吸引子设计**——本文填补这一空白。
- **核心主张**：提出 Sigmoid 函数构成的**局部活动忆阻器**（稳定平衡点个数由参数 M 任意可调），将其作为 **HNN 神经元自反馈突触**，构造仅含单向连接的**四神经元忆阻 HNN**，实现：① 滚动数任意可控（f1 → 2M+2 个双滚动，f2 → 2M+3 个双滚动）；② 同构/异构共存吸引子与极端多稳态（滚动数 → ∞ 时退化为极端多稳态）；③ 参数 α 的幅值控制（与 LE 解耦）；④ STM32 数字硬件实现并在示波器捕获多滚动吸引子；⑤ 基于该 HNN 混沌序列的**像素级图像加密算法**（像素拆分 → 像素选择性合并 → 像素选择性替换）。
- **创新点自评**：1) Sigmoid 型局部活动忆阻器作自反馈突触、简单拓扑生成任意数量复杂多滚动；2) 滚动吸引子随突触权重碎裂为同构/异构共存吸引子（混沌-混沌、混沌-周期、周期-周期）；3) 微控制器数字硬件平台验证；4) 像素级加密算法性能优于部分近年算法。

## 三、忆阻器模型（式 1–5）

磁通控制型忆阻器：

$$i = W(\varphi)\,v,\qquad \dot\varphi = \alpha v - \beta u(\varphi),\qquad W(\varphi) = p - q\tanh(\varphi) \tag{1}$$

$$u(\varphi) = \varphi - f(\varphi) \tag{2}$$

$f(\varphi)$ 由多 Sigmoid 函数组成，分偶数/奇数稳定平衡点两支：

$$f_1(\varphi) = 1 - 2H(n\varphi) + \sum_{i=0}^{M}\big[2H(n\varphi + 2in) - 1\big] + \sum_{i=0}^{M}\big[2H(n\varphi - 2in) - 1\big] \tag{3}$$

$$f_2(\varphi) = \sum_{i=0}^{M}\big[2H(n\varphi + (1+2i)n) - 1\big] + \sum_{i=0}^{M}\big[2H(n\varphi - (1+2i)n) - 1\big] \tag{4}$$

$$H(x) = \frac{1}{1 + e^{-x}} \tag{5}$$

- **f1 对应 2M+2 个（双）滚动，f2 对应 2M+3 个（双）滚动**（M = 0,1,2,…），n 为陡峭度正参数（n=50，跃迁宽度约 1/n=0.02）；f 实质是以 Sigmoid 逼近的阶梯函数（台阶位于 ϕ = 0,±2,…,±2M 或 ±1,±3,…,±(2M+1)），**台阶数 = 滚动数**，这是全文"滚动数可控"的代数核心。
- 标准参数：α = 16，β = 9.6，p = q = 1，n = 50，M = 1，ϕ(0) = 0。

## 四、忆阻器三大特性验证（式 6–9）

1. **捏滞回线（pinched hysteresis）**：1 V 正弦驱动、频率 F 从 0.4 → 200，回线过 v–i 原点、瓣面积随频率增大而收缩，F=200 时退化为单值函数（线性电阻）——符合 Chua 忆阻器判据。
2. **非易失性（POP 断电图）**：令 v=0，F(ϕ,0) = −βu(ϕ) = −βϕ + βf(ϕ)（式 6/7）。f1 时 POP 与横轴交于 Q1–Q7 **7 个平衡点（4 稳定）**，f2 时 C1–C9 **9 个（5 稳定）**；f1 各稳定点的忆导值按初值分区：W(ϕ(Q1))=1.9951（ϕ(0)<−2）、W(ϕ(Q3))=1.7616（−2<ϕ(0)<0）、W(ϕ(Q5))=0.2384（0<ϕ(0)<2）、W(ϕ(Q7))=0.0049（ϕ(0)>2）——断电后忆导稳定保持，**非易失**；且"与多数仅有有限稳定平衡点的忆阻器不同"，M 可调 ⇒ 稳定平衡点个数任意可调。
3. **局部活动（DC V–I 曲线）**：dϕ/dt=0 得 DC 平衡点方程（式 8/9）：

$$V = \frac{\beta}{\alpha}\big(X - f(X)\big),\qquad I = W(X)V = \frac{\beta}{\alpha}\big(p - q\tanh(X)\big)\big(X - f(X)\big)$$

   DC V–I 曲线出现负斜率区 ⇒ 局部活动：f1 有 **3 个局部活动区**（蓝/绿/红），f2 有 **4 个**（蓝/绿/红/品红，Table I 给出各区状态变量/DC 电压/电流范围）。局部活动 ⇒ 可作为"电源"向外界提供稳定能量（混沌边缘内核，神经形态电路天然候选）。

## 五、忆阻 HNN 模型与平衡点机理（式 10–13）

- **HNN 电路方程**（双曲正切激活，C_i = R_i = 1，I_i = 0）：

$$C_i \frac{dx_i}{dt} = -\frac{x_i}{R_i} + \sum_{j=1}^{n}\omega_{ij}\tanh x_j + I_i \tag{10}$$

- **网络拓扑**（Fig. 4）：四神经元**仅单向连接**；神经元 2、4 有自反馈，忆阻器（可调忆导）替换神经元 2 的自反馈突触权重：

$$\begin{cases} \dot x = -x + 0.3\tanh(y) \\ \dot y = -y + 9\tanh(z) + kW(\varphi)\tanh(y) \\ \dot z = -z + 0.3\tanh(w) - 6\tanh(x) \\ \dot w = -w + a\tanh(y) + \tanh(w) \\ \dot\varphi = \alpha\tanh(y) - \beta u(\varphi) \end{cases} \tag{11}$$

- **平衡点**：联立零斜率得两条曲线求交（式 12）：

$$l_1(\varphi,\omega) = 9\tanh(z) + kW(\varphi)\tanh(y) - y,\qquad l_2(\varphi,\omega) = a\tanh(y) + \tanh(w) - w$$

  其中 x = 0.3tanh(y)，y = 9tanh[(β/α)u(ϕ)]，z = 0.3tanh(w) − 6tanh(x)（线性化文本中 l1 的 "tanh(ϕ)" 应为 tanh(y)，按式 11 重构）。
- **5 双滚动 ↔ 15 平衡点机理**（f1/f2、M=1、a=15、α=16、β=9.6、n=50、初值 (0,0,0,1,1)）：每对 l1/l2 在每个双滚动上有 3 个交点 ⇒ 15 个平衡点；Jacobian（式 13，h_i = sech²(·)，r = kW(ϕ)h2）特征值分类：R>0、σ<0 为 **USF-1**（不稳定指数-1 鞍焦），R<0、σ>0 为 **USF-2**；**每个双滚动 = 2 个 USF-2（各自撑起一个滚动轨道）+ 1 个 USF-1（连接两滚动的键轨）**——Table II 给出 15 个平衡点坐标与特征值。这是"多滚动吸引子生成机制"的标准图景，本文用平衡点分析将其讲透。

## 六、动力学分析

1. **分岔与 LE**（α=16, β=9.6, n=50, 初值 (0,0,0,1,1)，a 为参量）：a∈[0, 6.45) 倍周期分岔道路，a=6.45 进入混沌且分岔图轨迹突变为 5（五双滚动），a∈[6.45, 30] 恒混沌。**a=15 时 LE（Wolf Jacobian 算法）**：L1=0.2512，L2=0，L3=−0.9444，L4=−3.1332，L5=−9.4291（**笔记推算**：和 = −13.2555 < 0，耗散；KY 维 ≈ 2 + 0.2512/0.9444 ≈ 2.27）。
2. **多滚动**：f1 → 2M+2 双滚动（M=1→4 个、M=2→6 个），f2 → 2M+3 双滚动（M=0→3 个、M=1→5 个）；f(ϕ)≡0 时多滚动消失、只剩单双滚动 ⇒ **忆阻器内部状态方程 f(ϕ) 的形式直接控制滚动数**，调整 f 可得任意数量多滚动（Fig. 7，ϕ–ω 平面）。
3. **对称破缺与共存吸引子**（α=16→β=16、n=50、f2、M=1、初值 (0,0,0,w0,ϕ0)）：
   - a=5.8：参数对称破缺，**异构共存** 10 个吸引子 B1–B10（混沌-混沌 B1−B2/B3−B4、混沌-极限环 B5−B6、极限环-极限环 B7−B8/B9−B10），吸引盆 S1–S10 分区（Fig. 8(a)(b)）；
   - a=15：多滚动碎裂为 **同构共存** 5 个双滚动吸引子 C1–C5，对应吸引盆 T1–T5（Fig. 8(c)(d)）；
   - 结论：共存吸引子数量随滚动数增长，滚动数 → ∞ ⇒ **极端多稳态**。
4. **幅值控制**：α∈[0,20] 时 ϕ 幅值随 α 线性增大，其余四路信号幅值不变；**α 不出现在 Jacobian（式 13）中 ⇒ LE 不受 α 影响、动力学行为不变**——纯正交幅值控制（Fig. 9）。
5. **硬件实现**：STM32F103ZET6 微控制器 + TLV5618 数模转换 + Tektronix TBS 2000B 示波器；迭代 2×10⁵ 次、采集 2 s；示波器捕获 4 双滚动与 5 双滚动吸引子（Fig. 10/11），与数值仿真一致——低成本数字实现路线（非 FPGA/模拟电路）。

## 七、图像加密算法（像素级三阶段）

加密总流程（Fig. 12）：**像素拆分 → 像素选择性合并 → 像素选择性替换**；相对传统"置乱-扩散"结构，该算法在打乱像素位置的同时改变像素值。

1. **像素拆分（Pixel Splitting）**：8 bit 像素拆为高 4 位图 H 与低 4 位图 L。
2. **像素选择性合并（Pixel Selective Merge）**：混沌序列生成随机数矩阵 S，索引为矩阵 I；在 I 作用下分别从 H、L 中选 4 位拼成新 8 位图像 Q；Q 与 S 解耦（"dissociated"）得合并矩阵 T（Fig. 13）。
3. **像素选择性替换（Pixel Selective Substitution）**（式 14，m×n 图像，列向链式替换，含 floor 运算，H_{i,j} = S_{i,j}×2³² 量级整数密钥流）：

$$C_{i,j} = \begin{cases} \big(T_{i,I(i,j)} + T_{m,I(m,j)} + H\big) \bmod F, & i = 1 \\ \big(T_{i,I(i,j)} + T_{1,I(1,j)} + H\big) \bmod F, & i = 2 \\ \big(T_{i,I(i,j)} + C_{i-1,j} + C_{i-2,j} + H\bigr) \bmod F, & i \geq 3 \end{cases} \tag{14}$$

   i=1 行锚定末行、i=2 行锚定首行（循环包裹），i≥3 为两级密文反馈——小改变沿列向级联传播。F 的确切取值文本层未交代（8 位图像推断 F=256）。

## 九、不足

1. **密钥机制空白（最严重）**：加密部分的密钥定义、密钥空间、密钥敏感性、密钥更新策略全部缺失；式 (14) 的 H_{i,j}=S_{i,j}×2³² 依赖混沌序列量化，但量化方式（floor 细节、F 取值）交代含糊，有限精度退化（论文库 paper_015/078 主题）未讨论；NPCR/UACI 只在默认密钥下报值，无法支撑"唯密钥可解"的结论。
2. **安全分析包严重缺项**：无 NIST/随机性检验混沌序列本身、无已知/选择明文攻击实验、无加密效率对比（Table V 只比 NPCR/UACI/熵/相关性等）、无与标准密码（AES）或轻量密码对照；作为 TCYB 论文，加密部分明显弱于动力学部分。
3. **内部口径不一致**：鲁棒性实验正文（10% 裁剪 + 0.1% 椒盐）与 Fig. 15 图注（5% 裁剪 + 1% 椒盐）矛盾；裁剪攻击强度只有视觉图无数值。
4. **数学严谨性**：系统有界性无证明（多滚动 + 共存 + 幅值控制的联合有界性仅数值展示）；"滚动数 → ∞ ⇒ 极端多稳态"是极限直觉断言，无测度/维数分析；共存吸引子的吸引盆只给二维切片图；LE 仅报单参数点（a=15）与 Wolf 算法，无复杂度（SE/C₀/PE）评测。
5. **动力学-加密脱节**：加密安全性叙事（"滚动拓扑越复杂、序列随机性越强"）未经验证——没有比较多滚动 vs 单滚动混沌序列的 NIST/相关指标；多滚动生成机制带来的密钥可解释性优势没有转化为任何密钥设计（如以 M 或 f 形式作密钥分量，Discussion 仅一笔带过"可提供更多密钥设置选择"）。
6. **硬件实现深度有限**：STM32 数字迭代只是数值重放（ODE 离散化），未给离散化步长/精度影响分析、无资源占用与实时性数据、无模拟电路实现（忆阻器模拟实现恰是 Sigmoid 光滑性的卖点，却只做数字验证）。

## 十、可借鉴之处

1. **"Sigmoid 阶梯函数 f(ϕ)"控制滚动数的代数构造**：台阶数=滚动数（2M+2 / 2M+3），一个参数 M 切换任意数量多滚动，比三角函数/分段线性方案更光滑、利于模拟电路；u(ϕ)=ϕ−f(ϕ) 的"分段线性 + 阶梯偏移"模板可移植到其他忆阻器/HNN 构造（库内 paper_108/135 同族可对照）。
2. **忆阻器特性验证三件套**：捏滞回线（频率扫描至退化为线性电阻）+ POP 断电图（稳定平衡点计数与忆导分区值）+ DC V–I 负斜率区（局部活动区列表格化）——"新忆阻器"论文的完整 checklist，局部活动区用表格（状态变量/电压/电流范围）呈现值得沿用。
3. **平衡点机理图谱**：l1/l2 曲线求交 + USF-1（键轨）/USF-2（滚动轨）分类 + "每双滚动 3 平衡点"的对应关系，把多滚动生成机制讲成可复核的几何图景（Table II 全平衡点-特征值表是范例）。
4. **幅值控制与 LE 解耦的正交性论证**（α 不进 Jacobian ⇒ 不动力学），一句话可检验，比多数"幅值控制"论文的论证更干净。
5. **像素级 bit-layering 加密结构**：8 bit 拆高/低 4 位 + 混沌索引选择性重组 + 列向两级密文反馈替换——轻量、无大矩阵排序，和库内 paper_138 高/低 4 位分治、paper_097 位平面交织构成一条 bit-level 结构谱系；式 (14) 的"首末行循环锚定"写法可借鉴。
6. **低成本硬件验证范式**：STM32 + TLV5618 + 示波器 2 s 捕获多滚动相图，对"可硬件实现"主张是低成本自证方案（与 FPGA 路线 paper_108/134 互补）。

## 十二、一句话定位

一篇 TCYB 2024 的"忆阻器构造 + HNN 动力学 + 图像加密"全线论文：**Sigmoid 阶梯忆阻器以"台阶数=滚动数"的干净代数实现任意数量多滚动，局部活动/非易失/POP 验证三件套与 USF-1/2 平衡点机理图谱是忆阻 HNN 构造的规范范例，α 幅值控制与 LE 解耦的论证简洁可鉴**；但加密部分密钥机制空白、无 NIST/攻击实验、鲁棒性口径自相矛盾、滚动复杂度到密钥设计优势的转化停在口头——动力学强、加密弱，适合作为"忆阻 HNN 构造方法论"的正面教材与"加密部分如何拖后腿"的反面教材双重引用。
