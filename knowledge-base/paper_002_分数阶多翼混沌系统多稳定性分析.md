## 二、研究背景与问题

### 2.1 研究背景

**分数阶微积分的兴起**：
- 分数阶微积分与经典微积分几乎同时出现，虽然早期无法给出明确物理解释，但突破传统整数阶微积分的限制，进一步补充了微积分概念
- 1983年，Mandelbrot首次发现自然界中许多动力系统具有分形特性，进而研究分形与整数维度之间的自相似现象
- 分数阶微积分在描述机械和物理过程方面具有历史记忆性和全局空间相关性的优势

**多稳定性现象的重要性**：
- 多稳定性是非线性系统中的关键现象，对于同一组参数，不同的初始条件可以获得多种类型的共存吸引子
- 与整数阶系统的共存吸引子研究相比，分数阶混沌系统中共存吸引子的报道相对较少
- 多翼混沌系统具有复杂的吸引子结构和运动轨迹，在混沌应用领域中比一般分数阶混沌系统表现出更好的性能

### 2.2 研究问题

1. **理论问题**：如何利用**Conformable Fractional Derivative (CFD)** 定义构建分数阶多翼混沌系统？
2. **数值求解**：如何采用**Adomian分解法 (ADM)** 高精度求解分数阶混沌系统？
3. **多稳定性分析**：当系统阶数 q=0.9 时，系统能展现哪些多稳定性现象？
4. **硬件实现**：如何在Multisim仿真软件和DSP平台上实现分数阶混沌系统？

### 2.3 研究动机

- CFD相比传统分数阶定义具有简单优雅的形式，但很少有学者研究使用CFD的非线性系统动力学和复杂性
- 分数阶混沌系统的电路实现难点在于如何实现可调阶数
- 数字信号处理器(DSP)在工程中很受欢迎，具有强大的信号处理能力

## 三、核心方法与创新点

### 3.1 核心方法

#### 3.1.1 Conformable分数阶导数定义

本文采用**Conformable Fractional Derivative (CFD)** 定义，相比传统的Riemann-Liouville (R-L)、Grünwald-Letnikov (G-L)和Caputo定义，CFD具有更简单优雅的形式。

#### 3.1.2 Adomian分解法 (ADM) 数值求解

**算法步骤**：

1. **微分方程形式**：
   $$
   \begin{cases}
   T_{t_0}^q x(t) = Lx(t) + Nx(t) + g \\
   x^{(k)}(t_0^+) = b_k, \quad k = 0, \cdots, m-1 \\
   m \in \mathbb{N}, \quad m-1 < q \leq m
   \end{cases}
   $$

2. **积分形式转换**：
   $$x(t) = I_{t_0}^q Lx(t) + I_{t_0}^q Nx(t) + I_{t_0}^q C + x(t_0^+)$$

3. **非线性项Adomian多项式展开**：
   $$Nx = \sum_{i=0}^{\infty} A_i(x_0, x_1, \cdots, x_i)$$

4. **迭代求解公式**（一般5-6次求导即可满足精度要求）：
   $$x = \sum_{i=0}^{\infty} x_i = \sum_{i=0}^{\infty} I_{t_0}^q Lx_i + \sum_{i=0}^{\infty} I_{t_0}^q A_i + I_{t_0}^q g + x(t_0)$$

#### 3.1.3 系统模型构建

**三维多翼分数阶混沌系统方程**：

$$
\begin{cases}
T_{t_0}^q x_1(t) = bx_2 + ax_1 - x_1x_3 \\
T_{t_0}^q x_2(t) = -x_2 - cx_1 + x_2x_3 \\
T_{t_0}^q x_3(t) = -x_3 - dx_2 + x_1x_2
\end{cases}
$$

其中 $q$ 表示系统阶数，参数 $a, b, c, d$ 为控制参数。

#### 3.1.4 稳定性与耗散分析

**耗散度计算**：
$$\nabla V = \frac{\partial \dot{x}}{\partial x} + \frac{\partial \dot{y}}{\partial y} + \frac{\partial \dot{z}}{\partial z} = a - c - d$$

当 $a - c - d < 0$ 时，系统是耗散的。

**分数阶稳定性判据**（定理1）：
设 $\lambda_i (i=1,...,n)$ 为非线性系统的所有特征值，若每个特征值满足：
$$|\arg(\lambda_i)| \geq \frac{\pi \alpha}{2}, \quad \alpha = \max(q_i, i=1,2,3,\cdots)$$

则该平衡点可确定为稳定平衡点。当 $q=0.9$ 时，系统稳定范围为 $|\arg(\lambda_i)| > 81°$。

### 3.2 主要创新点

| 创新点 | 说明 |
|--------|------|
| **1. CFD在多翼混沌系统的首次应用** | 将Conformable分数阶导数引入多翼混沌系统，拓展了CFD在非线性系统动力学研究中的应用 |
| **2. 发现六类多翼混沌吸引子** | 当 $q=0.9$ 时，系统至少存在六种不同形状的多翼混沌吸引子，参数 $d$ 可调节获得多翼混沌吸引子 |
| **3. 揭示镜像对称多稳定性** | 发现系统展现镜像对称、混沌气泡等多稳定现象，包括周期-周期、周期-混沌、混沌-混沌共存 |
| **4. 状态转移现象分析** | 观察到吸引子大小、形状和位置随时间变化的状态转移现象，通过LEs和分岔模型验证 |
| **5. 完整的硬件实现** | 在Multisim仿真软件中构建分数阶单元电路，并在DSP平台(TMS320F28335)上成功实现 |

### 4.2 多稳定性分析结果

#### 4.2.1 参数 $a$ 变化时的共存吸引子

- **参数范围**：$b=1, c=12, d=1.5, q=0.9$，$a \in (3.3, 10)$
- **初始值**：(1,1,1) 和 (5,5,5) 产生非对称共存吸引子
- **发现现象**：
  - 前向倍周期分岔进入混沌态后，经历边界危机和反向倍周期分岔回到周期态
  - 不同初始值影响混沌系统进入混沌态的时机
  - 最大LEs可达1.5，显著大于另一初始值的LEs

#### 4.2.2 参数 $b$ 变化时的镜像对称多稳定性

- **参数范围**：$a=7, c=12, d=4.5$，$b \in [0, 5]$
- **发现现象**：
  - 0.9阶混沌系统呈现镜像对称与乘性周期分岔
  - 仅发现单翼和双翼情况下的多稳定性现象
  - 主要共存现象为 Chaos-Period-2
  - 0-1测试验证：周期吸引子在p-s平面规则有界，混沌吸引子呈现不规则布朗运动

#### 4.2.3 状态转移现象

**实验设置**：$a=6, b=1, c=20, d=2.8, q=0.9$，初始值 $x_0=[-2,-2,5]$

**观察结果**：
- 时间 $t < 81s$ 时，序列 $z > 0$
- $t > 81s$ 时，$z$ 变为负值
- x-z平面吸引子相图包含转移前后的两个混沌吸引子
- 最大LEs从2.5逐渐下降至1，在 $t=81s$ 左右开始稳定

### 4.3 电路实现

#### 4.3.1 模拟电路实现 (Multisim)

**电路设计要点**：
- 对状态变量进行尺度压缩和时间转换
- 使用运算放大器、乘法器和积分模块
- 选择 $q=0.95$ 成功构建分数阶单元电路

**变换方程**：
$$\begin{cases}
\tau \frac{dv_x}{dt} = \frac{R_3}{R_5 R_{10} C} v_y + \frac{R_3}{R_1 R_4 C} v_x + \frac{R_3}{R_2 R_7 C} v_x v_z \\
\tau \frac{dv_y}{dt} = -\frac{1}{R_6 C} v_y - \frac{1}{R_7 C} v_x + \frac{1}{R_3 C} v_y v_z \\
\tau \frac{dv_z}{dt} = -\frac{1}{R_9 C} v_z - \frac{1}{R_{12} C} v_y + \frac{1}{R_8 C} v_x v_y
\end{cases}$$

其中 $\tau = RC$ 为时间常数，$v_x, v_y, v_z$ 为电路变量。

**实现结果**：

## 五、主要结论

### 5.1 核心结论

1. **系统构建成功**：基于CFD成功构建了三维分数阶多稳定混沌系统，使用ADM算法求解系统数值解

2. **多翼吸引子丰富**：当阶数 $q=0.9$ 时，系统至少存在六种类型的混沌吸引子，参数 $d$ 可调节获得多翼混沌吸引子（最多四翼）
