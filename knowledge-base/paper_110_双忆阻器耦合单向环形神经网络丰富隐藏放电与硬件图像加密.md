## 一、系统模型：DMCURNN（Section 2）

### 1. 网络结构动机

传统单向环形神经网络（图 1(a)）权重固定、拓扑简单，难以产生复杂放电动力学。本文用**两种阈值忆阻器分别替代神经元 1 和神经元 2 的自突触权重**（图 1(b)），神经元 3 注入外部正电流 I > 0，构成三维忆阻自突触单向环形神经网络（Dual Memristor-coupled Unidirectional Ring Neural Network, DMCURNN）。x, y, z 为三个神经元膜电位，u、w 为两忆阻器内部状态，tanh(u)、cos(w) 为忆导函数，k、p 为忆阻耦合强度，a、b、c 为忆阻器内部系数。

### 2. 系统方程（式 1，五维）

$$\begin{cases}
\dot{x} = -x + p\tanh(u)\tanh(x) + 2\tanh(z)\\
\dot{y} = -y - 3.5\tanh(x) + k\cos(w)\tanh(y)\\
\dot{z} = -z + 0.8\tanh(y) + 1.5\tanh(z) + I\\
\dot{u} = -a\big(u - \mathrm{sgn}(u-1) - \mathrm{sgn}(u+1) - \mathrm{sgn}(u-3) - \mathrm{sgn}(u+3)\big) + b\tanh(x)\\
\dot{w} = c\tanh(y)
\end{cases}$$

- 忆阻器 1（阈值型）：u 方程含四阈值符号函数（±1、±3），tanh(u) 作忆导，控制神经元 1 自反馈强度 p；
- 忆阻器 2（余弦型）：ẇ = c·tanh(y) 直接把神经元 2 膜电位积分进忆阻状态，cos(w) 作忆导，控制神经元 2 自反馈强度 k——**w 的 2π 周期性是后文同质多稳态"周期 2π 位置漂移"的几何来源**；
- a 控制忆阻状态 u 的内部更新特性，b、c 决定膜电位波能驱动忆阻状态的程度；I > 0 为注入神经元 3 的外部刺激电流。

### 3. 平衡分析（隐藏性证明）

联立式 (2) 五式左端为零：由第五式 tanh(y)=0 → y=0；代入第二式 → x=0；代入第一式 → u=0；代入第三式得 **I=0，与 I>0 矛盾** → 系统**无平衡点**，所有动力学行为均为隐藏（hidden）。证明干净，是"隐藏放电"全文的合法性基础。

## 二、隐藏放电动力学（Section 3）

数值平台 Matlab ode45，步长 0.01，弃 t>400 s 暂态；固定初值 (0.01, 0, 0, 0, 0)，a=1, b=1, c=0.83。

### 1. 三参数扫描（各识别 4 种隐藏放电模式）

- **k 扫描** [0,5]（p=4.48, I=0.001）：准周期 → 混沌 → 混沌危机 → 多周期分岔 + 周期窗 → 反复混沌危机 → 周期。代表模式：k=0.5 准周期峰放电、k=1.1 混沌簇发放电、k=2.15 混沌随机放电、k=5 周期 1 峰放电（图 2）。
- **p 扫描** [0,5]（k=1.5, I=0.001）：前向倍周期分岔 → 长混沌区间夹周期窗。代表模式：p=3.4 周期 2 峰放电、p=3.87 多周期放电、p=4.3 混沌簇发、p=4.88 混沌随机放电（图 3）。
- **I 扫描** [0,1]（p=4, k=5）：大部分区间为周期态，夹混沌与准周期态及周期窗；**I>0.5 后坠入长周期态**——外部电流过强反而降低混沌复杂性。代表模式：I=0.075 混沌簇发、I=0.08 混沌峰放电、I=0.434 准周期簇发、I=0.512 周期簇发（图 4）。

### 2. 模式分类的 LE 判据（值得注意的薄弱点）

论文用"LE 接近 0 的个数"分类：两个 LE≈0 为准周期、一个 LE≈0 为周期。给出的数值：I=0.434 时前三 LE = **0.008364, −0.001763, −0.770243**；I=0.512 时 = 0.000409, −0.017085, −0.922143。——**最大 LE 量级仅 10⁻³~10⁻²**，所谓"混沌"区段的正 LE 也未见显著大于零的数值表，分类证据主要靠分岔图形状与相图观感（详见"不足"）。

### 3. 放电模式转换（图 5，4 种）

固定初值 (0.01,0,0,0,0)（图 5(e)(f) 用 (0.01,0,0,4,0)）：
1. 准周期峰放电 → 准周期簇发放电 → 周期峰放电（k=4.5, I=0.001）；
2. 混沌簇发放电 → 周期簇发放电（k=1.7, I=0.03）；
3. 准周期峰放电 → 周期峰放电，**伴 u 方向位置偏移**（b=1.8, c=1.4, k=3.5）；
4. 混沌随机放电 → 周期峰放电（c=0.9, k=2.179）。

模式 3 的"相位漂移式转换"是该网络区别于普通环网切换（只变形态不变位置）的特色点。

## 四、放电幅值与频率调控（Section 5）

统一取 a=5, b=1, c=0.1, I=0.1, 初值 (0.01,0,0,0,0)：
- **k 调控**：k=5.06 处准周期簇发 → 周期峰放电分岔；k 增大 → 时间序列响应幅值增大、峰峰值减小、峰频率降低；
- **p 调控**：p∈[0,5] 全程准周期簇发；p 增大 → 幅值增大、峰峰值加宽、频率升高；**p>2 后幅值回落而频率持续升高**；
- **I 调控**：准周期 → 周期；I 增大 → 幅值维持、频率升高，终态周期峰放电。

该节价值在于把"忆阻耦合参数 = 放电幅频旋钮"的调控叙事补全（多数同类工作只报告模式切换，不量化幅频规律），为"参数→编码"的通信/加密应用叙事提供了实验素材。

## 六、FPGA 位流交织图像加密（Section 7）

### 1. 动机与方案

针砭三点：静态密钥易被已知明文攻破且无法更新；传统置乱需多轮迭代效率低；多数方案无硬件实现。方案要点：**2×3 点阵密钥 + Gray 码 + 位交织 + RAM 分区动态密钥更新**，全流水线在 FPGA 上单周期完成位级并行运算。

### 2. 加密流程（图 14，四步）

1. 灰度化并统一为 **256×256**；
2. 密钥流生成：归一化混沌放电序列，线性映射 **36 个隐藏同质共存放电模式**（h=2nπ，n=−17..18），排序取点提取 6 个模式生成 6 条混沌序列，构成 **2×3 点阵**；每条序列三通道求和：
$$S(i,j) = \left(\left|\sum_{m=1}^{3}x_{m,r}(t)\right| \times 10^{10}\right) \bmod 256, \qquad K(i,j)=\mathrm{Gray}(S(i,j))$$
Gray(b)=b⊕⌊b/2⌋ 增强相邻电平扩散；6 条密钥存 FPGA **RAM 分区动态存储**，实现实时密钥刷新；
3. 生成 256×256 图像的 Memory Initialization File，构建 16 位地址总线，**地址位分组 XOR 交叉打乱**（式 4）：
$$b'_i = b_i \oplus b_{(i+4)\bmod 16} \oplus b_{(i+9)\bmod 16},\quad i=0..15$$
HDMI 扫描同步地址更新；
4. 地址位取反操作 + 重复乱序处理 + 与混沌序列 XOR 完成最终扩散。

### 3. 安全指标（Table II–III）

- **直方图**：Baboon/Cameraman/Body 密图近似均匀（图 16–18）；
- **相邻像素相关**：密图 H/V/D 均近 0。⚠️ **Cameraman 垂直相关 0.040453** 比其他值（~10⁻³ 量级）高一个数量级，未解释；
- **NPCR/UACI**（理想 99.6094/33.4635）：Baboon 99.6094/33.4348、Cameraman 99.6078/33.4459、Body **99.5865/33.5011**——Body 的 NPCR 低于理想值 0.02 个百分点，未做临界值检验（paper_034 的 Wu 框架）；
- **信息熵**：7.9982 / 7.9981 / 7.9980；
- **抗裁剪**：中心裁剪 32×32、48×48、64×64、128×128 后解密，雪花状失真均匀分布、主信息可辨（图 19）；
- **速度**：60 Hz 同时处理并显示两幅 256×256 → 单幅 **0.0083 s**，比 [34] 0.162 s、[35] 2.1743 s、[36] 0.2195 s 快一个数量级以上，且为对比组中少数同时具备**密钥更新 + 硬件实现**者（[38] 亦有但熵更低）。

## 七、不足

1. **混沌证据薄弱**：全文无 LE 数值表，最大 LE 只给分类用的小数（10⁻³ 量级）；无 NIST SP 800-22、无 SE/C₀/排列熵复杂度、无 0-1 检验——按本库标准（paper_108 有 NIST 15 项 + 三种排列熵），"chaotic firing"的定量支撑不足，更像"复杂/准周期放电"。
2. **加密置乱层无密钥参与（结构性弱点）**：式 (4) 地址位 XOR 交叉打乱 $b'_i=b_i\oplus b_{i+4}\oplus b_{i+9}$ 是**固定的公开线性位变换**，与混沌密钥完全无关；Step 4 的"地址位取反 + 重复乱序"同理。攻击者已知算法即知整个置乱置换，**全部安全押在最后的混沌 XOR 扩散层**——选择明文攻击下置乱层形同虚设。论文无任何已知/选择明文讨论。
3. **"动态密钥更新"机制语焉不详**：2×3 点阵密钥的轮换/分区刷新规则只给了概念框图（图 14 的 dynamic key update），无更新周期、无新旧密钥切换时序、无更新前后密钥独立性分析；"36 个共存模式"如何排序取点提 6 条序列也未给可复现规则。
4. **密钥空间与密钥敏感性双缺**：无数值化密钥空间分析（初值+参数的可达组合数），无错钥解密/密钥扰动 NPCR 实验——"动态密钥"安全性无从谈起。
5. **量化规则未论证均匀性**：S=(|Σx|×10¹⁰) mod 256，三序列求和放大小数误差后取模的分布未做统计检验；Gray 码只改善相邻级联，对 mod 256 的均匀性无本质帮助。
6. **0.0083 s 口径存疑**：60 Hz 是 HDMI 显示刷新率，"单周期完成位运算"是 FPGA 的固有并行性表述而非实测吞吐；无时钟频率、无板上计时、无资源报告，速度数字不可复现（与 paper_109 的 0.0144 s 同类问题）。
7. **差分与相关指标有瑕疵未处理**：Body 的 NPCR 99.5865 低于理想值未讨论；Cameraman 垂直相关 0.040453 离群未解释；NPCR/UACI 无临界值判定、单样本差分。
8. **应用面窄**：仅灰度 256×256；抗噪攻击、抗遮挡+噪声混合攻击未测；彩图/视频仅 future work（引 [39]–[42]）。
9. 小疵：同质多稳态正文 h 扫描区间 [−17,20]，加密节却取 n∈[−17,18] 共 36 个模式，两处区间口径不一致；式 (3) 求和取绝对值位置排版含糊（|$\sum$| vs Σ|x| 有区别，按排版应为前者，但论证不充分）。

## 八、可借鉴之处

1. **"双忆阻器功能分工"建模范式**：阈值型 tanh(u) 忆阻器管吸引子位置（异质共存中的 u 方向偏移）、余弦型 cos(w) 忆阻器管周期复制（2π 位置平移）——"器件 1 管位置、器件 2 管复制"的清晰分工可作为多忆阻系统设计的叙事模板。
2. **无平衡点隐藏性证明**极简（I>0 与平衡条件矛盾一页讲完），写作干净，毕设论文可直接参考此范式。
3. **放电模式转换的"漂移式切换"**（模式 3：形态切换 + u 方向位置偏移）是区别于普通 attractor switching 的卖点，把 offset boosting 从"现象"升级为"转换机制"。
4. **幅频调控三节对齐结构**（k/p/I 各一节，分岔图 + LE + 时序图三件套）组织规整，适合作为动力学论文的章节模板。
5. **FPGA 位流加密与 HDMI 显示同步**的工程闭环（RAM 分区密钥 + 地址位交织 + 单周期位运算）思路对 IoT 实时加密有启发；地址位 XOR 交叉打乱虽然无密钥，但作为"零成本预置乱"思路配合密钥扩散并非没有价值——只是论文把它当安全层来卖。
6. Table I 的七维对比表（HF/FPN/HomoCSN/HeteroCSN/AR/FR/FPT）是多稳态类论文自我定位的好模板。

- **paper_089**（Yin 等 DNNHCMS 异质耦合多涡卷）："heterogeneous"在网络级耦合层面的对照样本——089 是双网络异质耦合，本文是单网络内异质放电共存，两文可厘清 heterogeneous multistability 的两种含义。
- **paper_097/098**（2D-CICFM 位平面扩散 / IIoT 硬件故障注入攻击）：本文的位交织硬件加密正好落在 098 定义的攻击面上（结构/状态/参数三类故障注入），写本子的安全性论证时应引 098 作为威胁模型。
- **paper_108**（Liu 等 CSF 2026 FPGA 遥感加密）：同刊同年 FPGA 加密对照组——108 有 NIST 15 项 + 资源/时序/功耗六项指标 + 弃暂态对照实验，本文全部缺失；"评测完备性"两篇可写成鲜明对照案例（也呼应用户对 NIST 重复值的 10-03 质疑：本文无 NIST，无从验证）。
- **paper_031/080**（CNN 混沌动力学/加密老谱系）：本文 HNN + 忆阻自突触是 CNN 路线在忆阻时代的延续，引言对 MP 模型→Hopfield→忆阻突触的谱系梳理可与之对接。
