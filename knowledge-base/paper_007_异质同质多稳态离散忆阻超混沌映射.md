## 二、研究背景与问题

### 2.1 研究背景

**忆阻器（Memristor）** 是蔡少棠教授于1971年提出的第四种基本电路元件，描述了磁通量与电荷之间的关系。2008年HP实验室成功制造出首个物理忆阻器后，忆阻器在神经网络、人工智能和安全通信等领域得到广泛应用。

**离散忆阻器（Discrete Memristor）** 是近年来兴起的研究热点，通过前向欧拉方法将连续忆阻器离散化得到。离散忆阻器在离散动力系统中展现出丰富的非线性特性，包括：
- 初始值增强现象（Initial-value-induced enhancement）
- 共存行为（Coexistence behaviors）
- 极端多稳态（Extreme multistability）

**多稳态（Multistability）** 是指系统在相同参数下因初始条件不同而产生两种或多种不同动力学模式的现象，可分为：
- **异质多稳态（Heterogeneous Multistability）**：不同初始条件产生不同大小和形状的吸引子
- **同质多稳态（Homogeneous Multistability）**：不同初始条件产生相同大小和形状的吸引子

**超混沌（Hyperchaos）** 是比混沌更复杂的非线性现象，连续系统至少需要四维才能产生超混沌，而离散系统仅需二维即可实现，这使得离散系统在通信安全和图像加密等应用中具有优势。

### 2.2 研究动机与问题

**现有研究的局限性：**
1. 离散忆阻器的构建方法研究有限
2. 离散忆阻器在离散动力系统中的应用仍受限制
3. 现有二维映射（如Henon映射、Lozi映射）大多不表现出超混沌行为

**本文要解决的问题：**
1. 设计新型离散忆阻器模型
2. 构建具有更高复杂度和更广泛混沌区域的三维离散忆阻超混沌映射
3. 探索异质与同质多稳态现象
4. 开发基于该映射的图像加密方案
5. 通过DSP硬件实现验证系统的物理可行性

## 三、核心方法与创新点

### 3.1 四种新型离散忆阻器模型

本文提出了四种离散忆阻器模型，通过指数函数与不同函数组合：

| 模型名称 | 简称 | 数学表达式 |
|---------|------|-----------|
| 正弦-指数型忆阻器 | SE-DM | $M(q_n) = e^{-\sin(\pi q_n)} - 1$ |
| 二次-指数型忆阻器 | QE-DM | $M(q_n) = e^{q_n^2} - 2$ |
| 绝对值-指数型忆阻器 | AE-DM | $M(q_n) = e^{|q_n|} - 2$ |
| 双曲正弦-指数型忆阻器 | HE-DM | $M(q_n) = e^{\sinh(q_n)} - 2$ |

**忆阻器指纹特征验证：**
- 施加离散电流源 $i_n = A\sin(\omega n)$，其中 $A=0.01$
- 固定初始忆阻值 $q_0 = 0$
- 在 $i_n - v_n$ 平面产生夹持磁滞回线（Pinched hysteresis loop）
- 随着频率增加，回线瓣面积减小，最终趋近于直线，符合广义忆阻器定义

### 3.2 SEDMM三维离散忆阻超混沌映射

通过对比分析，选择**SE-DM（正弦-指数型忆阻器）**与二维正弦映射耦合，构建三维离散忆阻超混沌映射（SEDMM）：

$$
\begin{cases}
x_{n+1} = x_n + a\sin(y_n) - kM(z_n)x_n \\
y_{n+1} = bx_n + c \\
z_{n+1} = z_n + dx_n
\end{cases}
$$

其中：
- $M(z_n) = e^{-\sin(\pi z_n)} - 1$ 为忆阻器函数
- $a, b, c$ 为控制参数
- $k$ 为耦合强度
- $d$ 为忆阻器步长
- $(x_n, y_n, z_n)$ 为第n次迭代的状态值

**参数选择依据：**
- SE-DM、HE-DM、HT-DM耦合时，$k < 0$ 时有界行为
- QE-DM、AE-DM耦合时，需要 $k < -2$ 才有界行为
- SE-DM耦合的二维正弦映射复杂度最高，混沌区域最广

### 3.3 核心创新点

1. **四种新型离散忆阻器模型**：首次提出指数函数与正弦、二次、绝对值、双曲正弦函数组合的离散忆阻器

2. **异质与同质多稳态共存**：
   - 异质多稳态：由忆阻器初始状态$\alpha$和参数$a, b, k$共同决定固定点稳定性
   - 同质多稳态：忆阻器的周期性导致系统具有周期为2的特性，产生无穷多个共存的分岔

3. **三维超混沌映射**：SEDMM展现周期、准周期、多周期、混沌和超混沌等丰富动力学行为

4. **新型图像加密方案**：结合Cube置乱、Arnold置乱和GF(257)扩散的三层加密结构

5. **DSP硬件实现**：在TMS320F28335 DSP平台上实现超混沌吸引子的物理捕获

## 四、实验设计与结果

### 4.1 固定点分析

固定点方程：
$$
\begin{cases}
x^* = x^* + a\sin(y^*) - k(e^{-\sin(\pi z^*)} - 1)x^* \\
y^* = bx^* + c \\
z^* = z^* + dx^*
\end{cases}
$$

**固定点**：$F(0, c, \alpha)$，其中$c$为系统参数，$\alpha$为任意常数

**结论**：该系统具有**无穷多个固定点**

**Jacobian矩阵**：
$$
J = \begin{bmatrix}
1 - k(e^{-\sin(\pi\alpha)} - 1) & a\cos(c) & 0 \\
b & 0 & 0 \\
d & 0 & 1
\end{bmatrix}
$$

**特征多项式**：
$$p(\lambda) = (\lambda - 1)[\lambda^2 + \lambda(k(e^{-\sin(\pi\alpha)} - 1) - 1) - ab\cos(c)]$$

**稳定性分析**：
- 当$\cos(c) = 1$时，特征值轨迹随$B = k(e^{-\sin(\pi\alpha)} - 1) - 1$变化
- 当$B \in [0, 0.37]$时，固定点稳定
- 当$B \in [0.38, 1]$时，固定点不稳定

### 4.2 参数依赖的动力学行为

#### 4.2.1 参数$a$的动力学行为

**参数设置**：$b=2.44, c=1, d=-0.13, k=-0.3$，初始值$(0.01, 0.01, 0.01)$

**动力学演化**：
| 参数范围 | 动力学状态 |
|---------|-----------|
| $a = 0.0225$ | 准周期态 |
| $a = 0.075$ | 多周期态 |
| $a \in [0.124, 0.1335]$ | 混沌态（1个正Lyapunov指数） |
| $a = 0.161$ | 超混沌态（2个正Lyapunov指数） |
| $a \in [0.161, 0.7]$ | 超混沌为主，存在窄周期窗口 |

#### 4.2.2 参数$b$的动力学行为

**参数设置**：$a=0.55, c=1, d=-0.1, k=-0.3$

**动力学演化**：
| 参数范围 | 动力学状态 |
|---------|-----------|
| $b \in [2.1144, 2.1218]$ | 准周期态 |
| $b \in [2.1218, 2.1236]$ | 周期态 |
| $b \in [2.1236, 2.125]$ | 混沌态 |
| $b = 2.1252$ | 超混沌态 |
| $b > 2.1252$ | 超混沌为主，存在窄周期窗口 |

#### 4.2.3 参数$k$的动力学行为

**参数设置**：$a=0.44, b=2.67, c=1.2, d=-0.1$

**超混沌区域**：
- $k \in [-0.4495, -0.3605] \cup [-0.346, -0.3395] \cup [-0.338, -0.2805] \cup [-0.2785, -0.276] \cup [-0.267, -0.22]$

### 4.3 二维分岔分析

固定$c=1, d=-0.1$，$a \in [0, 0.7]$，$b \in [2.1, 2.35]$，迭代步长$10^{-3}$

**不同$k$值下的动力学分布**：
- $k = -0.2$：超混沌区域主要集中在$a > 0.6$
- $k = -0.3$：系统表现出极大的超混沌区域
- $k = -0.4$：超混沌和混沌几乎占据整个区域
- $k = -0.5$：混沌复杂度降低，超混沌区域主要集中在$a > 0.5, b > 2.25$

### 4.4 异质多稳态分析

**定义**：不同初始条件产生不同大小和形状的吸引子

**实验验证**：
1. 固定$c=1, d=-0.1, k=-0.3$，初始值$(0.01, 0.01, 0.01)$ vs $(-3, -2.3, -0.01)$
2. 在$x_0 - y_0$平面绘制吸引域
3. 不同颜色代表不同动力学行为：红色（超混沌）、黄色（混沌）、绿色（准周期）、蓝色（周期）

**共存吸引子类型**：
- 超混沌-超混沌共存
- 超混沌-混沌共存
- 混沌-准周期共存
- 混沌-周期共存

### 4.5 同质多稳态分析

**定义**：不同初始条件产生相同大小和形状的吸引子

**数学机理**：
将式(4)第三项重写为求和形式：
$$z_n = z_0 + d\sum_{i=0}^{n-1}x_i$$

第一项可重写为：
$$x_{n+1} = x_n + a\sin(y_n) - k\left(e^{-\sin(\pi(z_0 + d\sum_{i=0}^{n-1}x_i))} - 1\right)x_n$$

**周期特性**：
$$x_{n+1} = x_n + a\sin(y_n) - k\left(e^{-\sin(\pi(z_0 + 2m + d\sum_{i=0}^{n-1}x_i))} - 1\right)x_n$$

其中$m$为任意整数。SEDMM表现出**周期为2**的特性，其动力学随忆阻器初始值$z_0$周期性变化。

**实验结果**：
- 固定$b=2.91, c=0.2, d=1, k=-0.5$
- 初始值$x_0=0.1, y_0=1, z_0=-1.5+2m$（$m=\pm2, \pm1, 0$）
- 观察到**无穷多个共存同质超混沌吸引子**，沿$z_0$轴偏移2个单位

### 4.6 图像加密方案

#### 4.6.1 加密流程

**三层加密结构**：
1. **Cube置乱**：将彩色图像重构为三维立方体进行置乱
2. **Arnold置乱**：对每个层面进行Arnold变换
3. **GF(257)扩散**：前向扩散和反向扩散

**密钥生成**：
```
key = [x₀, y₀, z₀, P_row, P_col, P_channel, P_edge]
```

其中初始值由明文图像计算：
- $x_0 = \sin(1 + (P_{sum} - 1) \times rand(1)) + rand(1)$
- $y_0 = \sin(-1 + (P_{edge} - 1) \times rand(1)) + rand(1)$
- $z_0 = \sin(1 + (P_{channel} - 1) \times rand(1)) + rand(1)$

#### 4.6.2 安全性分析结果

| 安全指标 | 结果 | 理论值 |
|---------|------|--------|
| 密钥空间 | $2^{220}$ | $> 2^{100}$ |
| NPCR | 99.6093% | 99.6094% |
| UACI | 33.4636% | 33.4635% |
| 信息熵 | 7.9973 | 8 |

**相邻像素相关性**：
- 明文：水平0.9904，垂直0.9786，对角0.9649
- 密文：水平-0.0294，垂直0.0087，对角-0.0066

**NIST随机性测试**：15项子测试全部通过（P-value > 0.01，通过率 > 0.98）

**鲁棒性测试**：
- 裁剪攻击：12.5%、25%、33%裁剪后仍可识别
- 噪声攻击：对椒盐噪声、高斯噪声、泊松噪声、斑点噪声具有强抵抗力

### 4.7 DSP硬件实现

**硬件平台**：
- TMS320F28335 DSP芯片
- 16位双通道DAC（DAC8552）
- XDS100V2 USB仿真器
- Siglent SDS1202X-C示波器

**实现步骤**：
1. 设置控制参数：$(a, b, c, d, k) = (-0.5381, 2.91, 0.2, 1, -0.5)$
2. 初始化值：$(x_0, y_0, z_0) = (0.1, 1, -1.5)$
3. MATLAB仿真验证混沌特性和数值迭代稳定性
4. Code Composer Studio (CCS)编写C程序
5. 编译代码烧录到DSP芯片
6. DAC输出混沌信号，示波器观察

**实验结果**：示波器显示的信号与MATLAB数值仿真结果完全一致，验证了SEDMM系统的物理可行性。

## 五、主要结论

### 5.1 理论贡献

1. **离散忆阻器模型创新**：提出了四种新型离散忆阻器模型，丰富了离散忆阻器的数学表达形式

2. **多稳态现象揭示**：
   - 首次在同一离散忆阻超混沌映射中同时观察到异质多稳态和同质多稳态
   - 异质多稳态源于固定点稳定性对忆阻器初始状态和系统参数的依赖
   - 同质多稳态源于忆阻器的周期性特性，可产生无穷多个共存吸引子

3. **高复杂度超混沌映射**：SEDMM具有比现有二维映射更高的复杂度和更广泛的混沌区域

### 5.2 应用贡献

1. **图像加密方案**：提出的三层加密结构（Cube+Arnold+GF257）在安全性和效率方面优于现有算法

2. **硬件实现验证**：通过DSP平台成功捕获超混沌吸引子，证明了系统的物理可实现性

### 5.3 研究局限与未来方向

**局限性**：
- 仅针对特定参数范围进行了详细分析
- 图像加密方案的安全性分析主要基于统计测试

**未来方向**：
- 离散忆阻器模型在安全通信中的应用
- 探索更多类型的多稳态现象
- 将SEDMM应用于其他混沌工程领域

## 六、批判性评价

### 6.1 论文优点

1. **系统性研究**：从忆阻器模型设计、动力学分析、图像加密应用到硬件实现，形成了完整的研究链条

2. **创新性突出**：
   - 四种新型离散忆阻器模型的提出具有原创性
   - 异质与同质多稳态的共存现象首次在同一系统中观察到
   - 无穷多个共存同质吸引子的发现具有重要的理论价值

3. **实验充分**：
   - 详细的参数扫描和分岔分析
   - 全面的图像加密安全性测试（密钥空间、NPCR、UACI、信息熵、NIST等）
   - 成功的DSP硬件实现验证

4. **工程应用价值**：提出的图像加密方案在多项安全指标上优于现有算法，具有实际应用潜力

### 6.2 论文不足

1. **理论深度**：
   - 对异质多稳态和同质多稳态的数学机理分析可以更深入
   - 缺乏对系统遍历性和混合性的严格数学证明

2. **对比分析**：
   - 与现有离散忆阻器超混沌映射的对比可以更加全面
   - 图像加密方案与更多最新算法的对比有待补充

3. **参数选择**：
   - 忆阻器模型选择（SE-DM）主要基于经验对比，缺乏理论指导
   - 最优参数范围的确定方法未详细说明

4. **硬件实现**：
   - DSP实现仅展示了吸引子相图，未展示图像加密的实时处理
   - 功耗和实时性能分析缺失

### 6.3 改进建议

1. 引入更严格的数学分析工具（如拓扑熵、测度论方法）研究系统的遍历性
2. 开展更广泛的算法对比实验，包括最新的深度学习辅助加密方法
3. 探索忆阻器模型参数的自适应优化方法
4. 在FPGA平台上实现图像加密的实时处理并评估性能
