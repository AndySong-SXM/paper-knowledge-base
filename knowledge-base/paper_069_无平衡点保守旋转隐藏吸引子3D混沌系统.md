## 二、研究背景与问题

### 2.1 研究动机

混沌系统的动力学行为与其平衡点特性密切相关。根据平衡点类型，混沌系统可分为三类：(1) 有平衡点系统（有限个或无穷多个）；(2) 无平衡点系统（non-equilibrium）。无平衡点系统因不存在平衡点对轨迹的约束，能够在相空间中自由演化，微小的初始条件变化即可导致难以预测的动力学行为，因此具有独特的研究价值。

### 2.2 现有研究基础

已有大量关于无平衡点混沌系统的研究，包括：
- Wei (2011): 无平衡点扰动Sprott-D系统
- Wei et al. (2014): 无平衡点隐藏超混沌吸引子
- Li et al. (2012): 无平衡点分数阶混沌系统

尽管这些系统都无平衡点，但其吸引子形态和底层动力学各不相同。三维混沌系统是产生隐藏吸引子的最简系统。

### 2.3 核心问题

1. 如何通过改造Sprott-B系统构造一个具有更丰富动力学行为的新型无平衡点混沌系统？
2. 无平衡点保守系统产生的隐藏动力学行为如何刻画？
3. 能否通过旋转矩阵操作，在原始系统基础上生成旋转隐藏吸引子？

## 三、核心方法与创新点

### 3.1 新系统方程构造

基于Sprott-B系统改造，引入 $e^{-z^2}$ 指数项增强非线性，提出三维微分方程：

$$\begin{cases}
\dot{x} = ay \\
\dot{y} = -x - byz \\
\dot{z} = -x^2 + cy^2 - e^{-z^2}
\end{cases}$$

其中 $a, b, c$ 为三个控制参数。

**关键创新**：指数项 $e^{-z^2}$ 的引入使得系统缺乏平衡点解，同时增强了系统的非线性复杂度。

### 3.2 无平衡点证明

令所有左侧导数为零：

$$\begin{cases}
0 = ay \\
0 = -x - byz \\
0 = -x^2 + cy^2 - e^{-z^2}
\end{cases}$$

由第一式得 $y=0$，代入第二式得 $x=0$，代入第三式得 $0 = -e^{-z^2}$，无解。因此**系统无任何平衡点**。

### 3.3 永恒点（Eternal Point）计算

对于无平衡点系统，加速度为零的点（永恒点）可能与其隐藏动力学行为相关。通过构造特殊Jacobian矩阵 $G$ 求解永恒点集：

$$P = (E_G - E_G \cap E_P)$$

得到永恒点集为 $P = (0, 0, c)$，其中 $c$ 为任意值。

### 3.4 保守性验证

通过计算Lyapunov指数验证系统保守性。典型参数下：
- $a=0.25, b=4, c=5$: $LE_1=0.0141, LE_2=0.0041, LE_3=-0.0176$，$\sum LE \approx 0.0006$
- $a=0.25, b=4, c=4.2$: $LE_1=0.0254, LE_2=-0.0007, LE_3=-0.0247$，$\sum LE \approx 0.0000$

所有测试参数下三个Lyapunov指数之和无限趋近于0，证明系统为**保守系统**。保守系统产生的吸引子本质上是隐藏吸引子。

### 3.5 旋转矩阵方法（核心创新）

本文最大的创新点：利用旋转矩阵对原始系统方程进行变换，生成旋转隐藏吸引子。

**旋转矩阵定义**（绕z轴）：

$$R = \begin{bmatrix} \cos\beta & -\sin\beta & 0 \\ \sin\beta & \cos\beta & 0 \\ 0 & 0 & 1 \end{bmatrix}$$

**变换因子**：
$$T_1 = x'\cos\beta + y'\sin\beta, \quad T_2 = -x'\sin\beta + y'\cos\beta$$

**旋转后系统方程**（x-y方向）：

$$\begin{cases}
\dot{x} = a\cos\beta T_2 - \sin\beta(-T_1 - bzT_2) \\
\dot{y} = a\sin\beta T_2 + \cos\beta(-T_1 - bzT_2) \\
\dot{z} = -T_1^2 + cT_2^2 - e^{-z^2}
\end{cases}$$

通过调节旋转角 $\beta$（取值：$0$, $\pi/3$, $2\pi/3$, $\pi/4$, $\pi/2$, $3\pi/4$），在三个方向（x-y、x-z、y-z）上生成不同颜色的旋转隐藏吸引子。

### 3.6 四种动力学分析工具

| 工具 | 功能 | 输出特征 |
|------|------|---------|
| 二维最大Lyapunov指数 | 衡量系统敏感度 | 深蓝→浅蓝→橙色：敏感度递增 |
| 二维动力学图 | 展示运动状态分布 | 黄色=混沌，蓝色=周期 |
| 谱熵 (SE) 算法 | 量化频谱复杂度 | 黄色→红→棕：熵值递增 |
| C₀ 复杂度算法 | 量化混沌程度 | 白→黄→红→棕黑：复杂度递增 |

四种工具在同一参数区间内呈现一致的演化规律，验证了分析结果的可靠性。

## 四、实验设计与结果

### 4.1 Lyapunov指数谱分析

固定参数 $b=4, c=5$，$a \in [0.1, 0.9]$ 绘制Lyapunov指数谱。曲线显示 $LE_1$（顶部）和 $LE_3$（底部）几乎关于 $LE_2$（中间）对称，三个指数之和无限趋近于0。

### 4.2 0-1测试

通过 $P(m)=\sum_{j=1}^m a(j)\cos(i)$ 和 $S(m)=\sum_{j=1}^m a(j)\sin(i)$ 绘制P-S图：
- 密集散点分布 → 系统具有高复杂度和随机性（混沌）
- 规则大圆 → 系统具有自相似性和均匀结构（周期/准周期）

在大部分参数区间（$a=0.2, b=4, c=5$等）中，P-S图呈现密集散点，表明系统处于混沌态。

### 4.3 周期通向混沌的演化路径

固定 $a=0.2$，初始值 $(0.1, 0.1, 0.1)$，改变 $b$ 和 $c$：

| 参数 | 状态 |
|------|------|
| $b=0.77, c=0.87$ | 周期-1 |
| $b=0.85, c=0.94$ | 周期-2 |
| $b=1, c=1.47$ | 周期-1 |
| $b=1.29, c=2.03$ | 周期-1 |
| $b=1.46, c=2.16$ | 混沌 |
| $b=2.77, c=2.92$ | 混沌 |
| $b=3.21, c=3.94$ | 混沌 |
| $b=3.45, c=4.55$ | 混沌 |
| $b=4, c=5$ | 混沌 |

系统展现出从周期态到混沌态的完整演化路径，且存在多个周期窗口和混沌窗口交替出现的现象。

### 4.4 旋转隐藏吸引子

**x-z方向旋转**（角度：$0, \pi/3, 2\pi/3$ 和 $0, \pi/4, \pi/2, 3\pi/4$）：
- 红色($0$)、粉色($\pi/3, \pi/4$)、绿色($2\pi/3, \pi/2$)、黑色($3\pi/4$)
- 旋转后方程无解，LE之和仍≈0

**x-y方向旋转**（同上角度设置）：
- 与x-z方向计算过程一致
- 无永恒点存在

**y-z方向旋转**（角度：$0, \pi/3, 2\pi/3$）：
- 变换因子：$T_2 = y'\cos\beta + z'\sin\beta$, $T_3 = -y'\sin\beta + z'\cos\beta$
- 系统方程相应调整

旋转Lyapunov指数验证（表2，轮换 $\pi/4$ 为例）：
- $a=0.114, b=4, c=5$: $LE_{1,2,3} = (0.0108, -0.0017, -0.0089)$, $\sum = 0.0002$
- $a=0.416, b=4, c=5$: $LE_{1,2,3} = (0.0476, -0.0094, -0.0380)$, $\sum = 0.0002$

所有旋转后系统仍保持保守性。

### 4.5 DSP硬件实现

- **DSP芯片**: TMS320F28335
- **仿真器**: XDS100v3
- **D/A转换**: DAC8552
- **求解方法**: Runge-Kutta迭代法
- **参数设置**: $a=0.2, b=4, c=5$，初始值 $(0.1, 0.1, 0.1)$
- **输出**: 通过示波器显示隐藏吸引子

成功验证了系统在工业应用中的可行性。

## 五、主要结论

1. **新型系统构造成功**：基于Sprott-B系统，引入 $e^{-z^2}$ 指数项构造了一个新型三维混沌系统，该系统无任何平衡点，属于保守系统（$\sum LE \approx 0$）。

2. **隐藏动力学行为丰富**：通过0-1测试、二维Lyapunov指数、二维动力学图、谱熵和C₀复杂度四种分析工具，全面刻画了系统的隐藏动力学行为，四种工具结果一致。

3. **旋转隐藏吸引子创新**：首次利用旋转矩阵变换原始系统方程，在x-y、x-z、y-z三个方向上成功生成不同旋转角度的隐藏吸引子，旋转后系统仍保持保守性和无平衡点特性。

4. **硬件验证可行性**：通过TMS320F28335 DSP平台实现了系统的物理验证，展示了其在工业应用中的潜力。

5. **未来方向**：参数区间需进一步优化和扩展；系统是否存在无限共存现象有待探索；实际应用场景有待开发。

### 8.3 变换因子

$$\begin{cases}
