## 🎯 研究动机与创新点

智慧医疗+云存储场景下，医疗机构需同时处理 1D 文本病历、2D 医学影像（CT/X 光/超声）与 3D 器官模型，现有混沌加密方案存在三个断层：**数据类型割裂**（2D 图像加密与 3D 模型加密各自为政）、**单密钥机制**（无法支撑多机构协同）、**混沌源单一**（单吸引子/有限稳态限制密钥空间与序列复杂度）。本文贡献：

1. **一类具有同构极端多稳态（isomorphic/homogeneous extreme multistability）的 MHNN**：不同初值下产生大规模共存混沌吸引子，且吸引子的**空间位置、涡卷数、幅值三个维度可独立调控**——位置由忆阻初值 φ₁(0)/φ₂(0) 控制，涡卷数由多分段忆阻函数 F(φ) 的段数控制，幅值由忆阻参数 d₁ 反向控制。
2. **多类型医疗多媒体数据统一加密算法 MICEA**：1D 文本（ASCII 编码）/2D 图像/3D 模型（顶点+面片矩阵定点量化拆分）统一转为 2D 矩阵并融合为 3D 加密立方体，配 3D 多维动态置乱（6 种模式混沌选择）+ 跨维耦合快速扩散。
3. **基于多稳态的双层密钥系统**：主密钥 SMK（突触权矩阵，决定共存吸引子集合的宏观结构）+ 吸引子选择密钥 ASK（幅值+初值，选定具体吸引子），支持多方协同标注——各医生用私有 ASK 二次加密自己的诊断标注并 LSB 嵌入载体区，实现细粒度隐私隔离。
4. **DSP 低资源硬件验证**（TMS320F28335）：程序 4.07 kB / 数据 3.74 kB / Flash 占用 8.048%，验证嵌入式可行性。

## 🔧 核心方法

### MHNN 系统方程（式1–3）

一般形式（式1）：

```
C_i·ẋ_i = −x_i/R_i + Σ_j w_ij·tanh(x_j)·(a_i + b_i·F(φ_i)) + I_i + k·x_i·F(φ_i)
φ̇_i = c_i·x_i − d_i·F(φ_i)
```

忆阻器非线性 F(φ) 取两种多分段 sign 函数（式2，B_i 默认 0.5，M 为段数控制整数）：

- f₁(φ) = φ − ½Σ(B_{i−1}+B_i)[sgn(φ−p_i)+sgn(φ+p_i)]，p_i = 2ΣB_j − B₀（不含原点折叠）
- f₂(φ) = φ − ½Σ(B_{i−1}+B_i)(sgn(φ−s_i)+sgn(φ+s_i)) − B₀·sgn(φ)，s_i = 2ΣB_j（含原点折叠）

忆阻指纹验证（Fig.1）：V = A·sin(2πft)，A=2/5/8 V 时侧叶面积随幅值增大；f=1/5/10 Hz 时侧叶面积随频率减小——紧磁滞回线特性成立。

**4 神经元 6D 实例（式3）**：两个忆阻器分别耦合神经元 3 的突触权重（a+bF(φ₁)）与神经元 1 的电磁辐射项（−k·x₁F(φ₂)），F(φ₁)=φ₁、F(φ₂)=φ₂。三种突触权矩阵 W¹₄₄/W²₄₄/W³₄₄ 定义 MHNN1（双涡卷）/MHNN2（单涡卷）/MHNN3（混合形态），Table II 给出 9 组 IC 的完整 LE 谱——LE1 全部为正（0.07–0.19，如 IC1: (0.18, 0, −0.87, −2, −3.13, −4.98)），且 c₁∈[1,5] 内 LE1 恒正（Fig.2j–l），宽参数范围鲁棒混沌。

### 同构极端多稳态的三维独立调控（II-B 节）

- **位置可控 + M×M 网格共存**：初值 (0.5,0.5,0.5,0.5,φ₁(0),φ₂(0))，F(φ)=f₁(φ)；φ₂(0)∈{−4,…,4} 取 9 值 → 9 个平移共存吸引子，φ₁(0)/φ₂(0) 联合变化 → **9×9=81 个共存稳态**，改造 f₁ 段数可扩展为任意 M×M 网格（Fig.3–4 吸引盆验证）。关键论断：极端多稳态**由忆阻器形式决定而非特定 IC/权矩阵**——权矩阵只塑造基础吸引子拓扑，三个 MHNN 均继承该多稳态。
- **涡卷数可控**：c₁=2, d₁=5, c₂=5, d₂=5 下三种 F(φ)（如 φ−sgn(φ±1)−sgn(φ±3)）分别产生 **5/6/9 双涡卷**吸引子；对 φ₁(0) 的分岔图呈**阶梯结构**——每个"台阶"对应一个稳定吸引子（Fig.5）。
- **幅值可控**：d₁ 为专用幅值缩放控制器（d₁ 增大→幅值减小），对双涡卷与 5 双涡卷均成立，且不改变全局拓扑与动力学性质（Fig.6）。

### NIST 与 DSP 实现（II-C 节）

- NIST SP 800-22 十五项测试：10⁶ bit 二值序列 × 4 个吸引子（Fig.2b/2e/2h/5c），全部 P-value > 0.01（Fig.7）。
- DSP 平台：TMS320F28335（硬件浮点单元）+ DAC8552 + CCS 开发环境；示波器相图与 MATLAB 一致；**连续运行 15 分钟无发散、10 次断电重启轨迹完全一致**。资源占用（Table III）：程序 4.07 kB、数据 3.74 kB、Flash 利用率 8.048%、150 MHz 下吞吐 755.19 iter/s。

### MICEA 多类型信息立方体加密算法（III 节）

**统一编码**：
- 1D 文本 → ASCII → 平面填充成 2D 矩阵；
- 3D 模型顶点矩阵 V → 保留两位小数定点量化：v1 = 100×[roundn(V,−2) − min(roundn(V,−2))]（式4）→ 256 进制拆分 v1 = M₁·256² + M₂·256¹ + M₃·256⁰（式5）得 V1,V2,V3 三张"图像"；面片矩阵同法得 C1,C2,C3。量化后 3D 模型视觉无损（Fig.10）。
- 所有 2D 矩阵按逻辑顺序拼接填充为 **3D 加密立方体 E1**；补齐零区定义为"功能冗余区"，兼作加密干扰分量与诊断标注元数据载体。

**置乱**：混沌序列 S1∼S4 按式6 量化（mod(⌊|S|×10¹⁰⌋,·)+1）；S1/S2/S3 重构为 6×H、6×W、6×L 矩阵，S4 映射为 R = mod(S4,6)+1 **动态选择 6 种空间置换模式**（Algorithm 1：相邻差分 ax/ay/az → 取整取模得偏移 bx/by/bz → R 决定 x/y/z 三轴全偏移或半偏移组合 → 模运算环绕换位 E1(x,y,z)↔E1(i,j,k)）。

**扩散（式7，跨维耦合快速扩散）**：每体素与三个正交方向的前一已扩散体素级联 XOR，再与混沌掩码 S5 二次 XOR：

```
Px = M(max(i−1,1),j,k);  Py = M(i,max(j−1,1),k);  Pz = M(i,j,max(k−1,1))
E2(i,j,k) = E1(i,j,k) ⊕ Px ⊕ Py ⊕ Pz;   E2(i,j,k) = E2(i,j,k) ⊕ S5(i,j,k)
```

**双层密钥与协同标注**：
- **SMK（系统主密钥）**= MHNN 权系数集合 → 定义共存吸引子的宏观态空间，持 SMK 可解密立方体全局数据；
- **ASK（吸引子选择密钥）**= 幅值调控参数 + 精确初值 → 导向唯一吸引子，各医生 D_i 持独立 ASK_i；
- 协同流程：D₁ 用 SMK 解密 → 生成诊断文本 T₁ → 用 ASK₁ 生成混沌序列加密 T₁ 转比特流 → 按混沌置乱索引 **LSB 嵌入空白载体 J 的指定区域**（三重重复码纠错）→ 再用 SMK 重加密上传云端同步。持 SMK 的内部人员无法解密他人 ASK 加密的标注 → 逻辑隔离。

## 📊 实验与性能分析

### 测试数据与无损性

F1∼F8 混合数据集：F1 1024×1024、F2 256×256、F3 1024×1024、F4 128×128、F5 600×600×3、F6 1000×1000×3、F7 顶点 217600×3（3D 模型）、F8 顶点 20000×3。2D 图像解密 MSE=0 / PSNR=∞（严格无损）；3D 模型量化简化引入 MSE=8×10⁻⁶ / PSNR=90.83 dB，但简化模型加解密严格无损（MSE=0）。

### 密钥空间与敏感性

密钥变量 = 6 初值 + 7 忆阻参数（a,b,c₁,c₂,d₁,d₂,k）+ 15 权参数，精度 10⁻¹² → 密钥空间 (10¹²)²⁸ = **10³³⁶ ≈ 2¹¹¹⁶ ≫ 2¹²⁸**。Fig.13：d₁ 或 φ₁(0) 扰动 10⁻¹² 即解密完全失败。

### 抗攻击测试

- **选择明文攻击**：20 张全白 + 20 张全黑 512×512 图像同密钥加密，密文呈类噪声、直方图近似均匀，平均 IE = **7.9993**；
- **裁剪攻击**：20 张图像加密立方体切除 1/8 体积（置零），解密后医学信息仍可辨识——归因于像素特征被均匀铺展到整个加密空间；
- **差分攻击**：见 Table IV（NPCR/UACI）；
- **文本恢复（BER）**：300×300 载体、5 个协作方、400 字符、10 次平均；低篡改强度下经三重重复码纠错后 **BER_A 恒为 0**，攻击增强后纠错能力渐降但仍显著低于未纠错曲线（Fig.18）。

## ⚠️ 不足与可借鉴之处

**不足**：
1. **正文与 Table VII 数据自相矛盾**：正文宣称 "AET 0.0383 s + 吞吐 52.448 Mbps"，Table VII 却为 0.1563 s / 13.428 Mbps（且 52.448 Mbps 与文中任何测试配置都对不上，0.0383 s 接近 Table V 中 256×256 的 ASIES 0.0382 s）——疑似不同测试条件混写或笔误；BER 段落引用"Fig.16"实应为 Fig.18。TCSVT 正式版仍有此类编辑疏漏，引用时须以表格为准。
2. **扩散并非严格链式结构**：式7 中 S5 掩码与明文无关，也无 SHA-256 类明文绑定（对照 091 号 Kong 的明文绑定密钥调度）；"选择明文攻击"仅做黑白图视觉+直方图展示，未给出明文差分→密钥流差分的严格分析，抗选择明文的论证强度一般。
3. **3D 量化有损**：顶点坐标仅保留两位小数，对放疗剂量场、精细术导模型等高精度场景可能不足；量化精度-安全性-可逆性权衡未讨论。
4. **LSB 嵌入的隐写安全性未评估**：容量低（300×300 载体、三重重复码再压 2/3 容量）、抗隐写分析（RS/卡方）未做；协同标注的"安全性"依赖 ASK 保密而非嵌入隐蔽性。
5. **威胁模型不完整**：云端不可信假设下的共谋攻击（多医生合谋）、密钥分发/撤销机制、SMK 泄露后的前向安全性均未讨论。
6. **DSP 吞吐偏低且未做 FPGA**：755.19 iter/s 的连续系统数值积分吞吐有限（未说明求解器与步长），加密实验全部在 PC 端完成——与同门 091/092 的 FPGA 全流程上板相比是明显倒退；且正文宣称的 52.448 Mbps 与 DSP 实测吞吐之间存在数量级鸿沟，未解释。
7. **弱密钥分析缺失**：2¹¹¹⁶ 密钥空间基于 10⁻¹² 精度假设，但 c₁ 等参数存在混沌退化区间风险，未给出弱密钥/退化参数排除规则。

**可借鉴**：
1. **"统一向量化 → 3D 立方体"融合加密框架**：1D/2D/3D 异构数据统一矩阵化再立方体化，功能冗余区一鱼三吃（凑块+干扰+元数据载体）——多模态数据保护（cipherflow 类产品）可直接复用该封装思想。
2. **6 模式混沌动态置乱选择（Algorithm 1）**：用一条混沌序列 R 在 6 种偏移组合间切换，代价极低地增加置乱路径多样性，比单一方向扫描置乱的抗分析性强。
3. **跨维三向耦合扩散（式7）**：每体素 O(1)、三方向前馈+掩码，结构简单可并行，可向视频帧间（时间维）扩展成 4D 扩散。
4. **"吸引子即密钥资源"的双层密钥范式**：SMK 定集合、ASK 选个体——把极端多稳态**真正用于密钥分层与多方权限隔离**，这正是 092 号被批评"浪费了多稳态"的补全做法；写本子时"多稳态 → 多密钥 → 多方协同"是现成的逻辑链。
5. **DSP 极低资源验证路径**（4.07 kB 程序+8% Flash）+ 10 次断电重现性测试：嵌入式混沌 PRNG 论证的简洁范式，比 FPGA 方案门槛低。
6. TCSVT 加密论文实验配置模板：无损性（MSE/PSNR）→ 密钥空间/敏感性 → 直方图/相关性 → 选择明文 → 熵 → 裁剪 → 差分 → 效率（变 N）→ 2D/3D 两张对比表 + 文本 BER，8+3 结构齐全。
