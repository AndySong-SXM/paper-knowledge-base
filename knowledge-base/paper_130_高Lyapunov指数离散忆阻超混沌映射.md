## 一句话定位

在三个 2 维离散忆阻映射的电流通道上，叠加一个**显式依赖迭代步 n 的正弦振荡强制项** `A sin(nπ/16)`，把已有 2D 离散忆阻系统典型 LE 区间（作者称 0–0.5）推高到约 1–4；随后用 FPGA 复现相图（SSIM>0.9、MSE≤0.0004），并从 IEEE 754 浮点比特流抽取伪随机数通过 NIST SP800-22 15 项测试。

## 一、核心思想与创新主张（Sec. I–II）

### 1.1 设计逻辑

1. **先建三个离散忆阻器（DM）模型**：理想模型 IM1、带光滑内部状态函数的通用模型 GM1、带符号函数的非光滑通用模型 GM2；通过正弦电压激励验证三者均呈过原点捏滞回线（Fig. 1）。
2. **再给状态更新方程加强制振荡项**：`x_{n+1}=A sin(ωnπ)+W(φ_n)v_n`，固定 `ω=1/16`，A 控制扰动强度。作者主张该平滑、周期、可调的显式扰动可增强非线性相互作用并诱发超混沌（式 3）。
3. **得到三个 2D 超混沌映射**：IM1-map、GM1-map、GM2-map，分别把忆导 `cos(φ²)`、`sin(φ²)`、`sin φ` 与振荡项叠加。
4. **工程闭环**：参数扫描（LE 谱、分岔图、相图、吸引盆）→ Zynq-7020 FPGA 浮点实现 → MATLAB/FPGA 相图 SSIM/MSE → IM1-map 伪随机数 NIST 测试。

### 1.2 作者声称的贡献

- **高 LE**：IM1-map 的 LE1、LE2 在参数扫描中最高均接近 4.0；GM1-map 的 LE1 广布于 1–3、LE2 在 −0.5–1.2 间波动；均显著高于既有 2D 离散忆阻系统的 0–0.5 典型区间。
- **复杂共存形态**：随耦合参数变化出现同构/异构/对称的混沌、超混沌与周期吸引子共存，以及多脉冲放电形态。
- **FPGA 保真度**：三幅 FPGA 相图与 MATLAB 相图的 SSIM 分别为 0.9124/0.9241/0.9049，MSE 均 ≤0.0004。
- **随机性**：基于映射的 PRNG 通过 NIST SP800-22 全部 15 项（文中列表只给 IM1-map，另两个映射仅文字声称同样通过）。

## 二、系统模型 ★系统方程

### 2.1 离散忆阻器通式与三个模型（式 1–2，Table 1）

离散忆阻器通式：

$$\begin{cases} i_n=W(\varphi_n)v_n \\ \varphi_{n+1}=f(\varphi_n,v_n) \end{cases}$$

其中 `i_n` 为输入电流，`v_n` 为输出电压，`W(φ_n)` 为忆导，`f` 为内部状态函数。三个 DM：

- **IM1（理想余弦二次忆导）**：

$$\begin{cases} i_n=v_n\cos(\varphi_n^2) \\ \varphi_{n+1}=\varphi_n+v_n \end{cases}$$

- **GM1（光滑正弦二次忆导）**：

$$\begin{cases} i_n=v_n\sin(\varphi_n^2) \\ \varphi_{n+1}=-0.1\sin(\varphi_n^2)+1.0\varphi_n+0.1v_n \end{cases}$$

- **GM2（正弦忆导 + 非光滑符号状态函数）**：

$$\begin{cases} i_n=v_n\sin(\varphi_n) \\ \varphi_{n+1}=0.1[\operatorname{sgn}(\varphi_n)+\operatorname{sgn}(\varphi_n+1)+\operatorname{sgn}(\varphi_n-1)]+0.9\varphi_n+1.4v_n \end{cases}$$

三者均在 `v_n=A sin(ωn)` 激励下验证捏滞回线：回线面积随 A 增大、随 ω 增大而收缩，符合离散忆阻器典型特征。

### 2.2 振荡项与三个 2D 超混沌映射（式 3，Table 2）★

统一构造：

$$x_{n+1}=A\sin(\omega n\pi)+W(\varphi_n)x_n,\qquad \omega=\frac1{16}$$

其中 `x_n` 同时充当忆阻器输入 `v_n`。三个映射为：

- **IM1-map**：

$$\begin{cases} x_{n+1}=A_1\sin(n\pi/16)+a x_n\cos(\varphi_n^2) \\ \varphi_{n+1}=\varphi_n+x_n \end{cases}$$

- **GM1-map**：

$$\begin{cases} x_{n+1}=A_2\sin(n\pi/16)+b x_n\sin(\varphi_n^2) \\ \varphi_{n+1}=-0.1\sin(\varphi_n^2)+\varphi_n+0.1x_n \end{cases}$$

- **GM2-map**：

$$\begin{cases} x_{n+1}=A_3\sin(n\pi/16)+c x_n\sin(\varphi_n) \\ \varphi_{n+1}=0.1[\operatorname{sgn}(\varphi_n)+\operatorname{sgn}(\varphi_n+1)+\operatorname{sgn}(\varphi_n-1)]+0.9\varphi_n+1.4x_n \end{cases}$$

固定初值 `(x0,φ0)=(0.1,0.1)`；`a,b,c` 为忆阻器非线性项的耦合强度，`A1,A2,A3` 为振荡强度。后文主扫描取 `(A1,A2,A3)=(1.2,2.5,2.0)`。

**关键结构性事实**：右端显式含 `n`，所以这是**非自治周期强制 2D 映射**，周期为 32 步；它并不是常规意义下右端只含状态的 2D 自治映射。这个性质贯穿本文“平衡点/隐藏吸引子”争议的批评（见不足①）。

### 2.3 作者的平衡点推导（式 4–9）

令状态不再随迭代变化，作者分别写：

- IM1-map：`x*=1.2 sin(nπ/16)+a x* cos(φ*²)`，`φ*=φ*+x*`，得 `x*=0`，`φ*` 任意。
- GM1-map：`x*=2.5 sin(nπ/16)+b x* sin(φ*²)`，且 `x*=sin(φ*²)`；化得 `b x*²−x*+2.5 sin(nπ/16)=0`。作者仅在 `n=16z` 时给出 `x*=0` 或 `x*=1/b`，再由 `sin(φ*²)=x*` 得到无穷多离散 φ*。
- GM2-map：由第二式得到分段直线（式 8–9），再代入第一式，作者称也存在无穷多平衡点。

作者的结论是三个系统“要么无平衡点，要么有无穷多平衡点”，因此吸引子属于隐藏吸引子。

## 三、动力学分析（Sec. III）

### 3.1 参数 a 对 IM1-map 的影响（Fig. 2–3）

- `A1=1.2`、初值 `(0.1,0.1)` 下扫描 `a`：LE 谱与分岔图显示宽超混沌区，LE1、LE2 峰值均接近 **4.0**；作者强调其远超既有 2D 离散忆阻系统 0–0.5 的典型范围。
- 两初值 `(0.1,0.1)`、`(−0.1,−0.1)` 的相图/时间序列对照：`a=-1.4,-1.0,0.75` 为异质超混沌共存，`a=-0.35,0.15` 为较接近/对称的混沌共存，`a=0.12` 为混沌—周期共存。
- 作者将 `a∈[-0.5,0.5]` 内 LE2 突变解释为由吸引子与不稳定结构碰撞引发的动力学状态快速切换。

### 3.2 参数 b 对 GM1-map 的影响（Fig. 4–5）

- `A2=2.5`：`b=-1` 为异质超混沌共存；`b=-0.55` 两初值吸引子靠近；`b=0.6` 再次分离；`b=1.0` 又呈异质超混沌。
- LE1 广布约 **1–3**，LE2 在 **−0.5–1.2** 间波动；分岔图显示 `φ_max` 变化范围大，作者以此说明复杂度较高。

### 3.3 参数 c 对 GM2-map 的影响（Fig. 6–7）

- `A3=2.0`：GM2-map 在相当宽的参数范围内 LE1>0.5；`c=-1` 为同构/异构混沌，`c=-0.8` 吸引子较散乱，`c=0.95` 较紧凑，`c=1.25` 出现近圆角方形边界的异质超混沌。
- 作者指出 LE2 在 `c∈[-0.8,0.8]` 内多次突变，是振荡项与忆阻非线性在阈值处相互作用导致相空间重组。

### 3.4 吸引盆（Fig. 8）

在 `(A_i, 耦合强度)` 平面绘制吸引盆：橙色为混沌、黄色为周期、蓝色为无界。总体规律：

- 振荡幅度 `A_i` 增大可扩展混沌区；
- `|a|,|b|,|c|` 初始增大提高复杂度，但绝对值超过约 **1.5** 后出现无界行为；
- 参数窗口依据 LE 谱和分岔图选取，覆盖周期到超混沌典型状态。

**价值**：这是本文较实用的工程图，直接标出可用参数岛和无界区；但图中未给 LE 数值标注，也没有给出确定“混沌/周期/无界”的数值判据和网格分辨率。

## 四、FPGA 实现（Sec. IV）★硬件口径

- **平台与工具**：Vivado 2018.3，Verilog-HDL，Xilinx Zynq **XC7Z020-CLG400-1** 开发板。
- **数值格式**：遵循 **IEEE 754 单精度 32-bit 浮点**；`CLK/RST` 为 1-bit 控制，初值 `(x(0),φ(0))` 为 32-bit 输入，输出 `(x(n),φ(n))` 为 32-bit 并以初值反馈进入下一迭代。
- **信号链**：FPGA 离散映射 → 信号截取与正值转换 → DAC → 示波器；因示波器只显示正信号，对输出加偏移。
- **结果**：`a=-0.35,b=0.56,c=0.95`、初值 `(0.1,0.1)` 时，三幅示波器相图与 MATLAB 仿真形态一致（Fig. 10）。
- **量化指标（Table 3）**：

| 映射 | SSIM | MSE | SSIM>0.9 面积占比 |
|---|---:|---:|---:|
| IM1-map | 0.9124 | 0.0002 | 80.8% |
| GM1-map | 0.9241 | 0.0004 | 86.4% |
| GM2-map | 0.9049 | 0.0004 | 81.2% |

作者以 SSIM>0.9 为高结构相似、MSE≤0.0004 为数值偏差可忽略，论证 FPGA 正确性。

## 五、PRNG 应用（Sec. V）★随机性指标

- **结构**：以 IM1-map 迭代生成 `s1,s2,...,sn`；转为符合 IEEE 754 的 64-bit 流；抽取第 16–48 bit 中的**奇数位**形成伪随机数（Fig. 12）。即大致取第 17,19,...,47 位，共 16 bit。

## 六、实验指标汇总

- **LE**：IM1 的 LE1/LE2 峰值约 4.0；GM1 的 LE1 约 1–3、LE2 −0.5–1.2；GM2 未给具体峰值，只称相当一部分参数区 LE1>0.5。无双正 LE 工作点表、无 LE 和、无 Kaplan–Yorke 维数。
- **共存吸引子**：两初值下的同构、异构、对称混沌/超混沌，以及混沌—周期共存；无共存数量统计、无偏移提升解析关系。
- **吸引盆**：振荡幅度增大会扩展混沌区；`|耦合|≳1.5` 进入无界区。
- **FPGA**：32-bit IEEE 754 浮点；SSIM 0.9124/0.9241/0.9049，MSE 0.0002/0.0004/0.0004；SSIM>0.9 面积占比 80.8%/86.4%/81.2%。
- **NIST**：IM1-map PRNG 15/15 通过；最低 P-value_T 0.161703、最低通过率 0.981；GM1/GM2 仅文字声称。
- **未测**：NPCR、UACI、图像信息熵（本文未做图像加密）；TestU01/Diehard；自相关与谱平坦度；FPGA LUT/DSP/BRAM/FF、时钟频率、迭代时延、吞吐与功耗；有限字长对 LE 与超混沌状态的影响；密钥空间与已知/选择明文攻击；动力学周期/退化测试。

## 七、不足

1. **“平衡点/隐藏吸引子”分析对非自治系统不成立，属于全文最大理论瑕疵**：三个映射右端显式含 `n`，严格说不存在与时间无关的 `(x*,φ*)`；正确对象应是周期轨道或把 32 步相位增广为第三维后的自治 3D 映射。作者把 `n` 冻结后代入求“平衡点”，再据此宣称无穷多平衡点与隐藏吸引子，数学对象错位。即便接受冻结时间解释，GM2 的“无穷多平衡点”也未真正联立求解，隐藏吸引子还需证明吸引盆不接触平衡点邻域，文中完全没有该证明。
2. **高 LE 的可信度不足**：未说明 LE 算法（Wolf、QR/Jacobian 或直接数值估计）、迭代数、瞬态剔除、步长/重正交策略；图上“接近 4.0”没有对应参数表和数值表。吸引盆显示大范围蓝色无界区，提示高 LE 可能受近无界发散轨迹影响，作者未做有界性、能量函数或最大有限时间验证。
3. **非自治正弦强制项是公开、确定的开放输入，安全增益没有被讨论**：`A sin(nπ/16)` 完全可预测，本身不提供密钥；若作为 PRNG/通信扰动，必须说明参数 A、频率、相位及初值如何构成密钥空间，并分析敌手已知结构时的可推断性。本文直接跳到 NIST，跳过了混沌密码学的基本威胁模型。
4. **FPGA 验证停留在相图视觉层**：SSIM/MSE 是有益尝试，但没有资源利用、时钟频率、迭代延迟、吞吐、功耗，也没有说明 sin/cos/浮点单元如何实现与流水线化；32-bit 浮点误差对 LE、双正判定、NIST 输出有何影响完全未量化。`MSE≤0.0004` 的图像归一化口径也未给出。
5. **PRNG 证据链不完整**：只完整列 IM1-map；GM1/GM2 的“也通过”没有表格和测试条件。抽取 IEEE 754 第 16–48 bit 奇数位的合理性、端序、参数/初值、序列长度、样本条数、是否后处理均缺失；直接抽浮点尾数位若无后处理，理论上容易受离散网格、舍入模式和短周期影响。
6. **NIST 不能替代密码学安全评估**：没有 TestU01/Diehard、自相关、谱平坦度、近似熵随序列长度稳定性、周期检测、密钥敏感性、差分攻击、密钥空间与穷举复杂度。对一篇宣称面向 secure communications 的论文，安全论证明显不足。
7. **“复杂度更高/多脉冲放电”主要是视觉描述**：没有 SE/C0 谱熵、关联维、排列熵、0-1 测试等独立复杂度指标；多脉冲放电模式也没有统计脉冲数、间隔分布或分岔机制解释。
8. **硬件与密码应用之间缺少闭环**：LE 高的参数区、FPGA 实际所用参数、PRNG 实际参数三者未逐一对应；例如 FPGA 展示 `a=-0.35`，PRNG 用何参数、该点是否双正 LE 均未交代，构成 127/128/129 笔记反复指出的“卖点与应用脱节”。
9. **可复现性细节偏少**：图表未给参数轴完整范围、扫描步长、LE 初值/长度、吸引盆分辨率；代码与数据均声明 reasonable request；GM2 的符号函数在浮点/离散实现中的边界处理也没有说明。
10. **编校与表达问题**：正文称 LE “significantly surpassing typical ranges (0-0.5)”，但 2D 混沌映射的 LE 幅值依赖时间归一化，直接跨文献比较绝对值并不严谨；“multi-pulse discharge modes”更像神经元放电术语，本文 2D 映射中的对应对象没有定义；GM1 的 `b1` 排版易误读为 `b/1`，应明确为 `1/b`。

## 八、可借鉴之处

1. **“忆阻器模型库 × 单一扰动机制”构造法**：IM1/GM1/GM2 三个忆导与内部函数各不相同，却共用同一振荡项，形成干净的横向对照实验。写论文时可借这种“最小变量替换”结构来论证机制贡献，而不是每次只换一个参数。
2. **把 FPGA 保真度写成 SSIM/MSE 指标**比“示波器图看起来一致”更规范，适合移植到库内其他 FPGA 混沌论文；若再补资源表、频率/延迟和定点误差，就是完整硬件验证模板。
3. **吸引盆同时画混沌/周期/无界三区**很实用，尤其直接标出 `|耦合|≳1.5` 的无界边界，可指导后续加密算法选取安全参数岛；建议移植到 104/119/129 等硬件 HNN 论文的鲁棒性分析。
4. **“高 LE 需要独立证据”的反面教材**：本文证明只画 LE 谱峰值不足以建立高复杂度主张；后续设计应同时报告 LE 算法、参数表、LE 和、KY 维、熵/复杂度与有界性，形成互相印证的链条。
5. **非自治振荡增广给库内“正弦调制/初态偏移”研究提供新接口**：047 用正弦调制提高连续系统 LLE，本文用显式正弦强制提高离散 2D 映射 LE；二者可与 022 的特征值配置理论、016/071 的初态机制组成“LE 增强方法谱系”。
6. **PRNG 比特抽取方案可反向复现为风险检查清单**：从 IEEE 754 中段抽取奇数位看似比直接取最低位稳，但仍需给出端序、参数、样本量、后处理与周期证据；这份清单可用于审阅后续混沌 PRNG 论文。

## 九、与知识库已有论文的关联

- **paper_129**（Yang/Wang/Sun/Deng，网格多结构 DMHNN，IEEE TCAD 2026）：**最直接前后篇关系**。129 原文把本文列为参考文献 [11]，团队部分重合（王春华、邓权丽、杨刚）；129 走 HNN 形态目录 + PRNG，本文走高 LE 离散忆阻映射 + FPGA/PRNG。129 未给 LE 数值，本文补了“高 LE”卖点；本文理论缺陷（非自治平衡点）也更凸显 129 固定点/Jacobian 分析的价值。
- **paper_047**（Sahoo & Roy，高 LLE 多翼混沌系统，CSF 2022）：**方法类比最直接**。047 用正弦调制函数把连续 Chen/Lu 系统的 LLE 提升至 7.354/32.7；本文用正弦强制项提升离散忆阻映射 LE。差别是 047 有清晰平衡点—翼数对应但无硬件/随机性，本文有 FPGA/NIST 但 LE 计算与有界性更薄弱。
- **paper_022**（Shen/Yu/Lü/Chen，任意正 LE 数超混沌，TCAS-I 2014）：022 以闭环级联与特征值圆周分布在理论上控制正 LE 数量；本文宣称 2D 映射获得高 LE，却缺少可比较的理论机制。二者构成“理论可控 LE 数”与“经验性高 LE 图”的对照。
- **paper_104**（Bao 等，离散双忆阻 HNN 网格多面体 + FPGA PRNG，Neural Networks 2026）：同属离散忆阻 HNN/FPGA/PRNG 生态位。104 明确 36-bit/20-bit 定点、AXI-DMA、LUT/FF/DSP/BRAM 与 473 Mbps 吞吐，并承认随机性部分来自 conditioner；本文只给 32-bit 浮点与 SSIM/MSE，无资源表、无后处理归因，正好可用 104 的口径作为补全模板。
- **paper_016 / 071**：本文的多初值共存与“隐藏吸引子”主张可回到 016 的双忆阻初态增强极端多稳态和 071 的初始切换提升分岔；016 对初态周期/位置的解析更扎实，提醒本文不能只凭相图命名隐藏吸引子。
- **paper_119 / 113 / 106**（FPGA HNN 系列）：硬件平台与“数值相图—DAC—示波器复现”叙事相同；本文的 SSIM/MSE 可作为这些笔记硬件节的补充指标。
- **paper_034 / 086 / 062**：随机性与信息论基础。本文只报 NIST，未报 Shannon 熵/谱熵/近似熵，恰好显示 NIST 与信息熵评价的边界。
- **paper_126 / 128**：126 批评定点字长和量化设计，128 有硬件资源-精度表；本文 IEEE 754 浮点 + 抽浮点比特的 PRNG 方案，正好触发同类“实现精度—随机性—安全性”链条检查。
- **待读队列关联**：11-06 最新落盘的 Xiong 预驱动/后门控 HNN、Yu 医疗物联网图像加密、Suzgen 混合医学加密、Ding SRA 均尚未读；本文的“高 LE—FPGA—PRNG”口径可作为这些后续论文的评测基准。

## 十、复现与后续检查清单

- 明确把系统改写为 32 步相位增广自治映射，重新分析周期轨道，而不是沿用原冻结时间“平衡点”。
- LE 采用 QR/Jacobian 法并报告：参数、初值、迭代总数、瞬态、重正交间隔、LE1/LE2/LE 和、KY 维。
- 补充有界性验证：最大状态范围、逃逸率、能量/耗散指标，排除近无界区造成的高 LE。
- FPGA 补 LUT/FF/DSP/BRAM、最大频率、单迭代时钟数、吞吐、功耗；同时给浮点误差与 LE/LE 和变化。
- PRNG 补三组映射完整 NIST 表、序列长度与样本条数，加 TestU01、自相关、谱平坦度、周期检测与密钥敏感性。
- 若走向加密应用，再补密钥空间、密钥雪崩、NPCR/UACI、信息熵、差分/选择明文攻击与抗噪声/抗压缩测试。
